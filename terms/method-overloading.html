Method overloading

  • Method overloading: two or more methods in the same class with the same name but different parameter lists (number, type or order). Return type alone is not enough

From Java › Overloading Methods and Constructors

Method overloading: several methods in one class share a name but differ in the number, type or order of parameters. The compiler chooses the version at compile time (static polymorphism).
