Term · DLD Lab, Digital Logic

BCD

  • Excess-3: BCD + 3. \(457\to0111\ 1000\ 1010\). Self-complementing (9's complement = flip all bits)

From Digital Logic › Binary Codes

  • Some input combinations never occur (e.g. BCD codes 1010–1111) or the output doesn't matter. Marked X (or d) on the map

From Digital Logic › Don't-Care Conditions

  • BCD adder correction: if sum \(>9\) add 6. Correct when \(C=K+Z_8Z_4+Z_8Z_2\) (used in Unit III)

From Digital Logic › Code Conversion

  • Synchronous BCD (decade) counter, JK flip-flops, sequence 0–9 then 0; states 10–15 don't care:

From Digital Logic › Synchronous Counters

  • BCD → Excess-3: add 3 (0011) to each BCD digit; inputs 1010–1111 are don't-cares. With K-map simplification: \(X_3=B_3+B_2(B_1+B_0)\), \(X_2=\overline{B_2}(B_1+B_0)+B_2\overline{B_1}\,\overline{B_0}\), \(X_1=\overline{B_1\oplus B_0}\), \(X_0=\overline{B_0}\)
