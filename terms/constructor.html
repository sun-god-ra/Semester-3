Home › Terms A–Z › Constructor

Term · Java, Java Lab

Constructor

  • new dynamically allocates memory at run time from heap, calls the constructor, returns the reference (address)

From Java › Declaring Objects and Reference Variables

  • If you write none, Java supplies a default constructor (no args, sets fields to default values). Once you write any constructor, the default is not supplied

From Java › Constructors

  1. Call another constructor: this(0, 0);

From Java › The `this` Keyword

  • Constructors: StringBuffer() (cap 16), StringBuffer(int cap), StringBuffer(String s) (cap = length + 16)

From Java › StringBuffer (and StringBuilder)

  • Order of constructor calls: superclass first, then subclass (top of hierarchy to bottom), because the base must be built before the derived

From Java › Using `super`
