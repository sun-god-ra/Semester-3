UML

  • Use-case driven, architecture-centric, iterative and incremental; uses UML. Related: Rational Unified Process (RUP)

From Software Eng › The Unified Process (UP)

  1. Deployment-level design elements — how software functionality and subsystems will be allocated to the physical computing environment (UML deployment diagram)

From Software Eng › The Design Model

Deployment-level design elements show how software functionality and subsystems are allocated to the physical computing environment (nodes, servers, devices, networks). Shown as UML deployment diagrams: nodes (e.g. PC, application server, database server) connected by communication links, each with the artifacts (software) deployed on it.
