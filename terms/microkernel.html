Term · Operating Systems, Software Eng

Microkernel

  • Hybrid systems — combine multiple approaches: Linux and Solaris — monolithic (performance) + modular (dynamic); Windows — monolithic with some microkernel behaviour (subsystems); macOS and iOS — layered Aqua UI over Cocoa (frameworks) over kernel environment (Mach microkernel + BSD UNIX kernel + I/O Kit + kernel extensions (kexts)); Android — Linux kernel modified, ART virtual machine, Java API, Bionic libc, HAL, libraries (SQLite, SSL, OpenGL)

From Operating Systems › Operating-System Structure

  • Other styles: client–server, model–view–controller (MVC) (model = data, view = display, controller = handles input), microservices, event-driven, peer-to-peer, publish–subscribe, service-oriented (SOA), microkernel

From Software Eng › Architectural Styles

  1. Microkernel: only the essentials (IPC, basic scheduling, memory) in the kernel; other services run in user space. Secure and extensible but slower due to message passing (Mach, QNX).
