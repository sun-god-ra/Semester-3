Cyclomatic complexity

  • Cyclomatic complexity \(V(G)\) — a software metric giving a quantitative measure of the logical complexity; gives the number of independent paths in the basis set → upper bound on the number of tests to ensure each statement executes at least once. Three ways (all equal)

From Software Eng › Basis Path Testing (Tom McCabe)

Steps: (1) draw the flow graph from the code; (2) compute the cyclomatic complexity \(V(G)\); (3) list the independent paths; (4) design one test case for each path.

From Software Engineering Unit V questions › question

A white-box technique (Tom McCabe) that uses the cyclomatic complexity of the control-flow graph to find the number of linearly independent paths and designs a test case for each. Every statement gets executed at least once. \(V(G) = E - N + 2 = P + 1\) (P = decision nodes).
