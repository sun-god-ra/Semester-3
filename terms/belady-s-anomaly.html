Belady's anomaly

  • FIFO replaces the oldest page; LRU replaces the page unused for the longest time (past); Optimal replaces the page that will not be used for the longest time (future; the lower bound, not implementable). FIFO may show Belady's anomaly; LRU and OPT are stack algorithms that do not. See Unit IV

From OS Lab › Task 14 — Page replacement: FIFO, LRU and Optimal

  • 15 page faults (FIFO). Belady's anomaly — for some algorithms, page-fault rate may increase as the number of allocated frames increases. Example reference string 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5: 3 frames → 9 page faults; 4 frames → 10 page faults (FIFO). Anomaly affects FIFO; stack algorithms (LRU, optimal) never suffer from it (the set of pages in memory with n frames is always a subset of the set with n+1 frames)

From Operating Systems › Page Replacement

Neither suffers from Belady's anomaly (more frames can give more faults in FIFO). They are stack algorithms.
