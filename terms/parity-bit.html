Term · Digital Logic

Parity bit

  • Error-detecting: parity bit — even parity: total number of 1s even; odd parity: odd. Detects single-bit (odd number of) errors, cannot correct

From Digital Logic › Binary Codes

  • Parity bit added to message so total number of 1s is even (even parity) or odd (odd parity)

From Digital Logic › Parity Generators and Checkers

A parity generator at the sender computes one extra bit so that the total number of ones in the word is even. At the receiver, a parity checker takes all the bits including the parity bit and XORs them. The output is 0 if the count is still even, and 1 if the count is odd, which signals an error. One flipped bit changes the count from even to odd and is detected. Two flipped bits cancel and pass unnoticed, so parity only detects odd numbers of errors, and it cannot tell which bit is wrong.

From Digital Logic › Exclusive-OR Functions

An extra bit added to a data word to detect single-bit errors. For even parity the total number of 1s (including the parity bit) is even. 1011 has three 1s, so the even-parity bit is 1 (word 11011).
