Design pattern

  • Design pattern use at component level (factory, observer, strategy…)

From Software Eng › Conducting Component-Level Design

  • Interface design patterns: reuse proven designs (breadcrumbs, search box, wizard)

From Software Eng › User Interface Analysis and Design

A design pattern is a proven, reusable solution to a commonly occurring design problem in a given context. It is described by a name, the problem, the solution and the consequences. Example: Singleton, Observer, Factory.
