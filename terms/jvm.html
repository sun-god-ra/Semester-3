JVM

  • JRE = JVM + class libraries (needed to run). JDK = JRE + tools (javac, java, javadoc, jar, jdb) (needed to develop). JDK ⊃ JRE ⊃ JVM

From Java › Bytecode, JVM, JRE, JDK

  • Daemon thread: background service thread (e.g. GC); JVM exits when only daemons remain. setDaemon(true) before start()

From Java › The Java Thread Model

  • CLASSPATH = list of directories / JAR files where JVM and javac look for classes and packages

From Java › CLASSPATH

  • JDK = compiler javac + tools + JRE. JRE = JVM + libraries. Source file .java → javac → bytecode .class → java runs it on the JVM

From Java Lab › Task 1 — Install JDK, Hello World, if and for

JVM executes bytecode (the virtual machine). JRE = JVM + class libraries needed to run programs. JDK = JRE + development tools (javac, jar, javadoc, debugger) needed to develop programs.
