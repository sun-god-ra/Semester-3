Term · Operating Systems

Multiprocessor

  • Uniprocessors: could disable interrupts — currently running code executes without preemption; generally too inefficient on multiprocessor systems (message passed to all processors → delays entry; affects system clock)

From Operating Systems › Synchronisation Hardware

  • Busy waiting (spinning): while a process is in its CS, any other process trying to enter loops continuously in acquire() — wastes CPU cycles. Lock that spins = spinlock. Advantage: no context switch is required when a process must wait on a lock — useful on multiprocessor systems when locks are held for a short time (less than two context switches) — one thread spins on one core while another performs its CS on another core

From Operating Systems › Mutex Locks

  • Caching — copying information into a faster storage on a temporary basis; check the cache first; if present (hit) use it, else (miss) get from lower level and copy into cache. Cache coherency problem in multiprocessor environments (cache coherency maintained by hardware). In the hierarchy each level acts as a cache for the level below it (registers cache the cache, cache caches main memory, main memory caches disk)

From Operating Systems › Computer-System Organization

  • Multiprocessor (parallel/tightly coupled) systems: two or more processors in close communication, sharing bus, clock, memory and peripherals. Advantages: increased throughput (not exactly n times, because of overhead and contention), economy of scale, increased reliability — graceful degradation / fault tolerance
    • Asymmetric multiprocessing (AMP): each processor assigned a specific task; a boss (master) processor controls the system, others take instructions from master or have predefined tasks (master–slave)
    • Symmetric multiprocessing (SMP): each processor performs all tasks within the OS; all peers; no master–slave relationship. Each has its own registers and private cache, shares physical memory
    • Multicore: several computing cores on a single chip — faster on-chip communication, less power
    • NUMA (non-uniform memory access): each CPU has local memory accessed fast; access to other CPU's memory is slower
    • Blade servers: multiple processor boards, I/O boards and networking boards in the same chassis, each board boots independently

From Operating Systems › Computer-System Architecture

  • CPU scheduling is more complex when multiple CPUs are available. Homogeneous processors within a multiprocessor (any CPU can run any process)
