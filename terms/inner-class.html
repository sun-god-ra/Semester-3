Term · Java

Inner class

  • 1996 JDK 1.0. 1997 JDK 1.1 (inner classes, JDBC, RMI). 1998 J2SE 1.2 (Swing, Collections). 2004 Java 5 (generics, annotations, enums, for-each, autoboxing). 2014 Java 8 (lambda, streams). 2017 Java 9 (modules). Since 2018, release every 6 months; LTS releases: 8, 11, 17, 21

From Java › History and Evolution of Java

  • Types: member inner class, local inner class (inside a method), anonymous inner class (no name; defined and instantiated in one expression; extends a class / implements an interface), static nested class

From Java › Nested and Inner Classes

  • Anonymous inner class vs lambda: lambda is shorter, no new scope (this = enclosing), compiled to invokedynamic; anonymous class can implement interfaces with many methods and has its own this

From Java › Method References

A lambda expression is a short anonymous function. Before Java 8, to pass a piece of behaviour to a method you had to write an anonymous inner class with several lines of ceremony. A lambda replaces that with just the parameters, an arrow, and the body. It can only be used where the expected type is a functional interface, an interface with exactly one abstract method. The compiler matches the lambda to that single method, infers the parameter types from the interface, and runs the body when the method is called.

From Java › Lambda Expressions — Fundamentals (Java 8)

  1. Less boilerplate: replaces anonymous inner classes.
