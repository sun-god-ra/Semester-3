Equivalence partitioning

  1. Equivalence partitioning: divides the input domain into classes of data from which test cases can be derived. Each class is an equivalence class: if one value in the class finds an error, any would; if one doesn't, none would. Guidelines for defining classes
    • range → one valid and two invalid classes
    • specific value → one valid and two invalid
    • member of a set → one valid and one invalid
    • boolean → one valid and one invalid

From Software Eng › Black-Box Testing

  1. Equivalence partitioning: divide the input domain into classes of valid and invalid data; one test case per class. Example: age 18 to 60 → classes: <18 (invalid), 18–60 (valid), >60 (invalid).
