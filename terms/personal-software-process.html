Personal software process

Personal Software Process (PSP) (Watts Humphrey) helps an individual engineer measure and improve his own work. Framework activities: Planning (size and resource estimates, defect estimates, schedule), High-level design, High-level design review, Development (detailed design, review, code, code review, compile, test) and Postmortem (compare actual with plan, update the process). Key idea: the engineer records time, size and defects and uses the data to estimate better and to remove defects early.

From Software Engineering Unit I questions › question

The Personal Software Process is about the individual developer. The developer measures the time spent, the size of the product and the defects found, and uses these data to plan more accurately and to improve personal quality. The Team Software Process extends this to teams of three to twenty engineers, who plan and manage their own work. Both were developed by Watts Humphrey at the Software Engineering Institute.
