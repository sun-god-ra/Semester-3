Term · DLD Lab, Digital Logic

Ring counter

  • Generated by: (1) ring counter; (2) \(n\)-bit counter + \(n\)-to-\(2^n\) decoder (fewer FFs, but decoder glitches); (3) Johnson counter + AND gates

From Digital Logic › Timing Sequences

  • Ring counter: a shift register whose last output is fed back to the first input (\(D_0=Q_{n-1}\)). It must be preset to a single 1 (1000). The 1 circulates, so \(n\) flip-flops give only \(n\) states (MOD-n). Outputs are already decoded (one-hot) — no extra decoder needed

From DLD Lab › Experiment 10 — Ring counter and Johnson counter

Ring counter (4 FFs): \(Q_3\) feeds back to \(D_0\); one flip-flop is preset to 1, the others cleared. The single 1 circulates: 1000 → 0100 → 0010 → 0001 → 1000. Mod-4 with 4 FFs (\(N\) states with \(N\) FFs). No decoding gates are needed (each output is a timing pulse).

From Digital Logic Design Unit V questions › question

A ring counter is a shift register with its last output connected back to the first input. If a single 1 is loaded, it circulates, and each flip-flop output is high during exactly one clock period out of \(n\). No decoder is needed because the outputs are already the timing signals, but \(n\) flip-flops give only \(n\) states. The counter is not self-starting: if the register powers up in an arbitrary pattern, extra 1s circulate forever, so the initial pattern must be preset.
