Term · DLD Lab, Digital Logic, Java, Java Lab

Comparator

  • Sorted map (red-black tree), sorted by natural order of keys or a Comparator. O(log n)

From Java › TreeMap

  • Comparator<T>: external order: int compare(T a, T b). Lambda: (a, b) -> a.age - b.age; Comparator.comparing(Person::getName).thenComparing(...), .reversed()

From Java › Iterators, Comparable and Comparator

  • TreeSet: red-black tree; sorted order (natural or Comparator); O(log n); no null; elements must be comparable

From Java › Set Interface

  • 4-bit comparator (7485): compares A3A2A1A0 with B3B2B1B0, the three cascade inputs (A>B, A=B, A<B) are used to extend to more bits: for a single IC, connect cascade input A=B to 1 and the other two to 0. 8-bit: the less-significant IC outputs go to the cascade inputs of the more significant IC
