Term · Operating Systems

Shared memory

  • Communications — shared memory or message passing (within a computer or between computers over a network)

From Operating Systems › Operating-System Services

  • If P and Q want to communicate, they need a communication link — physical (shared memory, hardware bus, network) or logical (direct/indirect, synchronous/asynchronous, automatic/explicit buffering)

From Operating Systems › Interprocess Communication (IPC)

  • Benefits of multithreaded programming: responsiveness (continues even if part is blocked), resource sharing (default sharing of memory — easier than shared memory/message passing between processes), economy (creating a thread is cheaper than a process; context switching among threads is faster — Solaris: creating a process is ~30× slower, context switching ~5× slower), scalability (use multiple processing cores, utilisation of multiprocessor architectures)

From Operating Systems › Threads

  • Inverted page table: rather than each process having a page table and tracking all possible logical pages, track all physical pages: one entry for each real page (frame) of memory; the entry consists of the virtual address of the page stored in that real memory location, with information about the process that owns the page (<process-id, page-number> plus offset). Decreases memory needed to store each page table, but increases time needed to search the table when a page reference occurs. Use a hash table to limit the search to one or at most a few page-table entries (TLB can accelerate). Difficulty with shared memory (only one virtual page mapped per physical frame → a shared page needs one mapping at a time). Used in 64-bit UltraSPARC, PowerPC

From Operating Systems › Structure of the Page Table

  • Sparse address space: virtual address spaces that include holes between the heap and stack (which grow), filled when a stack/heap grows or when dynamically linked libraries are loaded. System libraries shared via mapping into virtual address space; shared memory by mapping pages read–write into virtual address space; pages can be shared during fork(), speeding process creation
