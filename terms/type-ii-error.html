Type ii error

  • Type II error: failing to reject \(H_0\) when \(H_1\) is true. Probability \(=\beta\).

From Prob & Stats › Worked Examples from the Lecture Slides (Dr M. V. Rao)

Two mistakes are possible. A Type I error means rejecting a true null hypothesis (a false alarm), and its probability is the significance level \(\alpha\) chosen by us. A Type II error means keeping a false null hypothesis (a missed detection), with probability \(\beta\). The two pull against each other, so making the test stricter lowers \(\alpha\) but raises \(\beta\). Only a larger sample size improves both.
