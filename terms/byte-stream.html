Term · Java, Java Lab

Byte stream

  • Byte streams (InputStream/OutputStream: FileInputStream, FileOutputStream, BufferedInputStream, DataInputStream/DataOutputStream) handle raw 8-bit data — images, binary, any file. read() returns an int 0–255 or −1 at end of file

From Java Lab › Task 8 — Byte streams and character streams

  • InputStreamReader / OutputStreamWriter — bridge from byte stream to char stream with a chosen charset

From Java › Character Streams

Classes are layered like wrappers. A FileInputStream reads bytes from a file; wrapping it in a BufferedInputStream adds a buffer to reduce disk access; wrapping it in a DataInputStream adds methods to read ints and doubles. For text from the keyboard, System.in is a byte stream, so we wrap it in an InputStreamReader to get characters, and then a BufferedReader to read whole lines with readLine().

From Java › Byte Streams

Byte streams (InputStream/OutputStream) read and write raw 8-bit bytes, suited to binary data such as images. Character streams (Reader/Writer) read and write 16-bit Unicode characters, suited to text, and handle character encoding automatically.
