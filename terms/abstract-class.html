Abstract class

  • Abstract class: declared abstract; may have abstract methods and concrete methods, fields, constructors. Cannot be instantiated (new Shape() illegal); can have reference variables

From Java › Abstract Classes

Abstract class — declared abstract, cannot be instantiated. It may have abstract methods (no body) which every concrete subclass must implement, and normal methods, fields and constructors. It is used to give a common template.

From Object Oriented Programming Through Java Unit II questions › question

  • Open–Closed Principle (OCP): a module/component should be open for extension but closed for modification (use abstractions — interfaces/abstract classes)

From Software Eng › Designing Class-Based Components

  • Abstract class vs interface?

From Java Lab › Task 7 — Packages, interfaces and exceptions

Abstract class vs interface: an abstract class can have constructors, state and concrete methods and is single-inherited; an interface is a pure contract and is multiply-implemented.
