Random variable

  • RV (random variable) = a rule that gives a number to every outcome of an experiment. Usually written \(X\), \(Y\).

From Prob & Stats › Random Variables

A random variable \(X\) is a function that assigns a real number to every outcome of the sample space of a random experiment, \(X:S\to\mathbb R\). It is discrete if it takes countably many values and continuous if it takes any value in an interval. Example: number of heads in 3 tosses.

From Probability and Statistics Part A › question

A random variable \(X\) has \(P(X=x)=kx\) for \(x=1,2,\dots,8\) (that is \(k,2k,\dots,8k\)). Determine (i) \(k\), (ii) the mean, (iii) \(P(X>2)\), (iv) \(P(2<X<5)\).
