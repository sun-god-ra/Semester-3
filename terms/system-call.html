Term · OS Lab, Operating Systems

System call

  • System calls = interface to the services made available by the OS; written in C/C++, some low-level tasks in assembly

From Operating Systems › System Calls

  • Linux threads: clone() system call with flags (CLONE_FS, CLONE_VM, CLONE_SIGHAND, CLONE_FILES) decides how much is shared between parent and child; Linux uses the term task for process or thread; fork() = clone() with no sharing flags

From Operating Systems › Multithreading Models

  • Dual-mode operation — to ensure that an incorrect program cannot cause other programs or the OS itself to execute incorrectly: hardware has a mode bit: kernel mode (0) — OS code, privileged instructions allowed; user mode (1) — user code. On interrupt/trap/system call, hardware switches to kernel mode; return from system call → user mode (set bit to 1)
    • Privileged instructions (only in kernel mode): I/O control, timer management, interrupt management, switching to kernel mode, modifying memory-management registers, halting
    • Attempt to execute a privileged instruction in user mode → hardware traps to OS
    • Modern CPUs: more than two modes (virtualisation: VMM mode; Intel rings 0–3)

From Operating Systems › Operating-System Operations

  • Windows: priority-based, preemptive scheduling; dispatcher is the scheduler; thread runs until preempted by a higher-priority thread, terminates, its time quantum ends, or it calls a blocking system call; 32-level priority scheme: variable class (1–15), real-time class (16–31), memory-management thread at priority 0; queue for each priority; idle thread when no ready thread. Priority classes: REALTIME, HIGH, ABOVE_NORMAL, NORMAL, BELOW_NORMAL, IDLE; relative priorities within classes. Priority boost on wait for I/O or after a wait

From Operating Systems › Operating System Examples (scheduling)

  • File operations (OS provides system calls): create (find space; add an entry to the directory), write (write pointer at the location of the next write), read (read pointer / current-file-position pointer), reposition within file (seek), delete (release space, erase the directory entry), truncate (erase contents but keep attributes; file length reset to zero). Others: append, rename, copy
