Term · Operating Systems, Software Eng

Socket

  • Client–server communication: sockets (an endpoint for communication, identified by IP address + port number, e.g. 161.25.19.8:1625; well-known ports below 1024: 22 ssh, 23 telnet, 80 HTTP, 443 HTTPS, 21 FTP; 127.0.0.1 = loopback), remote procedure calls (RPC) (abstracts procedure calls between processes on networked systems; stubs (client-side proxy; marshalling parameters); XDR external data representation; matchmaker daemon), pipes

From Operating Systems › Interprocess Communication (IPC)

  • UML component diagram: component rectangle, provided interface (lollipop) and required interface (socket)

From Software Eng › Component-Level Design — What is a Component?

IPC is the set of mechanisms by which cooperating processes exchange data and synchronise. The two basic models are shared memory and message passing (pipes, message queues, sockets, signals).
