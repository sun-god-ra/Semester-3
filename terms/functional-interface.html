Term · Java, Java Lab

Functional interface

  • Marker interface: no methods (Serializable, Cloneable). Functional interface: exactly one abstract method (Runnable, Comparator) → lambdas (Unit IV)

From Java › Interfaces

  • Built-in functional interfaces (java.util.function)

From Java › Generic Functional Interfaces

  • A lambda can throw an exception only if the functional interface's method declares it (checked) — else only unchecked exceptions allowed

From Java › Lambda Expressions and Exceptions

  • Functional interface = interface with exactly one abstract method (SAM); @FunctionalInterface makes the compiler check it. A lambda (params) -> expression/block is an implementation of that method

From Java Lab › Task 10 — Generic functional interfaces and lambdas as arguments

  • parameter types inferred from the functional interface; if you declare one, declare all

From Java › Lambda Expressions — Fundamentals (Java 8)
