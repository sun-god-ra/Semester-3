Dynamic method dispatch

  • Dynamic method dispatch: a superclass reference can hold a subclass object; the method that runs is decided at run time by the actual object, not by the reference type. Fields are not overridden (they follow the reference type)

From Java Lab › Task 6 — Inheritance, `super`, overriding and dynamic dispatch

Method overriding: a subclass gives its own implementation of a method already defined in the superclass with the same signature. Dynamic method dispatch: the overridden method that runs is chosen at run time from the actual object type held by a superclass reference.

From Object Oriented Programming Through Java Unit II questions › question

Dynamic method dispatch is the run-time process in which a call to an overridden method is resolved by the actual object type held by a superclass reference, not by the reference type. It is how Java achieves run-time polymorphism. Example: Animal a = new Dog(); a.sound(); calls Dog's sound().
