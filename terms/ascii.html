Term · Digital Logic, Java

ASCII

  • Alphanumeric: ASCII 7-bit (128 chars; 'A' = 65 = 1000001, 'a' = 97, '0' = 48); EBCDIC 8-bit (IBM); Unicode 16+ bit

From Digital Logic › Binary Codes

char in Java is a 16-bit Unicode value, not an 8-bit ASCII value as in C. It can hold characters from most languages and behaves like a number in arithmetic. boolean takes only true or false, and cannot be converted to or from numbers. All other types, such as classes and arrays, are reference types: a variable holds the address of the object, not the object, and its default value is null.
