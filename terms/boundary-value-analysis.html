Boundary value analysis

  1. Boundary value analysis (BVA): a greater number of errors occurs at the boundaries of the input domain rather than in the "center". Select test cases at the edges of the class. Guidelines
    • range \(a..b\): test \(a\), \(b\), and just above and below (\(a-1\), \(a\), \(a+1\), \(b-1\), \(b\), \(b+1\))
    • number of values: min, max, just below min, just above max
    • apply to output conditions too; apply to internal data structures (array limits)
