Expected value

Two results about sums are used again and again. The expected value of a sum is always the sum of expected values. The variance of a sum equals the sum of variances only for independent variables. Applying both to \(\bar X=\frac1n\sum X_i\) gives the facts that the sample mean is centred on \(\mu\) and that its variance shrinks like \(\sigma^2/n\). This is the starting point for statistical inference in the next unit.

From Prob & Stats › Joint Distributions: Continuous

On a single processor one could disable interrupts, but that does not work well on multiprocessors. Hardware therefore provides atomic instructions. test_and_set sets a variable to true and returns the old value, so the process that gets false knows it has taken the lock. compare_and_swap changes the variable to a new value only if it has the expected value and returns the old value. Locks built with them give mutual exclusion, but not bounded waiting, because an unlucky process can spin forever. A longer algorithm using the waiting array hands the lock over to the next waiting process in the cyclic order and so achieves bounded waiting within n−1 turns. Atomic variables are the same idea for simple data types like integer counters.
