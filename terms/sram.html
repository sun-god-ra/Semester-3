Home › Terms A–Z › SRAM

Term · Digital Logic

SRAM

  • Configured by loading a bitstream (stored in SRAM → lost at power off, reloaded from flash) — hence "field programmable"

From Digital Logic › Introduction to FPGA

  • Hierarchy: registers → cache (SRAM) → main memory (DRAM) → disk

From Digital Logic › RAM — Design and Classification

FPGA (introduction): an array of configurable logic blocks (each with look-up tables and flip-flops), I/O blocks and programmable interconnect, configured by loading a bitstream into SRAM cells. It is reprogrammable and can implement large sequential and combinational designs.

From Digital Logic Design Unit III questions › question

RAM: volatile read/write memory. SRAM (flip-flop cell; fast, costly, used for cache) and DRAM (capacitor cell, refreshed periodically; dense, cheap, used for main memory).
