Arraylist

  • ArrayList: dynamic array — get(i) \(O(1)\), insert/remove in the middle \(O(n)\). LinkedList: doubly linked list — add/remove at the ends \(O(1)\), get(i) \(O(n)\); also a Deque

  • Constructors: ArrayList(), ArrayList(int capacity), ArrayList(Collection c)

From Java › ArrayList

A method reference is a shorter way of writing a lambda that does nothing but call an existing method. String::length stands for s -> s.length(). There are four kinds: a static method (Utils::isPrime), an instance method on a given object (u::longer), an instance method on whichever object is the first argument (String::length), and a constructor (ArrayList::new). To choose the right form, ask what the first lambda parameter would be: if it is the object on which the method is called, use the class name form; if the method is static, the parameters are all arguments.

From Java › Method References

So the rule for choosing is simple: if you mostly read by position, use ArrayList; if you mostly add and remove at the ends, use LinkedList (or better, ArrayDeque). A frequent mistake with List<Integer> is list.remove(1): it removes the element at index 1 because the int overload is chosen, whereas to remove the value 1 you must write list.remove(Integer.valueOf(1)).
