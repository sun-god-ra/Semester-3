Inheritance

  • Java supports single inheritance for classes (only one superclass). Multiple inheritance only via interfaces. Every class extends Object (root) implicitly

From Java › Inheritance — Basics

  • Types: aggregation (whole–part, hollow diamond, "has-a"), composition (strong whole–part: part cannot exist without whole, filled diamond), generalisation / inheritance (hollow triangle), dependency (dashed arrow: one class uses another temporarily; "client–server": uses)

From Software Eng › Associations and Dependencies

  • Components: naming conventions from the problem domain (OrderProcessor); interfaces are shown as lollipop and elaborated; dependencies and inheritance: model dependencies from left to right and inheritance from bottom (derived) to top (base)

From Software Eng › Designing Class-Based Components

  • Inheritance: class B extends A — B gets the non-private members of A (IS-A relationship). Java has single inheritance of classes (multiple through interfaces). Every class extends Object

From Java Lab › Task 6 — Inheritance, `super`, overriding and dynamic dispatch

  • Inheritance / continuity in each order (what carries the characteristic forward)
    • material order: structure-based (constituents and bonding decide the properties)
    • bio order: seed-based (seed → plant → seed)
    • animal order: breed-based (behaviour fixed as per breed)
    • human order: sanskar-based (values, understanding and education — not fixed by birth)
