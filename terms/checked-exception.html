Term · Java

Checked exception

  • Checked exceptions: subclasses of Exception except RuntimeException. Compiler forces you to handle (try/catch) or declare (throws). E.g. IOException, FileNotFoundException, SQLException, ClassNotFoundException, InterruptedException

From Java › Exception Types — Hierarchy

  • Declares in the method signature that the method may throw a checked exception which it does not handle; the caller must handle or redeclare

From Java › `throws`

  1. Checked exceptions: checked at compile time; must be caught or declared with throws (IOException, FileNotFoundException, SQLException, ClassNotFoundException).

From Object Oriented Programming Through Java Unit III questions › question

  • Rules: same signature; return type same or covariant (subtype); access cannot be more restrictive (public → public); cannot override static, final, private methods; may throw fewer/narrower checked exceptions

From Java › Method Overriding

  • Else wrap the checked exception: try/catch inside lambda body, or wrap into a RuntimeException
