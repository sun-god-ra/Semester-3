Lambda expression

  • Lambda expression = anonymous method (no name, no return type declared). A short way to give behaviour as data. Supports functional programming style

From Java › Lambda Expressions — Fundamentals (Java 8)

A lambda expression is an anonymous function: (parameters) -> expression or -> { statements }. It needs a functional interface (one abstract method) as its target type.

From Object Oriented Programming Through Java Unit IV questions › question

A lambda expression (Java 8) is a short, anonymous function with parameters and a body but no name, access modifier or return type. It treats behaviour as data: a lambda can be stored in a variable and passed to a method.
