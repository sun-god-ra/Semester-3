Term · Java

JIT

  • JVM (Java Virtual Machine): abstract machine that runs bytecode. Different JVM for each OS/CPU, but the same bytecode runs on all → portability. Parts: class loader, bytecode verifier, interpreter, JIT, garbage collector, runtime data areas (heap, stack, method area)

From Java › Bytecode, JVM, JRE, JDK

  1. Interpreted and high performance: bytecode is interpreted, and the JIT compiler converts hot spots into native code for speed.

From Object Oriented Programming Through Java Unit I questions › question

  • (Other features: simple, secure, robust, multithreaded, portable, high performance with JIT.)

From Object Oriented Programming Through Java Part A › question

Byte code is the intermediate, machine-independent code (.class file) produced by the Java compiler (javac) from the .java source. The JVM interprets it or the JIT compiler converts it to native code. Because bytecode is the same on every platform, Java programs are portable.
