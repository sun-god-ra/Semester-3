Synchronization

  • Synchronization = allow only one thread at a time to access the shared resource

From Java › Synchronization

Without synchronization two threads doing count++ 1000 times each may give less than 2000, because count++ is read–add–write, not one step.

From Object Oriented Programming Through Java Unit IV questions › question

Synchronization lets only one thread at a time execute a block or method that touches shared data (by taking the object's monitor lock, synchronized keyword). It prevents race conditions and inconsistent data when several threads update the same object.
