Term · Java, OS Lab, Operating Systems, Software Eng

Operating system

  • Within each genre several architectural styles may apply. Example: Genre: operating systems / Subcategory: ..., styles: layered, microkernel

From Software Eng › Architectural Genres

  • Computer system has 4 components: hardware (CPU, memory, I/O devices) → operating system → application programs (word processor, compilers, browsers) → users

From Operating Systems › What is an Operating System?

  • Distributed operating system — less autonomous: different OSes act as one single system; users see one machine, transparency

From Operating Systems › Distributed Systems

  • Three ways: (1) ensure the system never enters a deadlock state — prevention or avoidance; (2) allow it to enter, detect and recover; (3) ignore the problem and pretend deadlocks never occur — the ostrich algorithm, used by most operating systems, including UNIX and Windows (cheap; deadlocks rare; developers must write deadlock-free programs); manual restart when a system slows down because of a deadlock

From Operating Systems › Methods for Handling Deadlocks

  • Open-source operating systems are made available in source-code format rather than just binary closed-source form; free software (Richard Stallman, GNU, Free Software Foundation (FSF), GNU General Public License (GPL) → copyleft) vs open-source (Open Source Initiative); free software = freedom to run, study, share and modify
