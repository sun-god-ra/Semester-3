Crc card

  • CRC card (Class–Responsibility–Collaborator): index card with class name (top), responsibilities (left), collaborators (right). Developed by Beck & Cunningham

From Software Eng › Class-Based Modeling

  • Design: KISS principle; CRC cards as the only design work product; spike solution (prototype to reduce risk); refactoring (improve internal structure without changing external behaviour)

From Software Eng › Extreme Programming (XP)

XP process activities: Planning (user stories written by the customer, each given a cost; the team picks stories for the next release), Design (KISS principle, CRC cards, spike solutions, refactoring), Coding (pair programming, unit tests written before the code), Testing (unit tests, daily integration, acceptance tests from user stories).
