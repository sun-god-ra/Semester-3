Thrashing

  • Working-set model: \(\Delta\) = working-set window = a fixed number of page references (e.g. 10,000 instructions). \(WSS_i\) (working-set size of process \(P_i\)) = total number of pages referenced in the most recent \(\Delta\) (varies in time). If \(\Delta\) too small → won't encompass the entire locality; too large → will encompass several localities; \(\Delta=\infty\) → the entire program. \(D=\sum WSS_i\) = total demand for frames; if \(D>m\) → thrashing → the OS selects a process to suspend (swap out). Policy: if \(D>m\), then suspend or swap out one of the processes. Working-set model prevents thrashing while keeping the degree of multiprogramming as high as possible; difficulty: keeping track of the moving window — approximated with a fixed-interval timer interrupt and reference bits
    • Example: reference string ... with \(\Delta=10\): \(WS(t_1)=\{1,2,5,6,7\}\) (WSS = 5)
