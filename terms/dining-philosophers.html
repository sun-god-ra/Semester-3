Dining philosophers

  • Dining philosophers with a monitor — states THINKING, HUNGRY, EATING; philosopher i can set state[i] = EATING only if both neighbours are not eating; condition self[5]. Operations pickup(i), putdown(i), test(i). Deadlock-free, but starvation is possible

From Operating Systems › Monitors

Dining philosophers: 5 philosophers, 5 chopsticks (semaphore each). Naive solution: each picks left then right; if all pick the left, deadlock. Remedies: at most 4 philosophers sit, pick both chopsticks only if both are available (inside a critical section), or asymmetric pick (odd: left first, even: right first).
