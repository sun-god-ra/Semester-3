Shift register

  • Bidirectional shift register: each FF input selects between left and right neighbour with a 4:1 MUX (hold / shift right / shift left / parallel load) → universal shift register (IC 74194), mode select \(S_1S_0\):

From Digital Logic › Shift Registers

  • Ring counter: a shift register whose last output is fed back to the first input (\(D_0=Q_{n-1}\)). It must be preset to a single 1 (1000). The 1 circulates, so \(n\) flip-flops give only \(n\) states (MOD-n). Outputs are already decoded (one-hot) — no extra decoder needed

From DLD Lab › Experiment 10 — Ring counter and Johnson counter

  • Time to shift a number of \(n\) bits: \(n\) clock pulses (SISO/SIPO/PISO); 1 pulse for PIPO. Universal shift register 74194: modes selected by S1 S0: 00 hold, 01 shift right, 10 shift left, 11 parallel load

From DLD Lab › Experiment 11 — Shift registers: SISO, SIPO, PISO and PIPO

Universal shift register (e.g. 74194): mode inputs \(S_1S_0\) select hold (00), shift right (01), shift left (10) or parallel load (11); it has serial inputs for both directions and four parallel inputs/outputs, so it works as any of the four types.
