Term · Operating Systems

Virtual memory

  • Virtual memory — separation of user logical memory from physical memory: only part of the program needs to be in memory for execution; therefore the logical address space can be much larger than the physical address space; allows address spaces to be shared by several processes; allows more efficient process creation; more programs running concurrently; less I/O needed to load or swap processes. Virtual address space = logical view of how a process is stored in memory — usually starts at address 0, contiguous addresses until the end of the space, while the physical memory is organised in page frames and the MMU maps logical to physical

From Operating Systems › Virtual Memory — Background

  • Multitasking (time-sharing) systems: extension of multiprogramming where the CPU switches among jobs so frequently that users can interact with each program while it is running → response time < 1 s. Each user has at least one program in memory = process; CPU scheduling; swapping; virtual memory

From Operating Systems › Operating-System Operations

  • Enhanced second-chance algorithm: consider (reference bit, modify bit) as an ordered pair: (0,0) neither recently used nor modified — best to replace; (0,1) not recently used but modified — not quite as good (must be written out); (1,0) recently used but clean — probably used again soon; (1,1) recently used and modified — probably used again, and need to write out before replacement. Replace the first page encountered in the lowest nonempty class (may have to scan the circular queue several times) — used in old Macintosh virtual memory

From Operating Systems › Page Replacement

  • Swap-space management: swap space — virtual memory uses disk space as an extension of main memory; raw partition or a file in the file system; swap space is less than the disk's file system — usually allocated in larger chunks, often contiguous, with a swap map. Linux: swap partitions or swap files; Solaris: swap space only for pages evicted, anonymous memory (stack, heap)

From Operating Systems › Disk Scheduling

(1) No external fragmentation, since memory is divided into fixed-size frames. (2) The logical address space need not be contiguous in physical memory; it also allows sharing of pages (reentrant code) and supports virtual memory.
