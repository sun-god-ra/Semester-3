Multithreading

  • Multicore processors: each core has its own register set and appears as a separate logical CPU; faster, less power. Memory stall — a core spends up to 50 % of its time waiting for data from memory (cache miss) → multithreaded processing cores (two or more hardware threads assigned to each core; if one thread stalls, the core switches to another). Intel calls it hyper-threading (simultaneous multithreading, SMT). Coarse-grained (switch on long-latency event, flush pipeline — expensive) vs fine-grained (switch at the boundary of an instruction cycle — architecture has logic for thread switching → low cost). Two levels of scheduling: (1) the OS chooses which software thread to run on each hardware thread (logical CPU); (2) each core decides which hardware thread to run
