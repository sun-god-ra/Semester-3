Term · DLD Lab, Digital Logic, Operating Systems

Latch

  • D latch (data / transparent): gated SR with \(S=D\), \(R=D'\) → removes the invalid state. When \(E=1\): \(Q=D\); when \(E=0\): holds

From Digital Logic › Latches

  • SR latch (NOR): active-high S,R. S=1,R=0 → Q=1 (set); S=0,R=1 → Q=0 (reset); S=R=0 → hold; S=R=1 → forbidden (both outputs 0, and an unpredictable state when released). NAND latch: active-low \(\overline{S},\overline{R}\); set = (0,1), reset = (1,0), hold = (1,1), forbidden = (0,0)

From DLD Lab › Experiment 7 — Latches and flip-flops: SR latch, SR, JK, D, T and master-slave JK

  • Solutions to external fragmentation: compaction — shuffle memory contents to place all free memory together in one large block; possible only if relocation is dynamic (done at execution time); I/O problem (latch job in memory while it is involved in I/O, or do I/O only into OS buffers); expensive. Other solution: permit the logical address space of processes to be noncontiguous → paging and segmentation

From Operating Systems › Contiguous Memory Allocation

Gated (clocked) D latch: \(D\) is applied through an SR latch with \(S=D\), \(R=D'\) when the enable is 1: \(Q^+=D\). No forbidden state. The edge-triggered D flip-flop (master–slave) copies \(D\) to \(Q\) only at the clock edge.

From Digital Logic Design Unit IV questions › question

  • Cures the race-around problem of the JK latch (when \(J=K=1\) and the clock pulse is longer than the propagation delay, output toggles repeatedly)
