RAID

  • RAID structure: Redundant Arrays of Independent Disks — improve reliability via redundancy and performance via parallelism. Mean time to failure (MTTF) of a single disk, e.g. 100,000 h; with 100 disks, MTTF of some disk = 100,000/100 = 1,000 h (≈ 41.7 days) — so redundancy needed. Mean time to repair; mean time to data loss for a mirrored pair: MTTF²/(2 × MTTR) = \((100{,}000)^2/(2\times10)=5\times10^8\) h ≈ 57,000 years (with MTTR = 10 h). Mirroring (RAID 1): duplicate every disk — reliability, read speed-up (but writes to both). Striping: bit-level / block-level striping across several disks — parallelism for throughput. RAID levels: 0 (non-redundant block striping), 1 (mirrored disks), 2 (memory-style ECC), 3 (bit-interleaved parity, single parity disk), 4 (block-interleaved parity), 5 (block-interleaved distributed parity — parity spread across all disks; no bottleneck parity disk), 6 (P + Q redundancy, double parity — tolerates two disk failures), 0+1 and 1+0 (striping + mirroring — RAID 10 is better: a single disk failure only affects its mirror pair)

  • A collection of nodes containing information about all files; both the directory structure and the files reside on disk. Disk structure: a disk can be subdivided into partitions; disks or partitions can be RAID protected; partition: also called minidisks or volumes; each containing a file system (raw partitions without one); entity containing a file system = a volume; each volume tracks the file-system info in a device directory (volume table of contents); device directory records information such as name, location, size, type of all files on the partition. Operations performed on a directory: search for a file, create a file, delete a file, list a directory, rename a file, traverse the file system. Goals: efficiency (locating a file quickly), naming (convenient to users: two users can have the same name for different files, the same file can have several different names), grouping (logical grouping of files by properties, e.g. all Java programs)
