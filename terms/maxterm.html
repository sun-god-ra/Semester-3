Maxterm

  • Maxterm \(M_i\): OR term containing all variables; equals 0 for exactly one row. \(M_i=m_i'\). \(x+y'+z'=M_3\) (011, complemented bits)

From Digital Logic › Canonical and Standard Forms

A common mistake is the maxterm numbering. The maxterm \(M_i\) has the variable written uncomplemented where the bit in row \(i\) is 0, and complemented where the bit is 1, because the sum must be zero at that row. So row 011 gives \(x+y'+z'\).

From Digital Logic › Boolean Functions

A minterm is an AND (product) term containing every variable once, true or complemented, that equals 1 for exactly one input row (\(m_i\)). A maxterm is an OR (sum) term containing every variable once, equal to 0 for exactly one row (\(M_i\)). \(M_i=m_i'\).
