Regression testing

  • Thread-based testing — integrates the set of classes required to respond to one input or event; each thread integrated and tested individually; regression testing applied

From Software Eng › Test Strategies for Object-Oriented Software

  • Regression testing: re-execute a subset of tests after each change/addition.

From Software Engineering Unit V questions › question

  • Regression testing: re-execution of a subset of tests that have already been conducted to ensure that changes have not propagated unintended side effects. Kept in a regression test suite: representative sample of tests that exercise all functions; additional tests focused on functions likely affected; tests for the components changed. Often automated

From Software Eng › Test Strategies for Conventional Software

Regression testing means re-running earlier tests after a change (bug fix, new feature) to make sure the change has not broken the existing working behaviour. It uses a saved test suite and is often automated.
