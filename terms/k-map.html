Term · DLD Lab, Digital Logic

K-map

  • A K-map = truth table redrawn as a grid so that adjacent cells differ in exactly one variable. Lets us simplify by eye (graphical method)

From Digital Logic › The Map Method — Karnaugh Map (K-map)

  1. Simplify with K-maps (use don't-cares for unused states) → flip-flop input equations and output equations

From Digital Logic › Design Procedure for Sequential Circuits

  • BCD → Excess-3: add 3 (0011) to each BCD digit; inputs 1010–1111 are don't-cares. With K-map simplification: \(X_3=B_3+B_2(B_1+B_0)\), \(X_2=\overline{B_2}(B_1+B_0)+B_2\overline{B_1}\,\overline{B_0}\), \(X_1=\overline{B_1\oplus B_0}\), \(X_0=\overline{B_0}\)

From DLD Lab › Experiment 3 — Code converters: Binary ↔ Gray, BCD ↔ Excess-3

  • uses: shaft/position encoders, K-maps, avoid glitches

From Digital Logic › Binary Codes

  • Represent as: truth table, algebraic expression, logic diagram, K-map
