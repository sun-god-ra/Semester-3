Term · Java, Java Lab

Iterator

  • Iterator — traverse a collection one element at a time: hasNext(), next(), remove(). ListIterator goes both directions and can add/set. for-each uses an iterator internally

From Java › Iterators, Comparable and Comparator

  • Spliterator — iterator that can split itself for parallel traversal: tryAdvance, forEachRemaining, trySplit, estimateSize, characteristics (ORDERED, SIZED, SORTED, DISTINCT…)

From Java › Iterators and Streams

  • Iterator: hasNext(), next(), remove() — the only safe way to remove while traversing; ListIterator adds hasPrevious(), previous(), set(), add(). Modifying a collection in a for-each loop causes ConcurrentModificationException (fail-fast)

From Java Lab › Task 12 — Stream reduce, iterators and streams

Iterator. An Iterator<E> visits the elements of a collection one by one. Methods: hasNext(), next(), remove(). It is external iteration: we write the loop. ListIterator adds backward traversal and add()/set() for lists.

From Object Oriented Programming Through Java Unit V questions › question

  • Methods of Collection<E>: add(e), addAll(c), remove(o), removeAll(c), contains(o), containsAll(c), size(), isEmpty(), clear(), iterator(), toArray(), retainAll(c), removeIf(p), stream(), forEach
