Term · Operating Systems

IPC

  • Pipes: one of the first IPC mechanisms in UNIX. Issues: unidirectional or bidirectional? half-duplex or full-duplex? relationship (parent–child) needed? over a network?
    • Ordinary pipes: producer writes to one end (write end), consumer reads from the other (read end); unidirectional, cannot be accessed from outside the process that created it; typically a parent creates a pipe and uses it to communicate with a child it creates via fork(). pipe(int fd[2]) — fd[0] is the read end, fd[1] is the write end; Windows calls them anonymous pipes
    • Named pipes (FIFOs): bidirectional (in Windows; half-duplex in UNIX); no parent–child relationship necessary; continue to exist after the communicating processes finish; several processes can use it; UNIX mkfifo(); shell ls | wc -l

From Operating Systems › Interprocess Communication (IPC)

  • Domain structure: a domain = set of access rights; access right = <object-name, rights-set> (rights-set = subset of all valid operations on the object). Association between a process and a domain can be static (the set of resources available to a process is fixed over its lifetime) or dynamic (domain switching). Domain can be realised as: each user (the set of objects accessible depends on the identity of the user; domain switching when the user changes — logout/login), each process (depends on the process's identity; domain switching corresponds to IPC — message sent from one process to another), each procedure (depends on the local variables defined within the procedure; domain switching when a procedure call is made)

From Operating Systems › Protection

IPC is the set of mechanisms by which cooperating processes exchange data and synchronise. The two basic models are shared memory and message passing (pipes, message queues, sockets, signals).

From Operating Systems Part A › question

  1. Microkernel: only the essentials (IPC, basic scheduling, memory) in the kernel; other services run in user space. Secure and extensible but slower due to message passing (Mach, QNX).
