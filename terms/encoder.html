Term · DLD Lab, Digital Logic

Encoder

  • Encoder: reverse of decoder. \(2^n\) (or fewer) inputs → \(n\)-bit code. Only one input is 1 at a time

From Digital Logic › Encoders

  • Encoder: \(2^n\) (or fewer) inputs → \(n\) outputs; exactly one input should be high. Priority encoder handles several inputs at once: the highest priority wins; a valid output \(V\) shows at least one input is active (else the 00 output is ambiguous). 4×2: \(Y_1=D_3+D_2\), \(Y_0=D_3+\overline{D_2}D_1\). Octal-to-binary: \(Y_2=D_4+D_5+D_6+D_7\), \(Y_1=D_2+D_3+D_6+D_7\), \(Y_0=D_1+D_3+D_5+D_7\) (three 4-input OR gates). Decimal-to-BCD: \(Y_3=D_8+D_9\), \(Y_2=D_4+D_5+D_6+D_7\), \(Y_1=D_2+D_3+D_6+D_7\), \(Y_0=D_1+D_3+D_5+D_7+D_9\)

From DLD Lab › Experiment 5 — Decoders and encoders

  • uses: shaft/position encoders, K-maps, avoid glitches

From Digital Logic › Binary Codes

  • Gray code has only one bit change between consecutive numbers (used in encoders and K-maps); Excess-3 is a self-complementing code

From DLD Lab › Experiment 3 — Code converters: Binary ↔ Gray, BCD ↔ Excess-3

Encoder: \(2^n\) inputs (one active) → \(n\)-bit code. Decoder: \(n\)-bit code → \(2^n\) outputs.
