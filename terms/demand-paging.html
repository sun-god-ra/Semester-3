Term · Operating Systems

Demand paging

  • Performance of demand paging: page-fault rate \(p\), \(0\le p\le 1\): \(p=0\) → no page faults; \(p=1\) → every reference is a fault

From Operating Systems › Demand Paging

  • Memory-mapped files: map a disk block to a page in memory — file I/O treated as routine memory access; mmap(); a page-sized portion of the file is read from the file system into a physical page by demand paging; subsequent reads/writes treated as ordinary memory accesses; writes not necessarily immediately to the file (msync()/close); several processes can map the same file → shared pages; Windows CreateFileMapping(); memory-mapped I/O — ranges of device-register addresses are mapped to memory (serial/parallel ports, programmed I/O using control/status/data registers)

From Operating Systems › Copy-on-Write (COW)

  • Selection of a disk-scheduling algorithm: SSTF common, natural appeal; SCAN and C-SCAN perform better for systems that place a heavy load on the disk (less starvation, but starvation still possible with some variants); performance depends on the number and types of requests (file-allocation method and location of directories/index blocks influence it); the disk-scheduling algorithm should be a separate module of the OS (replaceable); default: SSTF or LOOK. Modern disks do their own scheduling using physical layout knowledge; OS also guarantees priorities (e.g., demand paging requests over application I/O, writes with order constraints); Linux has deadline, NOOP and CFQ schedulers — NOOP (FCFS with merging) is used for SSDs; NVM scheduling: FCFS with merging adjacent requests, since there is no seek time

From Operating Systems › Disk Scheduling

In demand paging, a page is brought in only when it is needed. Each page-table entry has a valid-invalid bit, where valid means the page is in memory. A reference to a page that is not in memory causes a page fault. The OS checks whether the reference was valid, finds a free frame, reads the page from disk, updates the page table, and restarts the instruction. In pure demand paging the process starts with no page in memory. Instruction restart needs care for instructions like block moves.
