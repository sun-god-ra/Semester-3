Verilog

  • Design flow: (1) design entry (HDL — Verilog/VHDL — or schematic) → (2) behavioural simulation (ISim) with a test bench → (3) synthesis (XST: RTL → gate netlist) → (4) implementation: translate (NGDBuild) → map (to LUTs/slices) → place and route → (5) timing analysis → (6) generate programming file (.bit) → (7) configure the device with iMPACT over JTAG. Constraints file (.ucf) assigns the signals to physical pins and sets I/O standards
