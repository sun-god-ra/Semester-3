Term · Java, OS Lab, Operating Systems

Mutual exclusion

  • Monitor (intrinsic lock): every Java object has a monitor. A thread that enters a synchronized method/block must acquire the object's lock; others block until it is released (mutual exclusion). Entering = lock, leaving (even by exception) = unlock

From Java › Synchronization

  1. Mutual exclusion — if process Pi is executing in its critical section, no other process can be executing in theirs

From Operating Systems › The Critical-Section Problem

  • Both give mutual exclusion but not bounded waiting (a process may be unlucky and spin forever)

From Operating Systems › Synchronisation Hardware

  • Uses: mutual exclusion (mutex initialised to 1: wait(mutex); CS; signal(mutex)); ordering / synchronisation — to execute statement S2 in P2 only after S1 in P1: share semaphore synch initialised to 0: P1: S1; signal(synch); P2: wait(synch); S2;

From Operating Systems › Semaphores

  • n buffers, each holds one item; semaphores: mutex = 1 (mutual exclusion for buffer access), empty = n (number of empty buffers), full = 0 (number of full buffers)
