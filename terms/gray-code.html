Gray code

  • Rows/columns labelled in Gray code (00, 01, 11, 10) — NOT binary order!

From Digital Logic › The Map Method — Karnaugh Map (K-map)

  • State assignment: give binary codes to states. Different assignments → different logic cost. Rules of thumb: states with the same next state get adjacent codes; Gray code assignment; one-hot assignment (one FF per state; fast, more FFs)

From Digital Logic › State Reduction and State Assignment

  • Gray code (reflected, unweighted): only one bit changes between consecutive numbers
    • binary → Gray: \(g_{n-1}=b_{n-1}\), \(g_i=b_{i+1}\oplus b_i\)
    • Gray → binary: \(b_{n-1}=g_{n-1}\), \(b_i=b_{i+1}\oplus g_i\)
    • 3-bit: 000 001 011 010 110 111 101 100
    • uses: shaft/position encoders, K-maps, avoid glitches
