Home › Terms A–Z › UNIX

Term · OS Lab, Operating Systems

UNIX

  • Examples: GNU/Linux (Linus Torvalds, 1991; Linux kernel + GNU tools = distributions: Ubuntu, Debian, Red Hat, Fedora…), BSD UNIX (FreeBSD, NetBSD, OpenBSD; BSD licence is less restrictive — allows closed-source derivatives), Solaris, Darwin (core of macOS, open source), Android (AOSP)

From Operating Systems › Free and Open-Source Operating Systems

  • A parent process creates children, which create other processes, forming a tree. Each identified by a process identifier (pid) (unique integer). In UNIX init (pid 1) is the root parent of all user processes; ps -el, pstree

From Operating Systems › Operations on Processes

  • Named pipes (FIFOs): bidirectional (in Windows; half-duplex in UNIX); no parent–child relationship necessary; continue to exist after the communicating processes finish; several processes can use it; UNIX mkfifo(); shell ls | wc -l

From Operating Systems › Interprocess Communication (IPC)

  • The shell (bash) reads a command, finds the program (searching the directories in $PATH), creates a child with fork(), runs it with exec() and waits (wait()) — see Unit I. Everything is a file in UNIX; every process has three open files: stdin (0), stdout (1), stderr (2)

From OS Lab › Task 1 — Linux commands and shell utilities

  • Command interpreter (shell) — CLI (command-line interface): user types commands; shell may be part of the kernel or a system program; implementation of commands: (a) the interpreter itself contains the code (built-in commands) or (b) the commands are names of programs (UNIX: rm file.txt → shell searches for the program rm, loads and executes it). Examples: Bourne shell (sh), bash, C shell (csh), Korn shell (ksh), PowerShell (Windows), cmd.exe
