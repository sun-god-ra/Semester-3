Term · Operating Systems

DMA

  • Interrupt-driven I/O is fine for small data but has high overhead for bulk transfers → Direct Memory Access (DMA): controller transfers a whole block between buffer and main memory without CPU intervention; only one interrupt per block instead of one per byte

From Operating Systems › Computer-System Organization

  • I/O structure: each controller has a local buffer; the driver moves data between the buffer and the memory. For bulk transfers DMA moves a whole block without CPU involvement, and gives one interrupt per block.
