Term · Operating Systems, Software Eng

Kernel

  • "The one program running at all times on the computer" = the kernel. Everything else = system programs (shipped with OS, not part of kernel) or application programs

From Operating Systems › What is an Operating System?

  • Examples: GNU/Linux (Linus Torvalds, 1991; Linux kernel + GNU tools = distributions: Ubuntu, Debian, Red Hat, Fedora…), BSD UNIX (FreeBSD, NetBSD, OpenBSD; BSD licence is less restrictive — allows closed-source derivatives), Solaris, Darwin (core of macOS, open source), Android (AOSP)

From Operating Systems › Free and Open-Source Operating Systems

  • Support for threads — user threads (above the kernel, managed without kernel support by a thread library) and kernel threads (supported and managed directly by the OS: Windows, Linux, macOS, Solaris, iOS, Android). A relationship must exist between user threads and kernel threads

From Operating Systems › Multithreading Models

  • Oracle SPARC Solaris (example): 64-bit, two hash tables (kernel, user); each entry is a TSB (translation storage buffer); TLB holds translation table entries (TTEs)

From Operating Systems › Structure of the Page Table

  • Dual-mode operation — to ensure that an incorrect program cannot cause other programs or the OS itself to execute incorrectly: hardware has a mode bit: kernel mode (0) — OS code, privileged instructions allowed; user mode (1) — user code. On interrupt/trap/system call, hardware switches to kernel mode; return from system call → user mode (set bit to 1)
    • Privileged instructions (only in kernel mode): I/O control, timer management, interrupt management, switching to kernel mode, modifying memory-management registers, halting
    • Attempt to execute a privileged instruction in user mode → hardware traps to OS
    • Modern CPUs: more than two modes (virtualisation: VMM mode; Intel rings 0–3)
