Term · Java, Java Lab, Operating Systems

Hash table

  • HashSet: backed by a hash table; no order; O(1) average add/contains/remove

From Java › Set Interface

  • Oracle SPARC Solaris (example): 64-bit, two hash tables (kernel, user); each entry is a TSB (translation storage buffer); TLB holds translation table entries (TTEs)

From Operating Systems › Structure of the Page Table

  • HashSet/HashMap: hash table — average \(O(1)\) add/get/remove; no order guarantee; uses hashCode() and equals(). LinkedHashSet/Map: insertion order. TreeSet/TreeMap: red-black tree — sorted order, \(O(\log n)\), needs Comparable or a Comparator; firstKey, floorKey, headMap…

From Java Lab › Task 11 — Collections: ArrayList, LinkedList, HashSet, HashMap, TreeMap

  • Directory implementation: linear list of file names with pointers to the data blocks — simple to program but time-consuming to execute (linear search to find a file: create and delete need the search; a software cache or a sorted list with binary search helps; or a B+ tree: NTFS); hash table — linear list with a hash data structure (decreases directory search time; collisions — situations where two file names hash to the same location; fixed size of the hash table, and the hash function depends on it → chained-overflow hash table; entry = linked list)

From Operating Systems › File-System Implementation — Structures and Operations

  1. Backed by a hash table (a HashMap inside); elements are placed by their hash code.
