Unit V

Collections Framework and Stream API

Object Oriented Programming Through Java · 24CS202

Syllabus: Collections overview, List, Set, Map, ArrayList, LinkedList, HashSet, HashMap, TreeMap. Stream basics, reduction operations, parallel streams, mapping, collecting, iterators and streams.

Part B questions for this unitPart A short questions

Topics in this unit

  1. Collections Framework — OverviewCollection = object that groups multiple elements into a single unit. Collections Framework (java.util, Java 2) = unified architecture of interfaces, …
  2. List InterfaceOrdered (insertion order), indexed (position 0…), allows duplicates and null
  3. ArrayListResizable array implementation of List. Capacity grows (about ×1.5) when full
  4. LinkedListDoubly-linked list implementation of List and Deque. Each node: data + prev + next
  5. Set InterfaceNo duplicate elements (uses equals()/hashCode()), at most one null (in HashSet). No index access
  6. HashSetUses hashing: element's hashCode() → bucket; then equals() to check duplicate. For custom classes override both equals and hashCode
  7. Map InterfaceMap<K,V> stores key → value pairs. Keys are unique; each key maps to at most one value; values may repeat
  8. HashMapHash table of buckets; hashCode() of key → bucket index; collisions: linked list → balanced tree when a bucket has more than 8 entries (Java 8)
  9. TreeMapSorted map (red-black tree), sorted by natural order of keys or a Comparator. O(log n)
  10. Iterators, Comparable and ComparatorIterator<E> — traverse a collection one element at a time: hasNext(), next(), remove(). ListIterator goes both directions and can add/set. for-each us…
  11. Queue, Deque, Stack, PriorityQueue (extra)Queue (FIFO): offer/add, poll/remove, peek/element
  12. Stream API — BasicsStream (java.util.stream, Java 8) = a sequence of elements supporting aggregate operations, processed in a pipeline. Not a data structure (doesn't sto…
  13. Reduction OperationsReduction = combine all elements into one result. count(), sum(), min(), max(), average() are special-case reductions; general: reduce
  14. Parallel StreamsParallel stream splits the data across multiple threads (Fork/Join common pool) and combines results. Make: list.parallelStream() or stream.parallel()…
  15. Mappingmap(Function) — transform each element 1-to-1 → new stream
  16. Collectingcollect(Collector) — mutable reduction: gather the elements into a collection, string, map etc. Collectors utility class
  17. Iterators and StreamsIterator = external iteration (you write the loop, hasNext/next). Stream = internal iteration (library runs the loop; can be parallel)
