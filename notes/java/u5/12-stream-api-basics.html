Stream API — Basics

Object Oriented Programming Through Java · Unit V: Collections Framework and Stream API

Stream API — Basics
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit V: Collections Framework and Stream API
Topic
12 of 17

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Stream (java.util.stream, Java 8) = a sequence of elements supporting aggregate operations, processed in a pipeline. Not a data structure (doesn't store elements); does not modify the source; consumable once; lazy
  • Pipeline = source → intermediate operations → terminal operation
  • Sources: list.stream(), Arrays.stream(arr), Stream.of(...), IntStream.range(1, 5), Stream.iterate(...), Stream.generate(...), Files.lines(...)
  • Intermediate (return a Stream, lazy): filter, map, flatMap, distinct, sorted, limit, skip, peek, mapToInt, boxed
  • Terminal (trigger the processing, return result): forEach, collect, reduce, count, min, max, sum, average, anyMatch, allMatch, noneMatch, findFirst, findAny, toArray, toList() (Java 16)
  • Primitive streams: IntStream, LongStream, DoubleStream — sum(), average(), range, rangeClosed
  • Stream vs collection: collection = stores data, external iteration; stream = computes, internal iteration, lazy
java
import java.util.*;
import java.util.stream.*;

public class StreamBasic {
    public static void main(String[] args) {
        List<Integer> nums = List.of(5, 2, 8, 1, 9, 4, 8);
        List<Integer> r = nums.stream().filter(n -> n % 2 == 0).map(n -> n * n).sorted().distinct().collect(Collectors.toList());
        System.out.println(r);
        System.out.println(nums.stream().count() + " " + nums.stream().mapToInt(Integer::intValue).sum());
        System.out.println(IntStream.rangeClosed(1, 5).sum() + " " + IntStream.range(0, 5).boxed().toList());
        nums.stream().limit(3).forEach(n -> System.out.print(n + " "));
        System.out.println();
        System.out.println(nums.stream().anyMatch(n -> n > 8) + " " + nums.stream().allMatch(n -> n > 1));
    }
}
  • Evens are 2, 8, 4, 8 → squares 4, 64, 16, 64 → sorted [4, 16, 64, 64] → distinct [4, 16, 64]
  • Output: [4, 16, 64], 7 37, 15 [0, 1, 2, 3, 4], 5 2 8, true false
Explanation

A stream is not a collection. It does not store data; it describes a pipeline of computations to run on a source. The pipeline has a source, any number of intermediate operations such as filter and map, and exactly one terminal operation such as collect, count or forEach. Intermediate operations are lazy: nothing happens until the terminal operation is called, and then each element passes through the whole pipeline in turn. A stream does not change its source, and once a terminal operation has run, the stream is used up and cannot be used again.

In the demonstration, the pipeline picks the even numbers (2, 8, 4, 8), squares them (4, 64, 16, 64), sorts and removes the duplicate (4, 16, 64). The IntStream and the similar primitive streams avoid boxing and provide sum and average directly.
