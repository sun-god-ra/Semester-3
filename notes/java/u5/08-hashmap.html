HashMap

Object Oriented Programming Through Java · Unit V: Collections Framework and Stream API

HashMap
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit V: Collections Framework and Stream API
Topic
8 of 17
Terms
Hash table, Linked list

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Hash table of buckets; hashCode() of key → bucket index; collisions: linked list → balanced tree when a bucket has more than 8 entries (Java 8)
  • Initial capacity 16, load factor 0.75, doubles when exceeded
  • Iteration order unpredictable
  • Key class must correctly implement equals and hashCode; keys should be immutable (e.g. String)
java
import java.util.*;

public class MapDemo {
    public static void main(String[] args) {
        Map<String, Integer> hm = new HashMap<>();
        hm.put("Ravi", 80); hm.put("Sita", 92); hm.put("Ravi", 85);   // overwrites
        System.out.println(hm.get("Ravi") + " " + hm.size() + " " + hm.getOrDefault("X", -1));
        for (Map.Entry<String, Integer> e : hm.entrySet())
            if (e.getKey().equals("Sita")) System.out.println(e.getKey() + "=" + e.getValue());
        Map<String, Integer> words = new TreeMap<>();
        for (String w : "to be or not to be".split(" ")) words.merge(w, 1, Integer::sum);
        System.out.println(words);
        System.out.println(words.containsKey("or") + " " + words.containsValue(5));
    }
}
  • Output: 85 2 -1, Sita=92, {be=2, not=1, or=1, to=2}, true false
Explanation

A map associates each key with one value. Keys are unique, so putting a second value with an existing key replaces the first, and put returns the old value. HashMap is the general-purpose implementation, using the hash of the key to find the bucket, and gives constant-time operations on average with no particular order. LinkedHashMap remembers insertion order, and TreeMap keeps the keys sorted and provides navigation methods like firstKey, headMap, floorKey and ceilingKey. Hashtable is the old synchronised class and does not allow nulls.

To traverse a map, use entrySet(), which gives key–value pairs together, and is faster than looping over keys and then calling get. The merge method is a neat way to count: words.merge(w, 1, Integer::sum) inserts 1 for a new word and adds 1 to the existing count otherwise.
