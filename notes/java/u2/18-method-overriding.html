Method Overriding

Object Oriented Programming Through Java · Unit II: Classes, Objects, Inheritance, and String Handling

Method Overriding
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit II: Classes, Objects, Inheritance, and String Handling
Topic
18 of 22
Terms
Checked exception, Polymorphism, JVM

Practice: Part B questions for Unit II and Part A short questions.

Notebook notes
  • Subclass defines a method with the same name, same parameters (signature) and compatible return type as in the superclass → overrides it. When called on a subclass object, the subclass version runs
  • Rules: same signature; return type same or covariant (subtype); access cannot be more restrictive (public → public); cannot override static, final, private methods; may throw fewer/narrower checked exceptions
  • Use @Override annotation (compile-time check)
  • Call the parent version with super.method()
  • Overloading vs overriding
Overloading Overriding
Where same class (or inherited) subclass vs superclass
Signature different parameters same
Binding compile time (static) run time (dynamic)
Return type can differ same / covariant
Polymorphism compile-time run-time
Explanation

When a subclass writes a method with the same signature as one in the superclass, it replaces the inherited behaviour for objects of the subclass. This is different from overloading, where the signatures differ and both methods remain available. Overriding must keep the access level at least as open as the original, and methods that are static, final or private cannot be overridden.

Dynamic dispatch is the real benefit. A variable of type Shape may refer to a Circle or a Square. When s.draw() is executed, the compiler cannot know which object s will hold, so the JVM looks at the actual object at run time and calls its version. This lets code written for the general type work on any specific subtype, including types added later, without being changed. Only instance methods behave this way. A field accessed through a Shape reference is the Shape field, whatever object is there.
