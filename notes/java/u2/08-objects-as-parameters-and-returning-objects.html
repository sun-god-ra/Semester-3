Objects as Parameters and Returning Objects

8 of 22
Terms
Polymorphism

Practice: Part B questions for Unit II and Part A short questions.

Notebook notes
  • Object passed → reference copied → method sees the same object (can change it). Used for comparing/copying objects
  • Method can return an object (return type = the class)
java
class Pt {
    int x, y;
    Pt(int x, int y) { this.x = x; this.y = y; }
    boolean same(Pt o) { return x == o.x && y == o.y; }
    Pt move(int dx, int dy) { return new Pt(x + dx, y + dy); }   // returns new object
}

public class ObjParam {
    public static void main(String[] args) {
        Pt a = new Pt(1, 2), b = new Pt(1, 2);
        System.out.println(a.same(b) + " " + (a == b));
        Pt c = a.move(3, 4);
        System.out.println(c.x + "," + c.y);
    }
}
  • Output: true false (same values, different objects) then 4,6
Explanation

Overloading means several methods with the same name in one class that differ in the number or the types of parameters. The compiler decides which one to call from the argument types, so it is called compile-time polymorphism. The return type is not part of the signature for this purpose, so two methods that differ only in return type are a compile error. When there is no exact match, Java looks for the nearest automatic conversion: calling test('A') with versions for int and double picks int, since char widens to int first.

Since an object variable holds a reference, passing an object to a method lets the method read and change the same object. This is why a.same(b) can compare the fields of two objects. Note that a == b compares the two references, which differ because they are two separate objects, even though their contents are equal.
