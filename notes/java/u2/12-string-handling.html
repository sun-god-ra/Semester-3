Practice: Part B questions for Unit II and Part A short questions.

Notebook notes
  • String = sequence of characters, object of java.lang.String. Immutable: once created, content cannot be changed; operations return a new String
  • Strings are not null-terminated char arrays; String is a class with many methods
  • String constructors
java
String s1 = new String();                        // empty
char[] c = {'J', 'a', 'v', 'a'};
String s2 = new String(c);                       // "Java"
String s3 = new String(c, 1, 2);                 // "av" (start, count)
String s4 = new String(s2);                      // copy
String s5 = "Java";                              // literal -> string pool
byte[] b = {65, 66, 67};
String s6 = new String(b);                       // "ABC"
  • String literal pool: "Java" == "Java" → true (same pooled object); new String("Java") == "Java" → false. Use equals() to compare content
  • Common methods
Method Use
length() number of characters
charAt(i) char at index
concat(s) or + join

compareTo(s) lexicographic: <0, 0, >0
substring(b), substring(b,e) part (e exclusive)
indexOf(x), lastIndexOf(x) position or −1
contains(s), startsWith(s), endsWith(s) tests
replace(a,b) replace chars / strings

split(regex) split to String[]
toCharArray(), getChars(...) to array
valueOf(x) any type → String
isEmpty(), isBlank()

intern() put in / get from pool
  • == compares references; equals() compares contents
java
public class StrDemo {
    public static void main(String[] args) {
        String a = "Java", b = "Java", c = new String("Java");
        System.out.println((a == b) + " " + (a == c) + " " + a.equals(c));
        String s = "Hello, World";
        System.out.println(s.length() + " " + s.charAt(4) + " " + s.indexOf("World")
                + " " + s.substring(7) + " " + s.substring(0, 5));
        System.out.println(s.toUpperCase() + " " + s.replace('l', 'L'));
        System.out.println("apple".compareTo("banana") + " " + "b".compareTo("a"));
        String[] parts = "a,b,c".split(",");
        System.out.println(parts.length + " " + String.join("-", parts));
        s.concat("!!");
        System.out.println(s);
    }
}
  • Output: true false true ; 12 o 7 World Hello ; HELLO, WORLD HeLLo, WorLd ; -1 1 ; 3 a-b-c ; Hello, World (unchanged: immutable)
Explanation

A String object is immutable. Methods such as concat or toUpperCase do not change it, they return a new string, which is why s.concat("!!") followed by printing s shows the old value. Immutability allows the JVM to share one object between all identical literals through the string pool, and it makes strings safe to use as keys and across threads. This also explains the == surprise. Two literals with the same text are the same pooled object, so == gives true, but new String("Java") creates a separate object, so == gives false though equals gives true. Always compare content with equals.

When you need many changes to a piece of text, such as building a result inside a loop, StringBuffer is the better choice, because it modifies one buffer in place instead of creating a new String for every step. It keeps a capacity larger than the length so that appends are cheap, and when the capacity is exceeded it grows to (old + 1) * 2. StringBuilder has the same methods but is not synchronised, so it is faster and should be used when only one thread touches the text.
