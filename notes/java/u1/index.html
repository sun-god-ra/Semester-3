Fundamental Java Programming Constructs

Object Oriented Programming Through Java · 24CS202

Syllabus: History and evolution of Java, features, bytecode, Java vs C/C++. Overview: OOP, two paradigms, principles of OOP, first program, two control statements, keywords. Data types, variables, arrays: primitive types, type conversion and casting, automatic promotion, arrays, operators.
