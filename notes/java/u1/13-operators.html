Notebook notes
Arithmetic
  • + - * / % ; ++ -- ; compound += -= *= /= %=
  • / on integers = integer division (truncates toward 0): 7/2 = 3, -7/2 = -3. % works on floating point too (5.5 % 2 = 1.5); sign of result = sign of dividend: -7 % 3 = -1
  • Integer divide by zero → ArithmeticException; floating by zero → Infinity / NaN
  • ++x (pre: increment then use), x++ (post: use then increment)
    • int x = 5; int y = x++ + ++x; → 5 + 7 = 12, x = 7
  • + also concatenates strings: "a" + 1 + 2 = "a12"; 1 + 2 + "a" = "3a"
Bitwise (on integer types)
  • ~ NOT, & AND, | OR, ^ XOR, << left shift, >> signed right shift (keeps sign), >>> unsigned right shift (fills 0)
  • x << n = \(x\times2^n\); x >> n = \(\lfloor x/2^n\rfloor\)
  • -8 >> 1 = −4 ; -8 >>> 28 = 15 (for int) ; 5 & 3 = 1, 5 | 3 = 7, 5 ^ 3 = 6, ~5 = −6
  • Shifts on byte/short are promoted to int first
Relational
  • == != > < >= <= → give boolean. == on references compares addresses, not content (use equals())
Boolean logical
  • & | ^ ! (non-short-circuit, evaluate both); && || short-circuit: right side not evaluated if result known
    • if (d != 0 && n / d > 2) — safe, no divide by zero
  • ==, !=, ?:, &=, |=, ^=
Assignment
  • = (right to left): a = b = c = 5; ; compound assignment gives implicit cast
Ternary ?:
  • expr1 ? expr2 : expr3 → int max = (a > b) ? a : b;
Others
  • instanceof, new, ., [], ( ) cast, lambda ->

  • Use parentheses to make order clear
java
public class OpDemo {
    public static void main(String[] args) {
        int a = 5, b = 3;
        System.out.println(a / b + " " + a % b + " " + (double) a / b);
        System.out.println((a & b) + " " + (a | b) + " " + (a ^ b) + " " + (~a));
        System.out.println((-8 >> 1) + " " + (-8 >>> 28) + " " + (a << 2));
        int x = 5;
        int y = x++ + ++x;
        System.out.println(x + " " + y);
        System.out.println("a" + 1 + 2);
        System.out.println(1 + 2 + "a");
        System.out.println(-7 % 3);
        System.out.println(5.5 % 2);
    }
}
  • Output (line by line): 1 2 1.6666666666666667 ; 1 7 6 -6 ; -4 15 20 ; 7 12 ; a12 ; 3a ; -1 ; 1.5
Explanation

Integer division truncates toward zero, so 5 / 3 is 1 and -7 / 2 is −3. The remainder operator takes the sign of the left operand, so -7 % 3 is −1. In Java % also works on floating-point numbers.

The prefix form of ++ increments and then uses the value, while the postfix form uses the value and then increments. In y = x++ + ++x with x = 5, the first operand gives 5 and makes x 6, then ++x makes it 7 and gives 7, so y = 12 and x = 7.

For bit shifts, >> fills with the sign bit, so a negative number stays negative, and >>> fills with zeros. The value −8 is 11111111 11111111 11111111 11111000 as a 32-bit int; shifting right by 28 with >>> leaves the top four bits 1111, which is 15.

The operators && and || stop evaluating as soon as the result is known, so in d != 0 && n / d > 2 the division is never attempted when d is zero. The non-short-circuit forms & and | always evaluate both sides. Finally, the + operator concatenates when either operand is a string. Evaluation goes left to right, so "a" + 1 + 2 gives a12 but 1 + 2 + "a" gives 3a.
