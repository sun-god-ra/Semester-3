Object Oriented Programming Through Java · Unit I: Fundamental Java Programming Constructs

Type Conversion and Casting
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit I: Fundamental Java Programming Constructs
Topic
11 of 13

Practice: Part B questions for Unit I and Part A short questions.

On this page
  1. Automatic (widening) conversion
  2. Casting (narrowing) conversion
  3. Automatic type promotion in expressions
Notebook notes
Automatic (widening) conversion
  • Done by Java when both types compatible and destination is larger: byte → short → int → long → float → double; char → int
  • int to float/long to double: may lose precision but allowed
  • No automatic conversion between numeric and char/boolean
java
int i = 100;
long l = i;      // widening, automatic
double d = l;    // widening
Casting (narrowing) conversion
  • Manual, may lose information: (target-type) value
  • int to byte: value mod 256 (keeps low 8 bits)
  • Floating → integer: truncates the fraction (no rounding)
java
public class CastDemo {
    public static void main(String[] args) {
        byte b;
        int i = 257;
        double d = 323.142;
        System.out.println("int -> byte");
        b = (byte) i;
        System.out.println("i = " + i + " b = " + b);
        System.out.println("double -> int");
        i = (int) d;
        System.out.println("d = " + d + " i = " + i);
        System.out.println("double -> byte");
        b = (byte) d;
        System.out.println("d = " + d + " b = " + b);
    }
}
  • Output: i = 257 b = 1 ; d = 323.142 i = 323 ; d = 323.142 b = 67 (323 mod 256 = 67)
Automatic type promotion in expressions
  • In an expression, byte, short (and char) are promoted to int before evaluation
  • If an operand is long → whole expression long; float → float; double → double
  • So byte a = 40, b = 50; byte c = a * b; → error (result is int). Fix: byte c = (byte)(a * b);
  • short s = 1; s = s + 1; → error, but s += 1; and s++ are fine (compound assignment has implicit cast)
  • char c = 'a'; c++; fine. char c2 = 'a' + 1; fine (constant expression fits). int x = 'a' + 1; → 98
Operand types Result
byte, short, char with byte, short, char int
any with long long
any with float float
any with double double
Explanation

When a value is assigned to a variable of a wider type (for example an int to a long), Java converts it automatically, because no information can be lost. When the target is narrower, you must write a cast, which tells the compiler that you accept the possible loss. Casting an int to a byte keeps only the lowest 8 bits, which is the same as taking the value modulo 256, so 257 becomes 1. Casting a double to an int drops the fractional part without rounding, so 323.142 becomes 323. Casting that double to a byte first truncates to 323 and then keeps the low 8 bits, giving 67.

During evaluation of an expression, byte, short and char operands are first promoted to int. This is why byte c = a * b; does not compile even when both are bytes: the product is an int and the narrowing needs an explicit cast. The compound operators such as += contain an implicit cast, so s += 1 works for a short while s = s + 1 does not.
