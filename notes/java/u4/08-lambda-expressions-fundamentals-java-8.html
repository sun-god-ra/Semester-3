Object Oriented Programming Through Java · Unit IV: Multithreading and Lambda Expressions

Lambda Expressions — Fundamentals (Java 8)
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit IV: Multithreading and Lambda Expressions
Topic
8 of 14
Terms
Lambda expression, Functional interface, Inner class

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes
  • Lambda expression = anonymous method (no name, no return type declared). A short way to give behaviour as data. Supports functional programming style
  • Lambda needs a target type: a functional interface
  • Functional interface: an interface with exactly one abstract method (SAM). May contain default/static methods. Optional annotation @FunctionalInterface. Examples: Runnable, Comparator, Callable, ActionListener
  • Syntax: (parameters) -> expression or (parameters) -> { statements; }
  • The arrow operator -> (lambda operator) splits left (parameters) and right (body)
  • Forms
    • no parameter: () -> 42
    • one parameter: n -> n % 2 == 0 (parentheses optional); with type (int n) -> ...
    • multiple: (a, b) -> a + b
    • parameter types inferred from the functional interface; if you declare one, declare all
java
interface MyNumber { double getValue(); }
interface NumTest { boolean test(int n); }

public class LambdaDemo {
    public static void main(String[] args) {
        MyNumber pi = () -> 3.1415;
        System.out.println(pi.getValue());
        NumTest isEven = n -> n % 2 == 0;
        System.out.println(isEven.test(10) + " " + isEven.test(9));
        NumTest nonNeg = (n) -> n >= 0;
        System.out.println(nonNeg.test(-1));
    }
}
  • Output: 3.1415, true false, false
  • The lambda is executed when the interface method is called (pi.getValue())
Explanation

A lambda expression is a short anonymous function. Before Java 8, to pass a piece of behaviour to a method you had to write an anonymous inner class with several lines of ceremony. A lambda replaces that with just the parameters, an arrow, and the body. It can only be used where the expected type is a functional interface, an interface with exactly one abstract method. The compiler matches the lambda to that single method, infers the parameter types from the interface, and runs the body when the method is called.

For example, n -> n % 2 == 0 is accepted for a NumTest interface because that interface has a single method boolean test(int n). If the interface had two abstract methods, the compiler would not know which one the lambda stands for.
