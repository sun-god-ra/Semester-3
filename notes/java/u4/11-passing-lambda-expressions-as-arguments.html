Passing Lambda Expressions as Arguments

Object Oriented Programming Through Java · Unit IV: Multithreading and Lambda Expressions

Passing Lambda Expressions as Arguments
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit IV: Multithreading and Lambda Expressions
Topic
11 of 14
Terms
Functional interface

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes
  • A lambda can be passed wherever the parameter type is a functional interface → pass behaviour to a method
  • Also used with collections: list.forEach(x -> ...), removeIf, sort((a,b)->...), streams
java
import java.util.*;
import java.util.function.*;

public class LambdaArg {
    static String stringOp(Function<String, String> f, String s) { return f.apply(s); }
    static int apply(BinaryOperator<Integer> op, int a, int b) { return op.apply(a, b); }

    public static void main(String[] args) {
        System.out.println(stringOp(String::toUpperCase, "java"));
        System.out.println(stringOp(s -> s.replace(' ', '-'), "a b c"));
        System.out.println(apply((x, y) -> x * y, 6, 7));
        List<Integer> nums = new ArrayList<>(List.of(5, 2, 8, 1));
        nums.sort((a, b) -> b - a);
        System.out.println(nums);
        nums.removeIf(n -> n < 3);
        nums.forEach(n -> System.out.print(n + " "));
        System.out.println();
    }
}
  • Output: JAVA, a-b-c, 42, [8, 5, 2, 1], 8 5
Explanation

The real value of lambdas is in passing behaviour to other methods. A sort method can take the comparison rule, a filter can take the condition and a loop can take the action for each element. In the example, the same method stringOp converts to upper case or replaces spaces, depending on the lambda supplied.
