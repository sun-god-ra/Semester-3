Method References

Object Oriented Programming Through Java · Unit IV: Multithreading and Lambda Expressions

Method References
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit IV: Multithreading and Lambda Expressions
Topic
14 of 14
Terms
Method reference, Functional interface, Constructor, Inner class

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes
  • Method reference: shorthand for a lambda that just calls an existing method. Operator :: (double colon). Works with a functional interface whose signature matches
  • Four kinds
Kind Syntax Lambda equivalent
Static method ClassName::staticMethod x -> ClassName.staticMethod(x)
Instance method of a particular object object::method x -> object.method(x)
Instance method of an arbitrary object of a type ClassName::instanceMethod (a, b) -> a.instanceMethod(b)
Constructor ClassName::new () -> new ClassName()
java
import java.util.*;
import java.util.function.*;

class Utils {
    static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i * i <= n; i++) if (n % i == 0) return false;
        return true;
    }
    boolean longer(String a, String b) { return a.length() > b.length(); }
}

public class MethodRef {
    public static void main(String[] args) {
        Predicate<Integer> p = Utils::isPrime;                       // static
        System.out.println(p.test(7) + " " + p.test(8));
        Utils u = new Utils();
        BiPredicate<String, String> bp = u::longer;                  // particular object
        System.out.println(bp.test("hello", "hi"));
        Function<String, Integer> len = String::length;              // arbitrary object
        System.out.println(len.apply("lambda"));
        Supplier<ArrayList<String>> sup = ArrayList::new;            // constructor
        ArrayList<String> l = sup.get();
        l.add("x");
        System.out.println(l);
        List.of("b", "a", "c").stream().sorted(String::compareTo).forEach(System.out::print);
        System.out.println();
    }
}
  • Output: true false, true, 6, [x], abc
  • Anonymous inner class vs lambda: lambda is shorter, no new scope (this = enclosing), compiled to invokedynamic; anonymous class can implement interfaces with many methods and has its own this
Explanation

A method reference is a shorter way of writing a lambda that does nothing but call an existing method. String::length stands for s -> s.length(). There are four kinds: a static method (Utils::isPrime), an instance method on a given object (u::longer), an instance method on whichever object is the first argument (String::length), and a constructor (ArrayList::new). To choose the right form, ask what the first lambda parameter would be: if it is the object on which the method is called, use the class name form; if the method is static, the parameters are all arguments.
