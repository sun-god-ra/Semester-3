Unit III

Packages and Interfaces, Exception Handling, and IO Streams

Object Oriented Programming Through Java · 24CS202

Syllabus: Packages, CLASSPATH, access, importing, interfaces, nested interfaces, variables in interfaces. Exception handling fundamentals, types, try/catch, multiple catch, throw, throws, finally, custom exceptions. Byte streams and character streams.

Part B questions for this unitPart A short questions

Topics in this unit

  1. PackagesPackage = container (namespace) for related classes and interfaces. Avoids name clashes, gives access protection, organises code. Maps to a directory …
  2. CLASSPATHCLASSPATH = list of directories / JAR files where JVM and javac look for classes and packages
  3. Access ProtectionFour access levels (visibility of class members)
  4. Importing Packagesimport statement after package, before class: brings classes into scope so we don't need the full name
  5. InterfacesInterface = a completely abstract type: specifies what a class must do, not how. Contains method declarations and constants. Achieves full abstraction…
  6. Nested Interfaces and Variables in InterfacesNested interface: an interface declared inside a class or another interface. Can be public, protected, private, or default when nested in a class; imp…
  7. Exception Handling — FundamentalsException = abnormal condition / run-time error that disrupts normal flow. Is an object describing the error, created and thrown at the point of error
  8. Exception Types — Hierarchymermaid
  9. `try` and `catch`try block encloses code to monitor; catch blocks handle. If exception occurs in try, rest of the try block skipped, control goes to the matching catch…
  10. Multiple `catch` ClausesSeveral catch blocks after one try, each for a different type. First matching catch runs; others skipped
  11. `throw`Explicitly throw an exception: throw ThrowableInstance; — instance must be of type Throwable (or subclass)
  12. `throws`Declares in the method signature that the method may throw a checked exception which it does not handle; the caller must handle or redeclare
  13. `finally`finally block always executes after try/catch — whether exception occurred or not, even with return, break, continue in try or catch. Used to release …
  14. Custom (User-Defined) ExceptionsCreate by extending Exception (checked) or RuntimeException (unchecked). Usually just constructors and a toString() / message
  15. Streams — Introduction to Java I/OStream = abstraction of a sequence of data flowing between a program and a source/destination (file, keyboard, network, memory). A stream is linked to…
  16. Byte StreamsInputStream methods: int read() (returns 0–255, or −1 at end), read(byte[]), available(), skip(n), mark/reset, close()
  17. Character StreamsReader: int read() (char as 0–65535 or −1), read(char[]), skip, close. Writer: write(int), write(String), write(char[]), append, flush, close
