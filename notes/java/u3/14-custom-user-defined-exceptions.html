Custom (User-Defined) Exceptions

Object Oriented Programming Through Java · Unit III: Packages and Interfaces, Exception Handling, and IO Streams

Custom (User-Defined) Exceptions
Subject
Object Oriented Programming Through Java (24CS202)
Unit
Unit III: Packages and Interfaces, Exception Handling, and IO Streams
Topic
14 of 17
Terms
Constructor, Checked exception

Practice: Part B questions for Unit III and Part A short questions.

Notebook notes
  • Create by extending Exception (checked) or RuntimeException (unchecked). Usually just constructors and a toString() / message
  • Use when built-in ones don't describe the problem (e.g. InsufficientFundsException, InvalidAgeException)
java
class InvalidAgeException extends Exception {
    private int age;
    InvalidAgeException(int age) { super("Invalid age: " + age); this.age = age; }
    int getAge() { return age; }
}

public class CustomEx {
    static void check(int age) throws InvalidAgeException {
        if (age < 18) throw new InvalidAgeException(age);
        System.out.println("Eligible");
    }
    public static void main(String[] args) {
        try {
            check(20);
            check(15);
        } catch (InvalidAgeException e) {
            System.out.println(e.getMessage() + " (" + e.getAge() + ")");
        } finally {
            System.out.println("done");
        }
    }
}
  • Output: Eligible, Invalid age: 15 (15), done
  • Chained exception: new RuntimeException("high level", cause); read with getCause()
  • Best practices: catch specific exceptions; never leave catch block empty; clean up in finally / try-with-resources; don't use exceptions for normal flow control
Explanation

When none of the standard classes describes the error, you write your own by extending Exception (for a checked exception) or RuntimeException (for an unchecked one). Pass a message to the superclass constructor so that getMessage() works. In the example, the check method declares throws InvalidAgeException, so the caller has to handle it, and the program prints the message and then still runs finally.
