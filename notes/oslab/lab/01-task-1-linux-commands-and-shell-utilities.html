Notebook notes
  • Aim: Use the common Linux commands, filters, redirection and pipes, and write shell scripts with variables, conditions, loops and functions.
  • Theory
    • The shell (bash) reads a command, finds the program (searching the directories in $PATH), creates a child with fork(), runs it with exec() and waits (wait()) — see Unit I. Everything is a file in UNIX; every process has three open files: stdin (0), stdout (1), stderr (2)
    • File permissions: 10 characters -rwxr-xr--: type, then user/group/others; octal chmod 754 = rwx r-x r--. Pipe a | b connects stdout of a to stdin of b. $? = exit status (0 = success), $# = number of arguments, $1 ... $9 = arguments, $$ = PID
    • Script header: #!/bin/bash and make it executable with chmod +x script.sh; run with ./script.sh args
  • Algorithm
    • Open the terminal and try each command of the table on a scratch directory
    • Combine commands with pipes and redirection
    • Write the scripts below, make them executable and run them with arguments

Program 1 — Commands in a script
bash
#!/bin/bash
# Task 1: Linux commands demo (run in a scratch directory)
set -e
rm -rf lab && mkdir lab && cd lab
printf "banana\napple\ncherry\napple\nbanana\napple\n" > fruits.txt
echo "== cat, wc, head, tail =="
cat fruits.txt | head -3
tail -2 fruits.txt
wc -l fruits.txt
echo "== sort | uniq -c | sort -nr =="
sort fruits.txt | uniq -c | sort -nr
echo "== grep, cut, tr, sed, awk =="
grep -c apple fruits.txt
grep -n "an" fruits.txt
echo "a:b:c" | cut -d: -f2
echo "hello" | tr 'a-z' 'A-Z'
sed 's/apple/mango/' fruits.txt | head -2
awk '{ n[$1]++ } END { for (k in n) print k, n[k] }' fruits.txt | sort
echo "== files and permissions =="
mkdir -p dir1/dir2
cp fruits.txt dir1/copy.txt
mv dir1/copy.txt dir1/dir2/moved.txt
ls dir1/dir2
chmod 640 fruits.txt
stat -c "%a %n" fruits.txt
find . -name "*.txt" | sort
ls -R | head -8
rm -r dir1
ls
echo "== redirection and pipes =="
echo "first" > out.txt
echo "second" >> out.txt
cat out.txt
ls nofile 2> err.txt || echo "ls failed, exit status $?"
wc -c < err.txt | awk '{ print ($1 > 0) ? "error message was redirected to err.txt" : "no error text" }'
echo "== variables, arithmetic, loop =="
x=7; y=3
echo "sum=$((x+y)) product=$((x*y)) remainder=$((x%y))"
for i in 1 2 3; do echo -n "$i "; done; echo
echo "exit status of last command: $?"

Program 2 — Shell programming
bash
#!/bin/bash
# Task 1 (shell programming): arguments, conditions, loops, functions
fact() { local n=$1 f=1; while [ $n -gt 1 ]; do f=$((f*n)); n=$((n-1)); done; echo $f; }
isprime() { local n=$1 i=2; [ $n -lt 2 ] && return 1; while [ $((i*i)) -le $n ]; do [ $((n%i)) -eq 0 ] && return 1; i=$((i+1)); done; return 0; }
echo "script name check: number of arguments = $#, first = $1"
echo "factorial of 5 = $(fact 5)"
a=0; b=1; printf "fibonacci:"; for ((k=0;k<10;k++)); do printf " %d" $a; t=$((a+b)); a=$b; b=$t; done; echo
printf "primes up to 30:"; for n in $(seq 2 30); do isprime $n && printf " %d" $n; done; echo
n=153; s=0; t=$n; while [ $t -gt 0 ]; do d=$((t%10)); s=$((s+d*d*d)); t=$((t/10)); done
[ $s -eq $n ] && echo "$n is an Armstrong number" || echo "$n is not an Armstrong number"
case "$1" in
  start) echo "starting" ;;
  stop)  echo "stopping" ;;
  *)     echo "usage: $0 start|stop" ;;
esac
if [ -f /etc/passwd ] && [ -r /etc/passwd ]; then echo "/etc/passwd exists and is readable"; fi

    • What does chmod 754 file do? What is umask 022? (new files get 644, directories 755)
    • What is the difference between a hard link and a symbolic link?
    • Explain ps -ef | grep java | wc -l
    • What is $$, $?, $#, $@? What does #!/bin/bash do?
Explanation

The first script makes a scratch directory and uses the common commands. sort | uniq -c | sort -nr is the standard idiom for counting how many times each line occurs. The numbers 3 apple, 2 banana, 1 cherry come from the file. grep -n prints the line numbers, cut -d: -f2 picks the second field and tr changes the case. awk keeps an associative array of counts. chmod 640 gives rw- to the owner, r-- to the group and nothing to others, which stat shows as 640. 2> sends error messages to a file, and $? shows the exit status 2 of the failed ls. In the second script, the functions use local variables, $((...)) for arithmetic, and while loops to compute the factorial, the first ten Fibonacci numbers, the primes (trial division up to \(\sqrt{n}\)) and an Armstrong number test (153 = 1³ + 5³ + 3³). The case statement matches the first argument.
