Task 8 — Producer–consumer problem using semaphores

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 8 — Producer–consumer problem using semaphores
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
8 of 17
Terms
Semaphore, Mutex, POSIX, Deadlock
Notebook notes
  • Aim: Implement the bounded-buffer problem with POSIX semaphores and a mutex.
  • Theory
    • Semaphores: empty (initial = buffer size), full (initial = 0), and a mutex (initial = 1). Producer: wait(empty); wait(mutex); insert; signal(mutex); signal(full). Consumer: wait(full); wait(mutex); remove; signal(mutex); signal(empty). The order of wait(empty) and wait(mutex) must not be reversed (deadlock). POSIX: sem_init, sem_wait, sem_post
  • Algorithm
    • Initialise empty = SIZE, full = 0
    • Producer thread: for each item sem_wait(empty), lock, store at in, in=(in+1)%SIZE, unlock, sem_post(full)
    • Consumer thread: sem_wait(full), lock, take from out, out=(out+1)%SIZE, unlock, sem_post(empty)
    • Compare the sums of produced and consumed items and check the buffer limit
c
/* Task 8: producer-consumer (bounded buffer) with POSIX semaphores */
#include <stdio.h>
#include <pthread.h>
#include <semaphore.h>
#define SIZE 5
#define ITEMS 20
int buffer[SIZE], in = 0, out = 0;
sem_t empty, full;
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
long produced_sum = 0, consumed_sum = 0;
int max_in_buffer = 0, count = 0;

void *producer(void *a) {
    for (int i = 1; i <= ITEMS; i++) {
        sem_wait(&empty);                    /* wait for an empty slot */
        pthread_mutex_lock(&mutex);
        buffer[in] = i; in = (in + 1) % SIZE; produced_sum += i;
        count++; if (count > max_in_buffer) max_in_buffer = count;
        pthread_mutex_unlock(&mutex);
        sem_post(&full);                     /* one more full slot */
    }
    return NULL;
}
void *consumer(void *a) {
    for (int i = 1; i <= ITEMS; i++) {
        sem_wait(&full);
        pthread_mutex_lock(&mutex);
        int item = buffer[out]; out = (out + 1) % SIZE; consumed_sum += item;
        count--;
        pthread_mutex_unlock(&mutex);
        sem_post(&empty);
    }
    return NULL;
}
int main() {
    pthread_t p, c;
    sem_init(&empty, 0, SIZE);               /* SIZE empty slots */
    sem_init(&full, 0, 0);                   /* no full slots */
    pthread_create(&p, NULL, producer, NULL);
    pthread_create(&c, NULL, consumer, NULL);
    pthread_join(p, NULL); pthread_join(c, NULL);
    printf("buffer size = %d, items = %d\n", SIZE, ITEMS);
    printf("sum produced = %ld, sum consumed = %ld\n", produced_sum, consumed_sum);
    printf("never more than %d items in buffer: %s\n", SIZE, max_in_buffer <= SIZE ? "OK" : "VIOLATED");
    printf("items left in buffer = %d\n", count);
    return 0;
}

Output

text
buffer size = 5, items = 20
sum produced = 210, sum consumed = 210
never more than 5 items in buffer: OK
items left in buffer = 0
  • Viva questions
    • What happens if the producer waits on mutex before empty?
    • Which semaphore blocks the consumer on an empty buffer?
    • Why is the mutex needed in addition to the semaphores?
    • Binary vs counting semaphore?
    • What is a circular buffer?
Explanation

The producer creates the numbers 1 to 20 and the consumer adds them, so both sums must be 210. The semaphore empty stops the producer when all 5 slots are full, and full stops the consumer when the buffer is empty. The mutex ensures that only one thread changes in, out and the counter at a time. The program checks that the buffer never holds more than 5 items and that it is empty at the end.
