Task 12 — Memory allocation: first fit, best fit, worst fit

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 12 — Memory allocation: first fit, best fit, worst fit
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
12 of 17
Terms
External fragmentation, Internal fragmentation
Notebook notes
  • Aim: Simulate the three contiguous memory-allocation strategies.
  • Theory
    • First fit: the first hole big enough; best fit: the smallest hole that is big enough (smallest leftover); worst fit: the largest hole (largest leftover). Leftover holes cause external fragmentation; unused space inside an allocated block is internal fragmentation
  • Algorithm
    • For each process in order, scan the list of holes
    • First fit: stop at the first hole ≥ size; best fit: remember the smallest such hole; worst fit: remember the largest hole
    • Allocate, reduce the hole by the size; if no hole fits the process waits
c
/* Task 12: memory allocation strategies: first fit, best fit, worst fit */
#include <stdio.h>
#include <string.h>
#define H 5
#define PRC 4
void run(const char *name, int strategy) {          /* 0 first, 1 best, 2 worst */
    int hole[H] = {100, 500, 200, 300, 600}, proc[PRC] = {212, 417, 112, 426};
    printf("%s:\n", name);
    for (int i = 0; i < PRC; i++) {
        int k = -1;
        for (int j = 0; j < H; j++) {
            if (hole[j] < proc[i]) continue;
            if (k < 0) k = j;
            else if (strategy == 1 && hole[j] < hole[k]) k = j;
            else if (strategy == 2 && hole[j] > hole[k]) k = j;
            if (strategy == 0) break;
        }
        if (k < 0) printf("  process %d K must wait\n", proc[i]);
        else { printf("  process %d K -> hole %d (%d K), leftover %d K\n", proc[i], k + 1, hole[k], hole[k] - proc[i]); hole[k] -= proc[i]; }
    }
    printf("  holes now:");
    for (int j = 0; j < H; j++) printf(" %d", hole[j]);
    printf("\n\n");
}
int main() {
    printf("Holes (K): 100 500 200 300 600; processes: 212 417 112 426\n\n");
    run("First fit", 0); run("Best fit", 1); run("Worst fit", 2);
    return 0;
}

  • Viva questions
    • Which strategy is generally the best and fastest? (first fit and best fit)
    • What is external fragmentation and how does compaction solve it?
    • What is the 50-percent rule?
    • Which strategy leaves the smallest leftover?
    • Difference between internal and external fragmentation?
Explanation

With holes of 100, 500, 200, 300 and 600 K and processes of 212, 417, 112 and 426 K, the best fit places all four processes, while the first fit and the worst fit cannot place the 426 K process. This is the example of Unit IV.
