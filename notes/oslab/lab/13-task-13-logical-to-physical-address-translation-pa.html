Task 13 — Logical to physical address translation (paging and segmentation)

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 13 — Logical to physical address translation (paging and segmentation)
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
13 of 17
Terms
Page table, Paging, Segmentation, TLB
Notebook notes
  • Aim: Translate logical addresses into physical addresses using a page table and a segment table.
  • Theory
    • Paging: \(\text{page}=\lfloor \text{logical}/\text{page size}\rfloor\), \(\text{offset}=\text{logical}\bmod\text{page size}\), \(\text{physical}=\text{frame}\times\text{page size}+\text{offset}\); a page number beyond the table is an invalid reference → trap. Segmentation: address = (segment, offset); if offset < limit then physical = base + offset, else trap
  • Algorithm
    • Divide the logical address by the page size to get the page number and offset
    • Look up the frame in the page table
    • Compute the physical address; check the validity
    • For segments compare the offset with the limit and add the base
c
/* Task 13: logical to physical address translation using paging (and segmentation) */
#include <stdio.h>
int main() {
    int page_size = 1024;                              /* bytes */
    int page_table[] = {5, 6, 1, 7, 2, 0, 3, 4};      /* page -> frame, 8 pages */
    int logical[] = {0, 1023, 1024, 3000, 5000, 7167, 8192};
    printf("Paging: page size = %d, %d pages\n", page_size, (int)(sizeof page_table / sizeof *page_table));
    printf("logical  page offset frame physical\n");
    for (int i = 0; i < 7; i++) {
        int p = logical[i] / page_size, d = logical[i] % page_size;
        if (p >= 8) { printf("%7d  %4d %6d  -> invalid page: trap (addressing error)\n", logical[i], p, d); continue; }
        int pa = page_table[p] * page_size + d;
        printf("%7d  %4d %6d %5d %8d\n", logical[i], p, d, page_table[p], pa);
    }
    printf("\nSegmentation: segment table (base, limit)\n");
    int base[] = {1400, 6300, 4300, 3200, 4700}, limit[] = {1000, 400, 400, 1100, 1000};
    int sg[][2] = {{2, 53}, {3, 852}, {0, 1222}, {1, 399}};
    for (int i = 0; i < 4; i++) {
        int s = sg[i][0], d = sg[i][1];
        if (d >= limit[s]) printf("(%d,%d) -> offset beyond limit %d: trap\n", s, d, limit[s]);
        else printf("(%d,%d) -> %d + %d = %d\n", s, d, base[s], d, base[s] + d);
    }
    return 0;
}

  • Viva questions
    • What is the MMU?
    • Why is the page size a power of 2? (bit-splitting)
    • Difference between paging and segmentation?
    • What is a TLB?
    • Calculate the physical address for logical 3000 with page size 1024 and page 2 → frame 1 (1976)
Explanation

The logical address 3000 is page 2 (3000 / 1024) with offset 952; page 2 is in frame 1, so the physical address is 1×1024 + 952 = 1976. The address 8192 is page 8, which is not in the table of 8 pages, so the hardware traps. For the segment table of Unit IV, byte 53 of segment 2 is at 4300 + 53 = 4353 and byte 1222 of segment 0 exceeds its limit of 1000, so there is a trap.
