Task 3 — UNIX system calls: process and file

Task 3 — UNIX system calls: process and file
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
3 of 17
Terms
System call, Zombie process
On this page
  1. Program 1 — fork, exec, wait
  2. Program 2 — File system calls
Notebook notes
  • Aim: Use the process-related (fork, exec, wait, exit, getpid) and file-related (open, read, write, lseek, close, stat, chmod, unlink) system calls in C.
  • Theory
    • fork() creates a child (copy of the parent); returns 0 in the child, the child's pid in the parent, −1 on error. exec family (execl, execlp, execv…) replaces the process image with a new program; it returns only on failure. wait(&status) blocks the parent until a child ends; WEXITSTATUS(status) gives the exit code. exit(n) ends the process. A child that ends before the parent calls wait = zombie; a child whose parent ended = orphan (adopted by init)
    • File calls: fd = open(name, flags, mode) returns a file descriptor (0, 1, 2 are taken: stdin, stdout, stderr); read(fd, buf, n), write(fd, buf, n) return the number of bytes; lseek(fd, offset, whence) (SEEK_SET, SEEK_CUR, SEEK_END); close(fd); stat(name, &st) gives size and mode; chmod, unlink (delete), access
    • \(n\) consecutive fork() calls give \(2^n\) processes in all (see Unit II)
  • Algorithm
    • Call fork(); the child runs exec, the parent calls wait and prints the status
    • Create a file with open(O_CREAT), write, close; reopen, read, lseek, read; stat; chmod; unlink
Program 1 — fork, exec, wait
c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int main() {
    printf("Parent: calling fork()\n");
    fflush(stdout);
    pid_t pid = fork();
    if (pid < 0) { perror("fork"); exit(1); }
    if (pid == 0) {                       /* child */
        printf("Child : fork returned 0, now running 'echo' with exec\n");
        fflush(stdout);
        execlp("echo", "echo", "hello from exec", (char *)NULL);
        perror("exec");                   /* reached only if exec fails */
        exit(2);
    } else {                              /* parent */
        int status;
        wait(&status);
        printf("Parent: child finished, exit status = %d\n", WEXITSTATUS(status));
    }
    /* fork count: 3 forks in a row give 2^3 = 8 processes */
    return 0;
}

Output

text
Parent: calling fork()
Child : fork returned 0, now running 'echo' with exec
hello from exec
Parent: child finished, exit status = 0
Program 2 — File system calls
c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>

int main() {
    const char *msg = "Operating Systems Lab\nsystem calls\n";
    int fd = open("demo.txt", O_CREAT | O_WRONLY | O_TRUNC, 0644);
    if (fd < 0) { perror("open"); return 1; }
    ssize_t w = write(fd, msg, strlen(msg));
    printf("write() wrote %zd bytes\n", w);
    close(fd);

    fd = open("demo.txt", O_RDONLY);
    char buf[16];
    ssize_t n = read(fd, buf, 9);
    buf[n] = '\0';
    printf("read() returned %zd bytes: \"%s\"\n", n, buf);
    off_t pos = lseek(fd, 10, SEEK_SET);          /* skip to byte 10 */
    n = read(fd, buf, 6); buf[n] = '\0';
    printf("lseek() to %ld, then read: \"%s\"\n", (long)pos, buf);
    close(fd);

    struct stat st;
    stat("demo.txt", &st);
    printf("stat(): size = %ld bytes, mode = %o\n", (long)st.st_size, st.st_mode & 0777);
    chmod("demo.txt", 0600);
    stat("demo.txt", &st);
    printf("after chmod: mode = %o\n", st.st_mode & 0777);
    unlink("demo.txt");                           /* delete the file */
    printf("exists after unlink? %s\n", access("demo.txt", F_OK) == 0 ? "yes" : "no");
    return 0;
}

Output

text
write() wrote 35 bytes
read() returned 9 bytes: "Operating"
lseek() to 10, then read: "System"
stat(): size = 35 bytes, mode = 644
after chmod: mode = 600
exists after unlink? no
  • Viva questions
    • What does fork() return in the parent and in the child?
    • Difference between fork() and exec()?
    • What is a zombie process? An orphan?
    • What is a file descriptor? Which are 0, 1, 2?
    • How many processes after fork(); fork(); fork();? (8)
Explanation

In program 1, fork() makes a child that runs echo through execlp, which replaces the child's code, and the parent waits for it with wait. The exit status 0 shows success. The output order is fixed because the parent waits. In program 2, open with O_CREAT creates the file and returns a descriptor, write returns the number of bytes (35), and read reads 9 bytes (Operating). lseek(fd, 10, SEEK_SET) moves the position to byte 10, so the next read gives System. stat gives the size and the permission bits (644 = rw-r--r--), chmod changes it to 600, and unlink removes the directory entry.
