Task 6 — Real-time scheduling: Earliest Deadline First (EDF) and Rate Monotonic (RMS)

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 6 — Real-time scheduling: Earliest Deadline First (EDF) and Rate Monotonic (RMS)
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
6 of 17
Terms
Real-time
Notebook notes
  • Aim: Simulate RMS and EDF for periodic tasks and check the deadlines.
  • Theory
    • A periodic task has period \(p\), burst \(t\), and its deadline is the end of the period. RMS: static priority — shorter period = higher priority; preemptive; schedulable if \(U=\sum t_i/p_i\le N(2^{1/N}-1)\) (0.828 for 2 tasks) — a sufficient test, not necessary. EDF: dynamic priority — the task with the earliest absolute deadline runs; optimal: schedulable if \(U\le1\)
  • Algorithm
    • At each time unit \(t\), release a new job of task \(i\) if \(t\) is a multiple of \(p_i\) (if the previous job is unfinished, report a missed deadline)
    • Choose among the ready jobs: RMS — the smallest period; EDF — the earliest absolute deadline
    • Run it for one unit; record the schedule over the hyper-period (LCM of the periods = 400 here; 200 shown)
c
/* Task 6: real-time scheduling simulation, RMS and EDF, unit time steps over the hyper-period */
#include <stdio.h>
#define N 2
int main() {
    int period[N] = {50, 80}, burst[N] = {25, 35};
    double u = 0;
    for (int i = 0; i < N; i++) u += (double)burst[i] / period[i];
    printf("P1: p=50 t=25, P2: p=80 t=35, utilisation = %.4f\n", u);
    printf("RMS bound for 2 tasks = 0.8284, EDF bound = 1.0\n");
    for (int mode = 0; mode < 2; mode++) {            /* 0 = RMS, 1 = EDF */
        printf("\n%s schedule over 0..200:\n", mode == 0 ? "Rate-monotonic" : "Earliest deadline first");
        int rem[N] = {0, 0}, dl[N] = {0, 0}, missed = 0;
        char last = 0; int start = 0;
        for (int t = 0; t < 200; t++) {
            for (int i = 0; i < N; i++) {
                if (t % period[i] == 0) {
                    if (rem[i] > 0) { printf("  t=%3d: P%d MISSED its deadline (%d units left)\n", t, i + 1, rem[i]); missed++; }
                    rem[i] = burst[i]; dl[i] = t + period[i];
                }
            }
            int k = -1;
            for (int i = 0; i < N; i++) {
                if (rem[i] <= 0) continue;
                if (k < 0) k = i;
                else if (mode == 0 ? period[i] < period[k] : dl[i] < dl[k]) k = i;
            }
            char c = k < 0 ? 'I' : (char)('1' + k);
            if (c != last) { if (last) printf("  %3d..%3d : %s%c\n", start, t, last == 'I' ? "idle " : "P", last == 'I' ? ' ' : last); last = c; start = t; }
            if (k >= 0) rem[k]--;
        }
        printf("  %3d..200 : %s%c\n", start, last == 'I' ? "idle " : "P", last == 'I' ? ' ' : last);
        printf("  deadlines missed = %d\n", missed);
    }
    return 0;
}

  • Viva questions
    • Why does RMS fail with U = 0.9375 while EDF succeeds?
    • State the RMS utilisation bound; what is its limit for large N? (69 %, ln 2)
    • Static vs dynamic priority?
    • Soft vs hard real-time?
    • Is EDF optimal? Is RMS?
Explanation

The two tasks are P1 (period 50, burst 25) and P2 (period 80, burst 35). Their utilisation is 0.9375, which exceeds the RMS bound 0.828, but is less than the EDF bound of 1. In RMS, P1 has the higher priority (shorter period), so it takes 25 units of every 50, and at time 80 P2 has run only 30 of its 35 units, so it misses the deadline. In EDF, at time 50 the deadline of P1 is 100 and that of P2 is 80, so P2 continues until it finishes, and no deadline is missed. This is the example of Unit II.
