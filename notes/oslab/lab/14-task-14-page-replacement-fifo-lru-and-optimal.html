Task 14 — Page replacement: FIFO, LRU and Optimal

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 14 — Page replacement: FIFO, LRU and Optimal
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
14 of 17
Terms
Page fault, LRU, Belady's anomaly, Thrashing
Notebook notes
  • Aim: Simulate the FIFO, LRU and Optimal page-replacement algorithms and count the page faults.
  • Theory
    • FIFO replaces the oldest page; LRU replaces the page unused for the longest time (past); Optimal replaces the page that will not be used for the longest time (future; the lower bound, not implementable). FIFO may show Belady's anomaly; LRU and OPT are stack algorithms that do not. See Unit IV
  • Algorithm
    • Keep an array of frames, initially empty
    • For each reference: if present → hit; else fault — use a free frame, or choose a victim by the algorithm
    • FIFO: a pointer going round the frames; LRU: time of last use of each frame; OPT: the frame whose next use is farthest
    • Count the faults; repeat for 1 to 7 frames
c
/* Task 14: page replacement: FIFO, LRU, Optimal */
#include <stdio.h>
#include <string.h>
#define MAXF 10
int ref[] = {7,0,1,2,0,3,0,4,2,3,0,3,2,1,2,0,1,7,0,1};
int n = sizeof ref / sizeof *ref;

int find(int f[], int nf, int pg) { for (int i = 0; i < nf; i++) if (f[i] == pg) return i; return -1; }
void show(int f[], int nf, int fault, int pg) {
    printf("  %2d : ", pg);
    for (int i = 0; i < nf; i++) { if (f[i] < 0) printf(" - "); else printf("%2d ", f[i]); }
    printf("%s\n", fault ? " fault" : "");
}
int fifo(int nf, int verbose) {
    int f[MAXF], next = 0, faults = 0; memset(f, -1, sizeof f);
    for (int i = 0; i < n; i++) {
        int fault = find(f, nf, ref[i]) < 0;
        if (fault) { f[next] = ref[i]; next = (next + 1) % nf; faults++; }
        if (verbose) show(f, nf, fault, ref[i]);
    }
    return faults;
}
int lru(int nf, int verbose) {
    int f[MAXF], last[MAXF], faults = 0; memset(f, -1, sizeof f);
    for (int i = 0; i < n; i++) {
        int k = find(f, nf, ref[i]), fault = k < 0;
        if (fault) {
            int v = 0;
            for (int j = 0; j < nf; j++) { if (f[j] < 0) { v = j; break; } if (last[j] < last[v]) v = j; }
            k = v; f[k] = ref[i]; faults++;
        }
        last[k] = i;
        if (verbose) show(f, nf, fault, ref[i]);
    }
    return faults;
}
int optimal(int nf, int verbose) {
    int f[MAXF], faults = 0; memset(f, -1, sizeof f);
    for (int i = 0; i < n; i++) {
        int fault = find(f, nf, ref[i]) < 0;
        if (fault) {
            int v = -1, far = -1;
            for (int j = 0; j < nf; j++) {
                if (f[j] < 0) { v = j; break; }
                int d = n + 1;
                for (int k = i + 1; k < n; k++) if (ref[k] == f[j]) { d = k; break; }
                if (d > far) { far = d; v = j; }
            }
            f[v] = ref[i]; faults++;
        }
        if (verbose) show(f, nf, fault, ref[i]);
    }
    return faults;
}
int main() {
    printf("Reference string: 7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1, 3 frames\n");
    printf("FIFO:\n"); int a = fifo(3, 1);
    printf("LRU:\n");  int b = lru(3, 1);
    printf("Optimal:\n"); int c = optimal(3, 1);
    printf("\nPage faults: FIFO = %d, LRU = %d, Optimal = %d\n", a, b, c);
    printf("\nFaults versus frames (FIFO / LRU / OPT):\n");
    for (int nf = 1; nf <= 7; nf++) printf("  %d frames: %2d / %2d / %2d\n", nf, fifo(nf, 0), lru(nf, 0), optimal(nf, 0));
    return 0;
}

  • Viva questions
    • What is Belady's anomaly? Which algorithm shows it?
    • Why can't Optimal be implemented?
    • How is LRU implemented in practice? (counters, stack, reference bits)
    • What is thrashing?
    • Page-fault rate for FIFO with 3 frames here? (15/20 = 75 %)
Explanation

For the reference string of Unit IV with three frames, FIFO gives 15 faults, LRU 12 faults and Optimal 9 faults, as in the notes. The last table shows that the faults decrease when more frames are used, and that LRU and OPT are never worse with more frames. For this string FIFO with two frames (15) and three frames (15) shows no benefit, but the string 1 2 3 4 1 2 5 1 2 3 4 5 gives the anomaly (9 faults with three frames and 10 with four).
