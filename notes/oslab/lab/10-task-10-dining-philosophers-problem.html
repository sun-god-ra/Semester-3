Task 10 — Dining philosophers problem

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 10 — Dining philosophers problem
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
10 of 17
Terms
Deadlock, Semaphore, Starvation, Dining philosophers, Mutual exclusion
Notebook notes
  • Aim: Solve the dining-philosophers problem without deadlock using semaphores.
  • Theory
    • Five philosophers, five chopsticks (semaphores = 1). The naive solution (each takes the left, then the right chopstick) may deadlock when all take the left one together. Solution used here: a semaphore room = 4 allows at most four philosophers at the table, so at least one can always get two chopsticks (no circular wait). Other solutions: asymmetric order (odd takes left first, even takes right first), picking both chopsticks only if both are free, or a monitor
  • Algorithm
    • Initialise chopstick[i] = 1 and room = N-1
    • Each philosopher: think; wait(room); wait(chopstick[i]); wait(chopstick[(i+1)%N]); eat; signal both; signal(room)
    • Check that no two neighbours eat at the same time; count the meals
c
/* Task 10: dining philosophers: semaphore solution, at most 4 philosophers sit at the table */
#include <stdio.h>
#include <pthread.h>
#include <semaphore.h>
#include <unistd.h>
#define N 5
#define MEALS 3
sem_t chopstick[N], room;                    /* room = N-1 prevents the circular wait */
pthread_mutex_t m = PTHREAD_MUTEX_INITIALIZER;
int eating[N], meals[N], bad = 0;

void *philosopher(void *arg) {
    int i = *(int *)arg;
    for (int k = 0; k < MEALS; k++) {
        usleep(100);                          /* think */
        sem_wait(&room);
        sem_wait(&chopstick[i]);
        sem_wait(&chopstick[(i + 1) % N]);
        pthread_mutex_lock(&m);
        eating[i] = 1;
        if (eating[(i + 1) % N] || eating[(i + N - 1) % N]) bad++;   /* neighbours must not eat together */
        pthread_mutex_unlock(&m);
        usleep(200);                          /* eat */
        pthread_mutex_lock(&m); eating[i] = 0; meals[i]++; pthread_mutex_unlock(&m);
        sem_post(&chopstick[i]);
        sem_post(&chopstick[(i + 1) % N]);
        sem_post(&room);
    }
    return NULL;
}
int main() {
    pthread_t t[N]; int id[N];
    for (int i = 0; i < N; i++) sem_init(&chopstick[i], 0, 1);
    sem_init(&room, 0, N - 1);
    for (int i = 0; i < N; i++) { id[i] = i; pthread_create(&t[i], NULL, philosopher, &id[i]); }
    for (int i = 0; i < N; i++) pthread_join(t[i], NULL);
    for (int i = 0; i < N; i++) printf("philosopher %d ate %d times\n", i, meals[i]);
    printf("neighbours eating together: %d times (must be 0)\n", bad);
    printf("no deadlock: all threads finished\n");
    return 0;
}

Output

text
philosopher 0 ate 3 times
philosopher 1 ate 3 times
philosopher 2 ate 3 times
philosopher 3 ate 3 times
philosopher 4 ate 3 times
neighbours eating together: 0 times (must be 0)
no deadlock: all threads finished
  • Viva questions
    • How can the naive solution deadlock? Which of the four conditions is broken by room = 4? (circular wait)
    • Name two other deadlock-free solutions
    • Does your solution prevent starvation?
    • How does the monitor solution work?
    • What does the dining philosophers problem represent? (allocation of several resources to several processes)
Explanation

Every philosopher eats three times, so the five threads end, which shows that there is no deadlock. The counter that detects two neighbours eating together stays at 0, which shows mutual exclusion on each chopstick. The limit of four philosophers at the table breaks the circular-wait condition.
