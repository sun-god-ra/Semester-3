Task 5 — CPU scheduling: priority (non-preemptive and preemptive)

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 5 — CPU scheduling: priority (non-preemptive and preemptive)
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
5 of 17
Terms
Starvation, Real-time
Notebook notes
  • Aim: Simulate priority scheduling and compute the waiting and turnaround times. Lower number = higher priority.
  • Theory
    • The CPU is allocated to the highest-priority ready process. Non-preemptive: a running process is not interrupted. Preemptive: a newly arrived process with a higher priority takes the CPU. Starvation of low-priority processes is possible; aging (raising priority with waiting time) solves it. SJF is priority scheduling with priority = predicted burst
  • Algorithm
    • Non-preemptive: at each decision point choose the unfinished arrived process with the smallest priority number; run it to completion
    • Preemptive: at every time unit choose the arrived process with the best priority; reduce its remaining time
c
/* Task 5: priority scheduling, non-preemptive and preemptive (lower number = higher priority) */
#include <stdio.h>
#include <string.h>
#define N 5
typedef struct { char name[3]; int at, bt, pr, ct, wt, tat; } P;

void show(const char *title, P p[], int n) {
    double w = 0, t = 0;
    printf("%s\nProc AT BT Pr CT TAT WT\n", title);
    for (int i = 0; i < n; i++) {
        p[i].tat = p[i].ct - p[i].at; p[i].wt = p[i].tat - p[i].bt;
        printf("%-4s %2d %2d %2d %2d %3d %2d\n", p[i].name, p[i].at, p[i].bt, p[i].pr, p[i].ct, p[i].tat, p[i].wt);
        w += p[i].wt; t += p[i].tat;
    }
    printf("Average waiting = %.2f, average turnaround = %.2f\n\n", w / n, t / n);
}
void np(P p[], int n) {
    int done[N] = {0}, t = 0, c = 0;
    while (c < n) {
        int k = -1;
        for (int i = 0; i < n; i++)
            if (!done[i] && p[i].at <= t && (k < 0 || p[i].pr < p[k].pr)) k = i;
        if (k < 0) { t++; continue; }
        printf("  t=%2d..%2d : %s\n", t, t + p[k].bt, p[k].name);
        t += p[k].bt; p[k].ct = t; done[k] = 1; c++;
    }
}
void pre(P p[], int n) {
    int rem[N], t = 0, c = 0;
    for (int i = 0; i < n; i++) rem[i] = p[i].bt;
    while (c < n) {
        int k = -1;
        for (int i = 0; i < n; i++)
            if (rem[i] > 0 && p[i].at <= t && (k < 0 || p[i].pr < p[k].pr)) k = i;
        if (k < 0) { t++; continue; }
        rem[k]--; t++;
        if (rem[k] == 0) { p[k].ct = t; c++; }
    }
}
int main() {
    P a[N] = { {"P1",0,10,3}, {"P2",0,1,1}, {"P3",0,2,4}, {"P4",0,1,5}, {"P5",0,5,2} };
    P b[N] = { {"P1",0,7,3}, {"P2",2,4,1}, {"P3",4,1,4}, {"P4",5,4,2}, {"P5",6,3,5} };
    P p[N];
    memcpy(p, a, sizeof a); printf("Non-preemptive priority (all arrive at 0):\n"); np(p, N); show("", p, N);
    memcpy(p, b, sizeof b); pre(p, N); show("Preemptive priority (different arrival times)", p, N);
    return 0;
}

  • Viva questions
    • What is starvation and how does aging solve it?
    • Which is better, preemptive or non-preemptive, for real-time systems?
    • How are priorities assigned? (internal: time limits, memory; external: importance, payment)
    • What is priority inversion? (see Unit III)
    • Is SJF a priority algorithm? (yes)
Explanation

In the first example all processes arrive at time 0, and the order of running is P2, P5, P1, P3, P4, so the average waiting time is 8.2, which is the same as the hand calculation in Unit II. In the second example, the processes arrive at different times. P1 starts first, since it is alone, but at time 2 the process P2 (priority 1) arrives and preempts it. P1 resumes only after the processes with a better priority are finished.
