Task 4 — CPU scheduling: FCFS, SJF (non-preemptive and preemptive), Round Robin

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 4 — CPU scheduling: FCFS, SJF (non-preemptive and preemptive), Round Robin
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
4 of 17
Terms
Round robin, FCFS, Starvation, Convoy effect, Interrupt
Notebook notes
  • Aim: Simulate FCFS, SJF (non-preemptive), SRTF (preemptive SJF) and Round Robin, and compute the waiting and turnaround times.
  • Theory
    • FCFS: serve in order of arrival (non-preemptive). SJF: pick the process with the shortest burst among those that have arrived; optimal average waiting time. SRTF: at each time unit run the process with the shortest remaining time (preemptive). Round Robin: each process gets a time quantum \(q\); then it goes to the back of the queue. See Unit II
    • \(TAT=CT-AT\); \(WT=TAT-BT\); average = sum divided by the number of processes
  • Algorithm
    • Read the processes (AT, BT)
    • FCFS: keep a clock \(t\); for each process in order of arrival, \(t=\max(t,AT)+BT\), \(CT=t\)
    • SJF: at time \(t\) pick the unfinished process with the smallest BT among those with \(AT\le t\); run to completion
    • SRTF: every unit of time, pick the one with the smallest remaining time; decrement; record CT when it reaches 0
    • RR: queue of ready processes; take the first, run for \(\min(q,\text{remaining})\); add newly arrived processes to the queue, then the preempted one at the back
c
/* Task 4: FCFS, SJF (non-preemptive and preemptive), Round Robin */
#include <stdio.h>
#include <string.h>
#define N 4
typedef struct { char name[3]; int at, bt, ct, wt, tat; } P;

void show(const char *title, P p[], int n) {
    double w = 0, t = 0;
    printf("%s\nProc AT BT CT TAT WT\n", title);
    for (int i = 0; i < n; i++) {
        p[i].tat = p[i].ct - p[i].at; p[i].wt = p[i].tat - p[i].bt;
        printf("%-4s %2d %2d %2d %3d %2d\n", p[i].name, p[i].at, p[i].bt, p[i].ct, p[i].tat, p[i].wt);
        w += p[i].wt; t += p[i].tat;
    }
    printf("Average waiting = %.2f, average turnaround = %.2f\n\n", w / n, t / n);
}
void fcfs(P p[], int n) {
    int t = 0;
    for (int i = 0; i < n; i++) { if (t < p[i].at) t = p[i].at; t += p[i].bt; p[i].ct = t; }
}
void sjf_np(P p[], int n) {
    int done[N] = {0}, t = 0, c = 0;
    while (c < n) {
        int k = -1;
        for (int i = 0; i < n; i++)
            if (!done[i] && p[i].at <= t && (k < 0 || p[i].bt < p[k].bt)) k = i;
        if (k < 0) { t++; continue; }
        t += p[k].bt; p[k].ct = t; done[k] = 1; c++;
    }
}
void srtf(P p[], int n) {                       /* preemptive SJF */
    int rem[N], t = 0, c = 0;
    for (int i = 0; i < n; i++) rem[i] = p[i].bt;
    while (c < n) {
        int k = -1;
        for (int i = 0; i < n; i++)
            if (rem[i] > 0 && p[i].at <= t && (k < 0 || rem[i] < rem[k])) k = i;
        if (k < 0) { t++; continue; }
        rem[k]--; t++;
        if (rem[k] == 0) { p[k].ct = t; c++; }
    }
}
void rr(P p[], int n, int q) {
    int rem[N], t = 0, c = 0, queue[100], head = 0, tail = 0, in[N] = {0};
    for (int i = 0; i < n; i++) rem[i] = p[i].bt;
    for (int i = 0; i < n; i++) if (p[i].at <= 0) { queue[tail++] = i; in[i] = 1; }
    while (c < n) {
        if (head == tail) { t++; for (int i = 0; i < n; i++) if (!in[i] && p[i].at <= t) { queue[tail++] = i; in[i] = 1; } continue; }
        int k = queue[head++];
        int run = rem[k] < q ? rem[k] : q;
        t += run; rem[k] -= run;
        for (int i = 0; i < n; i++) if (!in[i] && p[i].at <= t) { queue[tail++] = i; in[i] = 1; }
        if (rem[k] > 0) queue[tail++] = k; else { p[k].ct = t; c++; }
    }
}
int main() {
    P base[N] = { {"P1",0,8}, {"P2",1,4}, {"P3",2,9}, {"P4",3,5} };
    P p[N];
    memcpy(p, base, sizeof base); fcfs(p, N);   show("FCFS", p, N);
    memcpy(p, base, sizeof base); sjf_np(p, N); show("SJF (non-preemptive)", p, N);
    memcpy(p, base, sizeof base); srtf(p, N);   show("SJF (preemptive) = SRTF", p, N);
    memcpy(p, base, sizeof base); rr(p, N, 4);  show("Round Robin, quantum = 4", p, N);
    return 0;
}

  • Viva questions
    • Why is SJF optimal? What is its drawback? (starvation, burst unknown)
    • What is the convoy effect?
    • Effect of a very large and a very small quantum in RR?
    • Difference between SJF and SRTF?
    • Calculate the average waiting time for FCFS with arrival order P2, P3, P1 (try!)
Explanation

All four algorithms use the same processes (P1: AT 0 BT 8; P2: 1, 4; P3: 2, 9; P4: 3, 5). FCFS gives the average waiting time 8.75. Non-preemptive SJF picks P2 at time 8 (burst 4), then P4, and then P3, giving 7.75. The preemptive version, SRTF, interrupts P1 at time 1 because P2 needs only 4 units, and gets the best result, 6.5. For round robin with q = 4, the average is 11.75, which is worse for turnaround time, but every process gets the CPU early, which means a good response time. The results agree with the hand calculations of Unit II.
