Task 15 — Disk scheduling: FCFS, SSTF, SCAN and C-SCAN

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 15 — Disk scheduling: FCFS, SSTF, SCAN and C-SCAN
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
15 of 17
Terms
FCFS, C-SCAN, Starvation
Notebook notes
  • Aim: Simulate the disk-scheduling algorithms and compute the total head movement.
  • Theory
    • FCFS: in arrival order; SSTF: nearest request first (may starve); SCAN (elevator): move to one end servicing requests, then reverse; C-SCAN: move in one direction only; at the end jump to the start without servicing (more uniform wait). LOOK / C-LOOK go only as far as the last request. Total head movement = sum of \(|{\rm next}-{\rm current}|\) (see Unit V)
  • Algorithm
    • Read the request queue and the starting head position
    • FCFS: sum the distances in order
    • SSTF: repeatedly pick the unserved request with the smallest distance
    • SCAN: sort the requests; serve those on one side, go to the end, reverse and serve the rest
    • C-SCAN: go to the end, jump to 0 (count the jump as in the book), serve the rest
c
/* Task 15: disk scheduling: FCFS, SSTF, SCAN, C-SCAN (cylinders 0..199) */
#include <stdio.h>
#include <stdlib.h>
#define MAXC 199
int q[] = {98, 183, 37, 122, 14, 124, 65, 67}, n = 8, head = 53;

int fcfs() { int t = 0, c = head; printf("  order: %d", c); for (int i = 0; i < n; i++) { t += abs(q[i] - c); c = q[i]; printf(" -> %d", c); } printf("\n"); return t; }
int sstf() {
    int done[8] = {0}, t = 0, c = head; printf("  order: %d", c);
    for (int k = 0; k < n; k++) {
        int b = -1;
        for (int i = 0; i < n; i++) if (!done[i] && (b < 0 || abs(q[i] - c) < abs(q[b] - c))) b = i;
        t += abs(q[b] - c); c = q[b]; done[b] = 1; printf(" -> %d", c);
    }
    printf("\n"); return t;
}
int cmp(const void *a, const void *b) { return *(int *)a - *(int *)b; }
int scan(int up) {               /* up = 1: move toward higher cylinders first */
    int s[8], t = 0, c = head; for (int i = 0; i < n; i++) s[i] = q[i]; qsort(s, n, sizeof(int), cmp);
    printf("  order: %d", c);
    if (up) {
        for (int i = 0; i < n; i++) if (s[i] >= head) { t += s[i] - c; c = s[i]; printf(" -> %d", c); }
        t += MAXC - c; c = MAXC; printf(" -> %d", c);
        for (int i = n - 1; i >= 0; i--) if (s[i] < head) { t += c - s[i]; c = s[i]; printf(" -> %d", c); }
    } else {
        for (int i = n - 1; i >= 0; i--) if (s[i] <= head) { t += c - s[i]; c = s[i]; printf(" -> %d", c); }
        t += c; c = 0; printf(" -> 0");
        for (int i = 0; i < n; i++) if (s[i] > head) { t += s[i] - c; c = s[i]; printf(" -> %d", c); }
    }
    printf("\n"); return t;
}
int cscan() {                    /* toward higher cylinders, jump back to 0 without serving */
    int s[8], t = 0, c = head; for (int i = 0; i < n; i++) s[i] = q[i]; qsort(s, n, sizeof(int), cmp);
    printf("  order: %d", c);
    for (int i = 0; i < n; i++) if (s[i] >= head) { t += s[i] - c; c = s[i]; printf(" -> %d", c); }
    t += MAXC - c; c = MAXC; printf(" -> %d", c);
    t += MAXC; c = 0; printf(" => jump to 0");
    for (int i = 0; i < n; i++) if (s[i] < head) { t += s[i] - c; c = s[i]; printf(" -> %d", c); }
    printf("\n"); return t;
}
int main() {
    printf("Queue: 98 183 37 122 14 124 65 67; head at 53; cylinders 0..199\n");
    printf("FCFS:\n"); printf("  total head movement = %d\n", fcfs());
    printf("SSTF:\n"); printf("  total head movement = %d\n", sstf());
    printf("SCAN (toward 0 first):\n"); printf("  total head movement = %d\n", scan(0));
    printf("SCAN (toward 199 first):\n"); printf("  total head movement = %d\n", scan(1));
    printf("C-SCAN (toward 199, jump counted):\n"); printf("  total head movement = %d\n", cscan());
    return 0;
}

text
Queue: 98 183 37 122 14 124 65 67; head at 53; cylinders 0..199
FCFS:
  order: 53 -> 98 -> 183 -> 37 -> 122 -> 14 -> 124 -> 65 -> 67
  total head movement = 640
SSTF:
  order: 53 -> 65 -> 67 -> 37 -> 14 -> 98 -> 122 -> 124 -> 183
  total head movement = 236
SCAN (toward 0 first):
  order: 53 -> 37 -> 14 -> 0 -> 65 -> 67 -> 98 -> 122 -> 124 -> 183
  total head movement = 236
SCAN (toward 199 first):
  order: 53 -> 65 -> 67 -> 98 -> 122 -> 124 -> 183 -> 199 -> 37 -> 14
  total head movement = 331
C-SCAN (toward 199, jump counted):
  order: 53 -> 65 -> 67 -> 98 -> 122 -> 124 -> 183 -> 199 => jump to 0 -> 14 -> 37
  total head movement = 382
  • Viva questions
    • Which algorithm gives the least head movement in this example? (SSTF/SCAN toward 0, 236)
    • Why does SSTF cause starvation?
    • Difference between SCAN and C-SCAN? Between SCAN and LOOK?
    • Which algorithm is best under a heavy load? (SCAN/C-SCAN)
    • What does disk access time consist of? (seek + rotational latency + transfer)
Explanation

The queue 98, 183, 37, 122, 14, 124, 65, 67 with the head at 53 gives 640 cylinders for FCFS, 236 for SSTF and 236 for SCAN going towards 0 (53 + 183). If SCAN goes to 199 first the total is 331. C-SCAN gives 382 when the jump from 199 back to 0 is counted. These are the totals computed in Unit V.
