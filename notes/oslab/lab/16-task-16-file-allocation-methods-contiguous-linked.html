Task 16 — File allocation methods: contiguous, linked and indexed

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 16 — File allocation methods: contiguous, linked and indexed
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
16 of 17
Terms
External fragmentation, Inode
Notebook notes
  • Aim: Simulate the three file-allocation methods on a disk of 32 blocks.
  • Theory
    • Contiguous: the directory stores (start, length); block \(i\) is at \(start+i\); fast, but external fragmentation and difficult growth. Linked: each block points to the next; the directory stores the first block; no external fragmentation; only sequential access is efficient (FAT keeps the pointers in a table). Indexed: an index block holds all the pointers of the file; supports direct access; overhead of the index block
  • Algorithm
    • Mark some blocks as used
    • Contiguous: find the first run of free blocks of the required length (first fit)
    • Linked: take any free blocks and link them with next pointers; mark the last one with EOF
    • Indexed: choose an index block and store the block numbers of the data blocks in it
c
/* Task 16: file allocation methods: contiguous, linked (FAT style), indexed */
#include <stdio.h>
#include <string.h>
#define BLOCKS 32
int used[BLOCKS];
int fat[BLOCKS];                                   /* next-block pointers; -1 = end of file */

void map() { printf("  disk map: "); for (int i = 0; i < BLOCKS; i++) printf("%c", used[i] ? '#' : '.'); printf("\n"); }
int main() {
    for (int i = 0; i < BLOCKS; i++) { used[i] = 0; fat[i] = -2; }
    int busy[] = {2, 3, 7, 8, 9, 15, 20};          /* blocks already used by other files */
    for (int i = 0; i < 7; i++) used[busy[i]] = 1;
    printf("Initial state (# = used):\n"); map();

    /* ---- contiguous: first fit of a run of 4 blocks ---- */
    printf("\n1) Contiguous allocation of file A (4 blocks): directory holds (start, length)\n");
    int start = -1;
    for (int i = 0; i + 4 <= BLOCKS && start < 0; i++) {
        int ok = 1; for (int j = 0; j < 4; j++) if (used[i + j]) { ok = 0; break; }
        if (ok) start = i;
    }
    for (int j = 0; j < 4; j++) used[start + j] = 1;
    printf("  start = %d, length = 4, blocks:", start); for (int j = 0; j < 4; j++) printf(" %d", start + j); printf("\n"); map();
    printf("  block i of the file is at start + i, e.g. block 2 -> %d\n", start + 2);

    /* ---- linked: any free blocks, pointer in each block ---- */
    printf("\n2) Linked allocation of file B (5 blocks): directory holds the first block\n");
    int prev = -1, first = -1, cnt = 0;
    for (int i = 0; i < BLOCKS && cnt < 5; i++) if (!used[i]) {
        used[i] = 1; if (prev >= 0) fat[prev] = i; else first = i; prev = i; cnt++;
    }
    fat[prev] = -1;
    printf("  first = %d, chain:", first);
    for (int b = first; b != -1; b = fat[b]) printf(" %d%s", b, fat[b] == -1 ? " (EOF)" : " ->");
    printf("\n"); map();

    /* ---- indexed: one index block holds all pointers ---- */
    printf("\n3) Indexed allocation of file C (4 blocks): directory holds the index block\n");
    int index_block = -1, data[4], c = 0;
    for (int i = BLOCKS - 1; i >= 0 && (index_block < 0 || c < 4); i--) if (!used[i]) {
        used[i] = 1; if (index_block < 0) index_block = i; else data[c++] = i;
    }
    printf("  index block = %d, pointers:", index_block);
    for (int j = 0; j < 4; j++) printf(" %d", data[j]);
    printf("\n  direct access to block 2 of the file -> block %d (one lookup in the index)\n", data[2]); map();
    return 0;
}

  • Viva questions
    • Compare the three methods for random access
    • What is the FAT?
    • How large a file can an inode support? (12 direct + single + double + triple indirect)
    • Which method has external fragmentation?
    • What is an extent?
Explanation

The disk map shows the used blocks with #. For the contiguous method, the first run of four free blocks starts at block 10, so the file is stored in 10 to 13 and the directory needs only the start and the length. In the linked method, the file uses blocks 0, 1, 4, 5, 6 chained in order, although they are not neighbours. In the indexed method, one index block (31) points to the four data blocks 30, 29, 28, 27, so block 2 of the file is found by one lookup in the index.
