Lab

Programming Tasks 1 to 17

Operating Systems Lab · 24CS204

Syllabus: Seventeen tasks: shell, system calls, scheduling simulations, synchronization, Banker's algorithm, memory, paging, page replacement, disk scheduling, file allocation.

Topics in this unit

  1. Task 1 — Linux commands and shell utilitiesAim: Use the common Linux commands, filters, redirection and pipes, and write shell scripts with variables, conditions, loops and functions.
  2. Task 2 — PowerShell and batch scripts (Windows)Aim: Write simple batch (.bat) and PowerShell (.ps1) scripts: variables, arithmetic, conditions, loops, functions and file/process commands.
  3. Task 3 — UNIX system calls: process and fileAim: Use the process-related (fork, exec, wait, exit, getpid) and file-related (open, read, write, lseek, close, stat, chmod, unlink) system calls in …
  4. Task 4 — CPU scheduling: FCFS, SJF (non-preemptive and preemptive), Round RobinAim: Simulate FCFS, SJF (non-preemptive), SRTF (preemptive SJF) and Round Robin, and compute the waiting and turnaround times.
  5. Task 5 — CPU scheduling: priority (non-preemptive and preemptive)Aim: Simulate priority scheduling and compute the waiting and turnaround times. Lower number = higher priority.
  6. Task 6 — Real-time scheduling: Earliest Deadline First (EDF) and Rate Monotonic (RMS)Aim: Simulate RMS and EDF for periodic tasks and check the deadlines.
  7. Task 7 — Critical-section problem and Peterson's solutionAim: Show a race condition and solve the critical-section problem for two threads using Peterson's algorithm and a mutex lock.
  8. Task 8 — Producer–consumer problem using semaphoresAim: Implement the bounded-buffer problem with POSIX semaphores and a mutex.
  9. Task 9 — Readers–writers problemAim: Implement the first readers–writers problem (readers' priority) with semaphores.
  10. Task 10 — Dining philosophers problemAim: Solve the dining-philosophers problem without deadlock using semaphores.
  11. Task 11 — Banker's algorithm (deadlock avoidance)Aim: Implement the Banker's safety algorithm and the resource-request algorithm.
  12. Task 12 — Memory allocation: first fit, best fit, worst fitAim: Simulate the three contiguous memory-allocation strategies.
  13. Task 13 — Logical to physical address translation (paging and segmentation)Aim: Translate logical addresses into physical addresses using a page table and a segment table.
  14. Task 14 — Page replacement: FIFO, LRU and OptimalAim: Simulate the FIFO, LRU and Optimal page-replacement algorithms and count the page faults.
  15. Task 15 — Disk scheduling: FCFS, SSTF, SCAN and C-SCANAim: Simulate the disk-scheduling algorithms and compute the total head movement.
  16. Task 16 — File allocation methods: contiguous, linked and indexedAim: Simulate the three file-allocation methods on a disk of 32 blocks.
  17. Task 17 — Free-space management: bit vector, linked list and groupingAim: Simulate the free-space management techniques: bit vector, linked list, grouping and counting.

More explanation for this unit

How to use these programs

Compile each program with gcc, run it and compare it with the output shown. In scheduling and memory tasks, the inputs are written inside main(), so to try other data, change the arrays. The concepts behind each program are in the Operating Systems notes (Units I–V). When you write the record, always write the aim, the algorithm, the program, the output with your own inputs, and the result.
