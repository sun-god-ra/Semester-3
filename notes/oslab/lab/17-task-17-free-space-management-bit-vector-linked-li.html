Task 17 — Free-space management: bit vector, linked list and grouping

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 17 — Free-space management: bit vector, linked list and grouping
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
17 of 17
Terms
Linked list
Notebook notes
  • Aim: Simulate the free-space management techniques: bit vector, linked list, grouping and counting.
  • Theory
    • Bit vector: one bit per block (1 = free); finding the first free block or \(n\) consecutive free blocks is easy with bit instructions; needs memory: a 1 TB disk with 4 KB blocks needs \(2^{40}/2^{12}=2^{28}\) bits = 32 MB. Linked list: free blocks linked together; the head pointer is kept; allocation takes from the head; traversing is slow. Grouping: the first free block stores the addresses of \(n\) free blocks; the last of them points to the next group. Counting: stores (start, count) pairs of contiguous free runs
  • Algorithm
    • Mark the free blocks
    • Bit vector: print the bits; find the first free block and the first run of 3
    • Linked list: print the chain; allocate 3 blocks from the head
    • Grouping: split the addresses into groups of \(n-1\) with a link to the next group block
    • Counting: merge consecutive blocks into (start, count)
c
/* Task 17: free-space management: bit vector, linked list, grouping */
#include <stdio.h>
#define N 24
int main() {
    int free_blocks[] = {2, 3, 4, 5, 8, 9, 10, 11, 12, 13, 17, 18};
    int nf = sizeof free_blocks / sizeof *free_blocks;
    int bits[N] = {0};
    for (int i = 0; i < nf; i++) bits[free_blocks[i]] = 1;          /* 1 = free */

    printf("1) Bit vector (1 = free) for %d blocks:\n   ", N);
    for (int i = 0; i < N; i++) printf("%d", bits[i]);
    printf("\n   first free block = ");
    for (int i = 0; i < N; i++) if (bits[i]) { printf("%d\n", i); break; }
    printf("   first run of 3 consecutive free blocks starts at ");
    for (int i = 0; i + 3 <= N; i++) if (bits[i] && bits[i+1] && bits[i+2]) { printf("%d\n", i); break; }
    printf("   bit-map size for a 1 TB disk with 4 KB blocks = %llu MB\n", ((1ULL << 40) / 4096 / 8) >> 20);

    printf("\n2) Linked list of free blocks (head -> ...):\n   head");
    for (int i = 0; i < nf; i++) printf(" -> %d", free_blocks[i]);
    printf(" -> NULL\n   allocate 3 blocks: take from the head:");
    int head = 0;
    for (int k = 0; k < 3; k++) printf(" %d", free_blocks[head++]);
    printf("\n   new head = %d\n", free_blocks[head]);

    printf("\n3) Grouping (n = 4 addresses per group block):\n");
    int n = 4;
    for (int g = 0; g * (n - 1) < nf; g++) {
        printf("   group block %d holds free addresses:", g + 1);
        for (int k = 0; k < n - 1 && g * (n - 1) + k < nf; k++) printf(" %d", free_blocks[g * (n - 1) + k]);
        if ((g + 1) * (n - 1) < nf) printf("  + pointer to next group block %d", free_blocks[(g + 1) * (n - 1)]);
        printf("\n");
    }
    printf("\n4) Counting: (start, count) pairs:");
    for (int i = 0; i < nf;) { int j = i; while (j + 1 < nf && free_blocks[j + 1] == free_blocks[j] + 1) j++; printf(" (%d,%d)", free_blocks[i], j - i + 1); i = j + 1; }
    printf("\n");
    return 0;
}

Output

text

   001111001111110001100000
   first free block = 2
   first run of 3 consecutive free blocks starts at 2
   bit-map size for a 1 TB disk with 4 KB blocks = 32 MB

2) Linked list of free blocks (head -> ...):
   head -> 2 -> 3 -> 4 -> 5 -> 8 -> 9 -> 10 -> 11 -> 12 -> 13 -> 17 -> 18 -> NULL
   allocate 3 blocks: take from the head: 2 3 4
   new head = 5

3) Grouping (n = 4 addresses per group block):
   group block 1 holds free addresses: 2 3 4  + pointer to next group block 5
   group block 2 holds free addresses: 5 8 9  + pointer to next group block 10
   group block 3 holds free addresses: 10 11 12  + pointer to next group block 13
   group block 4 holds free addresses: 13 17 18

4) Counting: (start, count) pairs: (2,4) (8,6) (17,2)
  • Viva questions
    • Compare the bit vector and the linked list
    • What is the size of the bit map for a given disk?
    • What is grouping? counting?
    • How does ZFS manage free space? (space maps, in counting format)
    • What is TRIM for SSDs?
Explanation

The free blocks are 2 to 5, 8 to 13 and 17, 18. The bit vector 001111001111110001100000 has 1 for these blocks. Allocating 3 blocks from the head of the linked list takes blocks 2, 3, 4 and leaves 5 as the new head. In grouping with 4 addresses per block, each group block lists three free blocks and points to the next group block. The counting representation is the shortest: (2,4), (8,6), (17,2).
