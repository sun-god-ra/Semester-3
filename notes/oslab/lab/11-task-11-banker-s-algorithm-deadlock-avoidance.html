Task 11 — Banker's algorithm (deadlock avoidance)

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 11 — Banker's algorithm (deadlock avoidance)
Subject
Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
11 of 17
Terms
Banker's algorithm, Deadlock
Notebook notes
  • Aim: Implement the Banker's safety algorithm and the resource-request algorithm.
  • Theory
    • Data: Available[m], Max[n][m], Allocation[n][m], Need = Max − Allocation. Safety algorithm: Work = Available; repeatedly find an unfinished \(P_i\) with \(Need_i\le Work\); Work += Allocation_i; if all can finish the state is safe. Request algorithm: if \(Request_i\le Need_i\) and \(\le Available\), pretend to allocate and run the safety algorithm; grant only if the new state is safe (see Unit III)
  • Algorithm
    • Compute the Need matrix
    • Run the safety algorithm and print a safe sequence
    • For a request, perform the checks, do the tentative allocation, run the safety test, and either grant or roll back
c
/* Task 11: Banker's algorithm: safety and resource-request */
#include <stdio.h>
#include <string.h>
#define P 5
#define R 3
int alloc[P][R] = {{0,1,0},{2,0,0},{3,0,2},{2,1,1},{0,0,2}};
int max[P][R]   = {{7,5,3},{3,2,2},{9,0,2},{2,2,2},{4,3,3}};
int avail[R]    = {3,3,2};
int need[P][R];

int is_safe(int av[], int al[][R], int nd[][R], int seq[]) {
    int work[R], finish[P] = {0}, count = 0;
    memcpy(work, av, sizeof work);
    while (count < P) {
        int found = 0;
        for (int i = 0; i < P; i++) {
            if (finish[i]) continue;
            int ok = 1;
            for (int j = 0; j < R; j++) if (nd[i][j] > work[j]) { ok = 0; break; }
            if (ok) {
                for (int j = 0; j < R; j++) work[j] += al[i][j];
                seq[count++] = i; finish[i] = 1; found = 1;
            }
        }
        if (!found) return 0;
    }
    return 1;
}
void print_seq(int seq[]) { for (int i = 0; i < P; i++) printf("P%d%s", seq[i], i < P - 1 ? " -> " : "\n"); }

int request(int pid, int req[]) {
    for (int j = 0; j < R; j++) if (req[j] > need[pid][j]) { printf("error: process exceeded its maximum claim\n"); return 0; }
    for (int j = 0; j < R; j++) if (req[j] > avail[j]) { printf("P%d must wait: resources not available\n", pid); return 0; }
    int av[R], al[P][R], nd[P][R], seq[P];
    memcpy(av, avail, sizeof av); memcpy(al, alloc, sizeof al); memcpy(nd, need, sizeof nd);
    for (int j = 0; j < R; j++) { av[j] -= req[j]; al[pid][j] += req[j]; nd[pid][j] -= req[j]; }
    if (is_safe(av, al, nd, seq)) {                         /* grant */
        memcpy(avail, av, sizeof av); memcpy(alloc, al, sizeof al); memcpy(need, nd, sizeof nd);
        printf("request granted; safe sequence: "); print_seq(seq); return 1;
    }
    printf("request of P%d denied: the new state would be unsafe\n", pid);
    return 0;
}
int main() {
    int seq[P];
    for (int i = 0; i < P; i++) for (int j = 0; j < R; j++) need[i][j] = max[i][j] - alloc[i][j];
    printf("Need matrix:\n");
    for (int i = 0; i < P; i++) printf("P%d: %d %d %d\n", i, need[i][0], need[i][1], need[i][2]);
    if (is_safe(avail, alloc, need, seq)) { printf("System is SAFE. Safe sequence: "); print_seq(seq); }
    else printf("System is UNSAFE\n");
    int r1[R] = {1,0,2}, r2[R] = {3,3,0}, r3[R] = {0,2,0};
    printf("\nP1 requests (1,0,2): "); request(1, r1);
    printf("P4 requests (3,3,0): "); request(4, r2);
    printf("P0 requests (0,2,0): "); request(0, r3);
    return 0;
}

  • Viva questions
    • Why is the algorithm called the Banker's algorithm?
    • What is the difference between a safe state and a deadlock? (safe ⇒ no deadlock; unsafe ⇒ possible deadlock)
    • Complexity of the safety algorithm? (\(O(m\times n^2)\))
    • Why must the maximum need be declared in advance? (a limitation)
    • Can we have more than one safe sequence?
Explanation

For the textbook snapshot, the state is safe with the sequence P1, P3, P4, P0, P2 (the sequence P1, P3, P0, P2, P4 is also valid; the program finds the first one by scanning in order, repeating until no process can be added). P1's request for (1,0,2) is granted, because the resulting state is still safe. P4's request for (3,3,0) must wait, as only (2,3,0) is available. P0's request for (0,2,0) is refused, because the remaining Available (2,1,0) cannot satisfy any process's need, so the state would be unsafe. These are the numbers worked out in Unit III.
