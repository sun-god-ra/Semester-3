Task 2 — PowerShell and batch scripts (Windows)

Operating Systems Lab · Lab: Programming Tasks 1 to 17

Task 2 — PowerShell and batch scripts (Windows)

Operating Systems Lab (24CS204)
Unit
Lab: Programming Tasks 1 to 17
Topic
2 of 17
On this page
  1. Program 1 — Batch script
  2. Program 2 — PowerShell script
Notebook notes
  • Aim: Write simple batch (.bat) and PowerShell (.ps1) scripts: variables, arithmetic, conditions, loops, functions and file/process commands.
  • Theory
    • Batch is the old cmd.exe scripting; PowerShell is the modern shell that passes objects (not text) through the pipeline, with cmdlets named Verb-Noun (Get-ChildItem, Get-Process, Set-Location, Copy-Item, Remove-Item). Aliases: ls, cd, cat, ps
    • Batch: @echo off, set /a for arithmetic, %var%, %1 arguments, if ... (...) else (...), for %%i in (...) do, labels with goto, exist, pause. PowerShell: variables $x, -eq -ne -gt -lt -and -or, if/elseif/else, foreach, ForEach-Object, Where-Object, Select-Object, Sort-Object, functions, Write-Host. Run scripts after Set-ExecutionPolicy RemoteSigned (execution policy)
    • These two scripts have not been executed in the authoring environment (it has no Windows); the syntax is standard, so test them on a Windows machine before the lab
  • Algorithm
    • Batch: save as demo.bat, run in cmd (double-click or demo.bat)
    • PowerShell: save as demo.ps1, run .\demo.ps1 in PowerShell (set the execution policy first)
Program 1 — Batch script
bat
@echo off
rem Batch demo: arithmetic, loop, condition, factorial with goto
set /a a=7
set /a b=3
set /a sum=%a%+%b%
echo Sum = %sum%
for %%i in (1 2 3 4 5) do echo Square of %%i = & call set /a sq=%%i*%%i & call echo %%sq%%
if exist demo.bat (echo demo.bat exists) else (echo demo.bat is missing)
set /a n=5
set /a f=1
:loop
if %n% LEQ 1 goto done
set /a f=f*n
set /a n=n-1
goto loop
:done
echo Factorial of 5 = %f%
dir /b *.bat

Expected output (by hand, not executed): Sum = 10, then the squares 1 4 9 16 25 each on a line, demo.bat exists, Factorial of 5 = 120, then the names of the .bat files.

Program 2 — PowerShell script
powershell
# PowerShell demo: variables, loops, pipeline of objects, function
$a = 7; $b = 3
"Sum = $($a + $b), product = $($a * $b)"
1..5 | ForEach-Object { "Square of $_ = $($_ * $_)" }
function Get-Factorial([int]$n) { if ($n -le 1) { return 1 } else { return $n * (Get-Factorial ($n - 1)) } }
"Factorial of 5 = $(Get-Factorial 5)"
if (Test-Path .\demo.ps1) { "script file exists" } else { "script file is missing" }
Get-ChildItem -File | Sort-Object Length -Descending | Select-Object -First 3 Name, Length
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, Id, CPU
Get-Service | Where-Object { $_.Status -eq 'Running' } | Measure-Object | Select-Object Count

Expected output (by hand, not executed): Sum = 10, product = 21, five squares, Factorial of 5 = 120, a message about the script file, then the three tables produced by the cmdlets (the contents depend on your machine).

  • Viva questions
    • Difference between cmd and PowerShell? (text vs objects)
    • What is a cmdlet? Give examples.
    • Difference between %var% and %%i in a batch file? (variable vs loop variable)
    • What is the PowerShell execution policy?
    • Equivalent of ls | grep in PowerShell? (Get-ChildItem | Where-Object {...})
Explanation

The batch script sets two numbers with set /a, prints their sum, loops over a list with for, checks for a file and calculates the factorial with a label and goto, because batch files have no while loop. The PowerShell script does the same with cmdlets. The main difference is that the pipeline of PowerShell passes .NET objects, so Sort-Object Length sorts by a property, while in Linux you would sort text columns. These scripts were written from the standard syntax and not run in this environment, which is why only the expected output is described.
