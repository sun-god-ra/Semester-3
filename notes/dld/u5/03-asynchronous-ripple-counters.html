Asynchronous (Ripple) Counters

Digital Logic Design · Unit V: Registers, Counters, and Memory Units

Asynchronous (Ripple) Counters
Subject
Digital Logic Design (24CS201)
Unit
Unit V: Registers, Counters, and Memory Units
Topic
3 of 10
Terms
Ripple counter, NAND, Propagation delay, Flip-flop, Decoder

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Counter = register that goes through a prescribed sequence of states on clock pulses. Modulus = number of states
  • Asynchronous (ripple) counter: clock applied only to the first FF; each next FF is clocked by the output of the previous. FFs do not change at the same time
  • 4-bit binary ripple up counter: T (or JK with \(J=K=1\)) FFs, negative-edge-triggered; \(CK_{i+1}=Q_i\)
Clock \(Q_3Q_2Q_1Q_0\)
0 0000
1 0001
2 0010
3 0011
… …
15 1111
16 0000
  • Down counter: clock the next FF from \(Q'\) of previous (or use positive-edge FFs with \(Q_i\))
  • Frequency division: output \(Q_i\) has frequency \(f/2^{i+1}\) → \(Q_0\) is \(f/2\), \(Q_1\) is \(f/4\) … → counter = frequency divider; duty cycle 50 %
  • Mod-\(N\) ripple counter (\(N<2^n\)): use \(n=\lceil\log_2N\rceil\) FFs, detect count \(N\) with a NAND gate and feed to the asynchronous CLEAR of all FFs → resets immediately. Decade (mod-10) counter: NAND of \(Q_3\) and \(Q_1\) (count 1010) → clear. 7490 IC
    • state 1010 appears only for a very short glitch time
  • Advantages: simple, few gates. Disadvantages: propagation delays add up (\(n\,t_{pd}\)) → slower, glitches in decoding intermediate states → max clock frequency \(f_{max}=\dfrac{1}{n\,t_{pd}}\)
Explanation

In a ripple counter only the first flip-flop gets the external clock. A toggle flip-flop divides the frequency of its clock by two, so each following stage, clocked by the output of the one before, divides again. The outputs read as a binary count, with \(Q_0\) the least significant bit. This is also the reason a counter is used as a frequency divider.

The drawback is the cumulative delay. Each flip-flop changes only after its predecessor, so for a change such as 0111 to 1000 the outputs pass through intermediate wrong values for a moment (0110, 0100, 0000, then 1000). If a decoder is looking at the outputs it may react to these short-lived wrong values, producing glitches. The total delay also limits the highest clock frequency. For a mod-\(N\) counter that is not a power of two, we detect the first unwanted state with a NAND gate and use it to clear all stages immediately. For a decade counter the first unwanted count is 1010, so we use \(Q_3\) and \(Q_1\), the only bits that are 1 together for the first time at that count. The unwanted state exists for a moment before the clear takes effect.
