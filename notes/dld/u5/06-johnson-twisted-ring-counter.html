Johnson (Twisted-Ring) Counter

Digital Logic Design · Unit V: Registers, Counters, and Memory Units

Johnson (Twisted-Ring) Counter
Subject
Digital Logic Design (24CS201)
Unit
Unit V: Registers, Counters, and Memory Units
Topic
6 of 10
Terms
Johnson counter, Ring counter, Shift register, Flip-flop, Decoder

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Feedback from the inverted last output: \(D_0=Q_{n-1}'\). \(n\) FFs → \(2n\) states (mod-\(2n\))
  • 4-bit sequence: 0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000 (8 states)

  • Each output is a square wave at \(f/8\) (period = 8 clocks), and each is a copy of the previous one delayed by one clock (a 4-FF Johnson counter = divide-by-8, 8 phases)

  • Advantages over ring: twice the states for the same FFs; any state decoded with only a 2-input AND gate; no glitches in decoding

  • Example use: 8-phase clock, motor control, digital waveform generators
  • Self-starting version needed to avoid unused-state loops (2n of \(2^n\) states used, rest is a lock-out)
Ring Johnson
States with \(n\) FFs \(n\) \(2n\)
Feedback \(Q_{n-1}\) \(Q_{n-1}'\)
Decoding none 2-input AND
Unused states \(2^n-n\) \(2^n-2n\)
Explanation

A ring counter is a shift register with its last output connected back to the first input. If a single 1 is loaded, it circulates, and each flip-flop output is high during exactly one clock period out of \(n\). No decoder is needed because the outputs are already the timing signals, but \(n\) flip-flops give only \(n\) states. The counter is not self-starting: if the register powers up in an arbitrary pattern, extra 1s circulate forever, so the initial pattern must be preset.

The Johnson counter feeds back the complement of the last output. The register fills up with 1s from one end, and then fills with 0s, so it goes through \(2n\) states with \(n\) flip-flops. Any one of the \(2n\) states can be recognised from two adjacent flip-flop outputs, so each decoded signal needs only a 2-input AND gate. The remaining \(2^n-2n\) states form separate loops, so a self-correcting circuit or a reset is required.
