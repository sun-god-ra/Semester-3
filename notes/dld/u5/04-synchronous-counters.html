Synchronous Counters

Digital Logic Design · Unit V: Registers, Counters, and Memory Units

Synchronous Counters
Subject
Digital Logic Design (24CS201)
Unit
Unit V: Registers, Counters, and Memory Units
Topic
4 of 10
Terms
BCD, Jk flip-flop, Don't care, K-map, Flip-flop

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • All FFs get the same clock → all change at the same time → delay = one \(t_{pd}\) + gate delay. Faster, no decoding glitches
  • 4-bit synchronous binary up counter with T FFs (or JK with \(J=K=T\)):

\[T_0=1,\quad T_1=Q_0,\quad T_2=Q_0Q_1,\quad T_3=Q_0Q_1Q_2\]

  • a bit toggles when all lower bits are 1
  • Down counter: \(T_1=Q_0'\), \(T_2=Q_0'Q_1'\), \(T_3=Q_0'Q_1'Q_2'\) (toggle when all lower bits are 0)
  • Up/down: control line \(M\) chooses
  • Synchronous BCD (decade) counter, JK flip-flops, sequence 0–9 then 0; states 10–15 don't care:

\[J_0=K_0=1,\quad J_1=Q_3'Q_0,\ K_1=Q_0,\quad J_2=K_2=Q_1Q_0,\quad J_3=Q_2Q_1Q_0,\ K_3=Q_0\]

  • check: at 1001 (9): \(J_3\) = 0 but \(K_3=Q_0=1\) → \(Q_3\to0\); \(J_1=Q_3'Q_0=0\), \(K_1=1\) → \(Q_1\) stays 0; so 1001 → 0000 ✓
  • Binary counter with parallel load / clear (74161, 74193): count, load, clear, up/down, carry out
  • Ripple vs synchronous — compare
Ripple (asynchronous) Synchronous
Clock only first FF all FFs
Speed slow, delay \(n\,t_{pd}\) fast, constant
Hardware less more (gates)
Glitches yes no
Design simple needs state table + K-maps
Explanation

In a synchronous counter every flip-flop gets the same clock, so they all change at once, and the delay does not depend on the number of bits. To make each bit change at the right time we add gates in front of the inputs. A binary counter bit has to flip when all the lower bits are 1, which is the same rule as carrying in addition, so \(T_i\) is the AND of the lower outputs. For down-counting the rule is "all lower bits are 0", so we use the complemented outputs.

The decade counter follows the standard design procedure. After simplification using the don't-cares for states 10–15, the equations are simple. Check one row to be sure: at state 1001 (9) we need the next state 0000. \(K_3=Q_0=1\) resets \(Q_3\); \(K_1=Q_0=1\) keeps \(Q_1\) at 0; \(J_2=K_2=Q_1Q_0=0\) holds \(Q_2\) at 0; and \(J_0=K_0=1\) toggles \(Q_0\) to 0. This gives 0000, as wanted.
