Unit V

Registers, Counters, and Memory Units

Digital Logic Design · 24CS201

Syllabus: Registers, shift registers, asynchronous and synchronous counters, ring counter, Johnson counter, timing sequences. Memory unit block diagram, ROM design and classification, RAM design and classification.

Part B questions for this unitPart A short questions

Topics in this unit

  1. RegistersRegister = group of flip-flops storing a multi-bit word. n FFs → n-bit register. Common clock
  2. Shift RegistersShift register: register that can shift its stored bits left or right by one position per clock. Chain of FFs; output of one → input of next
  3. Asynchronous (Ripple) CountersCounter = register that goes through a prescribed sequence of states on clock pulses. Modulus = number of states
  4. Synchronous CountersAll FFs get the same clock → all change at the same time → delay = one t{pd} + gate delay. Faster, no decoding glitches
  5. Ring CounterShift register whose last output is fed back to the first input (D0=Q{n-1}). Starts with a single 1 (preset one FF, clear others)
  6. Johnson (Twisted-Ring) CounterFeedback from the inverted last output: D0=Q{n-1}'. n FFs → 2n states (mod-2n)
  7. Timing SequencesControl unit of a computer needs timing signals T0,T1,T2,\ldots — one active per clock period, in order, to sequence operations (fetch, decode, execut…
  8. Memory Unit — Basic Concepts and Block DiagramMemory unit stores binary info in groups of bits called words; one byte = 8 bits
  9. ROM — Design and ClassificationROM (read-only memory): stores permanently; read only in normal operation. Has k inputs (address), n outputs (data), no data inputs, no write
  10. RAM — Design and ClassificationRAM (random access memory): read and write; volatile
