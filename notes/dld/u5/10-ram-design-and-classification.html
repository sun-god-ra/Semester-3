RAM — Design and Classification

Digital Logic Design · Unit V: Registers, Counters, and Memory Units

RAM — Design and Classification
Subject
Digital Logic Design (24CS201)
Unit
Unit V: Registers, Counters, and Memory Units
Topic
10 of 10
Terms
Decoder, Flip-flop, DRAM, Tri-state, SRAM

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • RAM (random access memory): read and write; volatile
  • Memory cell stores 1 bit. Cell array organised in rows × columns; row decoder + column decoder (2-D / coincident decoding) → much fewer gates than a single big decoder
    • \(2^{10}\) words with one decoder: 1024 AND gates. With 2-D: two \(5\to32\) decoders = \(32+32=64\) AND gates
  • Read/write operation of one word: address → decoder selects the word line → data lines ↔ cell (R/W controlled)
  • Memory expansion:
    • Increase word length: put chips side by side, same address, data lines separate (e.g., two \(1\text{K}\times8\) → \(1\text{K}\times16\))
    • Increase number of words: stack chips, upper address bits → decoder → chip selects (four \(1\text{K}\times8\) → \(4\text{K}\times8\); address \(A_{11}A_{10}\) select chip)
  • Classification
SRAM (static) DRAM (dynamic)
Cell 6 transistors (flip-flop) 1 transistor + 1 capacitor
Refresh not needed needed (every few ms) as capacitor leaks
Speed fast slower
Density / cost low / high high / low
Use cache, registers main memory
  • SDRAM, DDR = synchronous DRAM (clocked, double data rate)
  • Volatile: all RAM. Non-volatile RAM: NVRAM, battery backed
  • Tri-state buffers on data lines let many chips share one data bus (output enable)
  • Hierarchy: registers → cache (SRAM) → main memory (DRAM) → disk
Explanation

A RAM can be read and written at any location in the same time. Static RAM stores each bit in a flip-flop of about six transistors, so it keeps the data as long as power is applied, and it is fast but large. Dynamic RAM stores a bit as charge on a capacitor, with only one transistor to access it. This makes it very dense and cheap, but the charge leaks away, so every row has to be read and rewritten (refreshed) every few milliseconds. That is why SRAM is used for caches and DRAM for main memory.

Address decoding uses two decoders, one for the row and one for the column, because a single decoder for a big memory would need an enormous number of gates. With 1024 words arranged in 32×32 cells, two 5-to-32 decoders use 64 gates instead of 1024. To make a bigger memory out of smaller chips, wider words come from chips with the same address and different data lines, and more words come from using the high address bits through a decoder to select one chip at a time.
