Registers

Digital Logic Design · Unit V: Registers, Counters, and Memory Units

Registers
Subject
Digital Logic Design (24CS201)
Unit
Unit V: Registers, Counters, and Memory Units
Topic
1 of 10
Terms
Flip-flop, Tri-state, Multiplexer, Shift register

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Register = group of flip-flops storing a multi-bit word. \(n\) FFs → \(n\)-bit register. Common clock
  • Simplest register: \(n\) D flip-flops, common clock. Parallel load: \(Q\leftarrow D\) on every clock edge
  • Register with load control: don't gate the clock (causes skew and glitches). Keep the clock running and feed back \(Q\) through a MUX: if Load = 1 → new data, if Load = 0 → recirculate old data (avoid clock gating, causes timing problems)
  • Register with clear: direct (asynchronous) CLR to all FFs; or synchronous clear
  • Uses: hold data (CPU registers: accumulator, program counter, instruction register), buffer, temporary storage
  • IC: 74175 (quad D), 74374 (octal D with tri-state)
Explanation

A register is a set of flip-flops that share a clock and hold a multi-bit word. If we want the register to load only sometimes, the wrong way is to switch off the clock, because gating a clock introduces skew and glitches. The right way is to leave the clock running and put a multiplexer in front of each flip-flop: the multiplexer passes the new data when the load signal is 1 and the flip-flop's own output when it is 0.

A shift register moves the stored word one position per clock. Because all flip-flops change at the same edge, each one takes the value its left neighbour had just before the edge, so the bits do not race through. The four types differ in how the data enters and leaves. Serial-in parallel-out converts a serial stream, as received on a communication line, into a word; parallel-in serial-out does the reverse for transmitting. Shifting left by one position doubles an unsigned number and shifting right halves it, as in decimal where adding a zero multiplies by ten. A universal shift register puts a 4-to-1 multiplexer in front of each flip-flop so that one chip can hold, shift in either direction, or load in parallel.
