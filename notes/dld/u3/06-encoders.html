Encoders

Digital Logic Design · Unit III: Combinational Circuits and Programmable Logic Devices

Encoders
Subject
Digital Logic Design (24CS201)
Unit
Unit III: Combinational Circuits and Programmable Logic Devices
Topic
6 of 9
Terms
Encoder, Decoder, Priority encoder, Interrupt

Practice: Part B questions for Unit III and Part A short questions.

Notebook notes
  • Encoder: reverse of decoder. \(2^n\) (or fewer) inputs → \(n\)-bit code. Only one input is 1 at a time
  • Octal-to-binary (8-to-3) encoder

\[A_2=D_4+D_5+D_6+D_7,\quad A_1=D_2+D_3+D_6+D_7,\quad A_0=D_1+D_3+D_5+D_7\]

  • Problems: (1) if two inputs are 1 together, output is wrong. (2) all-zero input gives 000, same as \(D_0\) → ambiguous
  • Priority encoder: highest-numbered input wins; extra output V (valid) = 1 if any input is 1
\(D_0\) \(D_1\) \(D_2\) \(D_3\) \(x\) \(y\) \(V\)
0 0 0 0 X X 0
1 0 0 0 0 0 1
X 1 0 0 0 1 1
X X 1 0 1 0 1
X X X 1 1 1 1

\[x=D_2+D_3,\qquad y=D_3+D_1D_2',\qquad V=D_0+D_1+D_2+D_3\]

  • IC 74148 (8-to-3 priority). Used in interrupt controllers, keyboards
Explanation

An encoder does the opposite of a decoder: it takes one active line among many and produces its number as a binary code. In an octal-to-binary encoder, output bit \(A_0\) is 1 for the inputs 1, 3, 5, 7 (those with the lowest bit set), and the other bits follow the same idea.

The simple encoder has two problems. If two inputs are active together, the OR gates mix the two codes and give a wrong number. And when no input is active the output is 000, which cannot be told apart from input \(D_0\) active. A priority encoder solves the first by ignoring all inputs below the highest active one, and the second by adding a valid output V that says whether any input was active at all.
