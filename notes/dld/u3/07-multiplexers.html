Multiplexers

Digital Logic Design · Unit III: Combinational Circuits and Programmable Logic Devices

Multiplexers
Subject
Digital Logic Design (24CS201)
Unit
Unit III: Combinational Circuits and Programmable Logic Devices
Topic
7 of 9
Terms
Decoder, Multiplexer

Practice: Part B questions for Unit III and Part A short questions.

Notebook notes
  • MUX (data selector): \(2^n\) data inputs → one output; \(n\) select lines choose which input appears
  • 4-to-1 MUX:

\[Y=S_1'S_0'I_0+S_1'S_0I_1+S_1S_0'I_2+S_1S_0I_3\]

  • Built from: 4 AND gates + OR + 2 inverters (decoder + AND-OR). Enable input optional
  • ICs: 74151 (8:1), 74153 (dual 4:1), 74157 (quad 2:1)
  • Expanding: two 4:1 + one 2:1 → 8:1 ; 16:1 from five 4:1 (4 + 1)
  • Boolean function implementation with MUX: function of \(n\) variables with a \(2^{n-1}\)-to-1 MUX
    • connect \(n-1\) variables to the select lines, last variable (or its complement, 0, 1) to the data inputs
    • Example: \(F(x,y,z)=\sum m(1,2,6,7)\) using 4:1 MUX, selects \(x,y\)
\(xy\) rows \(F\) data input
00 \(m_0,m_1\) 0,1 \(z\)
01 \(m_2,m_3\) 1,0 \(z'\)
10 \(m_4,m_5\) 0,0 0
11 \(m_6,m_7\) 1,1 1
  • \(I_0=z,\ I_1=z',\ I_2=0,\ I_3=1\)
  • A MUX with \(2^n\) inputs can implement any function of \(n\) variables directly (inputs tied to 0/1 = truth table) → universal logic module
  • MUX tree, bus selection, parallel-to-serial conversion
Explanation

A multiplexer chooses one of several data inputs and sends it to the single output, like a railway switch. Internally the select lines are decoded to turn on one AND gate, and an OR gate collects the result. It is the basic building block for data routing in computers, such as choosing which register feeds the ALU.

Any function of \(n\) variables can be built from a MUX in one of two ways. A \(2^n\)-input MUX can have its data inputs tied to 0 or 1 according to the truth table, with the variables on the select lines. The smarter way uses only a \(2^{n-1}\)-input MUX. The first \(n-1\) variables go to the select lines, and for each select combination the last variable \(z\) is examined: if \(F\) equals 0 for both values of \(z\) we connect 0; if it is 1 for both we connect 1; if \(F=z\) we connect \(z\); if \(F=z'\) we connect \(z'\). This explains the data inputs in the example.
