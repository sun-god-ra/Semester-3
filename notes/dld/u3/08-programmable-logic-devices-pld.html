Programmable Logic Devices (PLD)

Digital Logic Design · Unit III: Combinational Circuits and Programmable Logic Devices

Programmable Logic Devices (PLD)

Notebook notes
  • PLD: IC whose logic is programmed by the user (not fixed by factory). Contains AND array and OR array with fuses / switches (programmable links)
  • Why: smaller chip count, faster design, easy changes, lower cost for small volume
  • Basic structure: inputs → AND array (generates product terms) → OR array (sums them) → outputs
  • Block diagram
Device AND array OR array
PROM fixed (full decoder, all \(2^n\) minterms) programmable
PLA programmable programmable
PAL programmable fixed
PROM as PLD
  • \(n\) inputs, \(m\) outputs → \(2^n\times m\) memory. Inputs are address, outputs are data. Each output is a sum of minterms
  • Good for functions with many minterms; wasteful for functions with few product terms (all \(2^n\) minterms exist, most unused)
  • Types: PROM (one-time), EPROM (UV erasable), EEPROM / Flash (electrical)
PLA (Programmable Logic Array)
  • Both arrays programmable → only the needed product terms are made, and shared between outputs → smaller than PROM
  • PLA program table has columns: product term, inputs (1, 0, – ), outputs (1 or –)
  • Example: \(F_1=AB'+AC+A'BC'\), \(F_2=(AC+BC)'\)
Product term \(A\) \(B\) \(C\) \(F_1\) \(F_2\)
1: \(AB'\) 1 0 – 1 –
2: \(AC\) 1 – 1 1 1
3: \(BC\) – 1 1 – 1
4: \(A'BC'\) 0 1 0 1 –
  • \(F_2\) is made as \((AC+BC)\) and then complemented by an XOR with programmable polarity at the output → 4 product terms in all
  • Size is given as inputs × product terms × outputs. Here 3 × 4 × 2
PAL (Programmable Array Logic)
  • AND array programmable, OR array fixed → cheaper and easier to program than PLA, but each output has a fixed number of product terms (e.g. 4)
  • Output often has flip-flop and feedback → can build sequential circuits (registered PAL)
  • Example: PAL16L8. A function needing more terms than the OR gate allows → split using a feedback through another output
  • GAL = generic array logic: re-programmable PAL (EEPROM based)
  • CPLD: several PAL-like blocks + programmable interconnect
Explanation

All three classic PLDs are an AND array followed by an OR array. They differ in which array can be programmed. The PROM has a fixed AND array that decodes every possible input combination, and a programmable OR array, so it implements the truth table of each output directly. The PLA allows both arrays to be programmed and so produces only the product terms that are needed, and lets outputs share them. The PAL programs only the AND array and fixes the OR array. This is cheaper and faster, but each output can only collect a fixed number of product terms, so a big function must be split across outputs using feedback.

A PLA is smaller than a PROM when the functions have few product terms. For example, with 3 inputs a PROM always has 8 product terms, while the function \(F_1\) in the notes needs only 3, and one of the PLA terms is shared by both outputs. The program table is read like a truth table: 1 means the variable appears true, 0 means complemented, a dash means it is absent from the term.
