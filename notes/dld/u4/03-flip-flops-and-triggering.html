Notebook notes
  • Flip-flop (FF): edge-triggered 1-bit memory. Changes state only at the clock edge — either positive (rising) edge ↑ or negative (falling) edge ↓
  • Triggering types
    • Level triggering: active during whole high/low level (latch). Race problem
    • Edge triggering: only at a transition (instant). Best
    • Pulse (master–slave) triggering: master accepts on one level, slave outputs on the other
  • Edge-triggered D FF = master-slave of two D latches, or 6-NAND-gate circuit
  • Symbol: triangle ▷ on the clock pin = edge-triggered; bubble = negative edge
Master–slave flip-flop
  • While CK = 1: master follows input, slave holds old output. When CK falls: master freezes, slave copies master → output changes once per clock, no race
  • Cures the race-around problem of the JK latch (when \(J=K=1\) and the clock pulse is longer than the propagation delay, output toggles repeatedly)
Types of flip-flops
FF Inputs Characteristic table Characteristic equation
SR \(S,R\) 00 hold, 01 reset, 10 set, 11 invalid \(Q^+=S+R'Q\), with \(SR=0\)
D \(D\) \(Q^+=D\) \(Q^+=D\)
JK \(J,K\) 00 hold, 01 reset, 10 set, 11 toggle \(Q^+=JQ'+K'Q\)
T \(T\) \(T=0\) hold, \(T=1\) toggle \(Q^+=T\oplus Q\)
  • \(Q^+\) (or \(Q(t+1)\)) = next state, \(Q\) = present state
  • D = delay / data FF, simple. JK = most versatile, no invalid state. T = toggle, used for counters
  • Conversions: JK → T: connect \(J=K=T\). JK → D: \(J=D\), \(K=D'\). D → T: \(D=T\oplus Q\). SR → JK needs feedback
Excitation tables (what input is needed for a given transition)
\(Q\) \(Q^+\) SR: \(S\,R\) JK: \(J\,K\) D T
0 0 0 X 0 X 0 0
0 1 1 0 1 X 1 1
1 0 0 1 X 1 0 1
1 1 X 0 X 0 1 0
  • Memorise the JK and T rows — used in every design problem
  • Direct inputs (asynchronous preset / clear): PRESET (set \(Q=1\)) and CLEAR (reset \(Q=0\)) act immediately, independent of clock, used to initialise. Usually active low (\(\overline{PR}\), \(\overline{CLR}\))
  • Timing parameters: setup time (input stable before the edge), hold time (after the edge), propagation delay \(t_{pd}\)
Explanation

A latch is sensitive to its input for the whole time the enable is active, so in a feedback circuit the output can change and then be fed back and change again within the same pulse. A flip-flop looks at the input only at the instant of the clock edge. In a master–slave arrangement two latches work on opposite clock levels. When the clock is high, the master follows the input but the slave holds the old value, so the output does not change. When the clock goes low, the master freezes and the slave copies it. Output changes only once per clock cycle, and there is no path from the output through the master back to the output during the same level.

The JK flip-flop works like an SR flip-flop but gives the toggle action for \(J=K=1\), which removes the forbidden case. Without a master–slave or edge-triggered structure, toggling would repeat for as long as the clock pulse stays high (race-around). The characteristic equation \(Q^+=JQ'+K'Q\) says: set when \(J=1\) and the output is 0, and keep the output when \(K=0\).

The excitation table is the characteristic table read backwards. Given the present and desired next state, it tells what to put on the inputs. For \(0\to0\) on a JK flip-flop, \(J\) must be 0 but \(K\) can be anything, since \(K=1\) also leaves a 0 at 0. That is where the don't-cares come from, and they reduce the logic in a design.

The preset and clear inputs are direct inputs that override the clock. They are used to put the circuit in a known state at power-up.
