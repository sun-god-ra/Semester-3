Design Procedure for Sequential Circuits

Digital Logic Design · Unit IV: Sequential Logic and State Machine Design

Design Procedure for Sequential Circuits
Subject
Digital Logic Design (24CS201)
Unit
Unit IV: Sequential Logic and State Machine Design
Topic
6 of 7
Terms
State diagram, Flip-flop, K-map

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes
  1. Word description → state diagram
  2. State reduction, if possible
  3. State table, state assignment
  4. Choose flip-flop type; number of FFs
  5. Use the excitation table to get the flip-flop input values for every row of the state table
  6. Simplify with K-maps (use don't-cares for unused states) → flip-flop input equations and output equations
  7. Draw the logic diagram; check unused states
Unused states
  • With \(n\) FFs there are \(2^n\) states; if fewer are used, the rest are unused (invalid) states
  • Treat them as don't-cares when simplifying → smaller logic
  • But the circuit might enter an unused state (noise, power-up). Check where it goes: it should return to a valid state (self-correcting). If it gets stuck → modify the design or add reset
Explanation

The design starts with a description in words and finishes with gates and flip-flops. The central step is to use the excitation table. For each row of the state table, compare the present and next values of each flip-flop bit, and read off the inputs that make that transition. These become columns of a truth table whose rows are the present states and inputs, and K-maps then give the simplest input equations.

The unused states are special. They never occur in normal operation, so they are don't-cares in the K-maps. But a circuit can still start in one of them at power-up or after a noise pulse. After finding the equations, always check what the circuit does from each unused state. If it goes to a valid state, the counter is self-correcting. If it stays in an unused cycle (a lock-out), the design must be changed.
