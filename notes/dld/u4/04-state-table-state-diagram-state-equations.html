State Table, State Diagram, State Equations

Digital Logic Design · Unit IV: Sequential Logic and State Machine Design

State Table, State Diagram, State Equations
Subject
Digital Logic Design (24CS201)
Unit
Unit IV: Sequential Logic and State Machine Design
Topic
4 of 7
Terms
State diagram, Flip-flop

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes
  • State table: present state, input → next state, output (for each combination)
  • State diagram: circles = states, arrows = transitions labelled input/output (Mealy) or just input (Moore, output inside the circle)
  • State equations (flip-flop input equations): \(A(t+1)=\ldots\) in terms of present state and inputs
  • Analysis procedure: circuit → input equations → state equations (use characteristic eq.) → state table → state diagram

Example (Mealy "101" detector, overlapping): output 1 when last three inputs are 1,0,1

Present \(x=0\): next / out \(x=1\): next / out
S0 S0 / 0 S1 / 0
S1 S2 / 0 S1 / 0
S2 S0 / 0 S1 / 1
Explanation

The state table and state diagram carry the same information. The state diagram is easier for humans to read, and the table is what is used for the design. In the example, the machine must remember how much of the pattern 101 has been seen. State S0 means nothing useful has been seen, S1 means the last input was 1, S2 means the last two inputs were 10. When a 1 arrives in S2 the pattern is complete, so the Mealy output is 1, and since this last 1 can start a new pattern, the next state is S1. That is what makes the detector overlapping.
