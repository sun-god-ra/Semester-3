Unit IV

Sequential Logic and State Machine Design

Digital Logic Design · 24CS201

Syllabus: Sequential circuits, classification, latches, flip-flops, triggering, master-slave, excitation tables, direct inputs. State table, state diagram, state equations, state reduction and assignment, design procedure, unused states, counter design.

Part B questions for this unitPart A short questions

Topics in this unit

  1. Sequential Circuits — IntroductionSequential circuit = combinational logic + memory (storage elements). Output depends on present inputs AND present state (past history)
  2. LatchesLatch = basic 1-bit memory, level-sensitive; output follows input while enabled
  3. Flip-Flops and TriggeringFlip-flop (FF): edge-triggered 1-bit memory. Changes state only at the clock edge — either positive (rising) edge ↑ or negative (falling) edge ↓
  4. State Table, State Diagram, State EquationsState table: present state, input → next state, output (for each combination)
  5. State Reduction and State AssignmentState reduction: fewer states → fewer flip-flops and gates. Two states are equivalent if, for every input sequence, they give the same outputs and go …
  6. Design Procedure for Sequential Circuits1. Word description → state diagram
  7. Counter DesignExample: counter with sequence 0\to1\to2\to4\to6\to0 (binary 000,001,010,100,110), state ABC, using JK flip-flops. Unused: 3, 5, 7 (don't-cares)
