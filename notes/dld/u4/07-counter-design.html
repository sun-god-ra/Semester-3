Counter Design

Digital Logic Design · Unit IV: Sequential Logic and State Machine Design

Counter Design
Subject
Digital Logic Design (24CS201)
Unit
Unit IV: Sequential Logic and State Machine Design
Topic
7 of 7
Terms
Jk flip-flop, K-map, Flip-flop

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes

Example: counter with sequence \(0\to1\to2\to4\to6\to0\) (binary 000,001,010,100,110), state \(ABC\), using JK flip-flops. Unused: 3, 5, 7 (don't-cares)

Present \(ABC\) Next \(ABC\) \(J_A K_A\) \(J_B K_B\) \(J_C K_C\)
000 001 0 X 0 X 1 X
001 010 0 X 1 X X 1
010 100 1 X X 1 0 X
100 110 X 0 1 X 0 X
110 000 X 1 X 1 0 X
  • K-map simplification (with don't-cares at 3, 5, 7):

\[J_A=B,\ K_A=B;\qquad J_B=A+C,\ K_B=1;\qquad J_C=A'B',\ K_C=1\]

  • Check unused states with these equations: \(011\to100\), \(101\to110\), \(111\to000\) → all return to valid sequence ✓ self-starting
  • Binary counter with T flip-flops: a \(n\)-bit up counter: \(T_0=1\), \(T_1=Q_0\), \(T_2=Q_0Q_1\), \(T_3=Q_0Q_1Q_2\) (toggle when all lower bits are 1)
  • Mod-\(N\) counter needs \(\lceil\log_2N\rceil\) FFs; counts \(N\) states then returns to zero
  • Up/down counter: add a control \(M\): \(T_i=M\,(Q_{i-1}\cdots Q_0)+M'\,(Q'_{i-1}\cdots Q'_0)\)
Explanation

For the counter in the notes, each flip-flop is treated separately. For bit \(A\), the transitions \(0\to1\) and \(1\to0\) happen from states 010 and 110, respectively, which are the states where \(B=1\). That is why \(J_A=K_A=B\). The don't-cares at the unused states 3, 5, and 7 allowed \(K_B=1\) and \(K_C=1\) to be constants, since a 1 on \(K\) is harmless whenever the bit is already 0. Substituting the unused states into the final equations shows that 011 goes to 100, 101 to 110, and 111 to 000, so the counter recovers from all of them.

A binary up-counter is simplest with T flip-flops. A bit has to toggle exactly when all lower bits are 1, so \(T_i\) is the AND of all lower outputs. A counter with \(n\) flip-flops can count up to \(2^n\) states, and a mod-\(N\) counter uses the first \(N\) of them and returns to zero.
