Latches

Digital Logic Design · Unit IV: Sequential Logic and State Machine Design

Latches
Subject
Digital Logic Design (24CS201)
Unit
Unit IV: Sequential Logic and State Machine Design
Topic
2 of 7
Terms
Latch, Sr latch, NOR, NAND, Flip-flop

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes
  • Latch = basic 1-bit memory, level-sensitive; output follows input while enabled
  • SR latch (NOR): inputs \(S\) (set), \(R\) (reset). Two cross-coupled NOR gates
\(S\) \(R\) \(Q\) (next) Action
0 0 no change memory
0 1 0 reset
1 0 1 set
1 1 invalid (\(Q=Q'=0\)) forbidden
  • SR latch (NAND): inputs are active low (\(S',R'\)). \(S'R'=00\) forbidden; \(11\) = hold
  • Gated (clocked) SR latch: enable \(E\) / clock: \(S\), \(R\) affect output only when \(E=1\)
  • D latch (data / transparent): gated SR with \(S=D\), \(R=D'\) → removes the invalid state. When \(E=1\): \(Q=D\); when \(E=0\): holds
  • Problem: while the enable is high, any change of input passes through (transparent) → feedback may cause race / oscillation. Solution: flip-flops
Explanation

A latch stores one bit using two gates connected in a loop. In the SR latch made of NOR gates, a 1 on \(S\) forces \(Q\) to 1, a 1 on \(R\) forces \(Q\) to 0, and with both at 0 the cross-coupling keeps whatever was stored. The combination \(S=R=1\) forces both outputs to 0, which breaks the rule that \(Q\) and \(Q'\) are complements, and when both inputs return to 0 together the final state is unpredictable. That is why it is forbidden.

The D latch avoids the forbidden case by connecting \(S=D\) and \(R=D'\), so the two can never be 1 together. It is called transparent because, while the enable is high, the output simply follows the input.
