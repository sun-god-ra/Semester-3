Sequential Circuits — Introduction

Digital Logic Design · Unit IV: Sequential Logic and State Machine Design

Sequential Circuits — Introduction
Subject
Digital Logic Design (24CS201)
Unit
Unit IV: Sequential Logic and State Machine Design
Topic
1 of 7
Terms
Flip-flop, Moore machine, Mealy machine

Practice: Part B questions for Unit IV and Part A short questions.

Notebook notes
  • Sequential circuit = combinational logic + memory (storage elements). Output depends on present inputs AND present state (past history)
  • Block diagram: inputs → combinational logic → outputs; next state fed back through storage elements (flip-flops)
  • Classification
    • Synchronous: state changes only at clock pulses. Predictable, easy to design. (Clocked sequential)
    • Asynchronous: state changes whenever inputs change; no clock. Faster but hazards, races
    • Moore model: outputs depend only on present state
    • Mealy model: outputs depend on present state and present inputs
  • Moore outputs are written in the state; Mealy outputs on the arrows (input/output)
  • Moore: output changes only at clock edge, may need more states. Mealy: fewer states, output may glitch when input changes
Explanation

In a combinational circuit the output is a pure function of the present inputs. That is not enough for anything that must remember, such as a counter, which needs to know what number it has reached. A sequential circuit adds storage, and the stored bits are called the state. The next state and the outputs are computed from the input and the present state, and the next state is loaded into the storage on the clock.

In a synchronous circuit all storage elements change together on a common clock edge. This makes the timing predictable: between clock edges the logic has time to settle, and then everything is sampled together. Asynchronous circuits have no clock and react as soon as an input changes, which can be fast but makes them hard to design because of races and hazards.

The two models differ in where the output comes from. In a Moore machine the output depends only on the state, so it is stable for the whole clock period and changes only when the state changes. In a Mealy machine the output also depends on the current input, so it can react within the same clock period, and the machine often needs fewer states. The price is that a changing input can make the output change at any time, so the output can glitch.
