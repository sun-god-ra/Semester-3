Don't-Care Conditions

Digital Logic Design · Unit II: Boolean Function Simplification and Combinational Logic Design

Don't-Care Conditions
Subject
Digital Logic Design (24CS201)
Unit
Unit II: Boolean Function Simplification and Combinational Logic Design
Topic
4 of 10
Terms
BCD

Practice: Part B questions for Unit II and Part A short questions.

Notebook notes
  • Some input combinations never occur (e.g. BCD codes 1010–1111) or the output doesn't matter. Marked X (or d) on the map
  • Treat an X as 1 if it helps to make a bigger group, otherwise 0. Never need to cover all X's
  • Example: \(F=\sum m(1,3,7,11,15)+d(0,2,5)\)
  • \(F=A'B'+CD\) (X at 5 left as 0). Without X's it would cost more literals
  • Don't-cares in POS: treat X as 0 when it helps
Explanation

In many designs some inputs never happen. A BCD digit never takes the values 1010 to 1111, so what the circuit outputs for those inputs does not matter. We mark them X on the map and use them where they help: an X may be treated as a 1 to enlarge a group, or as a 0 if it does not help. We never have to cover all of them. In the example, using the X at cells 0 and 2 turns two 1s that were not joined into a group of four, which saves two literals in the term \(A'B'\).
