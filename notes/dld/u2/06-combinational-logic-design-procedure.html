Combinational Logic — Design Procedure

Digital Logic Design · Unit II: Boolean Function Simplification and Combinational Logic Design

Combinational Logic — Design Procedure
Subject
Digital Logic Design (24CS201)
Unit
Unit II: Boolean Function Simplification and Combinational Logic Design
Topic
6 of 10
Terms
K-map, Comparator

Practice: Part B questions for Unit II and Part A short questions.

Notebook notes
  • Combinational circuit: outputs depend only on present inputs. No memory, no feedback. \(n\) inputs, \(m\) outputs
  • Design steps
    1. Read the specification, decide number of inputs and outputs
    2. Assign symbols, build the truth table
    3. Get simplified Boolean functions for each output (K-map)
    4. Draw the logic diagram (check fan-in, gates available)
    5. Verify with the truth table
  • Analysis procedure (circuit → function)
    1. Label all gate outputs that are functions of inputs only
    2. Label next-level gate outputs with names. Continue to the outputs
    3. Write each output as an expression, substitute step by step
    4. Build the truth table from the final expression
    5. State what the circuit does (adder? comparator?)
Explanation

Design goes from words to hardware: decide the inputs and outputs, write the truth table, simplify each output with a K-map, and draw the gates. Analysis goes the other way, from a drawn circuit to what it does. Label the output of each gate, write expressions from the inputs towards the outputs, and construct a truth table to recognise the function. Since the circuit has no memory, the truth table describes it completely.
