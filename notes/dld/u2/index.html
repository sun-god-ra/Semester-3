Unit II

Boolean Function Simplification and Combinational Logic Design

Digital Logic Design · 24CS201

Syllabus: K-map (2, 3, 4, 5 variable), product of sums, don't cares, tabulation method, prime implicants. Combinational logic: design procedure, adders, subtractors, code conversion, analysis procedure, XOR gates, parity generators and checkers.

Part B questions for this unitPart A short questions

Topics in this unit

  1. The Map Method — Karnaugh Map (K-map)A K-map = truth table redrawn as a grid so that adjacent cells differ in exactly one variable. Lets us simplify by eye (graphical method)
  2. Five-Variable MapTwo 4-variable maps side by side: A=0 (minterms 0–15) and A=1 (minterms 16–31)
  3. Product-of-Sums SimplificationTo get POS: group the 0s → get F' in SOP → complement with De Morgan
  4. Don't-Care ConditionsSome input combinations never occur (e.g. BCD codes 1010–1111) or the output doesn't matter. Marked X (or d) on the map
  5. Tabulation (Quine–McCluskey) MethodSystematic method — works for any number of variables, programmable. K-map is limited to ~5–6 variables
  6. Combinational Logic — Design ProcedureCombinational circuit: outputs depend only on present inputs. No memory, no feedback. n inputs, m outputs
  7. Adders and Subtractors| x | y | C | S |
  8. Code ConversionDesign a combinational circuit that converts one code to another. Inputs = bits of the source code, outputs = target code. Unused input combos → don't…
  9. Exclusive-OR Functions2-input: x\oplus y=xy'+x'y; XNOR: x\odot y=xy+x'y'=(x\oplus y)'
  10. Parity Generators and CheckersParity bit added to message so total number of 1s is even (even parity) or odd (odd parity)
