24CS201

Digital Logic Design

Engineering Science · 3 credits · L-T-P 3-0-0

Questions and answers

Units

  1. Unit I Number Systems, Boolean Algebra, and Logic Gates12 topics

    Binary systems: digital computers and systems, number systems, conversions, r's and (r-1)'s complements, binary codes, integer and floating-point representation, integer arithmetic. Boolean algebra: definitions, axioms, theorems, functions, canonical and standard forms, other logic operations, logic gates.

  2. Unit II Boolean Function Simplification and Combinational Logic Design10 topics

    K-map (2, 3, 4, 5 variable), product of sums, don't cares, tabulation method, prime implicants. Combinational logic: design procedure, adders, subtractors, code conversion, analysis procedure, XOR gates, parity generators and checkers.

  3. Unit III Combinational Circuits and Programmable Logic Devices9 topics

    Binary parallel adder, decimal adder, magnitude comparator, decoders, demultiplexers, encoders, multiplexers. PLD, PROM, PLA, PAL, introduction to FPGA.

  4. Unit IV Sequential Logic and State Machine Design7 topics

    Sequential circuits, classification, latches, flip-flops, triggering, master-slave, excitation tables, direct inputs. State table, state diagram, state equations, state reduction and assignment, design procedure, unused states, counter design.

  5. Unit V Registers, Counters, and Memory Units10 topics

    Registers, shift registers, asynchronous and synchronous counters, ring counter, Johnson counter, timing sequences. Memory unit block diagram, ROM design and classification, RAM design and classification.
