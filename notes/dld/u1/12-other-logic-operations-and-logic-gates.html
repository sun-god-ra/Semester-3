Other Logic Operations and Logic Gates

Topic
12 of 12
Terms
NAND, NOR, XOR, XNOR, Universal gate, Fan-out, Propagation delay, De morgan

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • With 2 variables there are 16 Boolean functions. Important ones:
Name Symbol Expression Truth (00,01,10,11)
AND \(x\cdot y\) \(xy\) 0 0 0 1
OR \(x+y\) \(x+y\) 0 1 1 1
NOT \(x'\) \(\bar x\) 1 0
NAND \((xy)'\) 1 1 1 0
NOR \((x+y)'\) 1 0 0 0
XOR \(x\oplus y\) \(xy'+x'y\) 0 1 1 0
XNOR (equivalence) \(x\odot y\) \(xy+x'y'\) 1 0 0 1
Inhibition \(xy'\) 0 0 1 0
Implication \(x'+y\) 1 1 0 1
  • XOR properties: \(x\oplus0=x\), \(x\oplus1=x'\), \(x\oplus x=0\), \(x\oplus x'=1\); commutative & associative. XOR of \(n\) bits = 1 if odd number of 1s (odd-parity function). XNOR = 1 if even number of 1s
  • Universal gates: NAND and NOR alone can build any function
    • NOT from NAND: tie inputs: \((xx)'=x'\)
    • AND = NAND followed by NAND-as-NOT. OR = NAND of inverted inputs (\(x'\) NAND \(y'\) = \(x+y\))
    • NOR dual
  • Logic gates (standard symbols): AND (flat back, D-shape), OR (curved back), NOT (triangle + bubble), NAND/NOR = AND/OR + bubble, XOR = OR with extra curved line
  • Positive / negative logic, fan-in, fan-out, propagation delay, noise margin — gate characteristics
  • Gate families: TTL (7400, 5 V), CMOS (low power), ECL (fastest), NMOS/PMOS
  • NAND-only / NOR-only conversion of SOP: SOP → NAND-NAND two-level; POS → NOR-NOR two-level
    • \(F=AB+CD\) → \(F=((AB)'(CD)')'\)
Explanation

With two inputs there are 16 possible functions, but only a few have names. NAND and NOR are complete: any function can be built using NAND gates alone, or NOR gates alone. This matters in practice because the NAND gate is the cheapest to make in CMOS and TTL, so real designs are often converted to all-NAND. To convert an SOP to two-level NAND-NAND, double-complement the expression and use De Morgan once: \(AB+CD=((AB)'\cdot(CD)')'\), so each AND becomes a NAND and the OR becomes a NAND with the same inputs.

The XOR gate gives 1 when the inputs differ. For many inputs it gives 1 when an odd number of inputs are 1, which is why XOR trees are used to compute parity. XNOR is the equality detector. Real gates have a propagation delay, a limited fan-out (how many gate inputs one output can drive), and a noise margin, and these limits decide how circuits are built in practice.
