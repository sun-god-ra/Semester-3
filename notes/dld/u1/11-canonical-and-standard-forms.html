Canonical and Standard Forms

Digital Logic Design · Unit I: Number Systems, Boolean Algebra, and Logic Gates

Canonical and Standard Forms
Subject
Digital Logic Design (24CS201)
Unit
Unit I: Number Systems, Boolean Algebra, and Logic Gates
Topic
11 of 12
Terms
Minterm, Maxterm, Sum of products, K-map

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • Minterm \(m_i\): AND term containing all variables, each in true or complemented form; equals 1 for exactly one input row. \(x'yz=m_3\) (011)
  • Maxterm \(M_i\): OR term containing all variables; equals 0 for exactly one row. \(M_i=m_i'\). \(x+y'+z'=M_3\) (011, complemented bits)
  • Complement relation: \(m_i'=M_i\)
\(x y z\) minterm maxterm
000 \(x'y'z'=m_0\) \(x+y+z=M_0\)
001 \(x'y'z=m_1\) \(x+y+z'=M_1\)
010 \(x'yz'=m_2\) \(x+y'+z=M_2\)
011 \(x'yz=m_3\) \(x+y'+z'=M_3\)
100 \(xy'z'=m_4\) \(x'+y+z=M_4\)
101 \(xy'z=m_5\) \(x'+y+z'=M_5\)
110 \(xyz'=m_6\) \(x'+y'+z=M_6\)
111 \(xyz=m_7\) \(x'+y'+z'=M_7\)
  • Canonical SOP (sum of minterms): \(F=\sum m(\ldots)\) — list rows where \(F=1\)
  • Canonical POS (product of maxterms): \(F=\prod M(\ldots)\) — list rows where \(F=0\)
  • Same function: \(F(x,y,z)=\sum m(1,4,5,6,7)=\prod M(0,2,3)\). The indices not in the Σ are in the Π
  • \(F'=\sum m(0,2,3)\) (missing minterms)
  • Converting a non-canonical expression to canonical SOP: expand missing variables using \(x=x(y+y')\)
    • \(F=A+B'C\) → \(A(B+B')(C+C')+B'C(A+A')=\sum m(1,4,5,6,7)\)
  • Standard forms: SOP/POS where terms need not contain all variables (simplified). Examples: \(F=y'+xy+x'yz'\) (SOP), \(F=x(y'+z)(x'+y+z')\) (POS)
  • Two-level implementation: SOP → AND-OR; POS → OR-AND
Explanation

A minterm is a product term that is 1 for exactly one combination of the inputs. To get a function from its truth table we OR the minterms of all the rows where the function is 1. This gives the canonical sum of products. A maxterm is a sum that is 0 for exactly one input combination, and the function is the AND of the maxterms for the rows where it is 0. Both forms describe the same function, so their index lists are complementary, which is a useful check on an answer.

A common mistake is the maxterm numbering. The maxterm \(M_i\) has the variable written uncomplemented where the bit in row \(i\) is 0, and complemented where the bit is 1, because the sum must be zero at that row. So row 011 gives \(x+y'+z'\).

Canonical forms are unique but big. The standard forms drop the requirement that every term contains every variable, and the simplified expressions we get from K-maps are in standard form. SOP leads to a two-level AND-OR circuit, POS to OR-AND.
