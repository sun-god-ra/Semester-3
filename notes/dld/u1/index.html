Unit I

Number Systems, Boolean Algebra, and Logic Gates

Digital Logic Design · 24CS201

Syllabus: Binary systems: digital computers and systems, number systems, conversions, r's and (r-1)'s complements, binary codes, integer and floating-point representation, integer arithmetic. Boolean algebra: definitions, axioms, theorems, functions, canonical and standard forms, other logic operations, logic gates.

Part B questions for this unitPart A short questions

Topics in this unit

  1. Digital Computers and Digital SystemsAnalog signal: continuous values (voltage varies smoothly). Digital signal: only discrete values, usually 2 → binary 0 and 1
  2. Number SystemsPositional number system with base (radix) r: digits 0\ldots r-1
  3. Number Base ConversionsAny base → decimal: multiply each digit by its weight r^i and add
  4. Complements — $r$'s and $(r-1)$'sUsed to represent negative numbers and to subtract using addition
  5. Binary CodesBCD (8421): each decimal digit → 4-bit binary. 457=0100\ 0101\ 0111. Codes 1010–1111 invalid
  6. Integer and Floating-Point RepresentationUnsigned n bits: 0 to 2^n-1
  7. Integer ArithmeticBinary addition: 0+0=0, 0+1=1, 1+1=10 (sum 0 carry 1), 1+1+1=11
  8. Boolean Algebra — Definitions and AxiomsBoolean algebra = algebra of two values \{0,1\} with operations AND (·), OR (+), NOT (′ or bar)
  9. Basic Theorems and Properties| Law | Form 1 (OR) | Form 2 (AND) |
