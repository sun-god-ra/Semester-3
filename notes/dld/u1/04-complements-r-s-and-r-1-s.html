Complements — $r$'s and $(r-1)$'s

Digital Logic Design · Unit I: Number Systems, Boolean Algebra, and Logic Gates

Complements — $r$'s and $(r-1)$'s
Subject
Digital Logic Design (24CS201)
Unit
Unit I: Number Systems, Boolean Algebra, and Logic Gates
Topic
4 of 12

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • Used to represent negative numbers and to subtract using addition
  • For base \(r\), number \(N\) with \(n\) digits:
    • \((r-1)\)'s complement \(=r^{n}-r^{-m}-N\) (for integers: \(r^n-1-N\))
    • \(r\)'s complement \(=r^{n}-N\) (for \(N\ne0\)) \(=\) \((r-1)\)'s complement \(+1\) (in the last place)
Binary (\(r=2\)) Decimal (\(r=10\))
\((r-1)\)'s 1's complement — flip every bit 9's complement — 9 − each digit
\(r\)'s 2's complement — 1's complement + 1 10's complement — 9's compl. + 1
  • Shortcut for 2's complement: copy bits from the right up to and including the first 1, flip all remaining bits
  • Examples
    • 1's compl. of 1011001 = 0100110
    • 2's compl. of 1011001 = 0100111
    • 9's compl. of 546700 = 453299 ; 10's compl. = 453300
  • Subtraction \(M-N\) using \(r\)'s complement
    1. add \(M\) + \(r\)'s compl. of \(N\)
    2. if an end carry occurs → discard it, result is positive \(M-N\)
    3. if no end carry → result is negative; answer \(=-(r\text{'s compl. of the sum})\)
  • Using \((r-1)\)'s complement: add; if end carry → add it back (end-around carry); if none → negative, answer is \(-(\,(r-1)\text{'s compl. of sum})\)
  • Example: \(1010100-1000011\) (84 − 67) in 2's complement: 2's compl. of 1000011 = 0111101; sum = 1 0010001 → discard carry → \(0010001=17\) ✓
Explanation

Subtraction needs a different circuit than addition, but complements let one adder do both. In base \(r\), the \(r\)'s complement of \(N\) is \(r^n-N\). So \(M-N=M+(r^n-N)-r^n\), which is \(M\) plus the complement, minus \(r^n\). Subtracting \(r^n\) is the same as discarding the carry out of the top digit. That is why an end carry means the answer is positive and is simply dropped.

If there is no end carry the true answer is negative. The sum then equals \(r^n-(N-M)\), which is the complement of the magnitude. So we take the complement again and attach a minus sign. With the \((r-1)\)'s complement the sum is one short, so the end carry is added back at the bottom. This is the end-around carry.

In binary the 1's complement is just flipping every bit, which is why it is cheap in hardware. The 2's complement adds one to that. The shortcut of keeping everything up to the first 1 and flipping the rest gives the same answer and is quicker by hand.
