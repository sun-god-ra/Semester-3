Correlation Based on Ranks — Spearman's $r_s$

Probability and Statistics · Unit V: Non-Parametric Statistical Tests

Correlation Based on Ranks — Spearman's $r_s$
Subject
Probability and Statistics (24MA203)
Unit
Unit V: Non-Parametric Statistical Tests
Topic
5 of 7
Terms
Spearman

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Measures monotonic association using ranks (not values). Range \(-1\le r_s\le1\)
  • Steps: rank \(x\)'s and \(y\)'s separately (ties → average rank), \(d_i=\) rank\((x_i)-\)rank\((y_i)\)

\[r_s=1-\frac{6\sum d_i^2}{n(n^2-1)}\]

  • \(r_s=+1\) perfect agreement of ranks, \(-1\) perfect reverse, 0 none
  • \(H_0\): no association (\(\rho_s=0\)). Small \(n\) → table of critical \(r_s\) (two-sided 5%: \(n=8\): 0.738, \(n=10\): 0.648). Large \(n\):

\[z=r_s\sqrt{n-1}\qquad(\text{lecture slides use } z=r_s\sqrt{n};\ \text{write the slide version and note this one})\]

  • Used when data are ordinal or relation is non-linear but monotone, or outliers
  • With many ties the shortcut formula is only approximate → compute Pearson \(r\) on the ranks

Example 1: ranks 1..8 vs 2,1,4,3,6,5,8,7: \(d=\mp1\) each, \(\sum d^2=8\)

  • \(r_s=1-\frac{6\cdot8}{8\cdot63}=0.905>0.738\) → significant positive association

Example 2: \(n=10\) pairs gave \(\sum d^2=194\) → \(r_s=1-\frac{1164}{990}=-0.176\); \(|r_s|<0.648\) → no significant association

Example 3 (large \(n\)): \(r_s=0.6\), \(n=30\) → \(z=0.6\sqrt{29}=3.23>1.96\) → reject \(H_0\)

Explanation

Pearson's coefficient measures straight-line association and is thrown off by outliers. Spearman's coefficient replaces the values with their ranks, so it measures whether one variable tends to rise when the other rises, whatever the shape of the curve. If the ranks agree exactly, every \(d_i\) is zero and \(r_s=1\). The more the ranks disagree, the larger \(\sum d_i^2\) and the smaller \(r_s\). The formula is just Pearson's \(r\) computed on the ranks, simplified for the case without ties.

For small \(n\) we compare \(|r_s|\) with a table value. In Example 1 the ranks nearly agree, so \(r_s=0.905\) exceeds the critical value 0.738. In Example 2, with \(r_s=-0.176\), the value is far from the critical 0.648, so no association is shown. For large \(n\) we use \(z=r_s\sqrt{n-1}\). Tables for critical values differ slightly between books, so use the one printed in your own textbook.
