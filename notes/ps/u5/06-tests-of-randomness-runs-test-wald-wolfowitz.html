Tests of Randomness — Runs Test (Wald–Wolfowitz)

Probability and Statistics · Unit V: Non-Parametric Statistical Tests

Tests of Randomness — Runs Test (Wald–Wolfowitz)
Subject
Probability and Statistics (24MA203)
Unit
Unit V: Non-Parametric Statistical Tests
Topic
6 of 7
Terms
Runs test, Variance

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Run = unbroken sequence of identical symbols. HHTTTH has runs: HH, TTT, H → 3 runs
  • \(H_0\): the order of the sequence is random
  • Too few runs → clustering / trend. Too many runs → alternating pattern / cyclic
  • Numeric data → convert to two symbols: above (+) / below (−) the median (or mean); drop values equal to it
  • Let \(n_1,n_2\) = counts of each symbol, \(r\) = number of runs
  • Small sample (either count below 10 in the lecture slides; many books use \(\le20\)): compare \(r\) with table lower & upper critical values; reject if \(r\le\) lower or \(r\ge\) upper. Use the normal approximation below when both counts are at least 10.
  • Large sample:

\[\mu_r=\frac{2n_1n_2}{n_1+n_2}+1,\qquad \sigma_r^2=\frac{2n_1n_2(2n_1n_2-n_1-n_2)}{(n_1+n_2)^2(n_1+n_2-1)},\qquad z=\frac{r-\mu_r}{\sigma_r}\]

Example 1: HHTTTHTHHHTTHTHT → \(n_1=8\), \(n_2=8\), \(r=10\)

  • \(\mu_r=9\), \(\sigma_r=1.93\), \(z=0.52\). Table (8,8): critical 4 and 14; \(4<10<14\) → random

Example 2: \(n_1=18\), \(n_2=12\), \(r=10\)

  • \(\mu_r=15.4\), \(\sigma_r=2.58\), \(z=-2.09<-1.96\) → reject randomness (too few runs → clustering)
Explanation

The runs test checks the order of observations rather than their values. A run is a block of identical symbols, and the number of runs tells us about the pattern. Too few runs means similar values cluster together, as in a trend. Too many means the sequence alternates unnaturally, as in a cyclic pattern. A truly random arrangement is in between.

For numerical data, mark each value as above or below the median and then count the runs. Values exactly equal to the median are dropped. With few observations we use a table of critical run counts, with both a lower and an upper limit. For larger samples, the number of runs is approximately normal with the mean and variance given in the notes. In Example 2 the observed 10 runs is well below the expected 15.4, so the sequence is not random and shows clustering.
