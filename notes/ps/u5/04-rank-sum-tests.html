Notebook notes
4a. Mann–Whitney U test (Wilcoxon rank-sum) — two independent samples
  • \(H_0\): both samples from the same population (same distribution / median)
  • Steps
    1. pool both samples, rank all \(n_1+n_2\) values (1 = smallest); ties → average rank
    2. \(R_1\) = sum of ranks of sample 1
    3. \[U_1=R_1-\frac{n_1(n_1+1)}{2},\qquad U_2=n_1n_2-U_1\]
    4. \(U=\min(U_1,U_2)\); reject if \(U\le\) table value
  • Large samples (\(n_1,n_2>8\) roughly):

\[\mu_U=\frac{n_1n_2}{2},\qquad \sigma_U=\sqrt{\frac{n_1n_2(n_1+n_2+1)}{12}},\qquad z=\frac{U-\mu_U}{\sigma_U}\]

Example: A: 27 31 29 35 38 26 33 (\(n_1=7\)); B: 22 25 28 24 30 21 23 27.5 (\(n_2=8\))

  • ranks of A: 7, 12, 10, 14, 15, 6, 13 → \(R_1=77\)
  • \(U_1=77-28=49\), \(U_2=56-49=7\), \(U=7\)
  • critical \(U\) (\(n_1=7,n_2=8\), two-sided 5%) \(=10\); \(7\le10\) → reject
  • (normal approx gives \(z=2.43\) with \(\mu_U=28\), \(\sigma_U=8.64\) — same decision; exact \(p=0.014\))
4b. Kruskal–Wallis H test — \(k\ge3\) independent samples
  • Non-parametric version of one-way ANOVA. \(H_0\): all \(k\) populations identical
  • Rank all \(N=\sum n_i\) values together; \(R_i\) = rank sum of sample \(i\)

\[H=\frac{12}{N(N+1)}\sum_{i=1}^{k}\frac{R_i^2}{n_i}-3(N+1)\]

  • \(H\approx\chi^2_{k-1}\) (each \(n_i\ge5\) ideally). Reject if \(H>\chi^2_{\alpha}(k-1)\)

Example: G1: 27 31 29 35 ; G2: 22 25 28 24 30 ; G3: 21 23 26 20 (\(N=13\))

  • \(R_1=43,\ R_2=34,\ R_3=14\) (check 43+34+14 = 91 = 13·14/2 ✓)
  • \(H=\frac{12}{13\cdot14}\left(\frac{43^2}{4}+\frac{34^2}{5}+\frac{14^2}{4}\right)-42=6.95\)
  • \(\chi^2_{0.05}(2)=5.991\); \(6.95>5.991\) → reject (groups differ)
Explanation

For two independent samples we cannot pair the values, so we pool them and rank everything together. If both samples come from the same population, the small and large ranks should be mixed evenly between them. If one sample has mostly the high ranks, its rank sum \(R_1\) is large. The \(U\) statistic converts the rank sum into the number of times a value from sample 1 beats a value from sample 2. The two values \(U_1\) and \(U_2\) add up to \(n_1n_2\), which is a handy check, and we use the smaller one. As with the signed-rank test, small \(U\) is the evidence.

In the example \(U=7\) out of a possible 56 pairs means sample A beat sample B in all but 7 pairs, which is very unlikely under \(H_0\).

The Kruskal–Wallis \(H\) test extends the idea to three or more groups, as ANOVA does for means. It compares the actual rank sums with those expected when all groups are alike. If \(H_0\) holds, \(H\) follows a chi-square distribution with \(k-1\) degrees of freedom, and only large values count as evidence. The result \(H=6.95\) is greater than 5.991, so at least one group differs. The test does not say which one, and a follow-up comparison would be needed.
