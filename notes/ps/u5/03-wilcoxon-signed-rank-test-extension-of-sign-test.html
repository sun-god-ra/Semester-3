Wilcoxon Signed-Rank Test (extension of sign test)

Probability and Statistics · Unit V: Non-Parametric Statistical Tests

Wilcoxon Signed-Rank Test (extension of sign test)
Subject
Probability and Statistics (24MA203)
Unit
Unit V: Non-Parametric Statistical Tests
Topic
3 of 7
Terms
Sign test

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Uses sign + size (rank) of differences → more powerful than the sign test
  • Steps
    1. find differences \(d_i\), drop zeros
    2. rank \(|d_i|\) from smallest (1) up; ties get average rank
    3. \(W^+\) = sum of ranks of positive \(d\); \(W^-\) = sum for negative
    4. \(T=\min(W^+,W^-)\) (two-sided). Reject if \(T\le\) table value
  • Check: \(W^++W^-=\dfrac{n(n+1)}{2}\)
  • Large \(n\):

\[\mu_T=\frac{n(n+1)}{4},\qquad \sigma_T^2=\frac{n(n+1)(2n+1)}{24},\qquad z=\frac{T-\mu_T}{\sigma_T}\]

  • Assumes differences come from a symmetric distribution (sign test doesn't)

Example: before 78 84 68 92 85 76 90 71 ; after 72 80 70 85 80 76 82 65

  • \(d\): 6, 4, −2, 7, 5, 0, 8, 6 → drop the 0, \(n=7\)
  • \(|d|\) ranks: 2→1, 4→2, 5→3, 6,6→4.5 each, 7→6, 8→7
  • \(W^+=27\), \(W^-=1\) (27+1 = 28 = 7·8/2 ✓), \(T=1\)
  • table, two-sided 5%, \(n=7\): critical \(=2\). \(1\le2\) → reject
Explanation

The sign test ignores how big each difference is, so a difference of 0.1 counts the same as a difference of 100. The signed-rank test fixes this by ranking the absolute differences. If \(H_0\) is true, the positive and negative differences should have similar rank sums. If one sum is tiny, the other direction dominates and we reject. Since the two sums always add to \(n(n+1)/2\), only the smaller one, \(T\), needs to be compared with the table. Note the direction: for this table we reject when \(T\) is small, not large.

In the example, only one difference is negative and it has the smallest rank, so \(W^-=1\) and \(T=1\). The table value for \(n=7\) is 2, so we reject. The test needs the differences to be symmetric about the median, which is a stronger assumption than the sign test needs.
