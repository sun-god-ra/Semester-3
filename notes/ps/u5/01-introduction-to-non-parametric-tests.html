Introduction to Non-Parametric Tests

Probability and Statistics · Unit V: Non-Parametric Statistical Tests

Introduction to Non-Parametric Tests
Subject
Probability and Statistics (24MA203)
Unit
Unit V: Non-Parametric Statistical Tests
Topic
1 of 7
Terms
Variance, Non-parametric, Sign test, Wilcoxon, Rank-sum test, Spearman, Runs test, P-value

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Parametric tests (z, t, F, \(\chi^2\) for variance) assume a population shape — usually normal — and test its parameters (\(\mu,\sigma^2\))
  • Non-parametric / distribution-free tests assume little or nothing about the shape. They use signs, ranks, runs, counts
  • Use them when
    • population clearly not normal and sample small
    • data are only ordinal (ranks, grades, ratings), no real numbers
    • there are outliers
    • sample too small to trust the CLT
  • Advantages
    • few assumptions, works for ordinal data, simple calculations, robust to outliers
  • Disadvantages
    • less powerful than parametric test when the normal assumption is true (needs more data for same power)
    • throws away some information (uses only order / sign, not size)
    • tables needed for small \(n\)
  • Parametric ↔ non-parametric pairs
Parametric Non-parametric equivalent
one-sample \(t\) / paired \(t\) sign test, Wilcoxon signed-rank test
two-sample \(t\) rank-sum test (Mann–Whitney U, Wilcoxon)
one-way ANOVA (\(F\)) Kruskal–Wallis H test
Pearson \(r\) Spearman rank correlation \(r_s\)
(no direct equal) runs test for randomness
Explanation

Every test in the earlier units started with an assumption, normally that the population is normal. When the assumption is false and the sample is small, the p-values from those tests can be wrong. Non-parametric tests do not rely on the shape of the population. Instead of the raw numbers they use only the signs of differences, the order (ranks) of the values, or the pattern of the sequence. This makes them suitable for ordinal data such as grades or satisfaction ratings, where a gap of one unit does not mean the same thing everywhere, and for data with outliers, because an extreme value is only the largest rank and cannot dominate a calculation.

The cost is power. If the data really are normal, the parametric test detects a true difference with a smaller sample than the matching non-parametric test, because the latter discards the magnitudes. So the rule is: use the parametric test when its assumptions are believable, and switch to the non-parametric equivalent when they are not. The table in the notes gives the matching pairs. Learning those pairs is the most efficient way to remember this unit, because an exam question will almost always describe the situation (paired, two groups, three groups, relation, randomness) and ask which test to use.
