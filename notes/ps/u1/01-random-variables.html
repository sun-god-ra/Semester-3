Random Variables
Subject
Probability and Statistics (24MA203)
Unit
Unit I: Probability Distributions and Random Variables
Topic
1 of 6
Terms
Random variable, Probability mass function, Variance, Cumulative distribution function

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • RV (random variable) = a rule that gives a number to every outcome of an experiment. Usually written \(X\), \(Y\).
  • Small letter \(x\) = a value that \(X\) can take.
  • Two types:
    • Discrete → countable values (0, 1, 2 ...) e.g. no. of defective chips
    • Continuous → any value in an interval e.g. time, weight
  • pmf (probability mass function) \(f(x)=P(X=x)\) → for discrete only
  • Rules for a valid pmf:
    • \(f(x)\ge 0\) for all \(x\)
    • \(\sum f(x)=1\) (imp. use this to find unknown constant \(k\))
  • cdf (distribution function) \(F(x)=P(X\le x)=\sum_{t\le x} f(t)\)
    • goes 0 → 1, never decreases
    • \(P(a<X\le b)=F(b)-F(a)\)
  • Mean \(\mu=E(X)=\sum x\,f(x)\)
  • Variance \(\sigma^2=E(X^2)-\mu^2\), where \(E(X^2)=\sum x^2 f(x)\)
  • S.D. \(\sigma=\sqrt{\sigma^2}\)
  • Shortcut to remember: Var = (mean of squares) − (square of mean)

Example: \(f(x)=\dfrac{x}{10}\) for \(x=1,2,3,4\). Sum = \(\frac{1+2+3+4}{10}=1\) ✓. \(\mu=\frac{1+4+9+16}{10}=3\).

Explanation

A random variable turns the outcome of a chance experiment into a number so that we can do arithmetic with it. If you toss a coin three times, the outcomes are strings such as HHT, but "number of heads" is a number, and that number is the random variable. A discrete random variable takes isolated values that can be listed, such as 0, 1, 2, 3. A continuous random variable can take any value in a range, such as the exact time a machine runs before failing.

For a discrete variable the probabilities are collected in the probability mass function \(f(x)=P(X=x)\). Two conditions must always hold: no probability is negative, and all probabilities add up to 1. The second condition is the standard way to find an unknown constant in a question. For example, if the probabilities are given as \(K, 0.1+K, 0.2+2K, 0.4+2K\) you add them, set the total to 1 and solve for \(K\).

The cumulative distribution function \(F(x)=P(X\le x)\) keeps a running total. It is useful for interval questions, because \(P(a<X\le b)=F(b)-F(a)\). The mean \(E(X)=\sum x f(x)\) is the long-run average, and the variance measures spread around that average. The computing formula \(E(X^2)-\mu^2\) is almost always quicker than summing squared deviations.
