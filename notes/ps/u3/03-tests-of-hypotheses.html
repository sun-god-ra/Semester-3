Tests of Hypotheses

Probability and Statistics · Unit III: Statistical Inference

Tests of Hypotheses
Subject
Probability and Statistics (24MA203)
Unit
Unit III: Statistical Inference
Topic
3 of 11
Terms
Type i error, Type ii error, Level of significance, Critical region, P-value, Null hypothesis

Practice: Part B questions for Unit III and Part A short questions.

Notebook notes
  • Hypothesis = statement about a population parameter. Test = rule to decide using sample.
  • \(H_0\) (null) = status quo, always has "=" (e.g. \(\mu=\mu_0\))
  • \(H_1\) (alternative) = what we suspect; \(\ne\) (two-tailed), \(>\) or \(<\) (one-tailed)
  • Errors:
\(H_0\) true \(H_0\) false
Reject \(H_0\) Type I error (prob. \(\alpha\)) correct (power \(=1-\beta\))
Accept \(H_0\) correct Type II error (prob. \(\beta\))
  • \(\alpha\) = level of significance (usually 0.05 or 0.01) = P(Type I)
  • Decrease \(\alpha\) → \(\beta\) increases (for same \(n\)). Only bigger \(n\) reduces both.
  • Critical region = values of test statistic where we reject \(H_0\)
  • P-value = prob. (if \(H_0\) true) of getting a result as extreme as observed. If \(p\le\alpha\) → reject.
  • Say "fail to reject \(H_0\)" (not "prove \(H_0\)")
Explanation

A hypothesis test is a formal way of deciding between two competing statements using sample data. The null hypothesis is the cautious default, and the data must give strong evidence before we abandon it. This is similar to a court case where the accused is presumed innocent: failing to convict does not prove innocence, and in the same way, failing to reject \(H_0\) does not prove it true.

Two mistakes are possible. A Type I error means rejecting a true null hypothesis (a false alarm), and its probability is the significance level \(\alpha\) chosen by us. A Type II error means keeping a false null hypothesis (a missed detection), with probability \(\beta\). The two pull against each other, so making the test stricter lowers \(\alpha\) but raises \(\beta\). Only a larger sample size improves both.

The p-value is a convenient summary. It is the probability of seeing data at least as extreme as ours if \(H_0\) were true. A small p-value says the data would be surprising under \(H_0\), so we reject it when \(p\le\alpha\).
