A Software Testing Strategy — The Big Picture (Spiral)

Software Engineering · Unit V: Software Testing

A Software Testing Strategy — The Big Picture (Spiral)
Subject
Software Engineering (24CS203)
Unit
Unit V: Software Testing
Topic
3 of 12
Terms
Unit testing, Integration testing, Software architecture

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Development goes inward along the spiral (system → requirements → design → code); testing moves outward
  • Four test steps in sequence
    1. Unit testing — concentrates on each unit (component); white-box techniques; exercises control paths and boundary conditions
    2. Integration testing — design and construction of the software architecture; black-box (and limited white-box) techniques
    3. Validation testing — validates requirements established against the software; black-box
    4. System testing — software + other system elements (hardware, people, database) tested as a whole
  • V-model: each development phase has a corresponding test level: requirements ↔ acceptance test, design ↔ system test, detailed design ↔ integration test, code ↔ unit test
Explanation

The developer who wrote a module understands it best, so developers do the unit testing, but they may not want to find faults in their own work. For this reason, large projects also use an independent test group, which tests integration and the whole system and works with the developers throughout the project.

Imagine a spiral. Development moves inwards, from system engineering through requirements and design to code, and testing moves outward in four steps. Unit testing checks each component, mostly with white-box methods. Integration testing checks that the components work together and builds the architecture. Validation testing checks the software against the requirements, with black-box methods. System testing checks the software together with the hardware, people and data. The V-model draws the same idea as a V: each stage on the left, such as requirements and design, has a matching test level on the right.
