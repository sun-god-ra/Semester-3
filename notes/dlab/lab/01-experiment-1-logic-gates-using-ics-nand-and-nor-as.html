Experiment 1 — Logic gates using ICs; NAND and NOR as universal gates

Digital Logic Design Lab · Lab: Tasks 1 to 12

Experiment 1 — Logic gates using ICs; NAND and NOR as universal gates
Subject
Digital Logic Design Lab (24CS282)
Unit
Lab: Tasks 1 to 12
Topic
1 of 12
Terms
NAND, NOR, XOR, XNOR, Universal gate, De morgan, Verilog
Notebook notes
  • Aim: Verify the truth tables of the basic gates AND, OR, NOT, NAND, NOR, XOR, XNOR with ICs, and realise NOT, AND and OR using only NAND gates and only NOR gates.
  • Components: IC 7400 (NAND), 7402 (NOR), 7404 (NOT), 7408 (AND), 7432 (OR), 7486 (XOR); trainer kit, LEDs, patch cords
  • Theory
    • Gates: AND \(Y=AB\); OR \(Y=A+B\); NOT \(Y=\overline{A}\); NAND \(Y=\overline{AB}\); NOR \(Y=\overline{A+B}\); XOR \(Y=A\oplus B=A\overline{B}+\overline{A}B\) (1 when inputs differ); XNOR \(Y=\overline{A\oplus B}\) (1 when inputs are equal)
    • Universal gates: NAND and NOR can build any gate. With NAND: NOT \(=\overline{A\cdot A}\); AND \(=\overline{\overline{AB}}\) (NAND followed by NAND-as-NOT); OR \(=\overline{\overline{A}\cdot\overline{B}}\) (De Morgan). With NOR: NOT \(=\overline{A+A}\); OR \(=\overline{\overline{A+B}}\); AND \(=\overline{\overline{A}+\overline{B}}\)
    • Gate count: NAND-only → NOT 1, AND 2, OR 3; NOR-only → NOT 1, OR 2, AND 3
  • Procedure
    • Insert the IC in the trainer, connect pin 14 to +5 V and pin 7 to GND
    • Connect the two inputs of a gate to the data switches and its output to an LED; apply all four input combinations and note the output; repeat for every IC
    • For 7404 connect one inverter; for 7402 note that the output pins are 1, 4, 10, 13
    • Wire three NOT/AND/OR circuits from 7400 gates only (using the diagram), verify; then the same from 7402
verilog
// Task 1: logic gates (behavioural/gate primitives) and universal-gate realisations
module gates(input a, b, output y_and, y_or, y_not, y_nand, y_nor, y_xor, y_xnor);
  and  g1(y_and,  a, b);
  or   g2(y_or,   a, b);
  not  g3(y_not,  a);
  nand g4(y_nand, a, b);
  nor  g5(y_nor,  a, b);
  xor  g6(y_xor,  a, b);
  xnor g7(y_xnor, a, b);
endmodule

// everything from NAND gates only
module nand_universal(input a, b, output y_not, y_and, y_or);
  wire n1, n2, n3;
  nand (y_not, a, a);              // NOT  = NAND with inputs tied
  nand (n1, a, b);
  nand (y_and, n1, n1);            // AND  = NAND followed by NOT
  nand (n2, a, a);
  nand (n3, b, b);
  nand (y_or, n2, n3);             // OR   = NAND of the inverted inputs
endmodule

// everything from NOR gates only
module nor_universal(input a, b, output y_not, y_or, y_and);
  wire m1, m2, m3;
  nor (y_not, a, a);
  nor (m1, a, b);
  nor (y_or, m1, m1);
  nor (m2, a, a);
  nor (m3, b, b);
  nor (y_and, m2, m3);
endmodule

  • Precautions: switch off the supply before changing wiring; check Vcc/GND; tie unused inputs; confirm LED polarity; no loose wires
  • Result: the observed outputs matched the truth table, so the circuit works as the theory predicts
  • Viva questions
    • Why are NAND and NOR called universal gates?
    • Pin numbers of Vcc and GND of a 14-pin IC? ( 14 and 7 )
    • Which gate gives 1 only when inputs are different? (XOR)
    • Draw the XOR using NAND gates (4 NANDs)
    • What does a floating TTL input act as? (logic 1)
Explanation

Each gate IC has four gates in the same package, with pin 14 as Vcc and pin 7 as ground. You connect the inputs to the switches and watch the LED. The table printed by the simulation is the truth table that you should see. For the universal-gate circuits the idea is De Morgan's law: \(\overline{\overline{A}\cdot\overline{B}}=A+B\). To make a NOT from a NAND the two inputs are tied together, because \(\overline{A\cdot A}=\overline{A}\). An AND is a NAND followed by that NOT. An OR is a NAND of the two inverted inputs. The last three columns of each group in the output confirm that the NAND-built and NOR-built circuits give the same outputs as the gates themselves. The NAND-only and NOR-only versions must match AND/OR/NOT in all four rows.
