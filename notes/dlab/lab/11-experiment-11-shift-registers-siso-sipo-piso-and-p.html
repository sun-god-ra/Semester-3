Experiment 11 — Shift registers: SISO, SIPO, PISO and PIPO

Digital Logic Design Lab · Lab: Tasks 1 to 12

Experiment 11 — Shift registers: SISO, SIPO, PISO and PIPO
Subject
Digital Logic Design Lab (24CS282)
Unit
Lab: Tasks 1 to 12
Topic
11 of 12
Terms
Shift register, Flip-flop, Johnson counter, Verilog
Notebook notes
  • Aim: Verify the four modes of a 4-bit shift register using D flip-flops (IC 7474 / 7495 / 74194 / 74164 / 74165).
  • Components: IC 7474 ×2 (4 D flip-flops), 7495, 74194, 74164 (SIPO), 74165 (PISO); clock pulser; LEDs; switches
  • Theory
    • A shift register is a chain of D flip-flops sharing a clock, in which the output of each stage feeds the input of the next; at every clock edge the stored word moves by one position
    • SISO (serial in, serial out): delay line; \(n\) clocks are needed to get a bit out. SIPO (serial in, parallel out): serial-to-parallel converter (receiver). PISO (parallel in, serial out): parallel-to-serial converter (transmitter), a LOAD/SHIFT control with gates (or a mux) at the inputs. PIPO: a buffer/storage register; all bits loaded at once in one clock
    • Time to shift a number of \(n\) bits: \(n\) clock pulses (SISO/SIPO/PISO); 1 pulse for PIPO. Universal shift register 74194: modes selected by S1 S0: 00 hold, 01 shift right, 10 shift left, 11 parallel load
    • Uses: serial data communication, delay, ring/Johnson counters, multiplication and division by 2 (shift left or right), sequence generators
  • Procedure
    • Wire four D flip-flops in a chain; clear them; apply the serial data bit by bit with a clock pulse for each; observe SISO output and SIPO outputs
    • PISO: provide the parallel data, set LOAD, give one pulse, then set SHIFT and give 4 pulses; note the serial output
    • PIPO: apply parallel data and one pulse, read all four outputs
verilog
// Task 11: shift registers (D flip-flops)
module dffe(input clk, rst, d, output reg q);
  always @(posedge clk or posedge rst) if (rst) q <= 0; else q <= d;
endmodule

module siso(input clk, rst, din, output dout);
  wire q0, q1, q2;
  dffe f0(clk, rst, din, q0);
  dffe f1(clk, rst, q0, q1);
  dffe f2(clk, rst, q1, q2);
  dffe f3(clk, rst, q2, dout);
endmodule

module sipo(input clk, rst, din, output [3:0] q);     // q[0] is the newest bit
  dffe f0(clk, rst, din, q[0]);
  dffe f1(clk, rst, q[0], q[1]);
  dffe f2(clk, rst, q[1], q[2]);
  dffe f3(clk, rst, q[2], q[3]);
endmodule

module piso(input clk, rst, load, input [3:0] d, output dout);  // load=1 loads, load=0 shifts
  wire [3:0] q;
  dffe f0(clk, rst, load ? d[0] : 1'b0, q[0]);
  dffe f1(clk, rst, load ? d[1] : q[0],  q[1]);
  dffe f2(clk, rst, load ? d[2] : q[1],  q[2]);
  dffe f3(clk, rst, load ? d[3] : q[2],  q[3]);
  assign dout = q[3];
endmodule

module pipo(input clk, rst, input [3:0] d, output [3:0] q);
  dffe f0(clk, rst, d[0], q[0]);
  dffe f1(clk, rst, d[1], q[1]);
  dffe f2(clk, rst, d[2], q[2]);
  dffe f3(clk, rst, d[3], q[3]);
endmodule

  • Precautions: switch off the supply before changing wiring; check Vcc/GND; tie unused inputs; confirm LED polarity; no loose wires
  • Result: the observed outputs matched the truth table, so the circuit works as the theory predicts
  • Viva questions
    • Difference between serial and parallel transfer?
    • How many clock pulses to shift a 4-bit word out of a SISO register? (4)
    • What is the use of the 74194?
    • How can a shift register multiply by 2?
    • What is the difference between SIPO and PISO? (conversion direction)
Explanation

For the serial data 1011 sent MSB first, the SIPO output after four clock pulses is 1011, since the first bit has moved to the farthest flip-flop. The SISO output shows the same word again at the output only after four more clocks (see the 1, 0, 1, 1 coming out on pulses 4 to 7, the first bit 1 appears at pulse 4). In the PISO register the parallel word 1101 is loaded in one pulse, and then it is shifted out MSB first, one bit per pulse: 1, 1, 0, 1. PIPO loads all four bits in one clock pulse.
