Experiment 7 — Latches and flip-flops: SR latch, SR, JK, D, T and master-slave JK
Subject
Digital Logic Design Lab (24CS282)
Unit
Lab: Tasks 1 to 12
Topic
7 of 12
Terms
Sr latch, Flip-flop, Master-slave, Jk flip-flop, NAND, NOR, Latch, Race-around, Propagation delay, Verilog
Notebook notes
  • Aim: Study the SR latch (NAND and NOR), the clocked SR, JK, D and T flip-flops, and the master-slave JK flip-flop.
  • Components: IC 7400 (NAND), 7402 (NOR), 7476 / 7473 (JK), 7474 (D), 7404; clock source (pulser switch), LEDs
  • Theory
    • SR latch (NOR): active-high S,R. S=1,R=0 → Q=1 (set); S=0,R=1 → Q=0 (reset); S=R=0 → hold; S=R=1 → forbidden (both outputs 0, and an unpredictable state when released). NAND latch: active-low \(\overline{S},\overline{R}\); set = (0,1), reset = (1,0), hold = (1,1), forbidden = (0,0)
    • Characteristic equations: SR: \(Q^{+}=S+\overline{R}Q\) with \(SR=0\); JK: \(Q^{+}=J\overline{Q}+\overline{K}Q\); D: \(Q^{+}=D\); T: \(Q^{+}=T\oplus Q\)
    • JK: 00 hold, 01 reset, 10 set, 11 toggle — no forbidden state. Race-around: when J=K=1 and the clock pulse is longer than the propagation delay, Q toggles repeatedly in one pulse. Cures: master-slave construction (two latches, the master is active while CLK=1 and the slave while CLK=0, so the output changes only on the falling edge), or edge triggering
    • D flip-flop (delay): \(Q\) follows \(D\) at the active edge — 7474. T flip-flop: JK with J=K=T; T=1 toggles, so \(f_Q = f_{clk}/2\) (divide-by-2). Preset/clear are asynchronous (act without the clock)
  • Procedure
    • Build the NOR latch (two 7402 gates cross-coupled) and the NAND latch; apply all input combinations and note Q, Q'
    • Wire 7476: J, K from switches; clock from pulser; Preset and Clear tied high; set the initial state with clear; apply the 4 J-K combinations
    • D flip-flop 7474: apply D, give a clock pulse; observe Q
    • T flip-flop: tie J and K of the 7476 together; master-slave behaviour: observe output change at the falling edge

// Task 7: latches and flip-flops
module sr_latch_nor(input s, r, output q, qn);          // active-high inputs
  nor (q,  r, qn);
  nor (qn, s, q);
endmodule

module sr_latch_nand(input sn, rn, output q, qn);       // active-low inputs
  nand (q,  sn, qn);
  nand (qn, rn, q);
endmodule

module sr_ff(input clk, s, r, output reg q);
  initial q = 1'b0;                     // simulation only: power-on state
  always @(posedge clk) begin
    case ({s, r})
      2'b00: q <= q;
      2'b01: q <= 1'b0;
      2'b10: q <= 1'b1;
      2'b11: q <= 1'bx;               // invalid
    endcase
  end
endmodule

module jk_ff(input clk, j, k, output reg q);
  initial q = 1'b0;                     // simulation only: power-on state
  always @(posedge clk) begin
    case ({j, k})
      2'b00: q <= q;
      2'b01: q <= 1'b0;
      2'b10: q <= 1'b1;
      2'b11: q <= ~q;                 // toggle
    endcase
  end
endmodule

module d_ff(input clk, d, output reg q);
  initial q = 1'b0;                     // simulation only: power-on state
  always @(posedge clk) q <= d;
endmodule

module t_ff(input clk, t, output reg q);
  initial q = 1'b0;                     // simulation only: power-on state
  always @(posedge clk) if (t) q <= ~q;
endmodule

// master-slave JK flip-flop (behavioural): master follows J,K while CLK=1, slave copies master while CLK=0
module ms_jk(input clk, j, k, output reg q);
  reg m;
  initial begin m = 1'b0; q = 1'b0; end
  always @(clk or j or k)
    if (clk) begin                         // master enabled
      case ({j, k})
        2'b10: m = 1'b1;
        2'b01: m = 1'b0;
        2'b11: m = ~q;                     // uses the SLAVE output: feedback is safe, slave is closed
        default: m = m;
      endcase
    end else q = m;                        // slave enabled, master closed
endmodule

  • Viva questions
    • What is the race-around condition and how is it avoided?
    • Characteristic table vs excitation table?
    • How is a T flip-flop made from a JK? From a D? (D = T ⊕ Q)
    • What is the difference between a latch and a flip-flop? (level-sensitive vs edge-triggered)
    • What is the function of Preset and Clear? Are they synchronous? (No — asynchronous)
Explanation

A latch is a basic memory element made from two cross-coupled gates, so that each output feeds the other gate. In the NOR latch a 1 on S sets the output, a 1 on R resets it, and with both 0 the stored value stays. Both 1 forces both outputs to 0, which breaks the Q and Q' complement relation, so it is forbidden. For the NAND latch the inputs are active low. In the JK flip-flop J=K=1 toggles the output on each clock edge, which is the extra feature compared with the SR. When J=K=1 for the whole length of a long clock pulse, the output toggles again and again (race-around). The master-slave construction solves it. During CLK = 1 the master takes the inputs and the slave is closed; when CLK falls, the master closes and the slave copies the master. In the output, 'clock high' shows no change and the change appears only when the clock goes low. The D flip-flop stores D at the edge, and T toggles when T is 1.
