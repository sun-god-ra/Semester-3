Experiment 5 — Decoders and encoders

Digital Logic Design Lab · Lab: Tasks 1 to 12

Experiment 5 — Decoders and encoders
Subject
Digital Logic Design Lab (24CS282)
Unit
Lab: Tasks 1 to 12
Topic
5 of 12
Terms
Decoder, Encoder, Priority encoder, BCD, Minterm, Verilog, Full adder
Notebook notes
  • Aim: Implement decoders (2×4, 3×8, BCD-to-decimal, BCD-to-7-segment) and encoders (4×2, octal-to-binary, decimal-to-BCD).
  • Components: IC 74139 / 7408 (2×4), 74138 (3×8), 7442 (BCD to decimal), 7447 (BCD to 7-segment) with a common-anode display, 74148 / 74147 (priority encoders), 7432 (OR)
  • Theory
    • Decoder: \(n\) inputs → up to \(2^n\) outputs; each output is a minterm; with an enable: \(Y_i=E\cdot m_i\). 2×4: \(Y_0=\overline{A_1}\,\overline{A_0}\), \(Y_1=\overline{A_1}A_0\), \(Y_2=A_1\overline{A_0}\), \(Y_3=A_1A_0\). 74138 has active-low outputs and three enables (\(G_1\) high, \(\overline{G_{2A}}\), \(\overline{G_{2B}}\) low)
    • BCD to 7-segment: drives segments a–g; common cathode needs active-high outputs (7448); common anode needs active-low outputs (7447) with ~330 Ω resistors in series with every segment. Digit 8 lights all 7 segments, 1 lights b and c
    • Encoder: \(2^n\) (or fewer) inputs → \(n\) outputs; exactly one input should be high. Priority encoder handles several inputs at once: the highest priority wins; a valid output \(V\) shows at least one input is active (else the 00 output is ambiguous). 4×2: \(Y_1=D_3+D_2\), \(Y_0=D_3+\overline{D_2}D_1\). Octal-to-binary: \(Y_2=D_4+D_5+D_6+D_7\), \(Y_1=D_2+D_3+D_6+D_7\), \(Y_0=D_1+D_3+D_5+D_7\) (three 4-input OR gates). Decimal-to-BCD: \(Y_3=D_8+D_9\), \(Y_2=D_4+D_5+D_6+D_7\), \(Y_1=D_2+D_3+D_6+D_7\), \(Y_0=D_1+D_3+D_5+D_7+D_9\)
    • Decoder ↔ encoder are inverse operations. A decoder can also implement any Boolean function (OR the minterm outputs)
  • Procedure
    • 2×4: connect A1, A0 to switches, outputs to LEDs, enable to Vcc; verify 4 rows
    • 3×8 with 74138: connect enables as required, verify 8 rows (outputs are active-low, so an LED connected to Vcc glows for 0)
    • BCD→7-segment: connect 7447 outputs a–g to the display through resistors; apply 0–9 and see the digits
    • Encoders: wire OR gates for 8×3 and 10×4; apply one-hot inputs; use 74148 for a priority encoder and test two inputs at once
verilog
// Task 5: decoders and encoders
module dec2x4(input [1:0] a, input en, output [3:0] y);
  assign y[0] = en & ~a[1] & ~a[0];
  assign y[1] = en & ~a[1] &  a[0];
  assign y[2] = en &  a[1] & ~a[0];
  assign y[3] = en &  a[1] &  a[0];
endmodule

module dec3x8(input [2:0] a, input en, output [7:0] y);
  assign y = en ? (8'b00000001 << a) : 8'b0;
endmodule

module bcd2dec(input [3:0] b, output [9:0] y);       // BCD to decimal (1-of-10)
  assign y = (b <= 4'd9) ? (10'b1 << b) : 10'b0;
endmodule

module bcd27seg(input [3:0] b, output reg [6:0] seg); // common cathode: seg = abcdefg
  always @(*) begin
    case (b)
      4'd0: seg = 7'b1111110;  4'd1: seg = 7'b0110000;
      4'd2: seg = 7'b1101101;  4'd3: seg = 7'b1111001;
      4'd4: seg = 7'b0110011;  4'd5: seg = 7'b1011011;
      4'd6: seg = 7'b1011111;  4'd7: seg = 7'b1110000;
      4'd8: seg = 7'b1111111;  4'd9: seg = 7'b1111011;
      default: seg = 7'b0000000;
    endcase
  end
endmodule

module enc4x2(input [3:0] d, output reg [1:0] y, output reg v);   // priority: D3 highest
  always @(*) begin
    v = 1'b1;
    casex (d)
      4'b1xxx: y = 2'b11;
      4'b01xx: y = 2'b10;
      4'b001x: y = 2'b01;
      4'b0001: y = 2'b00;
      default: begin y = 2'b00; v = 1'b0; end
    endcase
  end
endmodule

module oct2bin(input [7:0] d, output [2:0] y);        // octal to binary (8x3), one input high
  assign y[2] = d[4] | d[5] | d[6] | d[7];
  assign y[1] = d[2] | d[3] | d[6] | d[7];
  assign y[0] = d[1] | d[3] | d[5] | d[7];
endmodule

module dec2bcd(input [9:0] d, output [3:0] y);         // decimal to BCD (10x4), one input high
  assign y[3] = d[8] | d[9];
  assign y[2] = d[4] | d[5] | d[6] | d[7];
  assign y[1] = d[2] | d[3] | d[6] | d[7];
  assign y[0] = d[1] | d[3] | d[5] | d[7] | d[9];
endmodule

  • Viva questions
    • What is the use of the enable input of a decoder?
    • Difference between encoder and priority encoder?
    • Why 330 Ω resistors with a 7-segment display?
    • What is the difference between common-anode and common-cathode?
    • Implement a full adder with a 3×8 decoder and two OR gates (\(S=\sum m(1,2,4,7)\), \(C=\sum m(3,5,6,7)\))
Explanation

A decoder activates exactly one output line for each input code, so every output is a minterm. The 3×8 table shows that input 101 activates output 5 (bit 5 is set). The 7-segment table lists the segments abcdefg, with 1 meaning the segment is ON, so 8 = 1111111 and 1 = 0110000 (b and c). An encoder does the reverse. In the octal-to-binary encoder, the output bit for weight 4 is on if the input is 4, 5, 6 or 7, etc. In the plain encoder only one input may be active. The priority encoder removes this limitation. In the output, 0110 (D2 and D1 both on) is encoded as 10, the code of the higher input D2, and V = 0 only when no input is active.
