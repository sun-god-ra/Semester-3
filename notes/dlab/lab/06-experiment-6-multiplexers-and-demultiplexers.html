Experiment 6 — Multiplexers and demultiplexers

Digital Logic Design Lab · Lab: Tasks 1 to 12

Experiment 6 — Multiplexers and demultiplexers
Subject
Digital Logic Design Lab (24CS282)
Unit
Lab: Tasks 1 to 12
Topic
6 of 12
Terms
Multiplexer, Demultiplexer, Decoder, Verilog
Notebook notes
  • Aim: Implement 2×1 and 4×1 multiplexers, and 1×2 and 1×4 demultiplexers.
  • Components: IC 74153 / 74157 / 74151 (MUX), 74155 / 74139 (DEMUX), basic gate ICs 7408, 7432, 7404
  • Theory
    • MUX selects one of \(2^n\) data inputs using \(n\) select lines. 2×1: \(Y=\overline{S}I_0+SI_1\). 4×1: \(Y=\overline{S_1}\,\overline{S_0}I_0+\overline{S_1}S_0I_1+S_1\overline{S_0}I_2+S_1S_0I_3\)
    • DEMUX sends one data input to one of \(2^n\) outputs chosen by the select lines: 1×4: \(Y_0=D\overline{S_1}\,\overline{S_0}\), \(Y_1=D\overline{S_1}S_0\), \(Y_2=DS_1\overline{S_0}\), \(Y_3=DS_1S_0\). A decoder with the enable used as data input is a demultiplexer
    • Uses of MUX: data routing, parallel-to-serial conversion, function generator (an \(n\)-select MUX can implement any \((n+1)\)-variable function: take \(n\) variables as selects and connect the data inputs to 0, 1, the last variable or its complement)
  • Procedure
    • Wire the AND-OR circuit (or use the IC) for 2×1 MUX; set data inputs I0, I1 with switches; vary S; see Y
    • 4×1 MUX: use 74153 (one half) with S1, S0; check the 4 rows
    • DEMUX: connect D to Vcc (or a switch), vary S1, S0 and see which output goes high
verilog
// Task 6: multiplexers and demultiplexers
module mux2x1(input i0, i1, s, output y);
  assign y = s ? i1 : i0;                        // Y = S'.I0 + S.I1
endmodule

module mux4x1(input [3:0] i, input [1:0] s, output y);
  assign y = i[s];
endmodule

module demux1x2(input d, s, output y0, y1);
  assign y0 = d & ~s;
  assign y1 = d &  s;
endmodule

module demux1x4(input d, input [1:0] s, output [3:0] y);
  assign y[0] = d & ~s[1] & ~s[0];
  assign y[1] = d & ~s[1] &  s[0];
  assign y[2] = d &  s[1] & ~s[0];
  assign y[3] = d &  s[1] &  s[0];
endmodule

  • Result: the observed outputs matched the truth table, so the circuit works as the theory predicts
  • Viva questions
    • Number of select lines needed for a 16×1 MUX? (4)
    • Implement \(F=\sum m(1,2,6,7)\) with a 4×1 MUX
    • MUX is called a data selector, DEMUX a data distributor — why?
    • Difference between a decoder and a demultiplexer?
    • How can an 8×1 MUX be built from 4×1 MUXes? (two 4×1 + one 2×1)
Explanation

A multiplexer is a controlled switch: the select lines say which input is passed to the output. With data 1010 (I3 I2 I1 I0), selecting 0 gives I0 = 0, selecting 1 gives I1 = 1, and so on. The demultiplexer is the reverse. With D = 1, the selected output becomes 1 and all the others stay 0 (the select 10 gives output 2). A decoder with its enable used as the data line is a demultiplexer.
