Algorithm Evaluation

Operating Systems · Unit II: Process Management and Scheduling

Algorithm Evaluation
Subject
Operating Systems (24CS204)
Unit
Unit II: Process Management and Scheduling
Topic
14 of 14

Practice: Part B questions for Unit II and Part A short questions.

Notebook notes
  • How to select a CPU-scheduling algorithm? Define criteria (CPU utilisation, response time, throughput) then evaluate
  • Deterministic modelling — takes a predetermined workload and defines the performance of each algorithm for that workload; simple and fast, exact numbers, but only for the input given
  • Queueing models: the computer system is a network of servers each with a queue; use arrival and service rate distributions; Little's formula: \(n=\lambda\times W\) (average queue length = arrival rate × average waiting time), valid for any scheduling algorithm and arrival distribution. Limited accuracy
  • Simulations: a model of the system with a clock, gather statistics; data from random-number generator or from trace tapes (recorded real system); expensive, accurate
  • Implementation — code it, put it in the OS and see; most accurate but highest cost, environment changes (users change behaviour)
