Overview of Mass-Storage Structure

Operating Systems · Unit V: Storage Management and File System

Overview of Mass-Storage Structure

Unit
Unit V: Storage Management and File System
Topic
1 of 10
Terms
NAND, Garbage collection

Practice: Part B questions for Unit V and Part A short questions.

Notebook notes
  • Magnetic disks (HDD) — provide the bulk of secondary storage. Each disk platter is flat, circular like a CD (1.8″ to 3.5″, 2.5″ and 3.5″ common); both surfaces coated with magnetic material; a read–write head "flies" just above each surface; heads attached to a disk arm that moves all heads together. Platter surface is divided into circular tracks; each track into sectors; the set of tracks at one arm position forms a cylinder (thousands of cylinders). Sector = smallest unit of transfer (traditionally 512 bytes, now 4 KB on newer drives). Disks rotate at 60 to 250 rotations per second = 5,400 / 7,200 / 10,000 / 15,000 RPM
  • Disk performance
    • Transfer rate = rate at which data flow between drive and computer
    • Positioning time (random-access time) = time to move the disk arm to the desired cylinder (seek time) + time for the desired sector to rotate under the head (rotational latency)
    • Head crash — the head touches the surface → damages the magnetic surface; not repairable
    • Disk access time = seek time + rotational latency + transfer time
    • Rotational latency (average) = half a revolution: at 7,200 RPM one rotation = 60,000/7,200 = 8.33 ms → average latency = 4.17 ms; at 15,000 RPM = 2 ms
  • Disk drive attached to a computer via an I/O bus: ATA, SATA, eSATA, USB, SCSI, SAS, Fibre Channel; the host controller (computer end) and disk controller (built into the drive) transfer data using cache memory in the disk controller
  • Nonvolatile memory (NVM) devices: solid-state disks (SSDs) — flash memory based; no moving parts → faster, more reliable, more expensive per MB, shorter lifespan (limited write cycles), lower power; can be bus-attached (NVMe — NVM express, PCIe) — much faster than SATA. NAND flash: read/write in pages, but cannot overwrite in place — must first erase (in blocks); flash translation layer (FTL); garbage collection; over-provisioning; wear leveling (spread erasures evenly); write amplification. Used as cache tier or main storage. Other: magnetic tape (large archival, very slow random access, cheap, backup, ~200 GB to many TB), optical disks
  • Address mapping: storage devices addressed as large one-dimensional arrays of logical blocks (logical block = smallest unit of transfer); the array is mapped sequentially onto the sectors: sector 0 = first sector of the first track on the outermost cylinder, proceeding through that track, the rest of the tracks in that cylinder, then the rest of the cylinders from outermost to innermost. Logical → (cylinder, head, sector), but defective sectors are substituted (sector sparing) and the number of sectors per track is not constant (outer tracks hold more → constant linear velocity (CLV) in CDs vs constant angular velocity (CAV) in HDDs with bit density varying by zone)
  • Storage-system connection: host-attached storage (via local I/O ports), network-attached storage (NAS) (via NFS, CIFS over a network — remote file-system), cloud storage (over the Internet, via API), storage-area network (SAN) (private network, block-level, multiple hosts and storage arrays — flexible dynamic allocation)
Explanation

A hard disk has platters coated with magnetic material, with a head on an arm that moves over each surface. The surface is divided into tracks and each track into sectors, and the tracks at the same arm position form a cylinder. The access time of a disk = seek time (moving the arm to the cylinder) + rotational latency (waiting for the sector to come under the head) + transfer time. At 7,200 RPM one rotation takes 8.33 ms, so on average the latency is half of it, 4.17 ms. Seek time is normally the largest part, so scheduling aims to reduce head movement.

An SSD uses flash memory with no moving parts, which gives faster access and lower power but limited write cycles. Flash cannot be overwritten in place, since a block must be erased before it is written, so the flash translation layer, garbage collection and wear leveling are used. NVMe attaches the SSD over PCIe. Storage can be host-attached, network-attached (NAS), cloud or on a SAN.

The disk is addressed as a one-dimensional array of logical blocks, which are mapped to sectors starting from the outermost cylinder.
