Operating-System Services

Operating Systems · Unit I: Introduction and Operating System Structures

Operating-System Services
Subject
Operating Systems (24CS204)
Unit
Unit I: Introduction and Operating System Structures
Topic
7 of 12
Terms
Shared memory, Message passing

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • OS provides an environment for execution of programs and services to programs and users. Two groups
  • Services helpful to the user
    • User interface (UI) — CLI, GUI, touch-screen, batch
    • Program execution — load a program into memory, run it, end normally or abnormally
    • I/O operations — running programs may need I/O (file or device); users usually cannot control I/O devices directly (efficiency and protection)
    • File-system manipulation — read, write, create, delete, search, list files and directories, permissions
    • Communications — shared memory or message passing (within a computer or between computers over a network)
    • Error detection — in CPU and memory hardware, I/O devices (parity error, network failure, printer out of paper), user programs (arithmetic overflow, illegal memory access); take appropriate action for correct and consistent computing
  • Services for ensuring the efficient operation of the system itself
    • Resource allocation — when multiple users/jobs run concurrently, resources must be allocated to each (CPU scheduling routines, printers, USB storage)
    • Accounting (logging) — keep track of which users use how much and what kinds of computer resources (billing or usage statistics)
    • Protection and security — owners of information control its use; concurrent processes must not interfere with each other; security from outsiders — authenticate (passwords), defend external I/O devices and network adapters
Explanation

The OS gives services that help the user (user interface, program execution, I/O operations, file-system manipulation, communication, and error detection) and services that make the system itself run efficiently (resource allocation, accounting, and protection and security).
