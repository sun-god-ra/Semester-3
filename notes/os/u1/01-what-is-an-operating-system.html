What is an Operating System?

Operating Systems · Unit I: Introduction and Operating System Structures

What is an Operating System?
Subject
Operating Systems (24CS204)
Unit
Unit I: Introduction and Operating System Structures
Topic
1 of 12
Terms
Operating system, Kernel

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • Operating system (OS) = software that manages the computer hardware; it provides a basis for application programs and acts as an intermediary between the user and the hardware
  • Computer system has 4 components: hardware (CPU, memory, I/O devices) → operating system → application programs (word processor, compilers, browsers) → users
  • Two viewpoints
    • User view: depends on interface — PC (ease of use, little attention to resource utilisation), mainframe/minicomputer (maximise resource utilisation, fair sharing), workstation (compromise), handheld (usability + battery life), embedded (little or no user view)
    • System view: OS is a resource allocator (CPU time, memory, file storage, I/O) — decides conflicting requests for efficient and fair use; and a control program — manages execution of user programs to prevent errors and improper use of the computer
  • "The one program running at all times on the computer" = the kernel. Everything else = system programs (shipped with OS, not part of kernel) or application programs
  • Middleware — software frameworks giving extra services to application developers (databases, multimedia, graphics) e.g. in Android and iOS
  • Goals of OS: convenience for the user, efficient operation of the computer system
Explanation

An operating system is the program that sits between the hardware and everything else. A user cannot write a program that directly drives a disk head or a network card on every machine type, so the OS provides a clean way for programs to ask for these services. From the user's side the OS is whatever makes the computer convenient: the desktop, the window, the file manager. From the system's side the OS is a resource allocator, who decides which program gets the CPU, memory, and devices, and a control program, who prevents programs from damaging each other or the machine. The one program that runs all the time is the kernel; everything shipped with it, such as the shell and utilities, are system programs.
