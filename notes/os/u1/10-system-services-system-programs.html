Operating Systems · Unit I: Introduction and Operating System Structures

System Services (System Programs)
Subject
Operating Systems (24CS204)
Unit
Unit I: Introduction and Operating System Structures
Topic
10 of 12
Terms
System call, Debugging

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • Provide a convenient environment for program development and execution; some are simply user interfaces to system calls, others more complex. Categories
    • File management (create, delete, copy, rename, print, list, manipulate files and directories)
    • Status information (date, time, free memory/disk, users, performance, logging, debugging info; registry in Windows)
    • File modification (text editors, commands to search content, transform text)
    • Programming-language support (compilers, assemblers, debuggers, interpreters)
    • Program loading and execution (absolute loaders, relocatable loaders, linkage editors, overlay loaders, debugging systems)
    • Communications (virtual connections among processes, users and computer systems: send messages, browse web, remote login, transfer files)
    • Background services (daemons / services / subsystems) — launched at boot time, run until shutdown (network daemons, print servers, process schedulers); constantly running system-program processes
    • Application programs — browsers, word processors, spreadsheets, games — not part of the system; run by users
  • Most users' view of the OS is defined by the system programs, not the actual system calls
Explanation

System programs give a convenient environment: file management, status information, file modification, programming-language support, program loading and execution, communications, background services (daemons that start at boot and run continuously), and application programs. The user's view of an OS is mainly decided by the system programs.
