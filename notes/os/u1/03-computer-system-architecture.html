Computer-System Architecture

Unit
Unit I: Introduction and Operating System Structures
Topic
3 of 12
Terms
Multiprocessor, Symmetric multiprocessing

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • Single-processor systems: one general-purpose CPU (plus special-purpose processors e.g. disk, keyboard, graphics controllers — OS may send them tasks and monitor status)
  • Multiprocessor (parallel/tightly coupled) systems: two or more processors in close communication, sharing bus, clock, memory and peripherals. Advantages: increased throughput (not exactly n times, because of overhead and contention), economy of scale, increased reliability — graceful degradation / fault tolerance
    • Asymmetric multiprocessing (AMP): each processor assigned a specific task; a boss (master) processor controls the system, others take instructions from master or have predefined tasks (master–slave)
    • Symmetric multiprocessing (SMP): each processor performs all tasks within the OS; all peers; no master–slave relationship. Each has its own registers and private cache, shares physical memory
    • Multicore: several computing cores on a single chip — faster on-chip communication, less power
    • NUMA (non-uniform memory access): each CPU has local memory accessed fast; access to other CPU's memory is slower
    • Blade servers: multiple processor boards, I/O boards and networking boards in the same chassis, each board boots independently
  • Clustered systems: two or more individual systems (nodes) joined together, each often multicore, sharing storage via storage-area network (SAN); provide high availability (service continues if a node fails); asymmetric clustering (one machine in hot-standby mode) vs symmetric clustering (all hosts run applications and monitor each other); high-performance computing (parallelisation); DLM — distributed lock manager
Explanation

A single-processor system has one general-purpose CPU. Multiprocessor systems have two or more CPUs sharing the bus, clock and memory. They offer more throughput (though not n times for n CPUs, because of overhead), economy of scale, and reliability, because the system continues with reduced capacity if a CPU fails (graceful degradation).

In asymmetric multiprocessing, one boss processor controls the system and assigns work to the others. In symmetric multiprocessing (SMP), every processor is a peer that can run any task, including OS code; each has its own registers and cache and they share memory. Multicore means several cores on one chip, which communicate faster and use less power. NUMA gives each CPU its own local memory that is faster to reach than another CPU's memory. A clustered system joins several complete computers, usually sharing storage over a SAN, to give high availability: if one node fails, another takes over its work.
