Free and Open-Source Operating Systems

Terms
Operating system, Kernel, UNIX, Virtual machine, Java virtual machine

Practice: Part B questions for Unit I and Part A short questions.

Notebook notes
  • Open-source operating systems are made available in source-code format rather than just binary closed-source form; free software (Richard Stallman, GNU, Free Software Foundation (FSF), GNU General Public License (GPL) → copyleft) vs open-source (Open Source Initiative); free software = freedom to run, study, share and modify
  • Examples: GNU/Linux (Linus Torvalds, 1991; Linux kernel + GNU tools = distributions: Ubuntu, Debian, Red Hat, Fedora…), BSD UNIX (FreeBSD, NetBSD, OpenBSD; BSD licence is less restrictive — allows closed-source derivatives), Solaris, Darwin (core of macOS, open source), Android (AOSP)
  • Advantages: large community of programmers contributing to debug and improve; more secure through peer review (debatable — "many eyes") ; study how things work; no licence cost; customisable. Open-source ≠ always free of cost, and not automatically more secure
  • Virtualisation and emulation: a virtual machine manager (hypervisor/VMM) lets one computer run several guest OSes; emulation simulates hardware (e.g., running ARM code on x86 – slower), VMware, VirtualBox, Java Virtual Machine
Explanation

Open-source operating systems are distributed with their source code. The free-software movement of Richard Stallman used the GPL, which requires derived work to stay free (copyleft). Linux is a kernel by Linus Torvalds (1991) and, together with GNU tools, makes a complete OS. BSD UNIX has a more permissive licence that allows closed-source derivatives. Many people reviewing the code can improve quality, but open source is not automatically more secure.
