Notebook notes
  • Aim: Define classes and create objects; write default, parameterised and copy constructors and use the this keyword.
  • Key points
    • Class = blueprint (fields + methods); object = instance created with new; variable holds a reference
    • Student s3 = s1; copies the reference, not the object (both names point to one object)
    • Constructor: same name as the class, no return type, called automatically by new. If you write none, the compiler adds a default constructor; if you write any, it does not
    • this = reference to the current object: resolves name clashes (this.width = width), calls another constructor this(...) (must be the first statement), and can be returned for chaining
    • Copy constructor takes an object of the same class and copies its fields
  • Procedure
    • Declare the class with fields and methods
    • Create objects with new and use the dot operator
    • Add constructors with different parameters (overloaded)
    • Use this(...) to avoid repeating code
Program 1 — Class and objects
java
class Student {
    int rollNo;
    String name;
    double cgpa;
    void display() {
        System.out.println(rollNo + " | " + name + " | " + cgpa);
    }
    boolean isEligible() {
        return cgpa >= 7.0;
    }
}
public class ClassDemo {
    public static void main(String[] args) {
        Student s1 = new Student();      // object creation
        s1.rollNo = 101; s1.name = "Asha"; s1.cgpa = 8.4;
        Student s2 = new Student();
        s2.rollNo = 102; s2.name = "Bhanu"; s2.cgpa = 6.5;
        s1.display();
        s2.display();
        System.out.println(s1.name + " eligible? " + s1.isEligible());
        System.out.println(s2.name + " eligible? " + s2.isEligible());
        Student s3 = s1;                  // reference copy, not object copy
        s3.name = "Asha K";
        System.out.println("s1.name after changing through s3 = " + s1.name);
        System.out.println("s1 == s3 ? " + (s1 == s3) + ", s1 == s2 ? " + (s1 == s2));
    }
}

Output

text
101 | Asha | 8.4
102 | Bhanu | 6.5
Asha eligible? true
Bhanu eligible? false
s1.name after changing through s3 = Asha K
s1 == s3 ? true, s1 == s2 ? false
Program 2 — Constructors and this
java
class Box {
    double width, height, depth;
    Box() {                                   // default constructor
        this(1, 1, 1);                        // constructor chaining with this(...)
    }
    Box(double side) {
        this(side, side, side);
    }
    Box(double width, double height, double depth) {
        this.width = width;                   // this resolves the name clash
        this.height = height;
        this.depth = depth;
    }
    Box(Box other) {                          // copy constructor
        this(other.width, other.height, other.depth);
    }
    double volume() { return width * height * depth; }
    Box scale(double k) {                     // returns this for method chaining
        this.width *= k; this.height *= k; this.depth *= k;
        return this;
    }
    public String toString() {
        return "Box[" + width + " x " + height + " x " + depth + "]";
    }
}
public class ConstructorDemo {
    public static void main(String[] args) {
        Box b1 = new Box();
        Box b2 = new Box(3);
        Box b3 = new Box(2, 3, 4);
        Box b4 = new Box(b3);
        System.out.println(b1 + " volume " + b1.volume());
        System.out.println(b2 + " volume " + b2.volume());
        System.out.println(b3 + " volume " + b3.volume());
        System.out.println(b4 + " copy of b3, same object? " + (b3 == b4));
        System.out.println(b4.scale(2) + " volume " + b4.volume());
    }
}

Output

text
Box[1.0 x 1.0 x 1.0] volume 1.0
Box[3.0 x 3.0 x 3.0] volume 27.0
Box[2.0 x 3.0 x 4.0] volume 24.0
Box[2.0 x 3.0 x 4.0] copy of b3, same object? false
Box[4.0 x 6.0 x 8.0] volume 192.0
  • Viva questions
    • Difference between constructor and method?
    • Can a constructor be private? final? static? (private yes — singleton; final/static no)
    • What happens if you write only a parameterised constructor and call new Box()? (error)
    • What is constructor chaining?
    • Difference between == and .equals() for objects?
Explanation

In program 1 two Student objects are created with new and their fields are set with the dot operator. s3 = s1 makes both references point to the same object, so changing the name through s3 changes s1.name, and s1 == s3 is true. In program 2 the no-argument constructor calls this(1,1,1), the one-argument constructor makes a cube, and the copy constructor builds a new Box with the same values (so b3 == b4 is false although they look the same). scale returns this, so the call can be used directly in an expression; it changes b4 only, and b3 is unchanged.
