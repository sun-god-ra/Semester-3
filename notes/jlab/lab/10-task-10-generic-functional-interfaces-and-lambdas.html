Notebook notes
  • Aim: Use the functional interfaces of java.util.function and pass lambda expressions to methods.
  • Key points
    • Functional interface = interface with exactly one abstract method (SAM); @FunctionalInterface makes the compiler check it. A lambda (params) -> expression/block is an implementation of that method
    • Core interfaces (java.util.function): Predicate<T> boolean test(T); Function<T,R> R apply(T); Consumer<T> void accept(T); Supplier<T> T get(); BiFunction<T,U,R>; UnaryOperator<T> (T→T); BinaryOperator<T> (T,T→T). Primitive versions: IntPredicate, IntFunction, …
    • Default methods: Predicate.and/or/negate, Function.andThen/compose
    • Method references: String::length, Math::max, System.out::println. A lambda can use local variables only if they are effectively final
    • A lambda can be passed wherever a functional interface is expected (arguments to methods, Comparator, Runnable, forEach)
  • Procedure
    • Define your own @FunctionalInterface and implement it with a lambda
    • Use Predicate, Function, Consumer, Supplier, BiFunction, UnaryOperator, BinaryOperator
    • Write methods that take a functional interface as a parameter
    • Pass lambdas and method references to them; sort with a Comparator lambda
Program 1 — Functional interfaces
java
import java.util.function.*;
@FunctionalInterface
interface Calculator { int calculate(int a, int b); }          // our own functional interface
public class FunctionalDemo {
    public static void main(String[] args) {
        Calculator add = (a, b) -> a + b;
        Calculator mul = (a, b) -> a * b;
        System.out.println(add.calculate(6, 7) + " " + mul.calculate(6, 7));
        Predicate<Integer> isEven = n -> n % 2 == 0;           // T -> boolean
        Predicate<Integer> big = n -> n > 10;
        System.out.println(isEven.test(8) + " " + isEven.and(big).test(8) + " " + isEven.or(big).test(11) + " " + isEven.negate().test(8));
        Function<String, Integer> len = String::length;        // T -> R
        Function<Integer, Integer> twice = n -> n * 2;
        System.out.println(len.apply("lambda") + " " + len.andThen(twice).apply("lambda") + " " + twice.compose(len).apply("ab"));
        Consumer<String> printer = s -> System.out.println("Hello " + s);   // T -> void
        printer.accept("Java");
        Supplier<Double> rnd = () -> 42.0;                     // () -> T
        System.out.println(rnd.get());
        BiFunction<Integer, Integer, Integer> power = (b, e) -> (int) Math.pow(b, e);
        System.out.println(power.apply(2, 10));
        UnaryOperator<String> up = String::toUpperCase;        // T -> T
        BinaryOperator<Integer> max = BinaryOperator.maxBy(Integer::compare);   // (T,T) -> T
        System.out.println(up.apply("abc") + " " + max.apply(3, 9));
        IntPredicate positive = x -> x > 0;                    // primitive specialisation
        System.out.println(positive.test(-5));
    }
}

Program 2 — Lambdas as arguments
java
import java.util.*;
import java.util.function.*;
public class LambdaArgs {
    // a method that accepts behaviour as a parameter
    static int apply(int x, int y, BinaryOperator<Integer> op) { return op.apply(x, y); }
    static void filterPrint(List<Integer> list, Predicate<Integer> cond) {
        for (Integer n : list) if (cond.test(n)) System.out.print(n + " ");
        System.out.println();
    }
    static <T, R> List<R> mapAll(List<T> in, Function<T, R> f) {
        List<R> out = new ArrayList<>();
        for (T t : in) out.add(f.apply(t));
        return out;
    }
    public static void main(String[] args) {
        System.out.println(apply(8, 3, (a, b) -> a - b) + " " + apply(8, 3, Math::max) + " " + apply(8, 3, (a, b) -> a % b));
        List<Integer> nums = Arrays.asList(5, 12, 7, 20, 3, 18);
        filterPrint(nums, n -> n > 10);
        filterPrint(nums, n -> n % 2 == 1);
        System.out.println(mapAll(nums, n -> n * n));
        List<String> names = new ArrayList<>(Arrays.asList("Charan", "asha", "Bhanu", "Divya"));
        names.sort((a, b) -> a.length() - b.length());                // lambda as Comparator
        System.out.println(names);
        names.sort(String::compareToIgnoreCase);                      // method reference
        System.out.println(names);
        names.sort(Comparator.comparing(String::length).thenComparing(Comparator.reverseOrder()));
        System.out.println(names);
        names.forEach(n -> System.out.print(n.charAt(0)));
        System.out.println();
        int base = 100;                                               // effectively final capture
        Function<Integer, Integer> addBase = v -> v + base;
        System.out.println(addBase.apply(5));
        Runnable r = () -> System.out.println("running a lambda Runnable");
        new Thread(r).start();
    }
}

  • Viva questions
    • What is a functional interface? Can it have default methods? (yes, any number)
    • Difference between Function and Consumer?
    • What are the types of method references?
    • Why must captured variables be effectively final?
    • andThen vs compose? (f.andThen(g) = g(f(x)); f.compose(g) = f(g(x)))
Explanation

Calculator is a custom functional interface, with its one method implemented by two lambdas. Predicate objects are combined with and, or and negate. For Function, len.andThen(twice) computes length first and then doubles it (6 → 12), whereas twice.compose(len) applies len first, so for "ab" it is 2 → 4. In program 2, apply(x, y, op) takes the operation as an argument, so the same method subtracts, finds the maximum or the remainder. filterPrint and mapAll take a Predicate and a Function. names.sort takes a Comparator lambda, then method reference String::compareToIgnoreCase, then a composed comparator (by length, then reverse alphabetical). The captured base is effectively final; if it were changed, the lambda would not compile.
