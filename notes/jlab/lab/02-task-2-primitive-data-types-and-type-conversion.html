Task 2 — Primitive data types and type conversion

Task 2 — Primitive data types and type conversion
Subject

Topic
2 of 12
Terms
Type casting, Two's complement
On this page
  1. Program 1 — Eight primitive types
  2. Program 2 — Conversion and promotion
Notebook notes
  • Aim: Use all eight primitive types, and demonstrate automatic type promotion and explicit type casting.
  • Key points
    • 8 primitives: byte(8 bit), short(16), int(32), long(64), float(32), double(64), char(16, Unicode), boolean(true/false). Sizes are fixed on every platform
    • Literals: long needs L, float needs f; default for decimals is double, for integers int
    • Widening (automatic): byte → short → int → long → float → double, and char → int. Narrowing needs a cast (type) and may lose data
    • Promotion in expressions: byte, short, char are promoted to int; if one operand is long, float or double, the whole expression is promoted to that type
    • x += y has an implicit cast; overflow wraps around silently; instance variables get default values (0, false, \u0000, null)
  • Procedure
    • Declare a variable of each type and print it with Byte.MIN_VALUE, Integer.MAX_VALUE and so on
    • Increment the maximum value to show the overflow
    • Assign smaller to larger types (widening) and print
    • Cast larger to smaller types and observe the loss
    • Mix types in expressions and observe the result type
Program 1 — Eight primitive types
java
public class Primitives {
    public static void main(String[] args) {
        byte b = 127;
        short s = 32767;
        int i = 2147483647;
        long l = 9223372036854775807L;
        float f = 3.14159265f;
        double d = 3.141592653589793;
        char c = 'A';
        boolean flag = true;
        System.out.println("byte    : " + b + "  size " + Byte.SIZE + " bits, range " + Byte.MIN_VALUE + " to " + Byte.MAX_VALUE);
        System.out.println("short   : " + s + "  size " + Short.SIZE + " bits, range " + Short.MIN_VALUE + " to " + Short.MAX_VALUE);
        System.out.println("int     : " + i + "  size " + Integer.SIZE + " bits, range " + Integer.MIN_VALUE + " to " + Integer.MAX_VALUE);
        System.out.println("long    : " + l + "  size " + Long.SIZE + " bits");
        System.out.println("float   : " + f + "  size " + Float.SIZE + " bits, max " + Float.MAX_VALUE);
        System.out.println("double  : " + d + "  size " + Double.SIZE + " bits, max " + Double.MAX_VALUE);
        System.out.println("char    : " + c + "  size " + Character.SIZE + " bits, code " + (int) c);
        System.out.println("boolean : " + flag);
        // overflow wraps around
        b++;
        System.out.println("b after b++ : " + b);
        i++;
        System.out.println("i after i++ : " + i);
        // default values of instance variables
        System.out.println("default int = " + new Defaults().x + ", boolean = " + new Defaults().y
                + ", double = " + new Defaults().z + ", char code = " + (int) new Defaults().ch);
    }
    static class Defaults { int x; boolean y; double z; char ch; }
}

Program 2 — Conversion and promotion
java
public class Conversion {
    public static void main(String[] args) {
        // widening (automatic): byte -> short -> int -> long -> float -> double
        int i = 100;
        long l = i;
        float f = l;
        double d = f;
        System.out.println(i + " " + l + " " + f + " " + d);
        // narrowing (explicit cast) - may lose data
        double x = 259.99;
        int n = (int) x;           // fraction truncated
        byte bt = (byte) n;        // 259 % 256 = 3
        System.out.println("(int)259.99 = " + n + ", (byte)259 = " + bt);
        System.out.println("(byte)200 = " + (byte) 200 + ", (int)-7.9 = " + (int) -7.9);
        char ch = (char) 97;
        System.out.println("(char)97 = " + ch + ", (int)'a' = " + (int) 'a');
        // type promotion in expressions
        byte a = 40, b = 50, c = 100;
        int product = a * b / c;   // a*b is promoted to int: 2000 / 100
        System.out.println("a*b/c = " + product);
        byte r = (byte) (a * 4);   // needs a cast; a*4 is int 160 -> -96
        System.out.println("(byte)(a*4) = " + r);
        char c1 = 'A';
        System.out.println("'A' + 1 = " + ('A' + 1) + ", (char)('A'+1) = " + (char) ('A' + 1));
        float ff = 5.5f;
        double result = (ff * 2) + (10 / 4) + (10 / 4.0) + (7 % 3);
        System.out.println("result = " + result);
        System.out.println("long+float -> " + (10L + 2.5f) + ", int/int = " + (7 / 2) + ", int/double = " + (7 / 2.0));
        // compound assignment has an implicit cast
        short sh = 10;
        sh += 5.7;
        System.out.println("short after += 5.7 : " + sh);
        // string conversion and parsing
        String s = "123";
        int parsed = Integer.parseInt(s) + 1;
        System.out.println(parsed + " " + String.valueOf(3.5) + " " + Double.parseDouble("2.5"));
    }
}

  • Viva questions
    • Why is byte b = 10; b = b * 2; an error? (b*2 is int)
    • What is (byte)200? (−56 because 200−256)
    • Is char signed? (No, 0 to 65535)
    • float f = 3.14; — what is wrong? (double literal needs f or cast)
    • Why does int/int give an int? Difference between 5/2 and 5/2.0?
Explanation

Program 1 shows the size and the range of each type from the wrapper-class constants. b++ on 127 wraps to −128 and i++ on the largest int wraps to the smallest, since there is no overflow check. In program 2, widening int→long→float→double happens automatically (the float shows 100.0). The cast (int)259.99 truncates the fraction to 259, and (byte)259 keeps the low 8 bits, 259 mod 256 = 3; (byte)200 is −56 in two's complement. In a*b/c all operands are promoted to int, so 40·50 = 2000 does not overflow byte and the result is 20. short += 5.7 compiles because of the implicit cast, and 15.7 is truncated to 15.
