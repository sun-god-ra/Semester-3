Lab

Tasks 1 to 12

Java Programming Lab · 24CS281

Syllabus: Twelve tasks, two programs each: from Hello World to the Stream API.

Topics in this unit

  1. Task 1 — Install JDK, Hello World, if and forAim: Install the Java Development Kit, set up the environment, and write a first program; then use decision (if) and looping (for) statements.
  2. Task 2 — Primitive data types and type conversionAim: Use all eight primitive types, and demonstrate automatic type promotion and explicit type casting.
  3. Task 3 — Two-dimensional arraysAim: Work with a 2D array (matrix operations) and a practical use case (a marks table).
  4. Task 4 — Classes, objects and constructorsAim: Define classes and create objects; write default, parameterised and copy constructors and use the this keyword.
  5. Task 5 — Method overloading, String, StringBuffer and StringTokenizerAim: Show compile-time polymorphism through method overloading, and use the string-handling classes.
  6. Task 6 — Inheritance, `super`, overriding and dynamic dispatchAim: Build a class hierarchy using extends and super; show method overriding and run-time polymorphism.
  7. Task 7 — Packages, interfaces and exceptionsAim: Create and import a user-defined package; implement interfaces; handle built-in exceptions and define a custom exception.
  8. Task 8 — Byte streams and character streamsAim: Read and write files using byte-oriented and character-oriented I/O classes.
  9. Task 9 — Threads and thread prioritiesAim: Create threads by extending Thread and implementing Runnable, run several threads, and set priorities.
  10. Task 10 — Generic functional interfaces and lambdas as argumentsAim: Use the functional interfaces of java.util.function and pass lambda expressions to methods.
  11. Task 11 — Collections: ArrayList, LinkedList, HashSet, HashMap, TreeMapAim: Use the List, Set and Map implementations of the Collections Framework.
  12. Task 12 — Stream reduce, iterators and streamsAim: Use reduce to combine stream elements; traverse collections with iterators and process them with streams.
