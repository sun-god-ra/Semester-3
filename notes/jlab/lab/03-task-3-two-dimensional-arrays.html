Notebook notes
  • Aim: Work with a 2D array (matrix operations) and a practical use case (a marks table).
  • Key points
    • Declaration: int[][] a = new int[3][4]; — array of arrays. a.length = rows, a[i].length = columns of row i
    • Initialiser { {1,2}, {3,4} }; jagged array: new int[3][] and then a[i] = new int[size]
    • Matrix addition: c[i][j]=a[i][j]+b[i][j]; transpose: t[j][i]=a[i][j]; multiplication needs three loops: \(c_{ij}=\sum_k a_{ik}b_{kj}\)
    • Array indices start at 0; going outside gives ArrayIndexOutOfBoundsException; elements are auto-initialised to 0
  • Procedure
    • Declare the arrays and fill them using initialisers or loops
    • Use nested for loops with i for rows and j for columns
    • For multiplication add the inner loop k and accumulate
    • Print using nested loops or enhanced for
Program 1 — Matrix operations and jagged array
java
public class Matrix2D {
    public static void main(String[] args) {
        int[][] a = { {1, 2, 3}, {4, 5, 6}, {7, 8, 9} };
        int[][] b = { {9, 8, 7}, {6, 5, 4}, {3, 2, 1} };
        int[][] sum = new int[3][3], prod = new int[3][3], t = new int[3][3];
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++) {
                sum[i][j] = a[i][j] + b[i][j];
                t[j][i] = a[i][j];
                for (int k = 0; k < 3; k++) prod[i][j] += a[i][k] * b[k][j];
            }
        print("A + B", sum);
        print("A x B", prod);
        print("Transpose of A", t);
        // jagged array: rows of different length
        int[][] jag = new int[3][];
        for (int i = 0; i < 3; i++) {
            jag[i] = new int[i + 1];
            for (int j = 0; j <= i; j++) jag[i][j] = i + j;
        }
        System.out.println("Jagged array:");
        for (int[] row : jag) {
            for (int v : row) System.out.print(v + " ");
            System.out.println();
        }
        System.out.println("a.length = " + a.length + ", a[0].length = " + a[0].length);
    }
    static void print(String title, int[][] m) {
        System.out.println(title + ":");
        for (int[] row : m) {
            for (int v : row) System.out.print(v + "\t");
            System.out.println();
        }
    }
}

Program 2 — Use case: marks table
java
public class MarksTable {
    public static void main(String[] args) {
        String[] names = {"Asha", "Bhanu", "Charan", "Divya"};
        String[] subjects = {"PS", "DLD", "Java"};
        int[][] marks = { {78, 85, 92}, {64, 70, 58}, {88, 91, 95}, {55, 49, 67} };
        int topper = 0, best = -1;
        System.out.println("Name\tPS\tDLD\tJava\tTotal\tAvg");
        for (int i = 0; i < marks.length; i++) {
            int total = 0;
            System.out.print(names[i] + "\t");
            for (int j = 0; j < marks[i].length; j++) {
                System.out.print(marks[i][j] + "\t");
                total += marks[i][j];
            }
            System.out.printf("%d\t%.2f%n", total, total / 3.0);
            if (total > best) { best = total; topper = i; }
        }
        for (int j = 0; j < subjects.length; j++) {
            int s = 0;
            for (int i = 0; i < marks.length; i++) s += marks[i][j];
            System.out.printf("Class average in %s = %.2f%n", subjects[j], s / (double) marks.length);
        }
        System.out.println("Topper: " + names[topper] + " with " + best);
    }
}

    • Is a 2D array in Java really a matrix? (array of arrays, rows can differ)
    • Time complexity of matrix multiplication? (\(O(n^3)\))
    • Default value of an int[] element?
    • What is the difference between a.length and a[0].length?
    • Can you have int[][] a = new int[][3];? (No — the first dimension is mandatory)
Explanation

Program 1 builds A and B, computes A+B (every cell is 10 because corresponding elements add to 10), A×B using the triple loop (first row: 1·9+2·6+3·3 = 30, 1·8+2·5+3·2 = 24, 1·7+2·4+3·1 = 18) and the transpose by swapping the indices. The jagged array has rows of length 1, 2, 3, which shows that each row is an independent array. Program 2 stores marks of four students in three subjects, sums each row for the total and average, sums each column for the class average, and tracks the maximum total to find the topper (Charan, 274).
