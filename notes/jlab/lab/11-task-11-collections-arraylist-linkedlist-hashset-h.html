Notebook notes
  • Aim: Use the List, Set and Map implementations of the Collections Framework.
  • Key points
    • Hierarchy: Iterable → Collection → List (ordered, duplicates: ArrayList, LinkedList, Vector), Set (no duplicates: HashSet, LinkedHashSet, TreeSet), Queue/Deque (LinkedList, PriorityQueue, ArrayDeque); Map (key → value; separate from Collection): HashMap, LinkedHashMap, TreeMap, Hashtable
    • ArrayList: dynamic array — get(i) \(O(1)\), insert/remove in the middle \(O(n)\). LinkedList: doubly linked list — add/remove at the ends \(O(1)\), get(i) \(O(n)\); also a Deque
    • HashSet/HashMap: hash table — average \(O(1)\) add/get/remove; no order guarantee; uses hashCode() and equals(). LinkedHashSet/Map: insertion order. TreeSet/TreeMap: red-black tree — sorted order, \(O(\log n)\), needs Comparable or a Comparator; firstKey, floorKey, headMap…
    • HashMap allows one null key; TreeMap does not; Hashtable is synchronized and allows no null. put with an existing key replaces the value; Set.add returns false for a duplicate
    • Generics <String> give type safety; only objects (wrapper classes Integer) can be stored
  • Procedure
    • Create an ArrayList of strings; add, insert, remove, search, sort
    • Create a LinkedList; use addFirst, addLast, removeFirst, pop, peek
    • Create a HashSet, show that duplicates are ignored; compare with LinkedHashSet/TreeSet; do union, intersection, difference
    • Create a HashMap and a TreeMap; put, get, remove, iterate over entrySet()
Program 1 — ArrayList, LinkedList, HashSet
java
import java.util.*;
public class ListSetDemo {
    public static void main(String[] args) {
        // ArrayList: resizable array, fast get(i)
        ArrayList<String> al = new ArrayList<>();
        al.add("Java"); al.add("C"); al.add("Python"); al.add(1, "C++"); al.add("C");
        System.out.println(al + " size " + al.size());
        al.remove("C");                                   // removes the first match only
        al.set(0, "JAVA");
        System.out.println(al + " get(2) = " + al.get(2) + ", indexOf(Python) = " + al.indexOf("Python") + ", contains(C) = " + al.contains("C"));
        Collections.sort(al);
        System.out.println("sorted : " + al);
        // LinkedList: doubly linked, fast add/remove at the ends
        LinkedList<Integer> ll = new LinkedList<>(Arrays.asList(10, 20, 30));
        ll.addFirst(5); ll.addLast(40); ll.add(2, 15);
        System.out.println(ll + " first " + ll.getFirst() + " last " + ll.getLast());
        ll.removeFirst(); ll.removeLast(); ll.pop();
        System.out.println(ll + " peek " + ll.peek());
        // HashSet: no duplicates, no guaranteed order
        HashSet<Integer> hs = new HashSet<>(Arrays.asList(5, 3, 9, 3, 5, 1));
        System.out.println("HashSet : " + hs + " size " + hs.size() + " add(9)=" + hs.add(9) + " add(7)=" + hs.add(7));
        // LinkedHashSet keeps insertion order, TreeSet keeps sorted order
        Set<Integer> lhs = new LinkedHashSet<>(Arrays.asList(5, 3, 9, 3, 5, 1));
        Set<Integer> ts = new TreeSet<>(Arrays.asList(5, 3, 9, 3, 5, 1));
        System.out.println("LinkedHashSet : " + lhs + ", TreeSet : " + ts);
        // set operations
        Set<Integer> a = new TreeSet<>(Arrays.asList(1, 2, 3, 4)), b = new TreeSet<>(Arrays.asList(3, 4, 5));
        Set<Integer> union = new TreeSet<>(a); union.addAll(b);
        Set<Integer> inter = new TreeSet<>(a); inter.retainAll(b);
        Set<Integer> diff = new TreeSet<>(a); diff.removeAll(b);
        System.out.println("union " + union + " intersection " + inter + " difference " + diff);
        // iteration
        Iterator<String> it = al.iterator();
        while (it.hasNext()) System.out.print(it.next() + ";");
        System.out.println();
    }
}

Program 2 — HashMap and TreeMap
java
import java.util.*;
public class MapDemo {
    public static void main(String[] args) {
        // HashMap: key -> value, one null key allowed, no order guarantee
        HashMap<String, Integer> marks = new HashMap<>();
        marks.put("Asha", 85); marks.put("Bhanu", 72); marks.put("Charan", 91); marks.put("Divya", 64);
        marks.put("Asha", 88);                           // same key: value replaced
        System.out.println("size " + marks.size() + ", Asha = " + marks.get("Asha") + ", Zed = " + marks.get("Zed")
                + ", getOrDefault = " + marks.getOrDefault("Zed", 0));
        System.out.println("containsKey(Bhanu) " + marks.containsKey("Bhanu") + ", containsValue(64) " + marks.containsValue(64));
        marks.remove("Divya");
        marks.putIfAbsent("Esha", 55);
        marks.merge("Esha", 5, Integer::sum);            // 55 + 5
        for (Map.Entry<String, Integer> e : new TreeMap<>(marks).entrySet())
            System.out.println("  " + e.getKey() + " -> " + e.getValue());
        // TreeMap: sorted by key
        TreeMap<Integer, String> tm = new TreeMap<>();
        tm.put(30, "thirty"); tm.put(10, "ten"); tm.put(20, "twenty"); tm.put(40, "forty");
        System.out.println(tm + " first " + tm.firstKey() + " last " + tm.lastKey());
        System.out.println("floorKey(25) = " + tm.floorKey(25) + ", ceilingKey(25) = " + tm.ceilingKey(25)
                + ", headMap(30) = " + tm.headMap(30) + ", tailMap(30) = " + tm.tailMap(30));
        System.out.println("descending " + tm.descendingMap());
        // word frequency count
        String text = "to be or not to be that is the question to be";
        Map<String, Integer> freq = new TreeMap<>();
        for (String w : text.split(" ")) freq.put(w, freq.getOrDefault(w, 0) + 1);
        System.out.println(freq);
        // LinkedHashMap keeps insertion order
        Map<String, Integer> lhm = new LinkedHashMap<>();
        lhm.put("z", 1); lhm.put("a", 2); lhm.put("m", 3);
        System.out.println(lhm + " keys " + lhm.keySet() + " values " + lhm.values());
    }
}

Explanation

In program 1 add(1, "C++") inserts at an index, remove("C") removes only the first match, and Collections.sort orders the list alphabetically. In the LinkedList addFirst/addLast add at the ends, removeFirst, removeLast and pop (= removeFirst) take them out. The HashSet ignores the duplicates 3 and 5, so its size is 4, and add(9) returns false while add(7) returns true. LinkedHashSet keeps the insertion order [5,3,9,1], and TreeSet sorts [1,3,5,9]. For the sets, addAll is the union, retainAll the intersection and removeAll the difference. In program 2, putting "Asha" twice replaces the value (88); getOrDefault avoids null; merge adds to the old value (55+5 = 60). The TreeMap keeps the keys sorted, and floorKey(25) is the largest key ≤ 25 (20) while ceilingKey(25) is the smallest key ≥ 25 (30). The word-count loop uses getOrDefault(w, 0) + 1.
