Task 8 — Byte streams and character streams

Notebook notes
  • Aim: Read and write files using byte-oriented and character-oriented I/O classes.
  • Key points
    • Byte streams (InputStream/OutputStream: FileInputStream, FileOutputStream, BufferedInputStream, DataInputStream/DataOutputStream) handle raw 8-bit data — images, binary, any file. read() returns an int 0–255 or −1 at end of file
    • Character streams (Reader/Writer: FileReader, FileWriter, BufferedReader, PrintWriter) handle 16-bit Unicode text and convert bytes ↔ characters using the encoding. BufferedReader.readLine() returns null at the end
    • try-with-resources closes the streams automatically (they implement AutoCloseable). I/O methods throw the checked IOException — declare throws IOException or catch it
    • new FileWriter(name, true) opens in append mode; without true the file is overwritten. Buffering reduces the number of disk operations
    • Predefined streams: System.in (InputStream), System.out, System.err (PrintStream)
  • Procedure
    • Open a FileOutputStream and write bytes
    • Open a FileInputStream and read until −1
    • Copy a file with a byte buffer
    • Use FileWriter/BufferedReader for a text file; count characters, words and lines
Program 1 — Byte streams
java
import java.io.*;
public class ByteStreams {
    public static void main(String[] args) throws IOException {
        // write bytes
        try (FileOutputStream out = new FileOutputStream("data.bin")) {
            byte[] data = {65, 66, 67, 68, 69};
            out.write(data);
            out.write(70);
        }
        // read bytes one at a time
        try (FileInputStream in = new FileInputStream("data.bin")) {
            int b;
            while ((b = in.read()) != -1) System.out.print(b + " ");
            System.out.println();
        }
        // copy a file using a buffer
        try (FileInputStream in = new FileInputStream("data.bin");
             FileOutputStream out = new FileOutputStream("copy.bin")) {
            byte[] buf = new byte[4];
            int n, total = 0;
            while ((n = in.read(buf)) != -1) {
                out.write(buf, 0, n);
                total += n;
            }
            System.out.println("copied " + total + " bytes");
        }
        // data streams: primitive types in binary
        try (DataOutputStream dos = new DataOutputStream(new BufferedOutputStream(new FileOutputStream("prim.dat")))) {
            dos.writeInt(2024); dos.writeDouble(3.5); dos.writeUTF("hello"); dos.writeBoolean(true);
        }
        try (DataInputStream dis = new DataInputStream(new BufferedInputStream(new FileInputStream("prim.dat")))) {
            System.out.println(dis.readInt() + " " + dis.readDouble() + " " + dis.readUTF() + " " + dis.readBoolean());
        }
        System.out.println("size of copy.bin = " + new File("copy.bin").length());
        new File("data.bin").delete(); new File("copy.bin").delete(); new File("prim.dat").delete();
    }
}

Output

text
65 66 67 68 69 70 
copied 6 bytes
2024 3.5 hello true
size of copy.bin = 6
Program 2 — Character streams
java
import java.io.*;
public class CharStreams {
    public static void main(String[] args) throws IOException {
        try (FileWriter fw = new FileWriter("notes.txt")) {
            fw.write("Java is simple\n");
            fw.write("Java is portable\n");
            fw.write("Streams are fun\n");
        }
        // read character by character
        int chars = 0;
        try (FileReader fr = new FileReader("notes.txt")) {
            int c;
            while ((c = fr.read()) != -1) chars++;
        }
        // read line by line with BufferedReader
        int lines = 0, words = 0;
        try (BufferedReader br = new BufferedReader(new FileReader("notes.txt"))) {
            String line;
            while ((line = br.readLine()) != null) {
                lines++;
                words += line.split("\\s+").length;
                System.out.println(lines + ": " + line);
            }
        }
        System.out.println("characters = " + chars + ", words = " + words + ", lines = " + lines);
        // append mode and PrintWriter
        try (PrintWriter pw = new PrintWriter(new FileWriter("notes.txt", true))) {
            pw.println("Appended line");
            pw.printf("Pi = %.3f%n", Math.PI);
        }
        try (BufferedReader br = new BufferedReader(new FileReader("notes.txt"))) {
            System.out.println("lines now = " + br.lines().count());
        }
        new File("notes.txt").delete();
    }
}

Output

text
1: Java is simple
2: Java is portable
3: Streams are fun
characters = 48, words = 9, lines = 3
lines now = 5
  • Viva questions
    • Difference between byte and character streams?
    • Why use BufferedReader?
    • What does read() return at the end of file?
    • Difference between FileWriter and PrintWriter?
    • What is serialization? (Writing objects with ObjectOutputStream, class must implement Serializable)
Explanation

Program 1 writes the five bytes 65–69 and 70 into a file and reads them back as numbers (a loop that stops at −1). The copy loop reads up to 4 bytes at a time into a buffer and writes exactly n bytes (the last read may be shorter). DataOutputStream writes int, double, a UTF string and a boolean in binary, and DataInputStream must read them back in the same order. Program 2 writes three lines with FileWriter, counts characters with read() (48, including the newlines), and lines and words with readLine() and split. Reopening with true appends, and PrintWriter provides println and printf, so the file has 5 lines. The files are deleted at the end.
