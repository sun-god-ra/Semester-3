Task 7 — Packages, interfaces and exceptions

Java Programming Lab · Lab: Tasks 1 to 12

Task 7 — Packages, interfaces and exceptions
Subject
Java Programming Lab (24CS281)
Unit
Lab: Tasks 1 to 12
Topic
7 of 12
Terms
Inheritance, Constructor, Abstract class
On this page
  1. Program 1 — Package and import
  2. Program 2 — Interfaces

Notebook notes
  • Aim: Create and import a user-defined package; implement interfaces; handle built-in exceptions and define a custom exception.
  • Key points
    • Package = a namespace that groups related classes (and avoids name clashes); package mypack; must be the first statement; the folder structure must match (mypack/Calc.java). Compile with javac -d . mypack/Calc.java, import with import mypack.Calc; or mypack.*. Access: public (everywhere), protected (package + subclasses), default (package only), private (class only)
    • Interface: a contract of abstract methods; fields are public static final; methods are public abstract by default; since Java 8 may have default and static methods. A class can implement many interfaces (implements A, B) — this is how Java gets multiple inheritance of type
    • Exceptions: Throwable → Error (not handled) and Exception. Checked (compiler forces handling: IOException, custom ones extending Exception) vs unchecked (RuntimeException: ArithmeticException, NullPointerException, ArrayIndexOutOfBoundsException, NumberFormatException, ClassCastException)
    • try { } catch (E e) { } finally { } — finally always runs. throw throws an object; throws declares what a method may throw. Custom exception: class MyEx extends Exception { MyEx(String m){ super(m);} }. Catch the more specific exception before the general one
  • Procedure
    • Create the folder mypack and the class with package mypack;
    • Compile the package class, then compile and run the main class that imports it
    • Define an interface and implement it in two classes; call through the interface reference
    • Cause built-in exceptions inside try and catch them
    • Write a custom exception class, throw it with throw and handle it
Program 1 — Package and import

mypack/Calc.java

java
package mypack;

public class Calc {
    public int add(int a, int b) { return a + b; }
    public int mul(int a, int b) { return a * b; }
    int hidden() { return 42; }            // package-private: not visible outside mypack
}

UsePack.java

java
import mypack.Calc;                         // or: import mypack.*;

public class UsePack {
    public static void main(String[] args) {
        Calc c = new Calc();
        System.out.println("add = " + c.add(4, 5) + ", mul = " + c.mul(4, 5));
        // c.hidden();                      // compile error: not public
    }
}

Compile and run (from the folder that contains mypack):

text
javac -d . mypack/Calc.java UsePack.java
java UsePack

Output

text
add = 9, mul = 20
Program 2 — Interfaces
java
interface Shape {
    double PI = 3.14159;                       // constants are public static final
    double area();                             // abstract by default
    default void describe() {                  // Java 8 default method
        System.out.println(getClass().getSimpleName() + " with area " + String.format("%.2f", area()));
    }
    static void info() { System.out.println("Shape interface: static method"); }
}
class Circle implements Shape {
    double r;
    Circle(double r) { this.r = r; }
    public double area() { return PI * r * r; }
}
class Rect implements Shape {
    double l, b;
    Rect(double l, double b) { this.l = l; this.b = b; }
    public double area() { return l * b; }
}
interface Drawable { void draw(); }
class Canvas implements Shape, Drawable {      // multiple interfaces
    public double area() { return 10; }
    public void draw() { System.out.println("Drawing canvas"); }
}
public class InterfaceDemo {
    public static void main(String[] args) {
        Shape[] shapes = { new Circle(2), new Rect(3, 4), new Canvas() };
        for (Shape s : shapes) s.describe();
        Shape.info();
        Drawable d = new Canvas();
        d.draw();
    }
}

Output

text
Circle with area 12.57
Rect with area 12.00
Canvas with area 10.00
Shape interface: static method
Drawing canvas
Program 3 — Built-in and custom exceptions
java
class InsufficientFundsException extends Exception {          // custom (checked) exception
    private final double shortBy;
    InsufficientFundsException(String msg, double shortBy) { super(msg); this.shortBy = shortBy; }
    double getShortBy() { return shortBy; }
}
class Account {
    private double balance;
    Account(double balance) { this.balance = balance; }
    void withdraw(double amt) throws InsufficientFundsException {
        if (amt > balance)
            throw new InsufficientFundsException("Insufficient balance", amt - balance);
        balance -= amt;
        System.out.println("Withdrawn " + amt + ", balance " + balance);
    }
}
public class ExceptionDemo {
    public static void main(String[] args) {
        // ---- built-in exceptions ----
        try {
            int a = 10, b = 0;
            System.out.println(a / b);
        } catch (ArithmeticException e) {
            System.out.println("Caught: " + e.getMessage());
        } finally {
            System.out.println("finally always runs");
        }
        try {
            int[] arr = new int[3];
            arr[5] = 1;
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Caught: " + e.getMessage());
        }
        try {
            Integer.parseInt("12x");
        } catch (NumberFormatException e) {
            System.out.println("Caught: " + e.getMessage());
        }
        try {
            String s = null;
            s.length();
        } catch (NullPointerException | ClassCastException e) {      // multi-catch
            System.out.println("Caught: " + e.getClass().getSimpleName());
        }
        try {
            Object o = "text";
            Integer i = (Integer) o;
        } catch (ClassCastException e) {
            System.out.println("Caught ClassCastException");
        }
        // ---- custom exception ----
        Account acc = new Account(500);
        try {
            acc.withdraw(200);
            acc.withdraw(400);
        } catch (InsufficientFundsException e) {
            System.out.println(e.getMessage() + ", short by " + e.getShortBy());
        }
        // ---- throw inside a method, nested try ----
        try {
            check(15);
        } catch (IllegalArgumentException e) {
            System.out.println("Caught: " + e.getMessage());
        }
        System.out.println("Program continues normally");
    }
    static void check(int age) {
        if (age < 18) throw new IllegalArgumentException("Age " + age + " is below 18");
    }
}

Output

text
Caught: / by zero
finally always runs
Caught: Index 5 out of bounds for length 3
Caught: For input string: "12x"
Caught: NullPointerException
Caught ClassCastException
Withdrawn 200.0, balance 300.0
Insufficient balance, short by 100.0
Caught: Age 15 is below 18
Program continues normally
  • Viva questions
    • Can an interface have a constructor? (No) Can an interface extend another? (Yes, extends)
    • Abstract class vs interface?
    • What is the difference between throw and throws? final, finally, finalize?
    • Can there be a try without catch? (yes, with finally)
    • What happens if an exception is not caught? (default handler prints the stack trace and ends the thread)
Explanation

The package program has two files: Calc.java in the folder mypack (declared package mypack; and public methods) and UsePack.java which imports it. Commands: javac -d . mypack/Calc.java UsePack.java, then java UsePack, giving add = 9, mul = 20. A package-private method is not visible outside the package. In the interface program, Shape has a constant, an abstract method, a default method that every implementer inherits and a static method called on the interface name; Canvas implements two interfaces. In the exception program each failure is caught by its own handler (/ by zero, array index, number format, null pointer, class cast), and finally prints in any case. The checked InsufficientFundsException is declared with throws in withdraw, so the caller must catch it. The first withdrawal succeeds, and the second one fails with 400 > 300 and is short by 100. After the exception handling the program continues normally.
