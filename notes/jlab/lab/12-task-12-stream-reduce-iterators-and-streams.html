Notebook notes
  • Aim: Use reduce to combine stream elements; traverse collections with iterators and process them with streams.
  • Key points
    • Stream pipeline = source → zero or more intermediate operations (lazy: filter, map, sorted, distinct, limit, skip) → one terminal operation (collect, forEach, reduce, count, sum, anyMatch, findFirst). Nothing runs until the terminal operation. A stream can be used once; it does not change the source
    • reduce folds the elements into one value: reduce(identity, accumulator) returns the value; reduce(accumulator) returns an Optional (empty stream has no result); reduce(identity, accumulator, combiner) is the form for different result type / parallel streams. The accumulator must be associative
    • Collectors: toList(), toSet(), joining(), groupingBy(), counting(), partitioningBy(); primitive streams IntStream.range/rangeClosed, sum(), average(), boxed()
    • Iterator: hasNext(), next(), remove() — the only safe way to remove while traversing; ListIterator adds hasPrevious(), previous(), set(), add(). Modifying a collection in a for-each loop causes ConcurrentModificationException (fail-fast)
  • Procedure
    • Compute sum, product and maximum of a list using reduce
    • Use the three-argument reduce for a result of a different type
    • Traverse a list with Iterator and remove selected elements; traverse with ListIterator in both directions
    • Build stream pipelines with filter, map, sorted, collect, groupingBy
Program 1 — Stream reduce
java
import java.util.*;
import java.util.stream.*;
public class ReduceDemo {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(4, 8, 15, 16, 23, 42);
        int sum = nums.stream().reduce(0, (a, b) -> a + b);                 // identity + accumulator
        int sum2 = nums.stream().reduce(0, Integer::sum);
        int product = Stream.of(1, 2, 3, 4, 5).reduce(1, (a, b) -> a * b);
        Optional<Integer> max = nums.stream().reduce(Integer::max);         // no identity -> Optional
        Optional<Integer> none = new ArrayList<Integer>().stream().reduce(Integer::sum);
        System.out.println(sum + " " + sum2 + " " + product + " " + max.get() + " " + none.isPresent());
        String joined = Stream.of("a", "b", "c").reduce("", (x, y) -> x + y);
        System.out.println(joined);
        // three-argument reduce: identity, accumulator, combiner (for parallel streams)
        int totalLength = Stream.of("java", "stream", "reduce")
                .reduce(0, (acc, s) -> acc + s.length(), Integer::sum);
        System.out.println("total length " + totalLength);
        // reduce vs built-in terminal operations
        System.out.println(nums.stream().mapToInt(Integer::intValue).sum() + " "
                + nums.stream().mapToInt(Integer::intValue).average().getAsDouble() + " "
                + nums.stream().count());
        // sum of squares of the even numbers
        int sq = nums.stream().filter(n -> n % 2 == 0).map(n -> n * n).reduce(0, Integer::sum);
        System.out.println("sum of squares of evens = " + sq);
        System.out.println(IntStream.rangeClosed(1, 5).reduce(1, (a, b) -> a * b) + " = 5!");
    }
}

Program 2 — Iterators and streams
java
import java.util.*;
import java.util.stream.*;
public class IterStream {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>(Arrays.asList(1, 2, 3, 4, 5, 6, 7, 8));
        // Iterator: the only safe way to remove while traversing
        Iterator<Integer> it = list.iterator();
        while (it.hasNext()) if (it.next() % 2 == 0) it.remove();
        System.out.println("after removing evens : " + list);
        // ListIterator: both directions, add and set
        ListIterator<Integer> li = list.listIterator();
        while (li.hasNext()) { int v = li.next(); li.set(v * 10); }
        System.out.print("backwards : ");
        while (li.hasPrevious()) System.out.print(li.previous() + " ");
        System.out.println();
        // removing inside a for-each throws ConcurrentModificationException
        try {
            for (Integer x : list) if (x == 30) list.remove(x);
        } catch (ConcurrentModificationException e) {
            System.out.println("Caught ConcurrentModificationException");
        }
        // streams
        List<String> words = Arrays.asList("apple", "banana", "cherry", "date", "fig", "grape");
        System.out.println(words.stream().filter(w -> w.length() > 4).map(String::toUpperCase).collect(Collectors.toList()));
        Map<Integer, List<String>> byLength =
                words.stream().collect(Collectors.groupingBy(String::length, TreeMap::new, Collectors.toList()));
        System.out.println(byLength);
        System.out.println(words.stream().collect(Collectors.joining(", ", "[", "]")));
        System.out.println(IntStream.range(0, 5).map(i -> i * i).boxed().collect(Collectors.toList()));
        System.out.println(words.stream().sorted(Comparator.reverseOrder()).limit(3).collect(Collectors.toList()));
        System.out.println(words.stream().anyMatch(w -> w.startsWith("f")) + " " + words.stream().allMatch(w -> w.length() > 3)
                + " " + words.stream().skip(2).findFirst().get());
        System.out.println(Stream.iterate(1, n -> n * 2).limit(8).collect(Collectors.toList()));
        // a stream can be consumed only once
        Stream<String> s = words.stream();
        s.count();
        try { s.count(); } catch (IllegalStateException e) { System.out.println("Caught: " + e.getMessage()); }
    }
}

  • Viva questions
    • Intermediate vs terminal operations? What is laziness?
    • Why does reduce(Integer::sum) return an Optional?
    • map vs flatMap? findFirst vs findAny?
    • Difference between Iterator and Iterable? What is fail-fast?
    • Can a stream be reused? (No — IllegalStateException)
Explanation

In program 1, reduce(0, (a,b) -> a+b) starts from the identity 0 and adds each element (4+8+15+16+23+42 = 108); the product of 1 to 5 is 120. Without an identity the result is an Optional, which is empty for an empty stream. The three-argument form turns strings into a total length (4+6+6 = 16); the combiner only matters for parallel streams. In program 2, the iterator's remove() removes the even numbers safely, leaving [1,3,5,7]; ListIterator.set multiplies each by 10 and previous() walks backwards. Removing from the list inside a for-each loop makes the iterator detect the modification and throw ConcurrentModificationException. The stream examples filter by length and convert to upper case, group the words by length in a TreeMap, join with a delimiter, create squares with IntStream, and generate powers of 2 with Stream.iterate and limit. After the terminal operation count(), the stream is closed, and using it again throws IllegalStateException.
