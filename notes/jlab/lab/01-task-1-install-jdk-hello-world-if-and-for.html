Task 1 — Install JDK, Hello World, if and for

Java Programming Lab · Lab: Tasks 1 to 12

Task 1 — Install JDK, Hello World, if and for

Notebook notes
  • Aim: Install the Java Development Kit, set up the environment, and write a first program; then use decision (if) and looping (for) statements.
  • Key points
    • JDK = compiler javac + tools + JRE. JRE = JVM + libraries. Source file .java → javac → bytecode .class → java runs it on the JVM
    • File name must match the public class name (HelloWorld.java, case-sensitive); program starts at public static void main(String[] args)
    • if / else if / else choose one path; for(init; condition; update) repeats a block a known number of times
    • Leap year rule: divisible by 400, or divisible by 4 but not by 100
  • Procedure
    • Download a JDK (Oracle JDK or OpenJDK, e.g. version 17 or 21) and run the installer (Windows: .exe/.msi; Linux: sudo apt install openjdk-21-jdk; macOS: .pkg or brew install openjdk)
    • Set JAVA_HOME to the JDK folder and add %JAVA_HOME%\bin (Windows) or $JAVA_HOME/bin (Linux/macOS) to PATH (Windows: System Properties → Environment Variables)
    • Check: java -version and javac -version in a new terminal
    • Write the program in a text editor or IDE (VS Code, IntelliJ IDEA, Eclipse, NetBeans) and save as HelloWorld.java
    • Compile: javac HelloWorld.java (creates HelloWorld.class). Run: java HelloWorld (no .class)
Program 1 — Hello World
java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
        System.out.println("Welcome to Java Programming Lab");
    }
}

Welcome to Java Programming Lab
Program 2 — if and for
java
public class IfFor {
    public static void main(String[] args) {
        int year = 2024;
        // if - else if - else
        if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) {
            System.out.println(year + " is a leap year");
        } else {
            System.out.println(year + " is not a leap year");
        }
        int marks = 72;
        if (marks >= 90) System.out.println("Grade O");
        else if (marks >= 70) System.out.println("Grade A");
        else if (marks >= 50) System.out.println("Grade B");
        else System.out.println("Fail");

        // for loop: table of 7
        for (int i = 1; i <= 5; i++) {
            System.out.println("7 x " + i + " = " + (7 * i));
        }
        // for loop: sum of 1..10 and a star pattern
        int sum = 0;
        for (int i = 1; i <= 10; i++) sum += i;
        System.out.println("Sum 1..10 = " + sum);
        for (int i = 1; i <= 4; i++) {
            for (int j = 1; j <= i; j++) System.out.print("* ");
            System.out.println();
        }
    }
}

  • Viva questions
    • Difference between JDK, JRE, JVM? Why is Java platform independent? (bytecode)
    • Why must main be public static void? (JVM calls it without an object, from outside the class)
    • What does javac produce? What happens if the class name and file name differ for a public class? (compile error)
    • Difference between for and enhanced for?
    • What is String[] args? (command-line arguments)
Explanation

The JDK is installed and JAVA_HOME and PATH are set so that the terminal can find javac and java. javac converts the source into bytecode in a .class file, and java starts the JVM, which loads the class and calls main. In program 2 the leap-year condition combines || and &&; 2024 is divisible by 4 but not by 100, so it is a leap year. The ladder of if-else if stops at the first true condition, so 72 gives grade A. The for loops print the table of 7, add 1 to 10 (55) and print a triangle with a nested loop (the inner loop runs i times in row i).
