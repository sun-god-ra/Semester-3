Part A

Operating Systems: short answer questions

2 marks each · 25 questions

Gantt answers state their assumptions (lower priority number = higher priority; ties by arrival). Check the convention your teacher uses.

Q1Nov 20252MCO1 K1

What are system calls? Give two examples.

Answer

System calls are the programming interface through which a user program requests a service from the operating system kernel (the only controlled way into kernel mode). Examples: fork() (process control), open()/read() (file management), write(), getpid() (information), pipe() (communication). On a call the CPU switches from user mode to kernel mode through a trap.

Q2Nov 20252MCO1 K1

Name two free and open-source operating systems.

Answer

Linux (and its distributions such as Ubuntu, Debian, Fedora) and FreeBSD (also OpenBSD, NetBSD). Their source code is available to read, modify and redistribute under licences such as GPL and BSD.

Q3Nov 20252MCO2 K1

What is inter-process communication (IPC)?

Answer

IPC is the set of mechanisms by which cooperating processes exchange data and synchronise. The two basic models are shared memory and message passing (pipes, message queues, sockets, signals).

Q4Nov 20252MCO2 K1

List any two CPU scheduling criteria.

Answer

(1) CPU utilisation (keep the CPU as busy as possible); (2) Throughput (processes completed per unit time); also turnaround time, waiting time and response time.

Q5Nov 20252MCO3 K2

Write any two advantages of monitors over semaphores.

Answer
  1. Mutual exclusion is automatic: only one process can be active inside the monitor, so the programmer does not write wait/signal pairs around critical sections.
  2. Less error prone: the shared data and the procedures are encapsulated in one place; forgetting a signal or reversing the order (which causes deadlock with semaphores) cannot happen for mutual exclusion. Condition variables handle waiting.
Q6Nov 20252MCO3 K1

Name two classical synchronization problems.

Answer

The Producer–Consumer (bounded buffer) problem, the Readers–Writers problem and the Dining Philosophers problem.

Q7Nov 20252MCO4 K2

List two advantages of paging.

Answer

(1) No external fragmentation, since memory is divided into fixed-size frames. (2) The logical address space need not be contiguous in physical memory; it also allows sharing of pages (reentrant code) and supports virtual memory.

Q8Nov 20252MCO4 K1

What is a page fault?

Answer

A page fault is a trap raised when a process refers to a page that is not currently in main memory (valid–invalid bit = invalid). The OS finds a free frame, loads the page from the backing store, updates the page table and restarts the instruction.

Q9Nov 20252MCO5 K1

List the disk scheduling algorithms.

Answer

FCFS, SSTF (shortest seek time first), SCAN (elevator), C-SCAN, LOOK, C-LOOK.

Q10Nov 20252MCO5 K1

What is protection in an operating system?

Answer

Protection is the mechanism that controls the access of processes and users to the resources (files, memory, CPU, devices) defined by the system. It is built on domains of protection and access rights (access matrix), and it enforces policies decided by the owner/administrator.

Q11Expected2MCO1 K1

Differentiate between a process and a program.

Answer

A program is a passive entity, an executable file on disk. A process is an active entity: a program in execution, with program counter, stack, data section, heap and registers (its PCB).

Q12Expected2MCO1 K1

What is a kernel? Distinguish user mode and kernel mode.

Answer

The kernel is the core part of the OS that runs with full hardware privilege. In kernel (supervisor) mode privileged instructions (I/O, memory management) can run; in user mode they cannot. A mode bit (0 kernel, 1 user) records the mode.

Q13Expected2MCO2 K1

List the states of a process.

Answer

New, Ready, Running, Waiting (Blocked), Terminated.

Q14Expected2MCO2 K2

What is a context switch?

Answer

Saving the state (PCB) of the running process and loading the state of the next one when the CPU is given to another process. It is pure overhead; no useful work happens during it.

Q15Expected2MCO2 K2

Differentiate between a process and a thread.

Answer

A thread is a lightweight unit of CPU execution inside a process. Threads of one process share code, data and open files but have their own PC, registers and stack. Creation and switching are cheaper than for processes.

Q16Expected2MCO2 K2

What is starvation? How is it solved in scheduling?

Answer

Starvation (indefinite blocking) is when a low-priority process waits forever because higher-priority ones keep arriving. Aging (gradually increasing the priority of a waiting process) solves it.

Q17Expected2MCO3 K1

What is the critical-section problem? State the three requirements of a solution.

Answer

Designing a protocol so that processes can use shared data without conflict. A solution must give mutual exclusion, progress and bounded waiting.

Q18Expected2MCO3 K1

State the four necessary conditions for deadlock.

Answer

Mutual exclusion, hold and wait, no pre-emption, circular wait; all four must hold together.

Q19Expected2MCO3 K2

Differentiate between deadlock prevention and deadlock avoidance.

Answer

Prevention breaks at least one of the four necessary conditions by restricting how resources are requested. Avoidance lets the processes request freely but the OS grants a request only if the system stays in a safe state (Banker's algorithm), using advance information about maximum demands.

Q20Expected2MCO4 K1

Define internal and external fragmentation.

Answer

Internal: unused space inside an allocated block (fixed partitions, last page of a process). External: enough total free memory exists but it is scattered in small non-contiguous holes.

Q21Expected2MCO4 K2

What is thrashing?

Answer

When a process does not have enough frames, it page-faults continually and spends more time paging than executing; CPU utilisation collapses. Controlled by the working-set model or page-fault frequency, and lower multiprogramming.

Q22Expected2MCO4 K1

What is the Translation Look-aside Buffer (TLB)?

Answer

A small, fast associative cache of page-table entries. A TLB hit gives the frame number without a memory access to the page table, which speeds up address translation.

Q23Expected2MCO5 K1

List the file access methods.

Answer

Sequential access, direct (random) access, and indexed access.

Q24Expected2MCO5 K2

List the file allocation methods.

Answer

Contiguous, linked and indexed allocation.

Q25Expected2MCO5 K1

What is a directory? List its structures.

Answer

A directory is a table that maps file names to file control blocks/inodes. Structures: single-level, two-level, tree-structured, acyclic-graph and general graph directories.
