Q1Nov 20258MCO2 K2

Differentiate between message passing and shared memory models of inter-process communication.

Answer
Point Shared memory Message passing
Mechanism Processes share a region of memory and read/write it Processes exchange messages with send and receive
Kernel involvement Only to set up the region; then none On every send/receive (system calls)
Speed Faster (memory speed) Slower (copying and system calls)
Synchronisation Programmer must provide it (semaphores, mutex) Implicit in the blocking send/receive
Suited to Large data, same machine Small data, distributed systems
Conflicts Cache-coherence and race problems Easier to implement, no conflicts to avoid
Q2Nov 20258MCO2 K2

Explain the advantages of multilevel queue scheduling.

Answer

The ready queue is split into separate queues (e.g. system, interactive, batch processes), each with its own scheduling algorithm (e.g. RR for interactive, FCFS for batch). Between queues there is fixed priority (a lower queue runs only when all higher are empty) or time-slice sharing (e.g. 80 percent to foreground, 20 percent to background).

Advantages: (1) different process types get an algorithm that suits them (response time for interactive, throughput for batch); (2) low scheduling overhead, because a process is permanently assigned to its queue; (3) simple, with clear policy for priority between classes. Limitation: starvation of low queues, inflexible (no movement between queues; fixed by the multilevel feedback queue).

Q4Expected8MCO2 K2

Explain the process states and the process control block.

Answer

The PCB (task control block) holds: process state, process number (PID), program counter, CPU registers, CPU-scheduling information (priority, queue pointers), memory-management information (page table, limits), accounting information, I/O status (open files, devices). It is saved and restored at every context switch.

Q5Expected8MCO2 K2

Explain the CPU scheduling criteria and the scheduling algorithms.

Answer

Criteria: CPU utilisation (maximise), throughput (maximise), turnaround time, waiting time, response time (minimise).

  • FCFS: non-pre-emptive; simple; convoy effect.
  • SJF: shortest next burst first; optimal average waiting time; needs the burst length (predicted by exponential averaging \(\tau_{n+1}=\alpha t_n+(1-\alpha)\tau_n\)); can starve long jobs. Pre-emptive version is SRTF.
  • Priority: highest priority first; starvation solved by aging.
  • Round Robin: each process gets a time quantum, then goes to the back of the queue; good response; quantum too large → FCFS, too small → context-switch overhead.
  • Multilevel queue and multilevel feedback queue.
