Q1Expected8MCO1 K3

Convert (a) \((156.625)_{10}\) to binary, octal and hexadecimal; (b) \((2AF.8)_{16}\) to decimal and binary.

Answer

(a) Integer part: \(156=10011100_2\) (128+16+8+4). Fraction \(0.625\): \(\times2=1.25\to1\), \(0.25\times2=0.5\to0\), \(0.5\times2=1.0\to1\) so \(0.625=0.101_2\). Binary: \((10011100.101)_2\). Octal: group in 3 from the point: \(010\ 011\ 100\ .\ 101=(234.5)_8\). Hex: group in 4: \(1001\ 1100\ .\ 1010=(9C.A)_{16}\). Check: \(9\times16+12=156\); \(A/16=0.625\) ✓.

(b) \((2AF.8)_{16}=2\times256+10\times16+15+8/16=512+160+15+0.5=\mathbf{687.5}\). Binary: each hex digit to 4 bits: \(0010\ 1010\ 1111\ .\ 1000=(1010101111.1)_2\).

Q2Expected8MCO1 K3

Perform \((1010100)_2-(1000011)_2\) using 2's complement. Also explain the \(r\)'s and \((r-1)\)'s complement.

Answer

\(84-67=17\). 2's complement of \(1000011\): invert \(\to0111100\), add 1 \(\to0111101\). \(1010100+0111101=1\,0010001\). The carry out (1) shows the result is positive; discard it: \((0010001)_2=17\) ✓.

If there were no end carry, the result is negative: take the 2's complement of the sum and put a minus sign.

Complements. The \(r\)'s complement of an \(n\)-digit number \(N\) in base \(r\) is \(r^n-N\) (2's complement in binary, 10's in decimal). The \((r-1)\)'s complement is \((r^n-1)-N\) (1's complement in binary: flip all bits; 9's in decimal). Relation: \(r\text{'s}=(r-1)\text{'s}+1\). For 1's complement subtraction the end-around carry is added back.

Q3Expected8MCO1 K2

Prove using Boolean algebra: (a) \(A+AB=A\) (b) \(A+A'B=A+B\) (c) the consensus theorem \(AB+A'C+BC=AB+A'C\).

Answer

(a) \(A+AB=A(1+B)=A\cdot1=A\). (b) \(A+A'B=(A+A')(A+B)=1\cdot(A+B)=A+B\) (distributive law). (c) \(AB+A'C+BC=AB+A'C+BC(A+A')=AB+A'C+ABC+A'BC=AB(1+C)+A'C(1+B)=AB+A'C\) ∎

Q4Expected8MCO1 K3

Express \(F(A,B,C)=\sum m(1,3,5,6)\) in canonical SOP and POS. Implement the simplified form using NAND gates only.

Answer

SOP: \(F=A'B'C+A'BC+AB'C+ABC'\). POS: the other rows (0, 2, 4, 7): \(F=\prod M(0,2,4,7)=(A+B+C)(A+B'+C)(A'+B+C)(A'+B'+C')\).

Simplify: \(m1,m3,m5\): \(A'B'C+A'BC+AB'C=C(A'B'+A'B+AB')=C(A'+B')=C\,(AB)'\). So \(F=C(AB)'+ABC'\). This is \(F=C\oplus AB\) (since \(m6=ABC'\) and \(m1,3,5\) are \(C=1,AB=0\)). NAND realisation of \(F=C\oplus X\) with \(X=AB\):

  • \(X=AB\) needs an AND: one NAND plus one NAND used as an inverter (2 gates).
  • XOR from four NANDs: \(N_1=(CX)'\), \(N_2=(C\,N_1)'\), \(N_3=(X\,N_1)'\), \(F=(N_2N_3)'\). Total 6 NAND gates.
Q5Expected8MCO1 K2

Convert \(-13.25\) to the IEEE 754 single-precision format.

Answer

\(13.25=1101.01_2=1.10101\times2^3\). Sign \(=1\). Exponent \(=3+127=130=10000010_2\). Mantissa \(=10101\) followed by zeros (19 zeros to fill the 23 bits). \[1\ |\ 10000010\ |\ 10101000000000000000000\] In hex: \(\mathbf{C1540000}\).

Q6Expected8MCO1 K2

Explain the logic gates with symbols, truth tables and Boolean expressions. Show how NAND and NOR are universal.

Answer
Gate Expression Output is 1 when
NOT \(Y=A'\) input 0
AND \(Y=AB\) all inputs 1
OR \(Y=A+B\) any input 1
NAND \(Y=(AB)'\) any input 0
NOR \(Y=(A+B)'\) all inputs 0
XOR \(Y=A\oplus B=A'B+AB'\) inputs differ
XNOR \(Y=A\odot B=AB+A'B'\) inputs equal

Truth table for two inputs (A B → AND, OR, NAND, NOR, XOR, XNOR): 00 → 0,0,1,1,0,1; 01 → 0,1,1,0,1,0; 10 → 0,1,1,0,1,0; 11 → 1,1,0,0,0,1.

NAND is universal: NOT: \((AA)'=A'\). AND: \(((AB)')'\) (two NANDs). OR: \((A'B')'=A+B\) (three NANDs). NOR is universal: NOT: \((A+A)'=A'\). OR: \(((A+B)')'\). AND: \((A'+B')'=AB\).
