Part A

Digital Logic Design: short answer questions

2 marks each · 29 questions

No past SAHE paper for Digital Logic Design was found. Every DLD question below is style-derived: written to match the pattern of the other SAHE papers (10 × 2 marks, then 5 either/or pairs of 8 marks). Treat them as practice, not as recalled paper questions.

Q1Expected2MCO1 K1

Convert \((156)_{10}\) to binary.

Answer

Divide by 2 repeatedly: 156→78 r0, 78→39 r0, 39→19 r1, 19→9 r1, 9→4 r1, 4→2 r0, 2→1 r0, 1→0 r1. Read remainders upward: \((156)_{10}=(10011100)_2\).

Q2Expected2MCO1 K1

What is the 2's complement of \((1011)_2\)?

Answer

1's complement \(=0100\); add 1 \(\Rightarrow 0101\). So the 2's complement is \((0101)_2\). (Check: \(1011+0101=10000\).)

Q3Expected2MCO1 K1

State De Morgan's laws.

Answer

\((A+B)'=A'\cdot B'\) and \((A\cdot B)'=A'+B'\) (the complement of a sum is the product of complements and the other way round).

Q4Expected2MCO1 K1

Why are NAND and NOR called universal gates?

Answer

Any Boolean function can be built using only NAND gates (or only NOR gates), because NOT, AND and OR can all be made from them: NOT \(=\) NAND with both inputs tied, AND \(=\) NAND followed by NOT, OR \(=\) NANDs on inverted inputs.

Q5Expected2MCO1 K1

What is the difference between a minterm and a maxterm?

Answer

A minterm is an AND (product) term containing every variable once, true or complemented, that equals 1 for exactly one input row (\(m_i\)). A maxterm is an OR (sum) term containing every variable once, equal to 0 for exactly one row (\(M_i\)). \(M_i=m_i'\).

Q6Expected2MCO1 K2

What is the Gray code? Write the Gray code for 0 to 7.

Answer

A code in which successive numbers differ in one bit only. 3-bit: 000, 001, 011, 010, 110, 111, 101, 100. Conversion: \(G_n=B_n\), \(G_i=B_{i+1}\oplus B_i\).

Q7Expected2MCO1 K2

Write the IEEE 754 single-precision format.

Answer

32 bits: 1 sign bit, 8 exponent bits (bias 127), 23 mantissa bits. Value \(=(-1)^s\times1.m\times2^{e-127}\).

Q8Expected2MCO2 K1

What is a don't-care condition?

Answer

An input combination that never occurs or whose output is not important. It is marked X in the K-map and can be taken as 0 or 1, whichever helps to form larger groups and a simpler expression.

Q9Expected2MCO2 K1

Write the Boolean expressions of a half adder.

Answer

Sum \(S=A\oplus B\), Carry \(C=A\cdot B\).

Q10Expected2MCO2 K1

Write the Boolean expressions of a full adder.

Answer

\(S=A\oplus B\oplus C_{in}\), \(\;C_{out}=AB+C_{in}(A\oplus B)\).

Q11Expected2MCO2 K1

How many cells has a 4-variable K-map? What is a prime implicant?

Answer

\(2^4=16\) cells. A prime implicant is a product term (a group of 1s) that cannot be combined into a larger group. An essential prime implicant covers a minterm that no other prime implicant covers.

Q12Expected2MCO2 K2

What is a parity bit? Give the even parity bit for 1011.

Answer

An extra bit added to a data word to detect single-bit errors. For even parity the total number of 1s (including the parity bit) is even. 1011 has three 1s, so the even-parity bit is 1 (word 11011).

Q13Expected2MCO3 K1

What is a multiplexer?

Answer

A combinational circuit that selects one of \(2^n\) data inputs and sends it to a single output, using \(n\) select lines. Example: 4:1 MUX, \(Y=S_1'S_0'I_0+S_1'S_0I_1+S_1S_0'I_2+S_1S_0I_3\).

Q14Expected2MCO3 K1

What is a decoder? How many outputs has a 3-to-8 decoder?

Answer

A combinational circuit that converts an \(n\)-bit binary code into \(2^n\) unique outputs (only one active at a time). A 3-to-8 decoder has 3 inputs and 8 outputs.

Q15Expected2MCO3 K1

Differentiate between an encoder and a decoder.

Answer

Encoder: \(2^n\) inputs (one active) → \(n\)-bit code. Decoder: \(n\)-bit code → \(2^n\) outputs.

Q16Expected2MCO3 K1

What is a priority encoder?

Answer

An encoder in which, if more than one input is high, the output code is generated for the highest-priority input only. A valid bit tells whether any input is active.

Q17Expected2MCO3 K2

Write the equations of a 1-bit magnitude comparator.

Answer

\(A>B:\;AB'\), \(A=B:\;A\odot B=AB+A'B'\), \(A<B:\;A'B\).

Q18Expected2MCO3 K1

Name the programmable logic devices.

Answer

PROM, PLA, PAL, and the complex devices (CPLD) and FPGA. (PROM: fixed AND, programmable OR; PAL: programmable AND, fixed OR; PLA: both programmable.)

Q19Expected2MCO4 K1

Differentiate between combinational and sequential circuits.

Answer

Combinational: output depends only on the present input, no memory (adders, MUX). Sequential: output depends on the present input and the previous state, has memory (flip-flops, counters).

Q20Expected2MCO4 K1

What is a latch? How does it differ from a flip-flop?

Answer

A latch is a bistable storage element that is level-sensitive (changes while the enable is active). A flip-flop is edge-triggered, changing only at a clock edge.

Q21Expected2MCO4 K1

Write the characteristic equations of the SR, D, JK and T flip-flops.

Answer

SR: \(Q^+=S+R'Q\) (with \(SR=0\)). D: \(Q^+=D\). JK: \(Q^+=JQ'+K'Q\). T: \(Q^+=T\oplus Q\).

Q22Expected2MCO4 K2

What is the race-around condition? How is it avoided?

Answer

In a level-triggered JK flip-flop with \(J=K=1\) the output toggles repeatedly during the clock pulse if the pulse is longer than the propagation delay. It is avoided by the master–slave arrangement or by using edge-triggered flip-flops.

Q23Expected2MCO4 K2

Differentiate between Mealy and Moore machines.

Answer

Moore: output depends only on the present state. Mealy: output depends on the present state and the present input (so it can react in the same clock and usually needs fewer states).

Q24Expected2MCO5 K1

What is a register? What is a shift register?

Answer

A register is a group of flip-flops storing a binary word. A shift register is a register whose stored bits can be shifted left or right on each clock pulse.

Q25Expected2MCO5 K1

Differentiate between synchronous and asynchronous counters.

Answer

Synchronous: all flip-flops receive the same clock; fast, no ripple delay. Asynchronous (ripple): the output of one flip-flop clocks the next; simpler but slower, with accumulated delay and glitches in decoding.

Q26Expected2MCO5 K2

What is the modulus of a counter? What is the number of flip-flops needed for a mod-10 counter?

Answer

The modulus is the number of distinct states in its cycle. For a mod-\(N\) counter we need \(n\) flip-flops with \(2^n\ge N\); for mod-10, \(n=4\).

Q27Expected2MCO5 K1

Write the states of a 4-bit Johnson counter.

Answer

0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → (back to 0000): 8 states (\(2n\) for \(n\) flip-flops).

Q28Expected2MCO5 K1

Differentiate between ROM and RAM.

Answer

ROM: non-volatile, read-only (or rarely written), stores permanent programs. RAM: volatile read/write memory used for working data.

Q29Expected2MCO5 K1

How many address lines does a \(4K\times8\) memory need? What is its capacity in bits?

Answer

\(4K=2^{12}\) words, so 12 address lines; 8 data lines; capacity \(=4096\times8=32768\) bits \(=32\) Kbit.
