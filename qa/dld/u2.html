Part B · Unit II

Boolean Function Simplification and Combinational Logic Design

Digital Logic Design · 6 questions · Notes for this unit

Q1Expected8MCO2 K3

Simplify \(F(A,B,C,D)=\sum m(0,1,2,5,8,9,10)\) using a K-map.

Answer
\(AB\backslash CD\) 00 01 11 10
00 1 1 0 1
01 0 1 0 0
11 0 0 0 0
10 1 1 0 1

Groups: four corners \(m0,m2,m8,m10\to B'D'\); the quad \(m0,m1,m8,m9\to B'C'\); the pair \(m1,m5\to A'C'D\). \[F=B'D'+B'C'+A'C'D\] All minterms are covered (\(m5\) only by \(A'C'D\), \(m2\) only by \(B'D'\), \(m9\) only by \(B'C'\), so all three groups are essential).

Q2Expected8MCO2 K3

Simplify \(F(A,B,C,D)=\sum m(1,3,7,11,15)+d(0,2,5)\) and give the product-of-sums form of \(F=\prod M(0,1,2,3,4,10,11)\).

Answer

Part 1 (with don't-cares). Group \(m3,m7,m11,m15\to CD\); group \(m0,m1,m2,m3\) (with don't-cares 0 and 2 taken as 1) \(\to A'B'\). \[F=CD+A'B'\] (\(m5\) is a don't care and need not be covered.)

Part 2 (POS). \(F'=\sum m(0,1,2,3,4,10,11)\). Groups on the K-map: \(m0,1,2,3\to A'B'\); \(m0,m4\to A'C'D'\); \(m10,m11\to AB'C\). So \(F'=A'B'+A'C'D'+AB'C\) and by De Morgan \[F=(A+B)(A+C+D)(A'+B+C')\]

Q3Expected8MCO2 K3

Simplify \(F(A,B,C,D)=\sum m(0,1,2,8,10,11,14,15)\) using the Quine–McCluskey (tabulation) method.

Answer

Step 1: group by number of 1s.

Group Minterm Binary
0 ones 0 0000
1 one 1, 2, 8 0001, 0010, 1000
2 ones 10 1010
3 ones 11, 14 1011, 1110
4 ones 15 1111

Step 2: combine terms that differ in one bit.

  • (0,1)→000-; (0,2)→00-0; (0,8)→-000; (2,10)→-010; (8,10)→10-0; (10,11)→101-; (10,14)→1-10; (11,15)→1-11; (14,15)→111-
  • Second pass: (0,2,8,10)→-0-0; (10,11,14,15)→1-1-; (0,1) stays 000-.

Prime implicants: \(000-=A'B'C'\) (0,1); \(-0-0=B'D'\) (0,2,8,10); \(1-1-=AC\) (10,11,14,15).

Step 3: prime-implicant chart. \(m1\) appears only in \(A'B'C'\); \(m2\) only in \(B'D'\); \(m11\) and \(m14\) only in \(AC\). So all three are essential and cover all 8 minterms. \[F=A'B'C'+B'D'+AC\]

Q4Expected8MCO2 K3

Design a full adder and a full subtractor. Implement the full adder using two half adders.

Answer

Full adder (inputs \(A,B,C_{in}\)):

A B Cin Sum Cout
000 0 0
001 1 0
010 1 0
011 0 1
100 1 0
101 0 1
110 0 1
111 1 1

\(S=A\oplus B\oplus C_{in}\), \(C_{out}=AB+AC_{in}+BC_{in}=AB+C_{in}(A\oplus B)\). Two half adders: HA1 gives \(S_1=A\oplus B\), \(C_1=AB\); HA2 adds \(S_1\) and \(C_{in}\) to give \(S=S_1\oplus C_{in}\), \(C_2=S_1C_{in}\); \(C_{out}=C_1+C_2\) (one OR gate).

Full subtractor (\(A-B-B_{in}\)): \(D=A\oplus B\oplus B_{in}\), \(B_{out}=A'B+A'B_{in}+BB_{in}\) \(=A'B+B_{in}(A\odot B)\). Half subtractor: \(D=A\oplus B\), \(B_{out}=A'B\).

Q5Expected8MCO2 K3

Design a BCD to Excess-3 code converter.

Answer

Excess-3 code = BCD + 3. Inputs \(A,B,C,D\) (BCD 0 to 9), outputs \(w,x,y,z\). Inputs 10 to 15 are don't cares.

BCD ABCD Excess-3 wxyz
0000 0011
0001 0100
0010 0101
0011 0110
0100 0111
0101 1000
0110 1001
0111 1010
1000 1011
1001 1100

Using K-maps with don't-cares: \[w=A+BC+BD,\quad x=B'C+B'D+BC'D',\quad y=CD+C'D',\quad z=D'\] (I checked these four equations against all ten rows of the table.)

Q6Expected8MCO2 K2

Explain parity generators and checkers with a 3-bit even parity example.

Answer

Parity is an error-detecting bit. For even parity the number of 1s in the transmitted word (data + parity) must be even.

  • Generator (3-bit data \(A,B,C\)): \(P=A\oplus B\oplus C\) (makes the total even).
A B C P
000 0
001 1
010 1
011 0
100 1
101 0
110 0
111 1
  • Checker (4 bits received \(A,B,C,P\)): \(\text{PEC}=A\oplus B\oplus C\oplus P\). PEC \(=0\) means no error (even number of 1s); PEC \(=1\) means an error. Limits: detects single (odd number of) bit errors, but cannot correct them or detect an even number of bit errors.
