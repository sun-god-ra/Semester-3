Sequential Logic and State Machine Design

Digital Logic Design · 5 questions · Notes for this unit

Q1Expected8MCO4 K2

Explain the SR latch (NOR) and the D latch/flip-flop. Give the characteristic tables.

Answer

SR latch with NOR gates: \(Q=(R+Q')'\), \(Q'=(S+Q)'\).

S R \(Q^+\) Action
0 0 \(Q\) hold (no change)
0 1 0 reset
1 0 1 set
1 1 undefined (both outputs 0) forbidden

\(Q^+=S+R'Q\), with \(SR=0\). (With NAND gates the inputs are active low.)

Gated (clocked) D latch: \(D\) is applied through an SR latch with \(S=D\), \(R=D'\) when the enable is 1: \(Q^+=D\). No forbidden state. The edge-triggered D flip-flop (master–slave) copies \(D\) to \(Q\) only at the clock edge.

D \(Q^+\)
0 0
1 1
Q2Expected8MCO4 K2

Explain the JK and T flip-flops with characteristic tables, characteristic equations and excitation tables. What is the race-around condition?

Answer
J K \(Q^+\)
0 0 \(Q\) (hold)
0 1 0 (reset)
1 0 1 (set)
1 1 \(Q'\) (toggle)

\(Q^+=JQ'+K'Q\). T flip-flop (\(J=K=T\)): \(Q^+=T\oplus Q\) (toggle when \(T=1\)).

Excitation tables (what inputs are needed for \(Q\to Q^+\)):

\(Q\to Q^+\) J K T D
0 → 0 0 X 0 0
0 → 1 1 X 1 1
1 → 0 X 1 1 0
1 → 1 X 0 0 1

Race-around: for \(J=K=1\) and a level-triggered clock longer than the propagation delay, \(Q\) toggles many times in one clock pulse. Cures: master–slave flip-flop or edge triggering (or a clock pulse shorter than the delay).

Q3Expected8MCO4 K3

Reduce the following state table and give the reduced state diagram.

Answer
Present Next (x=0) Next (x=1) Output (x=0) Output (x=1)
a a b 0 0
b c d 0 0
c a d 0 0
d e f 0 1
e a f 0 1
f g f 0 1
g a f 0 1

Method (row matching): two states are equivalent if they have the same outputs and go to the same (or equivalent) next states.

  • \(e\) and \(g\) have the same next states (\(a,f\)) and outputs → equivalent. Remove \(g\), replace \(g\) by \(e\).
  • Now \(f\) goes to \((e,f)\) with outputs \((0,1)\), the same as \(d\): \((e,f)\) and \((0,1)\) → \(d\equiv f\). Remove \(f\), replace \(f\) by \(d\). Reduced table (5 states):
Present x=0 x=1 Out x=0 Out x=1
a a b 0 0
b c d 0 0
c a d 0 0
d e d 0 1
e a d 0 1

7 states need 3 flip-flops and 5 states also need 3, but the reduced circuit has fewer gates (more don't-cares).

Q4Expected8MCO4 K3

Design a sequence detector (Mealy) that detects the overlapping sequence 101 using D flip-flops.

Answer

States: \(S_0\) (nothing yet), \(S_1\) (seen "1"), \(S_2\) (seen "10").

State assignment: \(S_0=00,S_1=01,S_2=10\) (\(Q_1Q_0\)); state 11 is unused (don't care).

\(Q_1Q_0\) x \(Q_1^+Q_0^+\) z
00 0 00 0
00 1 01 0
01 0 10 0
01 1 01 0
10 0 00 0
10 1 01 1

With D flip-flops (\(D=Q^+\)) and K-map simplification using the don't-cares (11): \[D_1=Q_0\,x',\qquad D_0=x,\qquad z=Q_1\,x\] For the input stream 1 0 1 0 1 the output is 0 0 1 0 1 (the overlap at the middle 1 is detected twice).

Q5Expected8MCO4 K3

Design a synchronous mod-6 counter (0 to 5) using T flip-flops.

Answer

Sequence \(Q_2Q_1Q_0\): 000 → 001 → 010 → 011 → 100 → 101 → 000. States 110, 111 are unused (don't care). A T flip-flop toggles when \(T=1\). Excitation from the sequence:

Present Next \(T_2T_1T_0\)
000 001 001
001 010 011
010 011 001
011 100 111
100 101 001
101 000 101

K-map simplification (with don't-cares at 110, 111): \[T_0=1,\qquad T_1=Q_0Q_2',\qquad T_2=Q_0(Q_1+Q_2)\] Lock-out check: from 110: \(T_0=1,T_1=0,T_2=0\) → 111; from 111: \(T_1=0\), \(T_2=1\), \(T_0=1\) → 010. So the unused states return to the valid sequence (self-starting).
