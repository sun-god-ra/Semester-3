Part B · Unit V

Registers, Counters, and Memory Units

Digital Logic Design · 4 questions · Notes for this unit

Q1Expected8MCO5 K2

Explain the 4-bit shift registers (SISO, SIPO, PISO, PIPO) and the universal shift register.

Answer

A shift register is a chain of D flip-flops where each output feeds the next input; all share one clock.

  • SISO: serial in, serial out; 4 clock pulses to load, 4 more to read; used as a delay line.
  • SIPO: serial in, parallel out (all \(Q\)s read at once); serial-to-parallel conversion.
  • PISO: parallel load, serial out (mode control selects load or shift); parallel-to-serial.
  • PIPO: parallel in, parallel out; a plain storage register. Example: shifting the serial stream 1, 0, 1, 1 (first bit first) into a cleared SISO register, content shown as \(Q_0Q_1Q_2Q_3\):
Pulse Serial in \(Q_0Q_1Q_2Q_3\)
start – 0000
1 1 1000
2 0 0100
3 1 1010
4 1 1101

Each pulse moves every bit one place to the right and the new bit enters at \(Q_0\); after 4 pulses the first bit is at \(Q_3\). Universal shift register (e.g. 74194): mode inputs \(S_1S_0\) select hold (00), shift right (01), shift left (10) or parallel load (11); it has serial inputs for both directions and four parallel inputs/outputs, so it works as any of the four types.

Q2Expected8MCO5 K3

Design a 3-bit asynchronous (ripple) up counter. How do you convert it to a mod-10 (decade) counter?

Answer

Use T flip-flops (JK with \(J=K=1\)) that toggle on the falling edge. \(Q_0\) is clocked by the external clock; the clock of each next flip-flop is the previous output: \(CLK_1=Q_0\), \(CLK_2=Q_1\).

Clock \(Q_2Q_1Q_0\)
0 000
1 001
2 010
3 011
4 100
5 101
6 110
7 111
8 000

The frequency is halved at each stage: \(f_{Q_0}=f/2\), \(f_{Q_1}=f/4\), \(f_{Q_2}=f/8\). A down counter takes the clock from \(Q'\) of the previous stage. Mod-10: use 4 flip-flops (0000 to 1111); when the count reaches 1010 (10) a NAND gate of \(Q_3\) and \(Q_1\) clears all flip-flops asynchronously, so the sequence is 0000 to 1001 and back to 0000. The state 1010 lasts only a few nanoseconds (a glitch). Drawbacks of ripple counters: propagation delays add up (limits speed), decoding glitches.

Q3Expected8MCO5 K2

Explain the ring counter and the Johnson counter with their state tables. Compare them.

Answer

Ring counter (4 FFs): \(Q_3\) feeds back to \(D_0\); one flip-flop is preset to 1, the others cleared. The single 1 circulates: 1000 → 0100 → 0010 → 0001 → 1000. Mod-4 with 4 FFs (\(N\) states with \(N\) FFs). No decoding gates are needed (each output is a timing pulse).

Johnson (twisted-ring) counter (4 FFs): \(\overline{Q_3}\) feeds back to \(D_0\). Starting from 0000: 0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000. Mod-8 with 4 FFs (\(2N\) states).

Ring Johnson
Feedback \(Q_N\to D_0\) \(Q_N'\to D_0\)
States for \(N\) FFs \(N\) \(2N\)
Decoding none 2-input gate per state
Self-starting needs initial preset not self-starting without correction

Both are used for timing/sequence generation.

Q4Expected8MCO5 K2

Explain the memory unit: block diagram, memory read/write, and the classification of ROM and RAM.

Answer

A memory stores binary words in locations identified by addresses. A memory of \(2^k\) words of \(n\) bits has \(k\) address lines and \(n\) data lines, plus control lines Read/Write (R/W) and Memory enable (chip select).

Write: apply address, data, set R/W = write. Read: apply address, set R/W = read; data appears on the output.

  • Example: \(2K\times8\): \(k=11\), \(n=8\), capacity 16 Kbit. Expansion: four \(1K\times8\) chips with a 2:4 decoder on the two high address lines make a \(4K\times8\) memory.

ROM: non-volatile, internal AND-OR decoder structure; Mask ROM (programmed at the factory), PROM (one-time programmable by fusing), EPROM (erased by UV light), EEPROM (electrically erasable), Flash (block erasable). Used for the boot program and fixed look-up tables. A ROM can implement any combinational function: 3-bit binary to Gray code needs an \(8\times3\) ROM storing the code at each address.

RAM: volatile read/write memory. SRAM (flip-flop cell; fast, costly, used for cache) and DRAM (capacitor cell, refreshed periodically; dense, cheap, used for main memory).

SRAM DRAM
Cell flip-flop (6 transistors) 1 transistor + capacitor
Refresh not needed needed
Speed / cost fast, costly slower, cheap
Use cache main memory
