Q1Nov 20258MCO5 K2

Differentiate between ArrayList and LinkedList with suitable examples.

Answer

Both implement the List interface (ordered, allow duplicates, allow null).

Point ArrayList LinkedList
Internal structure Resizable (dynamic) array Doubly linked list of nodes
Access by index get(i) O(1) fast O(n) must walk the list
Insert/delete in the middle O(n) (shifting elements) O(1) once the node is reached (only pointers change)
Add at end O(1) amortised O(1)
Memory less (only elements) more (two links per node)
Implements List, RandomAccess List, Deque, Queue
Best use many reads, few changes many insertions/deletions, queue/stack use
java
import java.util.*;
public class ListDemo {
    public static void main(String[] args) {
        List<String> al = new ArrayList<>();
        al.add("A"); al.add("B"); al.add(1, "X");
        System.out.println(al + " get(1)=" + al.get(1));   // [A, X, B] get(1)=X

        LinkedList<String> ll = new LinkedList<>();
        ll.add("A"); ll.addFirst("Z"); ll.addLast("B");
        System.out.println(ll + " first=" + ll.getFirst()); // [Z, A, B] first=Z
        ll.removeFirst();
        System.out.println(ll);                              // [A, B]
    }
}
Q2Nov 20258MCO5 K3

Explain the features of the HashSet class. Write a Java program to demonstrate insertion and iteration of elements in a HashSet.

Answer

Features of HashSet

  1. Implements the Set interface; no duplicate elements (a duplicate add returns false).
  2. Backed by a hash table (a HashMap inside); elements are placed by their hash code.
  3. No guaranteed order: iteration order can differ from insertion order and may change.
  4. Allows one null element.
  5. Constant time O(1) average for add, remove, contains.
  6. Not synchronized (not thread-safe). Use Collections.synchronizedSet() if needed.
  7. Duplicates are detected using hashCode() and equals(), so custom classes must override both.
  8. Initial capacity 16, load factor 0.75. (LinkedHashSet keeps insertion order; TreeSet keeps sorted order.)
java
import java.util.*;
public class HashSetDemo {
    public static void main(String[] args) {
        HashSet<String> set = new HashSet<>();
        set.add("Java");
        set.add("Python");
        set.add("C");
        boolean added = set.add("Java");            // duplicate -> false
        System.out.println("Duplicate added? " + added);
        System.out.println("Size: " + set.size());  // 3
        System.out.println("Contains C? " + set.contains("C"));

        System.out.println("Using for-each:");
        for (String s : set) System.out.println(s);

        System.out.println("Using Iterator:");
        Iterator<String> it = set.iterator();
        while (it.hasNext()) System.out.println(it.next());
    }
}

The element order printed may differ from the insertion order, because the order depends on the hash codes.

Q3Nov 20258MCO5 K3

Explain how a TreeMap maintains elements in sorted order with an example program.

Answer

TreeMap<K,V> implements NavigableMap (and SortedMap). It stores the entries in a Red-Black tree, a self-balancing binary search tree. Every insertion places the key at its correct position by comparison, so the keys are always in ascending order. The ordering comes from

  • the keys' natural ordering (Comparable.compareTo) — e.g. String, Integer, or
  • a Comparator passed to the constructor.

Properties: sorted by key, O(log n) for put, get, remove, no null keys, not synchronized, keys must be mutually comparable (else ClassCastException).

java
import java.util.*;
public class TreeMapDemo {
    public static void main(String[] args) {
        TreeMap<Integer, String> tm = new TreeMap<>();
        tm.put(30, "Thirty");
        tm.put(10, "Ten");
        tm.put(20, "Twenty");
        tm.put(40, "Forty");
        System.out.println(tm);                       // {10=Ten, 20=Twenty, 30=Thirty, 40=Forty}
        System.out.println(tm.firstKey() + " " + tm.lastKey());   // 10 40
        System.out.println(tm.headMap(30));           // keys < 30   {10=Ten, 20=Twenty}
        System.out.println(tm.tailMap(30));           // keys >= 30  {30=Thirty, 40=Forty}
        System.out.println(tm.floorKey(25) + " " + tm.ceilingKey(25));  // 20 30

        TreeMap<String, Integer> rev = new TreeMap<>(Comparator.reverseOrder());
        rev.put("b", 2); rev.put("a", 1); rev.put("c", 3);
        System.out.println(rev);                      // {c=3, b=2, a=1}
    }
}

Even though keys were inserted as 30, 10, 20, 40, the map prints them as 10, 20, 30, 40.

Q4Nov 20258MCO5 K3

Write a program to demonstrate mapping and collecting operations using streams.

Answer
  • map() is an intermediate operation that transforms every element (one-to-one).
  • collect() is a terminal operation that gathers the elements into a collection or result using a Collector (Collectors.toList(), toSet(), joining(), groupingBy(), toMap()).
java
import java.util.*;
import java.util.stream.*;

public class StreamDemo {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("ravi", "asha", "kiran", "sita");
        List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5, 6);

        // mapping: transform each name to upper case, then collect to a list
        List<String> upper = names.stream()
                                  .map(String::toUpperCase)
                                  .collect(Collectors.toList());
        System.out.println(upper);                     // [RAVI, ASHA, KIRAN, SITA]

        // mapping + filter + collect: squares of even numbers
        List<Integer> sq = nums.stream()
                               .filter(n -> n % 2 == 0)
                               .map(n -> n * n)
                               .collect(Collectors.toList());
        System.out.println(sq);                        // [4, 16, 36]

        // collect to a single String
        String joined = names.stream().collect(Collectors.joining(", ", "[", "]"));
        System.out.println(joined);                    // [ravi, asha, kiran, sita]

        // collect to a Map: name -> length
        Map<String, Integer> lenMap = names.stream()
                .collect(Collectors.toMap(s -> s, String::length));
        System.out.println(lenMap.get("kiran"));       // 5

        // grouping by length
        Map<Integer, List<String>> byLen = names.stream()
                .collect(Collectors.groupingBy(String::length));
        System.out.println(byLen);                     // {4=[ravi, asha, sita], 5=[kiran]}
    }
}

Streams are lazy: nothing runs until the terminal operation collect(). The original list is not changed.

Q5Apr 20268MCO5 K2

Explain the Collections Framework in Java. Discuss the roles of the List, Set and Map interfaces.

Answer

The Java Collections Framework (JCF) (java.util) is a unified architecture of interfaces, implementation classes and algorithms for storing and processing groups of objects. It reduces effort (ready-made data structures), gives performance and is reusable. Generics make collections type safe.

(Map is not a child of Collection.)

Interface Role Main implementations
List ordered collection, indexed access, duplicates allowed ArrayList, LinkedList, Vector
Set collection with no duplicates HashSet (unordered), LinkedHashSet (insertion order), TreeSet (sorted)
Map stores key → value pairs; keys unique, values may repeat HashMap, LinkedHashMap, TreeMap, Hashtable

Common operations: add, remove, contains, size, isEmpty, iterator. Utility class Collections offers sort, reverse, shuffle, max, min.

Q6Apr 20268MCO5 K3

Write a Java program to demonstrate basic operations on an ArrayList (adding, removing, and retrieving elements).

Answer
java
import java.util.*;

public class ArrayListOps {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        // adding
        list.add("Apple");
        list.add("Banana");
        list.add("Cherry");
        list.add(1, "Mango");                    // insert at index 1
        System.out.println("After adding : " + list);   // [Apple, Mango, Banana, Cherry]

        // retrieving
        System.out.println("get(2)       : " + list.get(2));        // Banana
        System.out.println("indexOf      : " + list.indexOf("Cherry")); // 3
        System.out.println("contains     : " + list.contains("Mango")); // true
        System.out.println("size         : " + list.size());       // 4

        // updating
        list.set(0, "Orange");

        // removing
        list.remove("Banana");                   // by object
        list.remove(0);                          // by index
        System.out.println("After removing: " + list);   // [Mango, Cherry]

        // traversing
        for (String s : list) System.out.println(s);
        list.clear();
        System.out.println("isEmpty      : " + list.isEmpty());   // true
    }
}

remove(int) removes by index; remove(Object) removes the first matching element. For an ArrayList<Integer>, use list.remove(Integer.valueOf(5)) to remove the value 5.

Q7Apr 20268MCO5 K2

Explain reduction operations in Java streams with examples.

Answer

A reduction (terminal) operation combines all stream elements into a single result (a value, an Optional, or a collection).

Operation Returns Example
count() long number of elements
sum(), average(), max(), min() on IntStream etc. IntStream.of(..).sum()
reduce(identity, op) T reduce(0, Integer::sum)
reduce(op) Optional<T> reduce(Integer::max)
max(comparator), min(comparator) Optional<T>
collect(...) mutable reduction Collectors.toList()
anyMatch, allMatch, noneMatch boolean short-circuit
java
import java.util.*;
import java.util.stream.*;

public class ReduceDemo {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(4, 8, 15, 16, 23, 42);

        int sum = nums.stream().reduce(0, (a, b) -> a + b);            // identity + accumulator
        Optional<Integer> product = nums.stream().reduce((a, b) -> a * b);
        Optional<Integer> max = nums.stream().reduce(Integer::max);
        long cnt = nums.stream().filter(n -> n % 2 == 0).count();
        double avg = nums.stream().mapToInt(Integer::intValue).average().orElse(0);

        System.out.println(sum);                 // 108
        System.out.println(product.get());       // 4*8*15*16*23*42 = 7418880
        System.out.println(max.get());           // 42
        System.out.println(cnt);                 // 4  (4, 8, 16, 42)
        System.out.println(avg);                 // 18.0
        System.out.println(nums.stream().anyMatch(n -> n > 40));  // true
    }
}

How reduce works: (a, b) -> a + b starts with the identity 0: 0+4, +8, +15, … The accumulator must be associative so parallel streams can combine partial results.

Q8Apr 20268MCO5 K2

Explain the use of iterators and streams in Java.

Answer

Iterator. An Iterator<E> visits the elements of a collection one by one. Methods: hasNext(), next(), remove(). It is external iteration: we write the loop. ListIterator adds backward traversal and add()/set() for lists.

java
List<Integer> list = new ArrayList<>(Arrays.asList(1, 2, 3, 4, 5));
Iterator<Integer> it = list.iterator();
while (it.hasNext()) {
    int n = it.next();
    if (n % 2 == 0) it.remove();      // safe removal during iteration
}
System.out.println(list);             // [1, 3, 5]

(Removing with list.remove() inside a for-each loop throws ConcurrentModificationException.)

Stream. A Stream<T> is a sequence of elements supporting aggregate operations. It is internal iteration: the library does the looping and we say what to do.

java
int sumOfOddSquares = list.stream()
                          .filter(n -> n % 2 == 1)
                          .mapToInt(n -> n * n)
                          .sum();                       // 1 + 9 + 25 = 35
Iterator Stream
External iteration (explicit loop) Internal iteration (declarative)
Can remove elements Does not modify the source
Can be used many times (new iterator) Single use (consumed after terminal op)
Sequential only Can be parallel (parallelStream())
Eager Lazy (intermediate ops run at the terminal op)

A stream can also be created from an iterator-capable source: StreamSupport or iterator() can be obtained from a stream with stream.iterator().

Q9Expected8MCO5 K2

Differentiate between Comparable and Comparator with example programs.

Answer

Comparable<T> (package java.lang) puts the natural ordering inside the class by int compareTo(T o). Comparator<T> (package java.util) puts a separate ordering outside the class by int compare(T a, T b).

Comparable Comparator
One natural order, class must be modified Many orders, class unchanged
compareTo(o) compare(a, b)
Collections.sort(list) Collections.sort(list, cmp)
java
import java.util.*;
class Student implements Comparable<Student> {
    int roll; String name;
    Student(int r, String n) { roll = r; name = n; }
    public int compareTo(Student o) { return this.roll - o.roll; }   // natural: by roll
    public String toString() { return roll + ":" + name; }
}
public class SortDemo {
    public static void main(String[] args) {
        List<Student> l = new ArrayList<>();
        l.add(new Student(3, "Ravi")); l.add(new Student(1, "Sita")); l.add(new Student(2, "Asha"));
        Collections.sort(l);                                    // Comparable
        System.out.println(l);                                  // [1:Sita, 2:Asha, 3:Ravi]
        l.sort(Comparator.comparing(s -> s.name));              // Comparator (lambda)
        System.out.println(l);                                  // [2:Asha, 3:Ravi, 1:Sita]
    }
}
Q10Expected8MCO5 K3

Write a program to demonstrate HashMap operations. How does HashMap differ from TreeMap?

Answer

HashMap<K,V> stores key–value pairs in a hash table. Allows one null key and many null values; no order guarantee; O(1) average time.

java
import java.util.*;
public class HashMapDemo {
    public static void main(String[] args) {
        HashMap<Integer, String> map = new HashMap<>();
        map.put(101, "Ravi");
        map.put(102, "Asha");
        map.put(103, "Sita");
        map.put(102, "Kiran");                       // same key: value replaced
        System.out.println(map.get(102));            // Kiran
        System.out.println(map.containsKey(101));    // true
        System.out.println(map.getOrDefault(200, "none"));   // none
        map.remove(103);
        for (Map.Entry<Integer, String> e : map.entrySet())
            System.out.println(e.getKey() + " -> " + e.getValue());
    }
}
HashMap TreeMap
Hash table Red-black tree
Unordered Sorted by key
O(1) average O(log n)
One null key allowed No null key
Faster in general Needed for sorted/range queries
