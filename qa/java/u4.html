Multithreading and Lambda Expressions

Object Oriented Programming Through Java · 8 questions · Notes for this unit

Q1Nov 20258MCO4 K3

Write a Java program to create a new thread by extending the Thread class.

Answer

(Asked also in Apr 2026, Q8b.)

A thread can be created in two ways: (1) extend Thread and override run(); (2) implement Runnable and pass it to a Thread. The thread starts when start() is called (which makes the JVM call run() in a new call stack). Calling run() directly does not create a new thread.

java
class MyThread extends Thread {
    public void run() {                        // code of the thread
        for (int i = 1; i <= 3; i++) {
            System.out.println(getName() + " : " + i);
            try { Thread.sleep(200); } catch (InterruptedException e) { }
        }
    }
}
public class ThreadDemo {
    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.setName("Worker-1");
        t.start();                              // not t.run()
        System.out.println("main continues");
    }
}

Possible output (interleaving is decided by the scheduler)

main continues
Worker-1 : 1
Worker-1 : 2
Worker-1 : 3
Q2Nov 20258MCO4 K2

Explain the use of isAlive() and join() methods with an example.

Answer
  • final boolean isAlive() returns true if the thread has been started and has not yet terminated; otherwise false. It does not wait.
  • final void join() makes the calling thread wait until the thread on which it is called terminates. join(long ms) waits at most that long. Used so that main finishes last or results are ready before use.
java
class Task extends Thread {
    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println("Task " + i);
            try { Thread.sleep(100); } catch (InterruptedException e) { }
        }
    }
}
public class JoinDemo {
    public static void main(String[] args) throws InterruptedException {
        Task t = new Task();
        System.out.println("Before start, alive = " + t.isAlive());   // false
        t.start();
        System.out.println("After start, alive = " + t.isAlive());    // true
        t.join();                                                      // main waits
        System.out.println("After join, alive = " + t.isAlive());     // false
        System.out.println("main ends last");
    }
}

join() throws InterruptedException (checked), so it needs try/catch or throws.

Q3Apr 20268MCO4 K3

Write a Java program to create multiple threads and display their names.

Answer
java
class Worker implements Runnable {
    public void run() {
        System.out.println("Running: " + Thread.currentThread().getName());
    }
}
public class MultiThreadDemo {
    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new Thread(new Worker(), "Thread-A");
        Thread t2 = new Thread(new Worker(), "Thread-B");
        Thread t3 = new Thread(new Worker(), "Thread-C");
        t1.start(); t2.start(); t3.start();
        t1.join(); t2.join(); t3.join();       // wait for all
        System.out.println("Main thread: " + Thread.currentThread().getName());
    }
}

Output (names always appear, order may vary): Running: Thread-A, Running: Thread-B, Running: Thread-C, Main thread: main. Each Thread gets its own call stack and runs independently; the default names are Thread-0, Thread-1, …, and the main thread is named main.

Q4Nov 20258MCO4 K3

Write a program to demonstrate a simple lambda expression that computes the square of a number.

Answer

A lambda expression is an anonymous function: (parameters) -> expression or -> { statements }. It needs a functional interface (one abstract method) as its target type.

java
@FunctionalInterface
interface Square {
    int calculate(int x);
}
public class LambdaSquare {
    public static void main(String[] args) {
        Square sq = (x) -> x * x;                    // lambda
        System.out.println("Square of 5 = " + sq.calculate(5));    // 25

        // the same with a built-in functional interface
        java.util.function.Function<Integer, Integer> f = n -> n * n;
        System.out.println("Square of 9 = " + f.apply(9));          // 81
    }
}

Output: Square of 5 = 25, Square of 9 = 81. The compiler infers the types of x from the interface, so x -> x * x also works.

Q5Apr 20268MCO4 K2

Define lambda expressions. Write the syntax and explain how they simplify functional programming in Java.

Answer

A lambda expression (Java 8) is a short, anonymous function with parameters and a body but no name, access modifier or return type. It treats behaviour as data: a lambda can be stored in a variable and passed to a method.

Syntax

(parameter-list) -> expression
(parameter-list) -> { statements; return value; }

() -> 42                       // no parameter
x -> x * 2                     // one parameter, no parentheses needed
(a, b) -> a + b                // two parameters
(int a, int b) -> { return a + b; }   // block body

Parts: argument list, arrow token ->, body.

How it simplifies code.

  1. Less boilerplate: replaces anonymous inner classes.
java
// before
Runnable r = new Runnable() { public void run() { System.out.println("hi"); } };
// after
Runnable r2 = () -> System.out.println("hi");
  1. Enables functional style with streams: list.stream().filter(n -> n % 2 == 0).forEach(System.out::println);
  2. Passing behaviour to methods (Collections.sort(list, (a, b) -> b - a);).
  3. Works with functional interfaces (Runnable, Comparator, Predicate, Function, Consumer, Supplier).
  4. Can capture effectively final local variables of the enclosing method.
Q6Apr 20268MCO4 K2

Write a program to demonstrate the use of method references in Java.

Answer

A method reference (::) is a compact form of a lambda that simply calls an existing method.

Kind Syntax Equivalent lambda
Static method Class::staticMethod x -> Class.staticMethod(x)
Instance method of a particular object obj::method x -> obj.method(x)
Instance method of an arbitrary object of a type Class::instMethod x -> x.instMethod()
Constructor Class::new () -> new Class()
java
import java.util.*;
import java.util.function.*;

public class MethodRefDemo {
    static void show(String s) { System.out.println("Static: " + s); }
    void print(String s)       { System.out.println("Instance: " + s); }

    public static void main(String[] args) {
        List<String> names = Arrays.asList("Ravi", "Asha", "Kiran");

        names.forEach(MethodRefDemo::show);               // 1. static method
        MethodRefDemo obj = new MethodRefDemo();
        names.forEach(obj::print);                        // 2. object's method
        names.forEach(System.out::println);               // 2. System.out is an object

        Function<String, Integer> len = String::length;   // 3. arbitrary object
        System.out.println(len.apply("Hello"));           // 5

        Supplier<ArrayList<String>> sup = ArrayList::new; // 4. constructor
        ArrayList<String> list = sup.get();
        list.add("x");
        System.out.println(list);                         // [x]
    }
}
Q7Nov 20258MCO4 K2

Explain the concept of synchronization with a Java program to demonstrate synchronized methods.

Answer

When several threads use the same object at the same time, they can interfere with each other and leave the data in an inconsistent state (race condition). Synchronization makes sure that only one thread at a time executes a critical section. Every object has one monitor (lock); a thread must take it to enter a synchronized method or block, and the others wait.

Without synchronization two threads doing count++ 1000 times each may give less than 2000, because count++ is read–add–write, not one step.

java
class Counter {
    private int count = 0;
    synchronized void increment() { count++; }   // only one thread at a time
    int get() { return count; }
}
class Worker extends Thread {
    Counter c;
    Worker(Counter c) { this.c = c; }
    public void run() { for (int i = 0; i < 1000; i++) c.increment(); }
}
public class SyncDemo {
    public static void main(String[] args) throws InterruptedException {
        Counter c = new Counter();
        Worker t1 = new Worker(c), t2 = new Worker(c);
        t1.start(); t2.start();
        t1.join(); t2.join();
        System.out.println("Final count = " + c.get());   // always 2000
    }
}

Output: Final count = 2000.

Forms: synchronized method; synchronized (obj) { ... } block (finer, locks only the critical part); static synchronized (locks the class object). Drawbacks: slower, possible deadlock. Related: wait(), notify(), notifyAll() for inter-thread communication.

Q8Expected8MCO4 K2

Explain the life cycle of a thread and thread priorities.

Answer
  • New: object created, start() not called.
  • Runnable: ready to run, waiting for the CPU.
  • Running: executing run().
  • Blocked / Waiting / Timed waiting: not eligible for the CPU (waiting for a lock, for notify, for sleep to finish).
  • Terminated (dead): run() finished or an uncaught exception ended the thread. A dead thread cannot be restarted.

Priorities: integer 1–10 (MIN_PRIORITY=1, NORM_PRIORITY=5, MAX_PRIORITY=10). A new thread inherits the priority of its creator. t.setPriority(Thread.MAX_PRIORITY); Higher priority is only a hint: the OS scheduler decides, so a program must not depend on it for correctness.
