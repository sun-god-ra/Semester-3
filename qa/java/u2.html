Classes, Objects, Inheritance, and String Handling

Object Oriented Programming Through Java · 10 questions · Notes for this unit

Q1Nov 20258MCO2 K2

Write short notes on: i) this keyword ii) Garbage Collection.

Answer

i) this keyword. this is a reference to the current object (the object whose method or constructor is running).

java
class Student {
    int id; String name;
    Student(int id, String name) {
        this.id = id;           // field = parameter (removes shadowing)
        this.name = name;
    }
    Student() { this(0, "NA"); }        // constructor chaining
    Student self() { return this; }     // returning current object
}

Uses: (1) distinguish instance variable from local variable/parameter, (2) invoke another constructor (this(...) must be the first statement), (3) pass or return the current object, (4) call the current object's method. It cannot be used in a static context.

ii) Garbage collection. Java frees memory automatically: the garbage collector (GC) thread of the JVM finds objects that are no longer reachable (no reference points to them) and reclaims their memory. The programmer need not free memory, so memory leaks and dangling pointers are avoided.

An object becomes eligible when: its reference is set to null (s = null;), the reference is reassigned to another object, or the reference goes out of scope.

java
Student s = new Student(1, "Ravi");
s = null;               // object now eligible for GC
System.gc();            // only a *request*; JVM decides when to run

finalize() is a method that GC may call before destroying an object (deprecated since Java 9, not reliable for cleanup).

Q2Nov 20258MCO2 K2

Explain method overloading and how objects can be used as parameters and return values.

Answer

Method overloading: several methods in one class share a name but differ in the number, type or order of parameters. The compiler chooses the version at compile time (static polymorphism).

java
class Calc {
    int add(int a, int b)            { return a + b; }
    int add(int a, int b, int c)     { return a + b + c; }
    double add(double a, double b)   { return a + b; }
}

Objects as parameters. An object reference is passed by value (the reference is copied), so the method can change the fields of the caller's object.

Returning objects. A method can have a class type as return type and return a new or existing object.

java
class Box {
    int w, h;
    Box(int w, int h) { this.w = w; this.h = h; }

    boolean sameSize(Box b) {              // object as parameter
        return this.w == b.w && this.h == b.h;
    }
    Box doubled() {                        // object as return value
        return new Box(w * 2, h * 2);
    }
    public static void main(String[] args) {
        Box a = new Box(2, 3), b = new Box(2, 3);
        System.out.println(a.sameSize(b));      // true
        Box c = a.doubled();
        System.out.println(c.w + "x" + c.h);    // 4x6
    }
}

(Overloaded constructors work the same way: Box(), Box(int), Box(int,int), and a copy constructor Box(Box b) takes an object as parameter.)

Q3Nov 20258MCO2 K3

Explain the basics of inheritance in Java. Illustrate with an example.

Answer

Inheritance is the mechanism by which a class (subclass / child) acquires the fields and methods of another class (superclass / parent) using the extends keyword. It models an IS-A relationship and gives code reuse and run-time polymorphism.

java
class Animal {
    String name = "animal";
    void eat() { System.out.println("eating..."); }
}
class Dog extends Animal {                 // Dog IS-A Animal
    void bark() { System.out.println("barking..."); }
}
public class Test {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();      // inherited
        d.bark();     // own
    }
}

Rules / points.

  • Java supports single, multilevel and hierarchical inheritance for classes. Multiple inheritance of classes is not allowed (diamond problem), but a class can implement many interfaces.
  • private members are not inherited (not accessible); constructors are not inherited.
  • Object is the root of all classes.
  • A superclass reference can refer to a subclass object (Animal a = new Dog();).
Q4Nov 20258MCO2 K2

Discuss the use of the super keyword and the concept of multilevel inheritance with examples.

Answer

super keyword refers to the immediate superclass. Three uses:

  1. Call superclass constructor: super(args); must be the first statement of the subclass constructor.
  2. Access a hidden superclass variable: super.x.
  3. Call an overridden superclass method: super.display().

Multilevel inheritance: a chain of inheritance: Grandparent → Parent → Child.

java
class Person {
    String name;
    Person(String name) { this.name = name; System.out.println("Person()"); }
    void show() { System.out.println("Name: " + name); }
}
class Employee extends Person {
    int id;
    Employee(String name, int id) {
        super(name);                       // use 1: parent constructor
        this.id = id; System.out.println("Employee()");
    }
    void show() { super.show();            // use 3: parent method
                  System.out.println("Id: " + id); }
}
class Manager extends Employee {
    String dept;
    Manager(String n, int i, String d) {
        super(n, i); dept = d; System.out.println("Manager()");
    }
    void show() { super.show(); System.out.println("Dept: " + dept); }
    public static void main(String[] a) {
        new Manager("Asha", 101, "IT").show();
    }
}

Output: Person(), Employee(), Manager(), then Name: Asha, Id: 101, Dept: IT. Constructors run from the top of the hierarchy downward.

Q5Apr 20268MCO2 K3

Explain the fundamentals of classes and objects in Java with suitable examples.

Answer

Class = a user-defined type (blueprint) that groups data members (fields) and member functions (methods). Object = a runtime instance of a class with its own copy of instance variables.

java
class Student {                         // class
    int roll;                           // instance variables
    String name;
    void set(int r, String n) { roll = r; name = n; }   // method
    void show() { System.out.println(roll + " " + name); }
}
public class Demo {
    public static void main(String[] args) {
        Student s1 = new Student();     // object creation
        s1.set(1, "Ravi");
        s1.show();                      // 1 Ravi
        Student s2 = s1;                // second reference, same object
        s2.name = "Sita";
        s1.show();                      // 1 Sita
    }
}
  • Student s1; declares a reference (no object yet); new Student() allocates the object on the heap and runs the constructor.
  • Members are reached with the dot operator.
  • Assigning one reference to another copies the reference, not the object.
  • Access modifiers (private, default, protected, public) control visibility.
Q6Apr 20268MCO2 K2

What are constructors? Explain types of constructors with examples.

Answer

A constructor is a special method used to initialise a new object. Its name is the class name, it has no return type, and it runs automatically on new. If none is written, the compiler adds a default constructor.

Types

  1. Default (no-arg) constructor: takes no parameters.
  2. Parameterised constructor: takes arguments to set initial values.
  3. Copy constructor: builds an object from another object of the same class (Java does not provide it automatically; we write it).
java
class Point {
    int x, y;
    Point() { x = 0; y = 0; }                    // default
    Point(int x, int y) { this.x = x; this.y = y; }   // parameterised
    Point(Point p) { x = p.x; y = p.y; }         // copy
    public static void main(String[] a) {
        Point p1 = new Point();
        Point p2 = new Point(3, 4);
        Point p3 = new Point(p2);
        System.out.println(p1.x + "," + p1.y + " " + p2.x + "," + p2.y + " " + p3.x + "," + p3.y);
    }
}

Constructors can be overloaded. They cannot be static, final or abstract, and are not inherited.

Q7Apr 20268MCO2 K4

Write a Java program to demonstrate method overriding and dynamic method dispatch.

Answer

Method overriding: a subclass gives its own implementation of a method already defined in the superclass with the same signature. Dynamic method dispatch: the overridden method that runs is chosen at run time from the actual object type held by a superclass reference.

java
class Shape {
    void draw() { System.out.println("Drawing a shape"); }
}
class Circle extends Shape {
    @Override void draw() { System.out.println("Drawing a circle"); }
}
class Square extends Shape {
    @Override void draw() { System.out.println("Drawing a square"); }
}
public class DispatchDemo {
    public static void main(String[] args) {
        Shape ref;                 // superclass reference
        ref = new Shape();  ref.draw();   // Shape's draw
        ref = new Circle(); ref.draw();   // Circle's draw
        ref = new Square(); ref.draw();   // Square's draw
    }
}

Output

Drawing a shape
Drawing a circle
Drawing a square

The same call ref.draw() gives three different behaviours: run-time polymorphism. Rules: same name, parameters and compatible return type; the overriding method cannot be less accessible, and static, final and private methods cannot be overridden.

Q8Apr 20268MCO2 K2

Discuss the role of abstract classes and the final keyword in inheritance with examples.

Answer

Abstract class — declared abstract, cannot be instantiated. It may have abstract methods (no body) which every concrete subclass must implement, and normal methods, fields and constructors. It is used to give a common template.

java
abstract class Bank {
    abstract double rate();                     // must be implemented
    void info() { System.out.println("Rate = " + rate()); }   // concrete
}
class SBI extends Bank { double rate() { return 6.5; } }
class HDFC extends Bank { double rate() { return 7.0; } }

final with inheritance

Use Effect
final class A cannot be extended (e.g. String, Integer)
final void f() cannot be overridden in a subclass
final int x = 5; constant, cannot be reassigned
java
final class Secure { }                // class Hack extends Secure {}  -> error
class P { final void lock() { } }
class C extends P { /* void lock() {}  -> error */ }

abstract and final are opposites for a class: an abstract class must be extended; a final class cannot be. So abstract final class is illegal.

Q9Expected8MCO2 K2

Explain the static keyword and the different forms of inner (nested) classes.

Answer

static members belong to the class and are shared by all objects.

java
class Counter {
    static int count = 0;                 // one copy
    Counter() { count++; }
    static int total() { return count; }  // call as Counter.total()
    static { System.out.println("class loaded"); }   // static block, runs once
}

A static method cannot use this, super or non-static members directly.

Nested classes

Kind Declaration Notes
Static nested static class N inside outer Does not need an outer object
Inner (non-static) class I inside outer Has an outer object; can use outer's members
Local class inside a method visible only inside that method
Anonymous new Interface() { ... } unnamed, one-time implementation
java
class Outer {
    int x = 10;
    class Inner { void show() { System.out.println(x); } }
    static class SNested { void hi() { System.out.println("hi"); } }
    public static void main(String[] a) {
        Outer o = new Outer();
        Outer.Inner i = o.new Inner();
        i.show();                       // 10
        new Outer.SNested().hi();
    }
}
Q10Expected8MCO2 K2

Explain string handling in Java: String, StringBuffer and StringBuilder.

Answer
  • String is immutable (cannot be changed after creation). Any change makes a new object. Literals are kept in the string pool.
  • StringBuffer is mutable and thread-safe (synchronized methods).
  • StringBuilder is mutable, not synchronized, faster. Use it in a single thread.
String StringBuffer StringBuilder
Mutable No Yes Yes
Thread-safe Yes (immutable) Yes No
Speed slowest for repeated changes slower fastest
java
String s = "Hello";
System.out.println(s.length());            // 5
System.out.println(s.charAt(1));           // e
System.out.println(s.substring(1, 3));     // el
System.out.println(s.toUpperCase());       // HELLO
System.out.println(s.indexOf('l'));        // 2
System.out.println(s.concat(" World"));    // Hello World
System.out.println("a".equals("A"));       // false
System.out.println("a".equalsIgnoreCase("A")); // true

StringBuffer sb = new StringBuffer("Hello");
sb.append(" Java").insert(0, ">> ").reverse();
System.out.println(sb);                    // avaJ olleH >>

Key StringBuffer methods: append, insert, delete, deleteCharAt, replace, reverse, capacity, setLength.
