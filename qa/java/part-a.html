Part A

Object Oriented Programming Through Java: short answer questions

2 marks each · 39 questions

Q1Nov 20252MCO1 K1

Write any two important features of Java.

Answer
  1. Platform independent: source code is compiled to bytecode, and any machine with a JVM runs it ("write once, run anywhere").
  2. Object oriented: everything except primitives is an object; supports encapsulation, inheritance, polymorphism and abstraction. - (Other features: simple, secure, robust, multithreaded, portable, high performance with JIT.)
Q2Nov 20252MCO1 K1

What is Byte Code in Java?

Answer

Byte code is the intermediate, machine-independent code (.class file) produced by the Java compiler (javac) from the .java source. The JVM interprets it or the JIT compiler converts it to native code. Because bytecode is the same on every platform, Java programs are portable.

Q3Nov 20252MCO2 K1

Write any two uses of the final keyword in Java.

Answer
  1. final variable: its value cannot be changed after assignment (a constant), e.g. final double PI = 3.14;
  2. final method: cannot be overridden in a subclass.
  3. final class: cannot be inherited, e.g. String.
Q4Nov 20252MCO2 K1

Define dynamic method dispatch.

Answer

Dynamic method dispatch is the run-time process in which a call to an overridden method is resolved by the actual object type held by a superclass reference, not by the reference type. It is how Java achieves run-time polymorphism. Example: Animal a = new Dog(); a.sound(); calls Dog's sound().

Q6Nov 20252MCO3 K2

Write the purpose of the FileReader and FileWriter classes.

Answer

FileReader reads characters from a text file; FileWriter writes characters to a text file. They are character-stream classes (they handle Unicode text and do the byte-to-char conversion), unlike FileInputStream/FileOutputStream which work on raw bytes.

Q7Nov 20252MCO4 K2

What is a block lambda expression?

Answer

A lambda whose body is a block enclosed in { } and can contain several statements, local variables and an explicit return. Syntax: (a, b) -> { int s = a + b; return s; }. (An expression lambda has only a single expression and no braces.)

Q8Nov 20252MCO4 K2

Write the purpose of method references in Java.

Answer

A method reference is a short form of a lambda that just calls an existing method. It makes code compact and readable. Syntax: ClassName::method, object::method, ClassName::new. Example: list.forEach(System.out::println);

Q10Nov 20252MCO5 K1

Define a reduction operation in streams with one example.

Answer

A reduction is a terminal operation that combines all elements of a stream into one result. Examples: sum(), count(), reduce(), max(). int total = Stream.of(1,2,3,4).reduce(0, (a,b) -> a + b); gives 10.

Q11Apr 20262MCO1 K1

List any two differences between Java and C++.

Answer
  1. Java has no pointers (it uses references) and no explicit memory deallocation (garbage collector); C++ has pointers and delete.
  2. Java does not support multiple inheritance of classes (uses interfaces); C++ does. (Also: Java is platform independent through bytecode, C++ compiles to machine code; Java has no operator overloading or header files.)
Q12Apr 20262MCO1 K1

What is automatic type promotion in Java?

Answer

In an expression, Java automatically promotes byte, short and char operands to int, and promotes the whole expression to the type of the largest operand (long, float or double). Example: byte a = 40, b = 50; int c = a * b; the product is evaluated as int.

Q13Apr 20262MCO2 K2

What is the purpose of the this keyword?

Answer

this refers to the current object. Uses: (1) separate a field from a parameter of the same name (this.x = x;), (2) call another constructor of the same class (this(...)), (3) pass the current object as an argument or return it.

Q14Apr 20262MCO2 K2

Write the significance of the super keyword in inheritance.

Answer

super refers to the immediate superclass. It is used (1) to call the superclass constructor (super(args); must be the first statement), (2) to access a superclass member hidden by the subclass (super.name), and (3) to call an overridden superclass method (super.show()).

Q15Apr 20262MCO3 K2

Differentiate between Byte streams and Character streams.

Answer

Byte streams (InputStream/OutputStream) read and write raw 8-bit bytes, suited to binary data such as images. Character streams (Reader/Writer) read and write 16-bit Unicode characters, suited to text, and handle character encoding automatically.

Q16Apr 20262MCO3 K1

What is the use of the CLASSPATH in Java?

Answer

CLASSPATH is the environment variable (or -cp option) that tells the JVM and javac where to search for user-defined classes and packages (directories and JAR files). Example: javac -cp .;mylib.jar Main.java.

Q17Apr 20262MCO4 K2

Differentiate between isAlive() and join() methods in multithreading.

Answer

isAlive() is a non-blocking test: returns true if the thread has started and not yet died. join() is a blocking call: the calling thread waits until the thread on which join() was called finishes.

Q18Apr 20262MCO4 K2

What is the significance of thread priorities in Java?

Answer

A priority (1 to 10; MIN_PRIORITY=1, NORM_PRIORITY=5, MAX_PRIORITY=10) is a hint to the scheduler about which runnable thread should get the CPU first. Higher priority threads are more likely, not guaranteed, to run first. Set with setPriority(int), read with getPriority().

Q19Apr 20262MCO5 K1

What is the difference between HashMap and TreeMap?

Answer

HashMap stores key–value pairs in a hash table: no ordering, O(1) average operations, allows one null key. TreeMap stores keys in a red-black tree: keys are sorted (natural order or a Comparator), O(log n) operations, no null key.

Q20Apr 20262MCO5 K1

What is the purpose of the Stream API?

Answer

The Stream API (Java 8, java.util.stream) lets us process a collection of data in a declarative, functional style: filter, map, sort, reduce and collect without explicit loops. A stream does not store data and does not change the source.

Q21Expected2MCO1 K1

What is the role of the JVM, JRE and JDK?

Answer

JVM executes bytecode (the virtual machine). JRE = JVM + class libraries needed to run programs. JDK = JRE + development tools (javac, jar, javadoc, debugger) needed to develop programs.

Q22Expected2MCO1 K1

What is the difference between == and .equals()?

Answer

== compares references (are both variables pointing to the same object?) for objects, and values for primitives. equals() compares the contents when it is overridden (as in String). new String("a") == new String("a") is false but .equals gives true.

Q23Expected2MCO1 K1

List the eight primitive data types of Java.

Answer

byte (8 bits), short (16), int (32), long (64), float (32), double (64), char (16, Unicode), boolean (true/false).

Q24Expected2MCO2 K1

What is a constructor? How is it different from a method?

Answer

A constructor is a special member with the same name as the class and no return type, called automatically by new to initialise an object. A method has its own name and a return type and is called explicitly. The compiler supplies a default constructor if none is written.

Q25Expected2MCO2 K1

What is method overloading?

Answer

Defining two or more methods with the same name but different parameter lists (number, type or order) in the same class. It is compile-time polymorphism. Return type alone cannot distinguish overloaded methods.

Q26Expected2MCO2 K2

Answer

Q27Expected2MCO2 K2

What is an abstract class?

Answer

A class declared with abstract that cannot be instantiated and may contain abstract methods (no body) as well as concrete methods and fields. A subclass must implement all abstract methods or itself be abstract.

Q28Expected2MCO2 K1

What is the static keyword used for?

Answer

static makes a member belong to the class, not to an object: a static variable has one shared copy, a static method can be called without an object (Math.sqrt(4)), and a static block runs once when the class loads. A static method can use only static members directly.

Q29Expected2MCO3 K1

What is a package? Give one advantage.

Answer

A package is a named group of related classes and interfaces (package mypack;). Advantages: avoids name clashes, easy organisation, and access control (protected and default access work at package level).

Q30Expected2MCO3 K2

Differentiate between checked and unchecked exceptions.

Answer

Checked exceptions (e.g. IOException, SQLException) are checked by the compiler: they must be caught or declared with throws. Unchecked exceptions are subclasses of RuntimeException or Error (e.g. ArithmeticException, NullPointerException) and need not be handled.

Q31Expected2MCO3 K1

What is the purpose of the finally block?

Answer

finally holds code that always executes after try/catch, whether or not an exception occurs (except when System.exit() is called). It is used to release resources such as files and connections.

Q32Expected2MCO3 K2

What is an interface? How is it different from an abstract class?

Answer

An interface is a reference type with abstract methods (and constants, default and static methods) that a class implements with implements. A class can implement many interfaces but extend only one class. An interface has no instance variables or constructors, an abstract class may have both.

Q33Expected2MCO4 K1

List the states in the life cycle of a thread.

Answer

New → Runnable → Running → (Blocked / Waiting / Timed waiting) → Terminated.

Q34Expected2MCO4 K2

What is synchronization? Why is it needed?

Answer

Synchronization lets only one thread at a time execute a block or method that touches shared data (by taking the object's monitor lock, synchronized keyword). It prevents race conditions and inconsistent data when several threads update the same object.

Q35Expected2MCO4 K2

What are functional interfaces? Give an example.

Answer

An interface having exactly one abstract method, so it can be the target of a lambda expression. Annotated optionally with @FunctionalInterface. Examples: Runnable, Comparator, Predicate<T>, Function<T,R>.

Q36Expected2MCO5 K1

What is the difference between Collection and Collections?

Answer

Collection is the root interface of the collection hierarchy (List, Set, Queue). Collections is a utility class with static methods such as sort(), reverse(), max(), shuffle().

Q37Expected2MCO5 K2

Differentiate between Comparable and Comparator.

Answer

Comparable (java.lang) defines the natural order inside the class itself through compareTo(T). Comparator (java.util) defines an external, custom order through compare(T,T) and allows many different orderings of the same class.

Q38Expected2MCO5 K2

Differentiate between intermediate and terminal stream operations.

Answer

Intermediate operations (filter, map, sorted) return another stream and are lazy (do nothing until a terminal operation runs). Terminal operations (forEach, collect, reduce, count) produce a result or side effect and end the pipeline.

Q39Expected2MCO5 K1

What is the difference between ArrayList and Vector?

Answer

Both are index-based resizable arrays. ArrayList is not synchronized (faster, preferred in single thread use); Vector is synchronized (thread-safe but slower, legacy class). ArrayList grows by 50%, Vector doubles by default.
