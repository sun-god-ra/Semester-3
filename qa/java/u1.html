Q1Apr 20268MCO3 K2

Explain the history and evolution of Java in detail.

Answer

Origin. Java was started in 1991 at Sun Microsystems by James Gosling, Mike Sheridan and Patrick Naughton (the "Green Team"). The language was first called Oak (after an oak tree outside Gosling's office), made for set-top boxes and consumer devices. Oak was renamed Java in 1995 (a trademark clash, named after Java coffee) and released publicly as Java 1.0 in 1996. The target changed from devices to the Internet, because Java's platform independence (bytecode) was ideal for applets running in browsers.

Evolution (timeline).

Year Version Main additions
1996 JDK 1.0 first release, applets, AWT
1997 JDK 1.1 inner classes, JavaBeans, JDBC, RMI, event model
1998 J2SE 1.2 Swing, Collections framework, JIT, "Java 2"
2000 J2SE 1.3 / 2002 1.4 HotSpot JVM, assert, NIO, regex
2004 J2SE 5.0 generics, annotations, enums, autoboxing, varargs, enhanced for loop
2006 Java SE 6 performance and scripting support
2011 Java SE 7 try-with-resources, diamond <>, strings in switch
2014 Java SE 8 lambda expressions, streams, default methods, method references
2017+ Java 9 onward modules, var, records, sealed classes, text blocks, 6-monthly releases

Ownership. Oracle acquired Sun Microsystems in 2010. Java is now open source as OpenJDK.

Why Java succeeded. It was designed for the Internet (portable, secure), borrowed the familiar syntax of C/C++ but removed pointers and multiple inheritance, and had a garbage collector and a rich library.

Q2Apr 20268MCO3 K2

Discuss the important features of Java with examples.

Answer

Java's features are often called the "Java buzzwords".

  1. Simple: syntax similar to C/C++; no pointers, no operator overloading, no header files, automatic memory management.
  2. Object oriented: every program lives in a class; supports encapsulation, inheritance, polymorphism, abstraction.
  3. Platform independent / portable: javac produces bytecode, which any JVM runs. "Write once, run anywhere (WORA)".
  4. Secure: no pointers, bytecode verifier, class loader, and security manager prevent illegal memory access and untrusted code from harming the system.
  5. Robust: strong type checking, exception handling, garbage collection; compile time and run time checks.
  6. Multithreaded: built-in thread support (Thread, Runnable) for concurrent work, e.g. a game that animates and plays sound together.
  7. Architecture neutral: data sizes are fixed (int is always 32 bits), so there are no machine-dependent behaviours.
  8. Interpreted and high performance: bytecode is interpreted, and the JIT compiler converts hot spots into native code for speed.
  9. Distributed: java.net and RMI help in building network applications.
  10. Dynamic: classes are loaded on demand at run time; reflection allows runtime inspection.
java
// Example showing OOP and multithreading in one go
class Hello extends Thread {
    public void run() { System.out.println("Hello from " + getName()); }
    public static void main(String[] a) { new Hello().start(); }
}
Q3Apr 20268MCO1 K3

Write and explain the structure of a first simple Java program.

Answer
java
import java.util.*;                    // 1. optional import
public class Hello {                   // 2. class declaration
    public static void main(String[] args) {   // 3. main method
        System.out.println("Hello, Java!");    // 4. statement
    }
}

Explanation (line by line).

  1. import java.util.*; brings other classes into scope. (java.lang is imported automatically.)
  2. public class Hello every Java code is inside a class. The file must be named Hello.java when the class is public.
  3. public static void main(String[] args) is the entry point.
    • public: so that the JVM can call it from outside the class.
    • static: so that it can run without creating an object.
    • void: it returns nothing to the JVM.
    • main: the name the JVM looks for.
    • String[] args: command-line arguments.
  4. System.out.println() prints text. System is a class, out is its static PrintStream object, println is a method.

Steps to run.

javac Hello.java      -> produces Hello.class (bytecode)
java Hello            -> JVM runs it, prints: Hello, Java!
Q4Apr 20268MCO1 K2

Explain any two control statements in Java with examples.

Answer

Control statements decide the order in which statements run. Two common ones are the if-else selection statement and the for loop.

1. if … else if … else (selection)

java
int marks = 72;
if (marks >= 90)       System.out.println("A+");
else if (marks >= 60)  System.out.println("First class");
else                   System.out.println("Fail");

The condition must be a boolean. Only the first true branch runs. Output: First class.

2. for loop (iteration)

java
int sum = 0;
for (int i = 1; i <= 5; i++) {   // init; condition; update
    sum += i;
}
System.out.println(sum);        // 15

Order: initialise once → test → body → update → test again, until the condition is false.

(Other control statements: switch, while, do-while, break, continue, return.)

Q5Nov 20258MCO1 K2

Explain the concept of Object-Oriented Programming (OOP). How is it different from procedural programming?

Answer

OOP is a programming style in which a program is built from objects. An object bundles data (fields) and the functions that work on that data (methods) together. A class is the blueprint and an object is an instance of it. Real-world things (student, bank account) are modelled directly.

Four pillars: encapsulation, inheritance, polymorphism, abstraction.

Procedural (C) Object oriented (Java)
Program = a set of functions Program = a set of objects
Top-down design Bottom-up design
Data and functions are separate Data and methods are bound together
Data is usually global and exposed Data is hidden (private) and accessed through methods
No inheritance, little reuse Inheritance gives reuse
Adding new data types is difficult Easy to extend with new classes
e.g. C, Pascal e.g. Java, C++, Python

Because data is hidden, OOP programs are more secure, modular and easier to maintain for large systems.

Q6Nov 20258MCO1 K2

Describe the principles of OOP with suitable examples.

Answer

1. Encapsulation — wrapping data and methods in a class and hiding data using private. Access only through public getters/setters.

java
class Account {
    private double balance;                       // hidden
    public void deposit(double amt) { if (amt > 0) balance += amt; }
    public double getBalance() { return balance; }
}

2. Inheritance — a subclass acquires the fields and methods of a superclass using extends. Gives code reuse.

java
class Vehicle { void start() { System.out.println("Starting"); } }
class Car extends Vehicle { void honk() { System.out.println("Beep"); } }

3. Polymorphism — "many forms". One name, many behaviours.

  • Compile-time: method overloading (add(int,int), add(double,double)).
  • Run-time: method overriding + dynamic dispatch (Shape s = new Circle(); s.draw();).

4. Abstraction — showing only the essential features and hiding the details, via abstract classes and interfaces. A driver uses drive() without knowing the engine.

java
abstract class Shape { abstract double area(); }
class Circle extends Shape { double r = 2; double area() { return Math.PI * r * r; } }
Q7Nov 20258MCO1 K2

Explain the concept of arrays in Java with examples of one-dimensional and multi-dimensional arrays.

Answer

An array is a fixed-size collection of elements of the same type, stored in contiguous memory and accessed by an index starting at 0. In Java arrays are objects, created with new, and length gives the size.

One-dimensional

java
int[] a = new int[5];             // default values 0
int[] b = {10, 20, 30, 40, 50};   // declaration + initialisation
a[0] = 7;
for (int i = 0; i < b.length; i++) System.out.print(b[i] + " ");
for (int x : b) System.out.print(x + " ");    // enhanced for

Two-dimensional (array of arrays)

java
int[][] m = { {1, 2, 3}, {4, 5, 6} };
for (int i = 0; i < m.length; i++) {
    for (int j = 0; j < m[i].length; j++) System.out.print(m[i][j] + " ");
    System.out.println();
}

Jagged array (rows of different length)

java
int[][] j = new int[3][];
j[0] = new int[1]; j[1] = new int[2]; j[2] = new int[3];

Points to remember: an invalid index throws ArrayIndexOutOfBoundsException; arrays are passed to methods by reference; arr.length is a field (not a method), str.length() is a method.

Q8Nov 20258MCO1 K3

Discuss different operators in Java with examples.

Answer

Operators perform operations on operands.

Type Operators Example
Arithmetic + - * / % ++ -- 7 % 3 → 1
Relational == != > < >= <= 5 > 3 → true
Logical && \|\| ! (a>1) && (b<5)
Bitwise & \| ^ ~ << >> >>> 5 & 3 → 1
Assignment = += -= *= /= %= x += 2
Unary + - ++ -- ! -x, i++
Ternary ? : max = (a>b) ? a : b;
instanceof type test obj instanceof String
java
int a = 10, b = 3;
System.out.println(a / b);     // 3 (integer division)
System.out.println(a % b);     // 1
System.out.println(a++ + ++a); // 10 + 12 = 22
System.out.println(a > b && b > 0);   // true
System.out.println(a >> 1);    // right shift: 12 >> 1 = 6

Precedence (high → low): () [] , unary, * / %, + -, shifts, relational, equality, &, ^, |, &&, ||, ?:, assignment. && and || are short-circuit: the right side is skipped when the result is already known.

Q9Expected8MCO1 K2

Explain Java's primitive data types and type conversion (casting).

Answer

Primitive types

Type Size Range / values Default
byte 8 bits −128 to 127 0
short 16 −32,768 to 32,767 0
int 32 about ±2.1 × 10⁹ 0
long 64 about ±9.2 × 10¹⁸ 0L
float 32 ~7 digits precision 0.0f
double 64 ~15 digits precision 0.0
char 16 Unicode 0 to 65,535 '\u0000'
boolean JVM-dependent true / false false

Widening (automatic): a smaller type goes to a bigger one with no loss: byte → short → int → long → float → double; char → int.

java
int i = 100;
double d = i;          // widening, d = 100.0

Narrowing (explicit cast): bigger to smaller, possible data loss.

java
double x = 9.78;
int n = (int) x;       // n = 9 (fraction dropped)
byte b = (byte) 300;   // b = 44 (300 mod 256)

Type promotion in expressions: byte/short/char operands become int before the operation, so byte c = a * b; needs a cast: byte c = (byte)(a * b);.
