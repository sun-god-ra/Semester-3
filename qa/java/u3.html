Q1Nov 20258MCO3 K3

What are nested interfaces? Write a program to demonstrate the use of a nested interface.

Answer

A nested interface is an interface declared inside a class or inside another interface. It is used to group an interface logically with the class that uses it.

  • Inside a class: it can be public, protected, private or default. It is implicitly static.
  • Inside an interface: it is implicitly public and static.
  • It is accessed with the outer name: Outer.Inner.
java
class Shop {
    interface Payment {                    // nested interface
        void pay(double amount);
    }
}
class UPI implements Shop.Payment {
    public void pay(double amount) { System.out.println("Paid " + amount + " by UPI"); }
}
class Card implements Shop.Payment {
    public void pay(double amount) { System.out.println("Paid " + amount + " by Card"); }
}
public class NestedInterfaceDemo {
    public static void main(String[] args) {
        Shop.Payment p = new UPI();
        p.pay(250.5);
        p = new Card();
        p.pay(999);
    }
}

Output

Paid 250.5 by UPI
Paid 999.0 by Card
Q2Nov 20258MCO3 K2

Explain the concept of packages in Java. Write the steps to create and use a user-defined package.

Answer

A package is a namespace that groups related classes, interfaces and sub-packages (like a folder). Benefits: avoids name clashes, makes code reusable and organised, and gives access protection. Built-in packages: java.lang, java.util, java.io, java.net. A user-defined package is created with the package statement.

Steps to create and use a package mypack

  1. Write the class with the package statement as the first line and make the class (and methods) public:
java
// File: mypack/Calc.java
package mypack;
public class Calc {
    public int add(int a, int b) { return a + b; }
}

  1. Compile with -d so that the class file is put in the folder mypack: javac -d . mypack/Calc.java (creates mypack/Calc.class)

  2. Use it in another program with import:

java
// File: UsePack.java
import mypack.Calc;           // or import mypack.*;
public class UsePack {
    public static void main(String[] args) {
        Calc c = new Calc();
        System.out.println(c.add(5, 7));     // 12
    }
}
  1. Compile and run from the directory that contains the mypack folder (or set CLASSPATH): javac UsePack.java then java UsePack.

Access of members across packages

Modifier same class same package subclass (other pkg) other pkg
private ✔
default ✔ ✔
protected ✔ ✔ ✔
public ✔ ✔ ✔ ✔
Q3Nov 20258MCO3 K3

Write a Java program to copy the contents of one file into another using byte streams.

Answer

(Same program is asked again in Apr 2026 as "using FileInputStream and FileOutputStream".)

java
import java.io.*;

public class FileCopy {
    public static void main(String[] args) {
        // try-with-resources closes both streams automatically
        try (FileInputStream in = new FileInputStream("source.txt");
             FileOutputStream out = new FileOutputStream("target.txt")) {

            int b;
            while ((b = in.read()) != -1) {     // read one byte; -1 means end of file
                out.write(b);                   // write the byte
            }
            System.out.println("File copied successfully");

        } catch (FileNotFoundException e) {
            System.out.println("File not found: " + e.getMessage());
        } catch (IOException e) {
            System.out.println("I/O error: " + e.getMessage());
        }
    }
}

Explanation. FileInputStream opens source.txt for reading bytes and FileOutputStream creates/overwrites target.txt. read() returns the next byte as an int (0–255) or −1 at end of file. write(int) writes the low-order byte. A faster version reads a block: byte[] buf = new byte[4096]; int n; while ((n = in.read(buf)) > 0) out.write(buf, 0, n);. If source.txt does not exist a FileNotFoundException is thrown (it is a subclass of IOException, so it must be caught first).

Q4Nov 20258MCO3 K2

Discuss the differences between byte streams and character streams in Java.

Answer
Point Byte stream Character stream
Unit of data 8-bit byte 16-bit char (Unicode)
Abstract base classes InputStream, OutputStream Reader, Writer
Typical classes FileInputStream, FileOutputStream, BufferedInputStream, DataInputStream, ObjectOutputStream FileReader, FileWriter, BufferedReader, BufferedWriter, PrintWriter
Best for images, audio, video, any binary file text files
Encoding none, raw bytes translates bytes ↔ chars using a charset
Reading call int read() gives a byte int read() gives a char
Efficient line reading no BufferedReader.readLine()
java
// byte stream: works for any file
FileInputStream fin = new FileInputStream("pic.png");
// character stream: text only
BufferedReader br = new BufferedReader(new FileReader("notes.txt"));
String line;
while ((line = br.readLine()) != null) System.out.println(line);
br.close();

Both families are tied together by bridge classes InputStreamReader (bytes → chars) and OutputStreamWriter (chars → bytes). Standard streams System.in, System.out, System.err are byte streams.

Q5Apr 20268MCO3 K2

Define an interface in Java. Explain how to implement an interface with a suitable program.

Answer

An interface is a contract: a reference type that declares abstract methods (and constants) which implementing classes must define. It provides 100% abstraction and gives Java a form of multiple inheritance (a class can implement many interfaces).

Syntax and rules

java
interface Shape {
    double PI = 3.14159;          // constants: public static final
    double area();                // methods: public abstract
    default void info() { System.out.println("I am a shape"); }   // Java 8 default method
    static void hello() { System.out.println("hello"); }          // static method
}
  • A class uses implements and must define all abstract methods as public.
  • Interfaces cannot be instantiated and have no constructors or instance variables.
  • An interface can extends one or more interfaces.
java
interface Shape { double area(); }

class Circle implements Shape {
    double r;
    Circle(double r) { this.r = r; }
    public double area() { return Math.PI * r * r; }
}
class Rectangle implements Shape {
    double l, b;
    Rectangle(double l, double b) { this.l = l; this.b = b; }
    public double area() { return l * b; }
}
public class InterfaceDemo {
    public static void main(String[] args) {
        Shape s1 = new Circle(3);
        Shape s2 = new Rectangle(4, 5);
        System.out.printf("%.2f%n", s1.area());   // 28.27
        System.out.printf("%.2f%n", s2.area());   // 20.00
    }
}

Abstract class vs interface: an abstract class can have constructors, state and concrete methods and is single-inherited; an interface is a pure contract and is multiply-implemented.

Q6Apr 20268MCO3 K2

Explain the fundamentals of exception handling in Java. Discuss the different types of exceptions with examples.

Answer

An exception is an abnormal event at run time that disturbs the normal flow of the program (divide by zero, array index out of range, file not found). Exception handling lets the program deal with it and continue, using five keywords: try, catch, finally, throw, throws.

java
try {
    int a = 10 / 0;                       // exception raised
} catch (ArithmeticException e) {         // handler
    System.out.println("Error: " + e.getMessage());   // / by zero
} finally {
    System.out.println("always runs");
}

When an exception occurs, the JVM creates an exception object, stops normal execution, and looks for a matching catch; if none is found the default handler prints a stack trace and the program ends.

Hierarchy

Types

  1. Checked exceptions: checked at compile time; must be caught or declared with throws (IOException, FileNotFoundException, SQLException, ClassNotFoundException).
  2. Unchecked exceptions: subclasses of RuntimeException; need not be handled (ArithmeticException, NullPointerException, ArrayIndexOutOfBoundsException, NumberFormatException, ClassCastException).
  3. Errors: serious JVM problems, not meant to be caught (OutOfMemoryError, StackOverflowError).
  4. User-defined (custom) exceptions: your own class extending Exception or RuntimeException.
java
int[] a = new int[3];
try { a[5] = 1; }
catch (ArrayIndexOutOfBoundsException e) { System.out.println("bad index"); }
try { Integer.parseInt("abc"); }
catch (NumberFormatException e) { System.out.println("not a number"); }
String s = null;
try { s.length(); }
catch (NullPointerException e) { System.out.println("null reference"); }

Multiple catch: put the subclass handler first, the general Exception last. Multi-catch (Java 7): catch (IOException | SQLException e).

Q7Apr 20268MCO3 K3

Write a Java program to create a user-defined exception subclass for handling invalid age during voter registration.

Answer

A custom checked exception is made by extending Exception. We then throw it when the age is below 18.

java
class InvalidAgeException extends Exception {
    InvalidAgeException(String message) {
        super(message);                         // pass message to Exception
    }
}

public class VoterRegistration {
    static void register(String name, int age) throws InvalidAgeException {
        if (age < 18)
            throw new InvalidAgeException("Invalid age " + age + ": must be 18 or above");
        System.out.println(name + " registered as a voter.");
    }

    public static void main(String[] args) {
        try {
            register("Asha", 25);
            register("Ravi", 16);               // throws exception
        } catch (InvalidAgeException e) {
            System.out.println("Registration failed: " + e.getMessage());
        } finally {
            System.out.println("Registration process finished.");
        }
    }
}

Output

Asha registered as a voter.
Registration failed: Invalid age 16: must be 18 or above
Registration process finished.

Steps: (1) create class extending Exception; (2) write a constructor that calls super(message); (3) in the method, throw new ... when the rule is violated and declare throws; (4) catch it in the caller.

Q8Expected8MCO3 K2

Explain throw, throws, and finally with examples. Explain try-with-resources.

Answer
  • throw raises an exception explicitly: throw new IllegalArgumentException("bad");
  • throws declares that a method may pass a (checked) exception to its caller: void read() throws IOException.
  • finally always executes after try/catch (cleanup).
java
class Demo {
    static void check(int n) throws Exception {
        if (n < 0) throw new Exception("negative");
        System.out.println("ok " + n);
    }
    public static void main(String[] a) {
        try { check(5); check(-1); }
        catch (Exception e) { System.out.println("caught " + e.getMessage()); }
        finally { System.out.println("done"); }
    }
}

Output: ok 5, caught negative, done.

try-with-resources (Java 7): resources declared in try( … ) that implement AutoCloseable are closed automatically, even if an exception happens, so no explicit finally { close(); } is needed:

java
try (BufferedReader br = new BufferedReader(new FileReader("a.txt"))) {
    System.out.println(br.readLine());
} catch (IOException e) { System.out.println(e); }
