Part A

Probability and Statistics: short answer questions

2 marks each · 19 questions

Numbers in the worked answers were recomputed in Python. Where the scanned paper was unclear, both readings are solved and labelled.

Q1Nov 20252MCO1 K1

Define random variable.

Answer

A random variable \(X\) is a function that assigns a real number to every outcome of the sample space of a random experiment, \(X:S\to\mathbb R\). It is discrete if it takes countably many values and continuous if it takes any value in an interval. Example: number of heads in 3 tosses.

Q2Nov 20252MCO1 K1

Write the variance if the mean of a Poisson distribution is 3.

Answer

For a Poisson distribution mean = variance = \(\lambda\). So \(\text{Var}(X)=\lambda=\mathbf{3}\) (standard deviation \(\sqrt3\approx1.732\)).

Q3Nov 20252MCO2 K2

Determine the value of \(k\) for the continuous distribution \(f(x)=kx\), \(0<x<1\).

Answer

For a pdf the total area is 1: \(\displaystyle\int_0^1 kx\,dx=\frac k2=1\Rightarrow k=\mathbf 2\).

Q4Nov 20252MCO2 K1

Write the properties of the normal distribution.

Answer

\(X\sim N(\mu,\sigma^2)\), \(f(x)=\dfrac1{\sigma\sqrt{2\pi}}e^{-(x-\mu)^2/2\sigma^2}\).

  1. Bell-shaped curve, symmetric about \(x=\mu\).
  2. Mean = median = mode = \(\mu\).
  3. Total area under the curve is 1; \(x\)-axis is an asymptote.
  4. Points of inflection at \(\mu\pm\sigma\); skewness 0, kurtosis 3.
  5. Area within \(\mu\pm\sigma\) is 68.27%, \(\mu\pm2\sigma\) is 95.45%, \(\mu\pm3\sigma\) is 99.73%.
  6. Sum of independent normals is normal; standardised variable \(Z=(X-\mu)/\sigma\sim N(0,1)\).
  7. Binomial and Poisson tend to it for large \(n\) or \(\lambda\).
Q5Nov 20252MCO3 K1

Define null hypothesis.

Answer

The null hypothesis \(H_0\) is the statement being tested, assuming no difference or no effect (e.g. \(H_0:\mu=\mu_0\)). It is assumed true unless the sample gives strong evidence against it. It is always stated with an equality.

Q6Nov 20252MCO3 K1

Define critical region.

Answer

The critical (rejection) region is the set of values of the test statistic for which \(H_0\) is rejected. Its size equals the level of significance \(\alpha\) (probability of a Type I error). Example: for a two-tailed \(z\) test at 5%, \(|z|>1.96\).

Q7Nov 20252MCO4 K1

What is the test statistic used for testing a single population variance?

Answer

\[\chi^2=\frac{(n-1)s^2}{\sigma_0^2}\quad\text{with } n-1 \text{ degrees of freedom},\] for \(H_0:\sigma^2=\sigma_0^2\) (normal population).

Q8Nov 20252MCO4 K1

Write the formula for the standard error of a sample proportion.

Answer

\[\text{S.E.}(\hat p)=\sqrt{\frac{pq}{n}}=\sqrt{\frac{p(1-p)}{n}}\] where \(p\) is the population proportion and \(q=1-p\) (use \(\hat p\) if \(p\) unknown).

Q9Nov 20252MCO5 K2

Explain non-parametric tests.

Answer

Non-parametric (distribution-free) tests do not assume a particular distribution (such as normal) for the population, and use signs, ranks or counts rather than the actual values. They suit ordinal data, small samples and skewed data. Examples: sign test, Mann–Whitney \(U\), Kruskal–Wallis, Spearman's rank correlation, runs test. Disadvantage: less powerful than the parametric test when the parametric assumptions do hold.

Q10Nov 20252MCO5 K2

Explain the sign test.

Answer

The sign test checks the median of a population (or the difference of a paired sample). Write \(+\) for each value above the hypothesised median and \(-\) for each value below; discard ties. Under \(H_0\) the number of plus signs is Binomial\((n,\tfrac12)\), so the \(p\)-value is a binomial tail probability (for large \(n\) use the normal approximation). Reject \(H_0\) if the tail probability is \(\le\alpha\).

Q11Expected2MCO1 K1

State the addition theorem and Bayes' theorem.

Answer

Addition: \(P(A\cup B)=P(A)+P(B)-P(A\cap B)\). Bayes: \(P(A_i\mid B)=\dfrac{P(A_i)P(B\mid A_i)}{\sum_jP(A_j)P(B\mid A_j)}\).

Q12Expected2MCO1 K1

Write the mean and variance of the binomial distribution.

Answer

\(X\sim B(n,p)\): mean \(=np\), variance \(=npq\), with \(q=1-p\).

Q13Expected2MCO2 K1

Give the mean and variance of the exponential distribution.

Answer

For \(f(x)=\lambda e^{-\lambda x}\), \(x\ge0\): mean \(=1/\lambda\), variance \(=1/\lambda^2\). It has the memoryless property.

Q14Expected2MCO3 K1

Differentiate between Type I and Type II errors.

Answer

Type I: rejecting \(H_0\) when it is true; probability \(\alpha\). Type II: accepting \(H_0\) when it is false; probability \(\beta\). Power of a test \(=1-\beta\).

Q15Expected2MCO3 K1

State the central limit theorem.

Answer

For a random sample of size \(n\) from a population with mean \(\mu\) and variance \(\sigma^2\), the sampling distribution of \(\bar X\) tends to \(N(\mu,\sigma^2/n)\) as \(n\) becomes large, whatever the shape of the population.

Q16Expected2MCO4 K2

Write the conditions for applying the chi-square test.

Answer

The observations are independent, total frequency is large (\(N>50\) as a rule), each expected frequency is at least 5 (otherwise pool the classes), and the frequencies are actual counts, not percentages.

Q17Expected2MCO4 K1

Write the test statistic for testing the equality of two variances.

Answer

\(F=\dfrac{s_1^2}{s_2^2}\) with \((n_1-1,\,n_2-1)\) d.f., taking the larger variance in the numerator.

Q18Expected2MCO5 K1

Write the formula for Spearman's rank correlation coefficient.

Answer

\(r_s=1-\dfrac{6\sum d_i^2}{n(n^2-1)}\), where \(d_i\) is the difference between the two ranks of the \(i\)th item.

Q19Expected2MCO5 K2

When is the runs test used?

Answer

To test whether a sequence of observations is random (that is, whether its order is random). A run is an unbroken sequence of the same symbol. Too few runs suggest clustering or a trend; too many suggest alternation.
